# 术语类比卡 08 · SFT（监督微调）（Supervised Fine-Tuning）

| 栏目 | 内容 |
|---|---|
| **术语** | SFT（Supervised Fine-Tuning，监督微调） |
| **一句话定义** | 用数千到数万条人工编写的「标准问答对」教模型按指令回答，把接话员扭成助手。 |
| **生活类比** | 岗前培训——老员工示范、标准话术、作业模板一条条教；教完它才分得清「回答问题」和「续写文本」。 |
| **面试怎么用** | 被问「SFT 是干什么的」：用高质量示范教模型听指令，从续写引擎变成对话助手。 |
| **常见误解** | 以为示范数据越多越好——示范质量决定上限，一百条干净的胜过一千条潦草的。 |
