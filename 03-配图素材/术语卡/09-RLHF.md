# 术语类比卡 09 · RLHF（人类反馈强化学习）（RLHF）

> 所属课程：W1D2 / W2D2 ｜ AI 产品经理就业训练营 · 术语类比卡（共 18 张）
> 配套配图：同目录 `09-RLHF.svg`（1200×800，主色紫 #7C3AED / 蓝 #2563EB）

| 栏目 | 内容 |
|---|---|
| **术语** | RLHF（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习） |
| **一句话定义** | 让人对模型的多个回答排序打分，模型从排序中学出「什么是好答案」，越训越会说人爱听的话。 |
| **生活类比** | 师傅带教打分——实习生交的每份材料，师傅说这个好那个不行；时间长了，实习生心里长出一把尺子。 |
| **面试怎么用** | 解释两个模型「知识差不多、手感差很远」的根因在 RLHF；模型太轴先查对齐数据，别急着换模型。 |
| **常见误解** | 以为 RLHF 在教新知识——它教的是偏好和分寸；对齐过度还会把模型训得太「怂」，三句话不离免责声明。 |
