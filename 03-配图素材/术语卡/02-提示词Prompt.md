# 术语类比卡 02 · 提示词（Prompt）

> 所属课程：W1D3 提示词与上下文工程 ｜ AI 产品经理就业训练营 · 术语类比卡（共 18 张）
> 配套配图：同目录 `02-提示词Prompt.svg`（1200×800，主色紫 #7C3AED / 蓝 #2563EB）

| 栏目 | 内容 |
|---|---|
| **术语** | 提示词（Prompt，发给 AI 的指令文本） |
| **一句话定义** | 你发给 AI 的任务指令；写清角色、任务、约束、输出格式、示例五要素，产出质量直接翻倍。 |
| **生活类比** | 给新同事派活的任务单——「帮我弄一下」和「把这 20 页整理成一页纪要、下午 3 点前给我」，是两种命运。 |
| **面试怎么用** | 说「提示词是需求文档，上下文工程是系统设计」，把沟通软技能讲成可复制的方法论。 |
| **常见误解** | 把提示词当「咒语」，以为有万能模板——它是可验收的需求描述，任务写不清就得不到好结果。 |
