## 一句话定义

SQL 是 Structured Query Language 的缩写，中文「结构化查询语言」，用来向数据库要数据的读法。

## 生活类比

给图书管理员递一张借书单，写清「要哪几本书、只看哪一排、按什么归类」——你不用自己进书库，把需求说清楚就行。

## 易混辨析

最容易和「数据库」「编程」混。SQL 只是「提问的语言」，不是数据库本身；产品经理学它是为了读懂和核对，不是为了写程序。

## 面试说法

「SQL 我不做开发，但能读懂查询、核对分母、判断结论可不可信，这是我要求的边界。」
