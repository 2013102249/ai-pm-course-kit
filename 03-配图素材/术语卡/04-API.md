## 一句话定义

你递需求、对方递结果的那个「窗口」。

## 生活类比

食堂的打饭窗口——你不用进后厨，把要什么写在单子上从窗口递进去，里面按单装好，再从同一个窗口递回给你。窗口就是双方约好的「怎么递、递什么、从哪儿取」。

## 易混辨析

最容易混的是把 API 当成「API Key」或「接口文档」。API 是那个窗口和约定，Key 是「你有没有资格从这个窗口取餐」的凭证，文档是「窗口上贴的菜单说明」。三样东西别搅在一起：调不通先分清是窗口没开（地址 / 路由）、还是没带凭证（Key）。

## 面试说法

「API 是调用窗口和约定，Key 是凭证；我不把两者混说，排查时先分清是没打到窗口，还是没带对凭证。」
