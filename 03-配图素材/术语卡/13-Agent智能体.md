# 术语类比卡 13 · Agent（智能体）（Agent）

> 所属课程：W3D1 Agent 架构原理 ｜ AI 产品经理就业训练营 · 术语类比卡（共 18 张）
> 配套配图：同目录 `13-Agent智能体.svg`（1200×800，主色紫 #7C3AED / 蓝 #2563EB）

| 栏目 | 内容 |
|---|---|
| **术语** | Agent（中文叫智能体，会办事的 AI） |
| **一句话定义** | 给它一个目标，它自己拆解步骤、调用工具、把事办完的 AI——从「答题」走向「办事」。 |
| **生活类比** | 长着四肢的大模型——大脑再聪明，没手没脚只能动嘴；装上规划、记忆、工具、执行四要素才叫能办事。 |
| **面试怎么用** | 用「答题是给答案，办事是拆任务、用工具、拿结果、担责任」定义 Agent，再反问「什么时候交还人类」。 |
| **常见误解** | 以为所有产品都该上 Agent——固定流程更稳更便宜；先问单 Agent 能不能解决，再问要不要多个。 |
