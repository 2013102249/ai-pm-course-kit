## 一句话定义

多个 Agent 分工协作，各管一段任务。

## 生活类比

办一场婚礼，请了策划、摄影、司仪各管一摊——人多了，就得多一个人专门协调。

## 易混辨析

容易和「把一个 Agent 拆成多个步骤」混。那是同一个 Agent 的规划；多 Agent 是多个独立大脑，会多出传话、损耗、失败传播的代价。

## 面试说法

「多 Agent 是复杂度黑洞：两个 Agent 能做的事，别用五个；先问单 Agent 能不能解决。」
