# 术语类比卡 14 · ReAct（思考-行动循环）（ReAct）

> 所属课程：W3D1 Agent 架构原理 ｜ AI 产品经理就业训练营 · 术语类比卡（共 18 张）
> 配套配图：同目录 `14-ReAct.svg`（1200×800，主色紫 #7C3AED / 蓝 #2563EB）

| 栏目 | 内容 |
|---|---|
| **术语** | ReAct（Reasoning + Acting，思考与行动交替循环） |
| **一句话定义** | 「思考→行动→观察→再思考」的循环工作方式；对产品的意义是把思考过程摊开给用户看。 |
| **生活类比** | 靠谱同事干活会边做边汇报——「我先查航班，再比价，然后下单」；每一步你都看得见，才敢把事交给他。 |
| **面试怎么用** | 讲可观测、可中断、可纠偏三个价值，再补一句「呈现要分层：默认步骤清单，可展开细节」。 |
| **常见误解** | 把 ReAct 当纯技术名词背下来——面试的差异化答案，是把「摊开思考」讲成信任与体验设计。 |
