# 术语类比卡 15 · MCP（模型上下文协议）（MCP）

> 所属课程：W3D1 Agent 架构原理 ｜ AI 产品经理就业训练营 · 术语类比卡（共 18 张）
> 配套配图：同目录 `15-MCP.svg`（1200×800，主色紫 #7C3AED / 蓝 #2563EB）

| 栏目 | 内容 |
|---|---|
| **术语** | MCP（Model Context Protocol，模型上下文协议） |
| **一句话定义** | 给模型与工具定的统一接口标准，工具接入从「每个都单独适配」变成「即插即用」。 |
| **生活类比** | USB 接口/国标插座——没有它，每个设备一种线；有了它，任何电器插上就能用。 |
| **面试怎么用** | 用「M×N 变 M+N」讲标准化红利：接新工具从「排期两周」降到分钟级，是产品经理的新杠杆。 |
| **常见误解** | 以为 MCP 是某家产品的私有功能——它是开放协议；补一句「工具侧 MCP、Agent 互联侧 A2A」更显专业。 |
