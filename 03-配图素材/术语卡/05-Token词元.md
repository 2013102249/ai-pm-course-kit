# 术语类比卡 05 · Token（词元）（Token）

> 配套配图：同目录 `05-Token词元.svg`（1200×800，主色紫 #7C3AED / 蓝 #2563EB）

| 栏目 | 内容 |
|---|---|
| **术语** | Token（大模型处理与计费的最小文字单位） |
| **一句话定义** | 大模型处理与计费的最小文字单位，一个汉字约占一到两个；输入输出分开计价，输出单价更高。 |
| **生活类比** | 出租车计价器——用户每敲一个字、模型每吐一个字，表都在跳；「免费无限用」等于不打表白开车。 |
| **面试怎么用** | 被问商业模式时，用「输入输出分开计价」解释次数限制、长度上限、会员分级都是成本倒逼。 |
| **常见误解** | 以为成本只算输出——输入的长文档同样烧钱；不少产品的成本黑洞出在每次提问都塞整本文档。 |
