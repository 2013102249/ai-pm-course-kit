# 术语卡 · 推理

## 一句话定义

训练完之后现场答题、逐字生成答案。

## 生活类比

像饭店接到点单之后「现炒这一盘菜」。厨师学艺那些年（训练）不对你收费、也不让你等；你点完单站在窗口等的那几分钟，才是「推理」——现做、按料算钱、有快有慢。

## 易混辨析

最容易混的是「推理 vs 训练」。训练是「学」，一次性、烧大钱、产品经理基本不碰；推理是「用」，每次提问都发生、按 Token 计费、还带来用户等待的延迟。第二个坑：把「推理」理解成「逻辑推理 / 动脑子」——这里说的是「模型跑起来生成答案」这个动作，不是夸它聪明。选型时那个「能力 / 成本 / 延迟」三角，成本和延迟都挂在推理上。

## 面试说法

「训练是学、推理是用；用户等的、按 Token 计费的都是推理，所以选型要同时看能力、成本和延迟。」
