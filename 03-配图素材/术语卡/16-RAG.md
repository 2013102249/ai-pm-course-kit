# 术语类比卡 16 · RAG（检索增强生成）（RAG）

> 所属课程：W3D3 RAG 架构与知识库产品 ｜ AI 产品经理就业训练营 · 术语类比卡（共 18 张）
> 配套配图：同目录 `16-RAG.svg`（1200×800，主色紫 #7C3AED / 蓝 #2563EB）

| 栏目 | 内容 |
|---|---|
| **术语** | RAG（Retrieval-Augmented Generation，检索增强生成） |
| **一句话定义** | 让模型回答前先去资料库检索相关内容，带着资料作答——先查资料，再回答。 |
| **生活类比** | 开卷考试——闭卷靠记忆会记错；开卷照着课本答，书上没有的不敢乱写。 |
| **面试怎么用** | 说「RAG 的本质是给模型开卷考试的权利」「加知识用 RAG，改行为用微调」，再举退款政策编造事故。 |
| **常见误解** | 以为 RAG 升级了模型智力——它只是外挂资料；资料没入库、已过期、没权限，答案照样错。 |
