五、三条典型转岗路径（基于往期学员真实走向提炼，不涉数字）

以下三条路径来自 W1D1 三个往期案例的共性提炼，是「课程设计过的最优路径」，不是市场统计。每条路径回答四个问题：你的优势是什么、主攻哪类岗位、八周重点补什么、面试靠什么赢。

路径 A · 业务 / 运营背景 → AI 应用产品经理

环节内容
你的优势懂用户、懂数据、懂增长——产品硬功的一半你已经有了
主攻岗位AI 应用产品经理（备选：同行业的 RAG 知识库岗）
八周重点把运营经验翻译成两句话写进简历；主项目选你熟悉的行业场景；猛补评测（W2D3）与数据指标（W4D4）
面试靠什么赢用旧行业的真实案例回答产品问题——「用户为什么不用」你比科班更有体感
对应往期案例五年电商运营 → 教育 AI 应用产品经理（W1D1 导入故事一）

路径 B · 客户服务 / 交付 / 售前背景 → AI 行业解决方案产品经理

环节内容
你的优势一线客户语言、异常处理经验、对「流程哪里会断」有肌肉记忆
主攻岗位AI 行业解决方案产品经理（备选：Agent 与工作流产品经理）
八周重点把工单 / 交付案例整理成「流程断点清单」；主项目偏 B 端流程；重点打磨异常兜底设计（W4D3）与方案表达
面试靠什么赢讲三个你处理过的真实异常案例——这是应届生给不出的答案
对应往期案例客服主管 → SaaS 公司 AI 解决方案产品经理（W1D1 导入故事二）

路径 C · 技术 / 测试 / 开发背景 → 大模型平台产品经理

环节内容
你的优势能跟算法对话、能自己写脚本验证——转行者里的稀缺项
主攻岗位大模型平台产品经理（备选：Agent 与工作流产品经理）
八周重点警惕「技术崇拜」——补的是需求表达与开发者体验设计（W4 全周）；主项目可偏工具型；用技术背景把 W2D2 训练课、W3D1 Agent 课学成对话素材
面试靠什么赢「离技术最近的平台岗」：面试官说术语你接得住，还能翻译给业务方
对应往期案例四年测试工程师 → 大模型公司平台产品岗（W1D1 导入故事三）
使用方法：W1D5 职业规划书定主赛道时，先在三条路径里对号入座；拿不准的，周五工作坊 + 1v1 让讲师帮你定位。路径描述的是「往期走得通的路」，不是你的终点——你的定位卡（W1D1 填写）优先级高于任何模板。

六、双周自查节奏：检查卡与八周课表对应表

就业准备不是最后两周的事，是八周里的固定节拍。每两周一张检查卡、5 个可勾选指标，卡在导学案作业里，10 分钟自查完。
检查卡自查时点覆盖课程主项目里程碑作品集积木进度投递三轮位置
W2 卡第 2 周周日W1D1 开营 → W2D5 立项里程碑 ① 立项积木 2/8（P1 + P2）补作品期
W4 卡第 4 周周日W3D1 Agent → W4D5 PRD 评审里程碑 ② 原型、③ PRD 过审积木 4/8（P3 + P4）补作品期
W6 卡第 6 周周日W5D1 增长 → W6D5 路演里程碑 ④ 商业验证、⑤ 路演积木 6/8（P5 + P6）补作品期收尾 · 内推预备
W8 卡第 8 周结营W7D1 行业纵深 → W8D5 结营就业冲刺周积木 8/8（全册 + 弹药库）内推试水（W7）→ 批量投递（W8 起）

三轮投递节奏（与 W1D5 职业规划书、W7D5 投递策略课对齐）：补作品（W2–W6）→ 内推试水（W7）→ 批量投递（W8 起）。检查卡就是这条节奏的每两周打卡器——哪张卡上勾不满，缺的就是那两周该补的东西，还来得及补。
