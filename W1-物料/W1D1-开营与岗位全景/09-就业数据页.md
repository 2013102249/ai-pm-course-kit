## 三、offer 周期（口径先行，数字待教务补充）

**本页只给口径与测量方法，具体天数由教务按往期真实数据填充。**

| 指标 | 口径定义 | 往期中位数 | 说明 |
|---|---|---|---|
| 投递 → 首面 | 从首次投递到第一次面试的天数 | **待教务补充** | 反映简历与作品集的过筛能力 |
| 首面 → offer | 从第一次面试到拿到 offer 的天数 | **待教务补充** | 反映面试转化能力 |
| 结业 → offer | 从结业路演到拿到 offer 的天数 | **待教务补充** | 学员最关心的数；受市场季节影响大，须注明统计季节分布 |
| 投递量 → offer | 拿到 1 个 offer 平均需要的有效投递量 | **待教务补充** | 与 W7D5「投递漏斗五层」口径对齐 |

> 两条诚实话（讲师口径，可照读）：① 周期因人、因季节、因赛道差异极大，**中位数不是保证值，是参考值**；② 往期数据里比「快」更重要的是「卡在哪一层」——W7D5 的投递漏斗周报（每周五自报五层数字）就是让你卡住时知道该修简历、修作品集，还是修面试表达。

## 五、三条典型转岗路径（基于往期学员真实走向提炼，不涉数字）

> 以下三条路径来自 W1D1 三个往期案例的共性提炼，是「课程设计过的最优路径」，不是市场统计。每条路径回答四个问题：你的优势是什么、主攻哪类岗位、八周重点补什么、面试靠什么赢。

### 路径 A · 业务 / 运营背景 → AI 应用产品经理

| 环节 | 内容 |
|---|---|
| 你的优势 | 懂用户、懂数据、懂增长——产品硬功的一半你已经有了 |
| 主攻岗位 | AI 应用产品经理（备选：同行业的 RAG 知识库岗） |
| 八周重点 | 把运营经验翻译成两句话写进简历；主项目选你熟悉的行业场景；猛补评测（W2D3）与数据指标（W4D4） |
| 面试靠什么赢 | 用旧行业的真实案例回答产品问题——「用户为什么不用」你比科班更有体感 |
| 对应往期案例 | 五年电商运营 → 教育 AI 应用产品经理（W1D1 导入故事一） |

### 路径 B · 客户服务 / 交付 / 售前背景 → AI 行业解决方案产品经理

| 环节 | 内容 |
|---|---|
| 你的优势 | 一线客户语言、异常处理经验、对「流程哪里会断」有肌肉记忆 |
| 主攻岗位 | AI 行业解决方案产品经理（备选：Agent 与工作流产品经理） |
| 八周重点 | 把工单 / 交付案例整理成「流程断点清单」；主项目偏 B 端流程；重点打磨异常兜底设计（W4D3）与方案表达 |
| 面试靠什么赢 | 讲三个你处理过的真实异常案例——这是应届生给不出的答案 |
| 对应往期案例 | 客服主管 → SaaS 公司 AI 解决方案产品经理（W1D1 导入故事二） |

### 路径 C · 技术 / 测试 / 开发背景 → 大模型平台产品经理

| 环节 | 内容 |
|---|---|
| 你的优势 | 能跟算法对话、能自己写脚本验证——转行者里的稀缺项 |
| 主攻岗位 | 大模型平台产品经理（备选：Agent 与工作流产品经理） |
| 八周重点 | 警惕「技术崇拜」——补的是需求表达与开发者体验设计（W4 全周）；主项目可偏工具型；用技术背景把 W2D2 训练课、W3D1 Agent 课学成对话素材 |
| 面试靠什么赢 | 「离技术最近的平台岗」：面试官说术语你接得住，还能翻译给业务方 |
| 对应往期案例 | 四年测试工程师 → 大模型公司平台产品岗（W1D1 导入故事三） |

> 使用方法：W1D5 职业规划书定主赛道时，先在三条路径里对号入座；拿不准的，周五工作坊 + 1v1 让讲师帮你定位。**路径描述的是「往期走得通的路」，不是你的终点**——你的定位卡（W1D1 填写）优先级高于任何模板。

## 六、双周自查节奏：检查卡与八周课表对应表

> 就业准备不是最后两周的事，是八周里的固定节拍。每两周一张检查卡、5 个可勾选指标，卡在导学案作业里，10 分钟自查完。

| 检查卡 | 自查时点 | 覆盖课程 | 主项目里程碑 | 作品集积木进度 | 投递三轮位置 |
|---|---|---|---|---|---|
| W2 卡 | 第 2 周周日 | W1D1 开营 → W2D5 立项 | 里程碑 ① 立项 | 积木 2/8（P1 + P2） | 补作品期 |
| W4 卡 | 第 4 周周日 | W3D1 Agent → W4D5 PRD 评审 | 里程碑 ② 原型、③ PRD 过审 | 积木 4/8（P3 + P4） | 补作品期 |
| W6 卡 | 第 6 周周日 | W5D1 增长 → W6D5 路演 | 里程碑 ④ 商业验证、⑤ 路演 | 积木 6/8（P5 + P6） | 补作品期收尾 · 内推预备 |
| W8 卡 | 第 8 周结营 | W7D1 行业纵深 → W8D5 结营 | 就业冲刺周 | 积木 8/8（全册 + 弹药库） | 内推试水（W7）→ 批量投递（W8 起） |

**三轮投递节奏**（与 W1D5 职业规划书、W7D5 投递策略课对齐）：**补作品（W2–W6）→ 内推试水（W7）→ 批量投递（W8 起）**。检查卡就是这条节奏的每两周打卡器——哪张卡上勾不满，缺的就是那两周该补的东西，还来得及补。

## 七、本页的使用规则

| 谁 | 什么时候 | 怎么用 |
|---|---|---|
| 学员 | 第 1 天 | 读完五、六两节：找到自己的路径，记住四个自查时点 |
| 学员 | 每 2 周周日 | 完成对应检查卡（10 分钟），勾不满的指标写「补齐计划」 |
| 学员 | W7–W8 | 参照第三节口径记录自己的投递漏斗数据（自记录，不对比他人） |
| 讲师 | W1D1 授课 | 口头讲「就业全景」3 分钟段（讲稿已嵌入 02-讲课稿环节三末尾） |
| 教务 | 每期开营前 | 填充全页「待教务补充」数据并标注口径、样本量、更新日期 |
| 教务 | 每期结业后 30 天内 | 用结业数据更新本页，作为下一期的就业证据链 |
