# 工作坊组织方案 · W1 周五《行业选择 + 职业规划工作坊》

> 本课无专用交互页——本课的核心教具是「人」：分组、规则、产出物与巡场。
> 本文档即本日「交互使用说明」的对应件，供讲师与助教执行工作坊时对照使用。

## 一、分组方式

| 项目 | 规则 |
|---|---|
| 分组依据 | 按主赛道意向分组：教育 / 金融 / 内容营销 / 电商零售 / 企业 SaaS / 出海，每组一个赛道主题 |
| 组数与规模 | 预计 6 组，每组 4–6 人；不足 3 人的赛道并入「综合组」（跨赛道，由助教带） |
| 分组时机 | 环节二结束、实操开始前，由学员举手报主赛道意向，助教 2 分钟内引导入座 |
| 组内角色 | 不设组长，只设「计时员」1 名（管控互评时间盒）；同赛道邻座自动成为「互评搭子」 |
| 线上版 | 直播课用 breakout 房间，房间名即赛道名；主赛道意向提前一天在群内接龙，减少现场分组时间 |
| 设计意图 | 同赛道分组让互评「挑得出真毛病」——跨赛道互评只会客套；同时为 W2 起六大赛道分组教学埋下组织基础 |

## 二、讨论规则（时间盒）

| 阶段 | 时长 | 规则 |
|---|---|---|
| 独立填写（环节三） | 22 分钟 | 静默书写，禁止交谈；此为「和自己对话」时间，讲师与助教只巡场不打断 |
| 组内互评（环节四前半） | 5 分钟 | 只看邻座一份规划书；按三条清单提意见：① 目标行业收敛了没有 ② 8 周目标能量化吗 ③ 风险对策带时间点吗；必须提 1 条优点 + 1 条风险，不许只说优点 |
| 样本点评（环节四后半） | 8 分钟 | 讲师投屏 2 份典型样本（1 份良好 + 1 份待改）；学员只听不语，记录与自己规划书的差异 |
| 修订承诺 | 3 分钟 | 每人写下回看后要改的 3 件事（导学案互评记录表最后一行），周末修订时对照打勾 |

## 三、产出物收集方式

| 项目 | 规则 |
|---|---|
| 收集渠道 | 飞书群内发布收集表（腾讯文档表格或飞书多维表格均可，禁止微信私戳） |
| 命名规范 | 姓名-W1-个人职业规划书-V1（例：张某某-W1-个人职业规划书-V1） |
| 提交截止 | 本周日 24:00 前；周日 20:00 助教群内提醒一次，逾期未交计入周产出缺交名单 |
| 收集字段 | 姓名 / 主赛道 / 备选赛道 / 目标岗位 / 8 周目标条数 / 风险对策条数 / 是否已预约 1v1 |
| 验收动作 | 讲师与助教按教案第九节四项标准逐份过：目标行业 1 主 1 备、8 周目标可量化、投递三轮完整、风险 ≥2 条且有对策；缺项退回修订，修订后方可进入 1v1 |
| 1v1 排期 | 学员群内发「姓名 + 期望时段（本周六或下周一）」给助教，助教按报名序排表，每人 30 分钟；排表结果当晚发群 |
| 归档 | 定稿规划书归入个人学习档案（飞书），作为 W7《行业纵深手册》的基线文档 |

## 四、讲师巡场提问清单（实操 22 分钟，巡三圈）

| 圈次 | 巡场重点 | 每组至少问到 | 话术示例 |
|---|---|---|---|
| 第一圈（约第 5 分钟） | 目标行业字段 | 「你现在写的几个赛道？三标准打完分留哪个？」 | 「写三个等于没选。现在用 30 秒做排除：哪个赛道你一个人脉都约不到？先划掉它。」 |
| 第一圈（约第 5 分钟） | 目标行业字段 | 「你这个匹配度打 4 分，凭什么？说一条能迁移的经历。」 | 「说不出经历的打分都是感觉分。回去看预习表第二栏。」 |
| 第二圈（约第 12 分钟） | 8 周目标字段 | 「W4 周五前你的目标是什么？挂在哪条验收标准上？」 | 「写『提升能力』不算目标。W4 的验收是 PRD 过审，你的目标应该是PRD 里的哪一条？」 |
| 第二圈（约第 12 分钟） | 8 周目标字段 | 「投递节奏第一轮在干什么？现在就该投吗？」 | 「现在简历上没东西，投了就是炮灰。第一轮的任务是补作品，不是投递。」 |
| 第三圈（约第 18 分钟） | 风险与对策字段 | 「你写的风险，对策的时间点在哪一周？」 | 「『可能竞争激烈』谁不知道。改成：W3 前访谈两位从业者——这才叫对策。」 |
| 第三圈（约第 18 分钟） | 风险与对策字段 | 「备选赛道什么时候启用？简历怎么兼容两条叙事？」 | 「主赛道写深，备选留一句『同时关注』即可，别在简历里平均用力。」 |

**巡场纪律**：每圈每组成员都被问到至少一次；对卡住超过 3 分钟的学员，给「排除法」提示（先划掉不匹配的，再两两比较）而不是代填；巡场不打断静默书写的学员，只在停笔时接近。

## 五、常见异常处理

| 异常 | 处理 |
|---|---|
| 学员全部海投一个赛道的意向（如都选内容营销） | 正常现象，不干预分组；讲师在样本点评环节加一句「岗位池大的赛道竞争者也多，进入概率还要乘匹配度」 |
| 学员现场改主赛道（实操中途换意向） | 允许，要求把三标准打分重新写一遍，防止「听着听着别人赛道就好」 |
| 某组人数为 0（无人选该赛道） | 撤组，并在投屏点评时补一句该赛道的适用画像，保证六赛道信息不缺席 |
| 线上 breakout 房间卡顿 | 改为主群文字互评：邻座两两私聊改群内接龙，格式不变 |
| 1v1 预约超载（报名 > 讲师可排时段） | 助教按「主赛道冷门 + 目标行业未收敛」优先排序；确实排不上的，延到下周一并群内同步 |
