第 2 节 · 核心原理讲授 A（50–100 min，第 7–12 页）

7第 2 节小调查：你今天用过 AI 吗① 现场举手：写周报 / 翻译 / 问答 / 刷到 AI 内容 ② 收集 3–4 个答案 ③ 结论「你每天都在用，却没注意到它」 ④ 抛出问题：背后那个「大模型」到底是什么破冰，无论答案是什么都接住；为「你每天都在用」做证据无（纯互动页）
8第 2 节核心类比：超级接话员① 读过全世界所有的书，没人教过他回答问题 ② 只会一件事：接话，你说前半句他接后半句 ③ 问「退款政策」，他自信地编「72 小时无条件退款」 ④ 本能是接上话，不是答对题讲故事节奏，编答案处停顿 1 秒、环视；别急着解释原理接话员场景插画（待制，05 登记）
9第 2 节金句：它永远会接话，哪怕不知道答案① 全屏金句（紫底白字）② 副行「大模型不是百科全书，是超级接话员」③ 小字「学术界叫下一个词预测 = 概率续写」放慢语速重复一遍，让学员抄进导学案紫底白字全屏金句页（强调色规范见制作备注）
10第 2 节大模型五步链路总览① 用户输入 → 提示词组装 → 大模型 → 输出后处理 → 回复用户 ② 接话发生在中间紫色方块 ③ 前端决定模型听懂什么 ④ 后端决定用户安全看到什么手指沿五个方块走一遍，每块只念主标题，不念英文小字《LLM原理架构图》（已有）
11第 2 节你的主战场在两端① 模型只能选、改不动 ② 提示词组装 × 输出后处理是产品经理的活 ③ 划两端：用手同时框住两块 ④ 周三提示词课展开用例句验证「图中右下角已给答案」；强调「选」不是「改」《LLM原理架构图》；两端方块紫 #7C3AED、中间模型块蓝 #2563EB
12第 2 节Transformer：看全文再接话① 2017 年 Google 提出，是所有大模型的老祖宗 ② 自注意力 = 接每个词前先把全文看一遍 ③ 例句「小明把小红的书还给了图书馆，因为他已经看完了」 ④ 本课不碰公式、不碰层数与参数规模用例句让全班卡一下再揭晓；明确宣布「今天不碰公式」；对产品意味着能处理长文本 + 能吞下海量数据无（板书例句页）

第 3 节 · 核心原理讲授 B + 案例（100–150 min，第 13–18 页）

页所属节次页标题内容要点（3–5 条）讲师提示配图标注
13第 3 节第一阶段：预训练 = 读书① 遮住后半句让它接，接错修正、接对奖励，练几个月 ② 练成语言规律（说话像人话）③ 练成世界知识（读过所有的书）④ 但不会「回答问题」，只会接话承接第 2 节讲授的三阶段投屏复述；提问「只会接话的人能直接上岗吗」《一页纸通识卡》②三阶段区
14第 3 节第二阶段：SFT = 岗前培训① 人工编写成千上万条标准问答对 ② 问「写请假邮件」就给一封格式正确的邮件 ③ 从续写引擎变成对话助手 ④ 「AI 听话了、能用了」的根子在这一步提问「培训到位了为什么还有第三阶段」；点出 SFT 全称 Supervised Fine-Tuning，监督微调《一页纸通识卡》②三阶段区
15第 3 节第三阶段：RLHF = 满意度回访① 同一问题生成好几个回答，让人排序 ② 干巴巴的「正确的废话」人嫌，有结构有例子的爱看 ③ 模型的「脾气」是对齐产物 ④ 太轴的客服案例：对齐过度，不是能力问题讲「三句话不离免责声明」的反面故事；点出 RLHF 全称 Reinforcement Learning from Human Feedback，基于人类反馈的强化学习《一页纸通识卡》②三阶段区 + 对齐案例小图（待制）
16第 3 节三阶段成长史 · 一页总结① 读书 → 岗前培训 → 满意度回访 ② 学会说话 → 听懂指令 → 说人爱听的话 ③ 顺序填空（面试常考）④ 三步都在出厂前，产品经理只做选型让学员跟着念一遍三阶段；提示「这段在面试里怎么答：别背定义，讲三个人生阶段」《一页纸通识卡》②区；金句条「预训练让模型学会说话…」
17第 3 节正面案例 + 反面案例① 正面：智能客服按「选底座 → SFT 岗前培训 → RLHF 回访」三步走，上线反馈「懂业务、说话得体」 ② 反面：跳过岗前培训直接接客，用户问退货，模型接了一段散文，三天后下架 ③ 对照：漏的不是模型能力，是那一步培训双案例对照讲，请一位学员用一句话说「翻车团队漏了哪一步」案例对照图（待制，05 登记）；左右分栏紫 / 灰
18第 3 节深化：为什么 / 边界 / 常见误解① 为什么预训练完不能上线：全程只奖励「接得像」② 边界：三阶段都在出厂前，改不动也不该改 ③ 常见误解：微调万能、微调能加知识 ④ 这段在面试里怎么答：三阶段 + 「产品经理不训模型、只做选型」这是「补 why / 补边界 / 补反面 / 补面试连接」四种深化方式的落点页；放慢讲边界三档缩略 + 面试气泡（待制）
