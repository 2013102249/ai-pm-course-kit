逐图讲法脚本

图 1 · LLM原理架构图（环节一主图）

图中结构（讲师先熟悉再上讲台）：横向五个方块从左到右——用户输入（User Input）→ 提示词组装（System+User+上下文）→ 大模型（Transformer，紫色高亮块）→ 输出后处理（清洗·过滤·脱敏）→ 回复用户（Response）；大模型上方连一个虚线节点「参数配置（temperature · max tokens · 模型选型）」；图底部有一行注释「预训练 → SFT → RLHF（对齐）→ 推理生成」；右下角有一行结论「产品经理主战场：提示词组装 × 输出后处理」。

  • 讲法 · 第一遍（走骨架）：手指从左到右沿五个方块走一遍，每个方块只念主标题，不念英文小字。念到紫色「大模型」块时停一拍：「接话，就发生在这个方块里。」
  • 讲法 · 第二遍（划两端）：回扫到「提示词组装」和「输出后处理」，用手同时框住这两块，口播结论——「模型你只能选，改不动；这两端才是你的活。前端决定模型听懂什么，后端决定用户安全看到什么。」
  • 讲法 · 第三遍（指注释）：手指移到底部一行小字「预训练 → SFT → RLHF（对齐）→ 推理生成」，告诉学员：「今天环节二整段，就讲这一行字。现在看不懂没关系，20 分钟后回头看。」——提前埋钩子，防止学员在中途掉队。
  • 提问点：「整条链路里，哪两个环节是产品经理的主战场？」（预期：提示词组装 × 输出后处理，图中右下角已给出答案，可用于验证）
  • 过渡话术：「好，骨架有了。现在回答那个核心问题——中间这个方块里的接话员，是怎么练出来的？」

图 2 · 一页纸通识卡（环节二至五贯穿，已制成）

已按下述规格制成并归档（03-配图素材/一页纸通识卡.svg），规格留存备查。

项目 规格
尺寸 A4 竖版 210×297mm，300dpi；同时导出适合手机竖屏浏览的 1080×1920px PNG
布局 四栏横排分区，自上而下：① 一句话类比区 ② 三阶段成长史 ③ 两个仪表盘 ④ 「懂到什么程度」边界表
① 类比区 顶部通栏：大字「大模型 = 超级接话员」，副字「它永远会接话，哪怕它不知道答案」；紫底白字
② 三阶段区 三列表格：阶段名（预训练 / SFT / RLHF）｜我的类比（读书 / 岗前培训 / 满意度回访）｜解决什么问题；三列表头分别用紫 #7C3AED、蓝 #2563EB、深紫 #5B21B6
③ 仪表盘区 左右两卡：左卡「上下文窗口 = 模型的桌面大小」，右卡「推理成本 = 按 token 计费」；卡面浅紫底 #F1EBFD，数字与关键词用蓝 #2563EB 加粗
④ 边界表区 三档表格：必须懂（5 条）/ 应该懂（5 条）/ 不必懂（5 条），条目文字照抄教案第十节，不得自行改写；「不必懂」一档用灰字弱化处理
字体 标题无衬线加粗 28–36pt，正文 12–14pt；中文字体苹方 / 思源黑体
署名 右下角小字「AI 产品经理就业训练营 · W1D2 · 自主研发」
交付 SVG 源文件 + PNG 导出，放入 03-配图素材 目录，命名《一页纸通识卡》
验收 打印一张 A4 贴在 3 米外看：① 类比区 3 秒内可读；② 四个分区边界清晰不打架；③ 无错别字、无中英文标点混用
  • 讲法：本图是「屏幕常驻图」——环节二讲三阶段时切到②区，环节三讲仪表盘切到③区，环节五讲边界表切到④区，讲哪区用手指哪区，不整图重讲。
  • 提问点：环节五快问快答时，先用遮罩盖住答案列，让学员现场归类，再揭开。
  • 用途：本图同时是学员课后自学包核心物料，投屏时口播一句「这张图会发群，建议打印贴墙」。

图 3 · 交互式架构图 · LLM Tab（动态，配合 07 号件）

  • 讲法：环节三 temperature 演示时切入，点击「参数配置」节点，展示右侧「是什么 / 产品经理关心什么 / 面试怎么答」三段式；环节五收口时再切回，用节点里的面试金句做本课收尾。详细操作见《07-交互使用说明》。
  • 提问点：「temperature 调高和调低，分别适合什么产品？」
  • 注意：本图动态内容不在本清单重复展开，避免两件套口径不一致；本清单只登记使用时机。
