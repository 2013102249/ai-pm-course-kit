# 课堂交互使用说明 · 《交互式架构图 · LLM Tab》（W1 周二专用）

> 用途：本课环节三 temperature 演示（约 55 min）与环节五边界收口（约 74 min）的教具。
> 工具位置：02-交互工具/交互式架构图.html（单文件零依赖，断网可用；打开后点击顶部「LLM 基础链路」标签）。
> 使用前请完成「课前检查」，故障处理见文末。

## 一、课前检查（开课前 10 分钟）

| 检查项 | 操作 |
|---|---|
| 标签切换 | 打开页面，确认顶部「LLM 基础链路」标签可点击，图区渲染出 6 个节点 |
| 节点面板 | 先点一次「提示词组装」节点，确认右侧三段式面板（是什么 / 产品经理关心什么 / 面试怎么答）正常展开 |
| 投屏分辨率 | 浏览器窗口 ≥1280px 宽，确保五个横向节点不换行、底部结论条完整可见 |
| 字号 | 投屏后按 Ctrl/Cmd + 「+」放大至 125%，最后一排学员要能看清右侧面板文字 |
| 备用方案 | 另开一个标签页打开《LLM原理架构图.svg》，工具卡住时秒切不冷场 |
| 学员端 | 群里发布工具链接，提醒学员课后自学，课上不强求同步打开 |

## 二、讲师 5 步演示脚本（与讲课稿对应）

| 步骤 | 讲师操作 | 讲解要点（约 60 秒/步） | 提问 / 收口 |
|---|---|---|---|
| ① 看一句话 | 切入 LLM Tab，先停 3 秒让学员看整图，手指底部「一句话讲明白」 | 大模型是「看懂指令、续写答案」的概率引擎；产品经理的工作是把它圈进正确的笼子里 | 「先看全景，五个方块加一个虚线参数节点，等下每个都点开」 |
| ② 走一遍链路 | 从左到右依次点击「用户输入 → 提示词组装 → 大模型 → 输出后处理 → 回复用户」五个节点，每节点只念右侧「是什么」第一句 | 前端决定模型听懂什么，后端决定用户安全看到什么；中间模型只能选不能改 | 「哪两个环节是你的主战场？」（预期：提示词组装 × 输出后处理） |
| ③ 深挖参数节点 | 点击「参数配置」节点（temperature · max tokens · 模型选型），念右侧「产品经理关心什么」三条 | temperature 是产品性格：0.1 是严谨客服，0.9 是创意总监；参数变更是产品决策不是技术细节 | 「医疗产品和文案产品，temperature 各往哪调？」 |
| ④ 指多轮回边 | 手指底部虚线回边「多轮上下文」，沿箭头走一圈 | 每一轮对话都要重新带回历史——这就是上下文窗口压力的来源，直接铺垫「仪表盘一」 | 「聊得越久，模型在为什么事发愁？」 |
| ⑤ 金句收口 | 点「大模型」节点，念右侧「面试怎么答」一句：产品经理不需要会训模型，但必须能回答「为什么选这个模型」 | 把演示收回到本课边界表：懂边界，不懂公式；能选型，不训模型 | 「这句话，第八周面试课前再出现一次，现在先记住」 |

**两个关键演示动作（不可省略）**：
1. **第 ② 步必须点满五个节点**——本工具的教学价值在「每个节点都有产品经理视角的三段式」，只走图不点节点等于浪费；
2. **第 ④ 步必须用手指沿虚线回边走一圈**——多轮上下文是本课「聊久了变傻」习题的伏笔，动作比语言记得住。

## 三、学员端指引（发群文案）

> 同学们，今天课的交互工具已发群（交互式架构图.html，选「LLM 基础链路」标签）。课后请大家：① 依次点开 6 个节点，把每个节点「产品经理关心什么」的第一条抄进导学案；② 重点重看「参数配置」节点，想清楚你未来产品要调高还是调低 temperature；③ 周三提示词课前完成。课上没跟上不要紧，这个工具就是给大家补课的。

## 四、常见故障处理

| 故障 | 处理 |
|---|---|
| LLM 标签点击无反应 | 刷新页面；或直接关闭重开文件（单文件无网络依赖，刷新零成本） |
| 节点面板不展开 | 确认点的是节点方块本体而非标签文字；仍不行就换相邻节点先讲，不中断讲解节奏 |
| 投屏字太小 | 浏览器 Ctrl/Cmd + 「+」放大至 125%，不要改窗口宽度（会破坏布局） |
| 学员端打不开 | 无需等待——本工具课上以讲师演示为主，学员课后自学即可，不影响课堂进度 |
| 演示中工具卡死 | 用话术带过：「正好，这就是产品经理的日常——工具会崩，产品要有兜底。等它 5 秒，我们先用架构图讲。」同时切到备用标签页的 LLM原理架构图.svg |
