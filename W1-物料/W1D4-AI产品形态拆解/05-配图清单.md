## 二、已有资产讲法脚本

### 图 1 · AI 产品全链路图（对应板块 · 定位用）

- **图上有什么**（680×380 横版）：横向主链路五环节——需求输入（写 PRD，Product Requirements Document 产品需求文档）→ 数据准备（定标准）→ 模型选型（定基线）→ 应用开发（写方案）→ 评测验收（跑评测）；下方回环两节点——上线监控（盯指标）折回需求输入，形成闭环。主色紫 #7C3AED 标注各环节产品职责，辅色蓝 #2563EB 用于标题与强调。
- **讲法脚本**（约 3 分钟）：
  1. 从「需求输入」起，手指沿箭头逐一走到「评测验收」，一句话带过前四个环节：「写 PRD、定标准、定基线、写方案——这些都是你们第四到第七周的主战场。」
  2. 手指停在「应用开发」环节：「今天讲的六大形态，全部发生在这一环。同一个模型能力，包成不同形态，产品长相完全不同——这是形态课排在提示词后面的原因，也是对应板块先讲『产品形态』这个术语的原因。」
  3. 指向下方「上线监控」回环：「上线之后要盯指标，数据会把你打回需求输入。形态不是一锤子买卖，跑一段时间要用数据回头修。」
- **提问点**：「形态选择发生在全链路的哪一环？」（预期：应用开发）
- **关键板书**：在黑板上写「模型能力 × 形态包装 = 产品长相」。

### 2. 表格内容（制作时按此填写）

| 形态 | 代表产品 | 技术依赖 | 商业模式 |
|---|---|---|---|
| 对话式助手（Chatbot） | 豆包 / Kimi / DeepSeek | 基础模型对话、长上下文、推理 | 免费获客 + 会员订阅 + 生态导流 |
| 工作流编排 | 扣子（Coze） | 工作流引擎 + 工具调用 + 多模型路由 | 平台订阅 / 按量计费 + 开发者生态 |
| 知识库问答 | ima | RAG：解析、分块、向量化、检索、重排 | 订阅 / 席位收费 + 企业按量 |
| 多模态生成 | 即梦 | 文生图 / 文生视频 / 语音合成，算力成本高 | 积分 / 按生成量计费 + 订阅 |
| Copilot 副驾 | 钉钉 AI 助理 | 上下文工程 + 宿主系统集成 | 按席位订阅，随宿主分发 |
| 自主 Agent | Manus | 规划 + 工具调用 + 多步执行 + 错误恢复 | 订阅 + 按任务 / 积分计费 |

底部金句通栏（紫底白字）：**形态没有高下，匹配才对**

### 3. 讲法脚本（第 2、3 节 · 主视觉）

- **逐行讲**：每讲一个形态，高亮对应行，按「一句话定义 → 代表产品故事 → 三维点评」推进；每行停留 5–6 分钟，代表产品只讲公开可查的事实，不讲用户量、收入等未公开数据。前 3 行落在对应板块、后 3 行落在对应板块，与讲课稿第 2、3 节的分章一致。
- **纵向扫**：六行讲完后，用手指纵向扫一遍「技术依赖」列——「从对话到 Agent，技术依赖一层比一层重，这就是对应板块讲的『技术可行性』」；再扫「商业模式」列——「免费、订阅、按量、按席位，模式是从成本结构倒推出来的，不是拍脑袋定的」。
- **收尾定格**：对应板块末露出底部金句通栏，放慢语速读一遍「形态没有高下，匹配才对」，宣布这就是本课的判别总原则，并接反面案例（图 7）。
- **延伸用法**：此表同时作为学员课后复习卡，随课程资料包发放；建议学员打印贴墙，第八周面试课前过一遍。
