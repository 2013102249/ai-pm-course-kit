# 分层习题 · W7 周三《简历撰写》

> 5 层难度：第 0 层术语辨析 → 第 1 层基础巩固 → 第 2 层进阶实操 → 第 3 层求职挑战 → 第 4 层面试实战。对齐 300 分钟（6 课时 × 50 分钟）教学日：第 0 层对应第 1 节当堂小测，第 1–3 层对应第 2–4 节与今晚作业，第 4 层对应第 5 节两两模拟与第 6 节验收。
> 建议用法：第 0 层当堂测 8 分钟并订正；第 1 层当堂测 8 分钟；第 2 层当今晚作业、明天 1v1 诊断直接用；第 3 层自测、第八周面试课复用；第 4 层第 5 节两两模拟按评分表互评。
> **全部题目均附参考答案与评分标准。** 文中所有简历片段、人物、项目、数字均标注「教学示例」，为教学化虚构，以「设计背景学员」代称，不含真实学员姓名；「HR 初筛约 20 秒」为行业观察口径，精确来源「待教务补充」；不编造薪资、通过率与 offer 数字。

## 第 0 层 · 术语辨析（12 题，含选择 / 连线 / 改错 / 简答四种题型）

### 一、选择题（0-1 ~ 0-4，每题 2 分）

**0-1.** ATS 的全称与中文是：
A. Applicant Tracking System，申请人跟踪系统
B. Job Description，职位描述
C. Automatic Text Sorting，自动文本排序
D. Application Test Score，申请测试分数

**0-2.** 下列关于 STAR 的说法正确的是：
A. STAR 是简历上项目经历的书面格式，必须写成四段
B. STAR 是 Situation - Task - Action - Result，面试口述经历的顺序框架
C. STAR 和项目描述公式是同一个东西的两种叫法
D. STAR 中的 R 指「Requirement，岗位要求」

**0-3.** 「量化」的准确含义是：
A. 给任意一句话加一个百分数
B. 给结果配上能说清口径与对比基线的数字
C. 把简历写成一页
D. 把所有技能词都换成数字

**0-4.** 「一页原则」的首要理由是：
A. 一页纸更美观、更显专业
B. 适配约 20 秒浏览与 ATS 文本解析，结构清晰优先于视觉创意
C. 打印省钱
D. 招聘方规定只能收一页，多一页直接扔掉

### 二、连线题（0-5，6 组，每组 2 分，共 12 分）

将左列概念与右列最贴切的描述连线（填字母）：

| 左列 | 右列备选 | 我的答案 |
|---|---|---|
| ① ATS 与 JD | A. 纸上三段 / 嘴上四段 | |
| ② 关键词 与 岗位匹配 | B. 软件读文本 / 文本是题目要求 | |
| ③ 项目描述公式 与 STAR | C. 词级信号 / 整份证据级对应 | |
| ④ 量化 与 成果证据 | D. 为解析与注意力 / 为视觉好看 | |
| ⑤ 一页原则 与 排版美观 | E. 带口径的数字 / 整条可追问事实 | |
| ⑥ 可验证动词 与 免责动词 | F. 报得出动作 / 一问就露馅 | |

### 三、改错题（0-6 ~ 0-9，每题 3 分）

**0-6.** 改错：「参与公司 AI 客服项目，负责部分需求整理工作，配合团队完成上线。」

**0-7.** 改错：「精通 RAG、精通 LangChain、精通微调、精通 Agent、精通数据驱动。」

**0-8.** 改错：「原行业没前途，AI 是风口，所以裸辞转行，愿意从零学起。」

**0-9.** 改错：「上线后效果很好，用户反馈不错，数据提升明显。」

### 四、简答辨析（0-10 ~ 0-12，每题 4 分）

**0-10.** 写出 JD 的全称与中文，并说明它和 ATS 分别扮演什么角色。

**0-11.** 「熟悉 RAG」后面必须挂什么？请用「成果证据」与「量化」两个术语各说一句。

**0-12.** 转行叙事三段法的顺序是什么？重心为什么在第三段？

## 第 3 层 · 求职挑战题（面试层，原第三层保留并补 2 题）

**14.（原第 9 题，保留）面试真题（30 分）**：「你的简历我看了，你说说你自己最重要的一个项目，30 秒讲清楚它为什么值得写进简历。」

要求：用项目描述公式的逻辑做口述——先说背景盘子，再说两条动作，最后给一个数据结果，并在结尾点明「这段经历与我应聘岗位的关系」。

**15.（原第 10 题，保留）案例分析：一份简历投所有岗位（30 分）**

教学示例情景：一位设计背景学员用同一份简历投了教育 AI 产品、SaaS AI 产品、电商 AI 运营三个岗位，一周内零面试邀请。简历本身项目经历尚可、数据齐全。请分析最可能的原因（至少两条），并给出具体改进动作。（说明：投递结果以个人真实投递记录为准，本题不提供任何回复率、通过率数字。）

**16.（新增）三版微调（20 分）**

接第 15 题：请针对「教育 AI 产品」与「SaaS AI 产品」两份 JD（教学示例），各写出你会改的 3 处（定位行 / 技能区 / 项目侧重），并说明为什么是这 3 处而不是全篇重写。

**17.（新增）一页原则删减（20 分）**

某教学示例简历写了两页，包含：大段自我评价、6 段与岗位无关的早期经历、两段重复的项目、复杂图形排版、教育背景罗列 8 门课程。请按「删的优先级」给出删减顺序，并说明「一页原则」为什么不是「排版好看」的问题。

## 第 4 层 · 面试实战（7 题，每题含踩分点、追问链、失败答法、评分表）

> 用法：第 5 节两两模拟时，面试官按「踩分点」打分、按「追问链」连追 2–3 层；学员答完填《面试模拟记录表》。每题评分表满分 10 分，8 分及以上为「可进面试」，6–7 分为「合格待补」，≤5 分为「需重练」。所有 60 秒标准答法要点见文末「参考答案与评分标准 · 第五部分」。

### 第 18 题 · 「你的简历我只有 20 秒，先说说我该看哪里？」（场景设计题）

| 项 | 内容 |
|---|---|
| 踩分点（4 条，每条 2 分） | ① 说出「约 20 秒、首屏 1/3 决定去留」② 按视线顺序点出头部定位 / 技能区关键词 / 项目第一段三处 ③ 说明主项目站黄金位因「相关性优先于时间」④ 回扣贵司 JD 具体词条 |
| 追问链 | L1「为什么定位行要放数字？」→ L2「如果我更看重教育背景呢？」→ L3「这份简历针对我们岗位改过哪三处？」 |
| 典型失败答法 + 失分原因 | 「我简历写得很全面，您可以从头慢慢看。」——把 20 秒当通读，无用户视角与主次，丢「岗位匹配」分 |
| 评分表 | 见下方统一 Rubric A |

### 第 19 题 · 「你是转行的，简历上这段经历怎么解释？我怎么知道你不会干两天就走？」（行为题）

| 项 | 内容 |
|---|---|
| 踩分点（4 条，每条 2 分） | ① 用转行叙事三段法且顺序正确 ② 动机写「奔赴」、不出现「逃离 / 风口」③ 第三段给出可验证产出（主项目 / 真实试用 / 作品集链接）④ 回扣「行业理解 + 产品能力」组合稀缺，回应稳定性 |
| 追问链 | L1「原行业最舍不得的是什么？」→ L2「你说验证过 AI 提效，怎么验证的？」→ L3「前三个月做杂活会不会有落差？」 |
| 典型失败答法 + 失分原因 | 「原行业没前途，AI 很火，我想试试，愿意从零开始。」——逃离 + 追热点 + 亲手否定积累，「试试」坐实稳定性担忧 |
| 评分表 | 见 Rubric A |

### 第 20 题 · 「这个主项目里，你具体做了什么？团队几个人、你负责哪一块？」（项目深挖题）

| 项 | 内容 |
|---|---|
| 踩分点（4 条，每条 2 分） | ① 先给背景盘子 ② 两条动作全部「我 + 可验证动词」③ 一条带口径与基线的量化结果 ④ 结尾点明与目标岗位关系 |
| 追问链 | L1「哪条动作是你独立决策的？」→ L2「最大失败是什么、怎么改的？」→ L3「重做一次会砍掉哪部分？」 |
| 典型失败答法 + 失分原因 | 「我们团队一起做的，我负责需求整理和跟进，大家配合得挺好。」——全程「我们」、免责归属词、无盘子无数字，贡献无法定位 |
| 评分表 | 见 Rubric A |

### 第 21 题 · 「你简历里写人工咨询量下降三成半，这个数字怎么来的？」（项目深挖题 · 数字怎么答）

| 项 | 内容 |
|---|---|

| 追问链 | L1「分母是什么？含机器人自助会话吗？」→ L2「为什么选一个月不是两周？」→ L3「这个变化能全归功于你的项目吗？」 |
| 典型失败答法 + 失分原因 | 「系统里看到的，运营统计的，我不太清楚，反正确实降了。」——口径、基线、周期三层全空，还推责，全简历数字可信度破产 |
| 评分表 | 见 Rubric A（数字为教学示例示意，须替换本人真实数据） |

### 第 22 题 · 「你技能区写『熟悉 RAG』，具体做过什么？遇到最难的问题是什么？」（项目深挖 / 技术理解题）

| 项 | 内容 |
|---|---|
| 踩分点（4 条，每条 2 分） | ① 把「熟悉」翻成具体动作 ② 给出可验证结果（评测集验证）③ 说出一个真实困难与取舍 ④ 回扣 JD 对应词条 |
| 追问链 | L1「评测集怎么建的？多少条、怎么判对？」→ L2「提升靠换模型还是改检索策略？」→ L3「换到没见过的行业文档怎么冷启动？」 |
| 典型失败答法 + 失分原因 | 「RAG 我比较熟，就是检索增强生成嘛，看过不少资料，上手应该很快。」——只有名词复述，零动作零结果，坐实关键词堆砌 |
| 评分表 | 见 Rubric A |

### 第 23 题 · 「同一份简历投了三个岗位都没回音，你觉得问题出在哪？」（场景设计题）

| 项 | 内容 |
|---|---|
| 踩分点（4 条，每条 2 分） | ① 指出核心是岗位匹配缺失 ② 用 ATS / JD 解释匹配分低 ③ 给出三版微调动作（定位 / 技能 / 项目侧重）④ 给出投递记录迭代思路 |
| 追问链 | L1「会改哪三处、为什么？」→ L2「改完还是没回音呢？」→ L3「怎么判断是简历问题还是岗位问题？」 |
| 典型失败答法 + 失分原因 | 「可能是投得不够多，我再海投一百份。」——把结构问题当数量问题，不拆 JD、不复盘 |
| 评分表 | 见 Rubric A |

### 第 24 题 · 「30 秒讲清楚你最重要的一个项目，为什么它值得写进简历？」（行为 / 项目深挖题）

| 项 | 内容 |
|---|---|
| 踩分点（4 条，每条 2 分） | ① 用 STAR 顺序、30 秒内讲完 ② 含背景盘子 + 两条「我」的动作 + 一条量化结果 ③ 说清「为什么值得写」= 与 JD 相关性最强 ④ 结尾预埋钩子引导追问 |
| 追问链 | L1「为什么这段放黄金位不是另一段？」→ L2「30 秒里你省略了什么？」→ L3「你希望我接着问哪一层？」 |
| 典型失败答法 + 失分原因 | 「我做了一个 AI 学习助手，用了大模型和知识库，做了需求、评测、上线，还挺完整的……」——流水账、无数字、无「为什么值得」、超时且不给钩子 |
| 评分表 | 见 Rubric A |

**统一 Rubric A（第 18–24 题通用，满分 10 分）**

| 档位 | 分值 | 标准 |
|---|---|---|
| 可进面试 | 8–10 | 4 条踩分点命中 ≥3 条且含关键项；2–3 层追问不倒；全程说「我」、数字带口径；60 秒内收尾并回扣岗位 |
| 合格待补 | 6–7 | 命中 2–3 条踩分点；第 1 层追问能答，第 2 层起有卡顿；出现 1 次「我们」或 1 个无口径数字 |
| 需重练 | ≤5 | 只给结论无成果证据；或出现免责动词 / 逃离式动机 / 数字答不出口径；或 2 层内被问倒 |

**第 4 层补充扣分表（叠加在 Rubric A 之上，扣完不倒扣至负分）**

| 失分动作 | 扣分 |
|---|---|
| 出现 1 次「我们团队 / 参与 / 负责 / 协助」 | −1 |
| 数字无口径或无基线 | −1 |
| 转行动机写成「逃离 / 风口 / 从零开始」 | −2 |
| 60 秒严重超时（>90 秒）或 30 秒题 >60 秒 | −1 |

## 第三部分 · 第 2 层进阶实操

**第 11 题（原第 8 题）· 片段 A 诊断**：四个动词全是免责词（参与 / 负责 / 配合 / 完成），无盘子、无具体动作、无结果，HR 读不出任何可追问的事实。
**片段 A 改写（参考，教学示例）**：背景一句「面向五百名坐席的客服团队，高峰期人工响应超时率超三成」；动作两条「主导三类高频咨询场景的需求梳理并输出 PRD，两轮评审通过」「构建五十条评测集，联合研发完成两轮模型评测与知识库调优」；数据结果「上线一个月人工咨询量下降三成半，首响时长从两分钟降至二十秒」。注：数字为教学化示意，实际以学员真实项目数据替换，精确统计口径「待教务补充」，但必须三段俱全。

**片段 B 诊断**：技能区与岗位几乎无关（Office 非核心）；「AI 相关技术」笼统无物；「学习能力强」「性格开朗」是自我评价不是事实；无一条可验证。
**片段 B 改写（参考）**：「熟悉 RAG 架构与知识库产品设计：搭建知识库原型并经评测集验证检索准确率；掌握模型评测方法：构建五十条评测集完成三款模型对比与选型；熟练完成需求分析与 PRD 撰写：主项目 PRD 两轮评审通过并落地 MVP。」——每条技能后面必须挂一条成果证据。

**片段 C 诊断**：有动作但无盘子、无结果；「每周更新」「组织活动」是职责罗列，读不出水平差异。
**片段 C 改写（参考，教学示例）**：背景「公司公众号粉丝三万，内容打开率长期低于百分之一点五」；动作「主导选题方向调整，基于后台数据重构栏目结构」「策划线上活动并建立数据复盘机制」；结果「三个月打开率提升至百分之四，粉丝增长两成」。

**第 11 题评分 Rubric（每段 20 分，按档给分）**

| 档位 | 标准 |
|---|---|
| 合格（12–15 分） | 准确指出该段的核心问题；改写覆盖公式三段但动作不够具体或数据为空泛表述 |
| 良好（16–18 分） | 诊断能点出「免责动词 / 自我评价 / 职责罗列」的问题类型；改写三段齐全、动词可验证、数据量化 |
| 优秀（19–20 分） | 额外指出次要问题（如片段 B 技能与 JD 无关应重排优先级）；改写自带「面试追问防御」意识——每条事实都可被追问三层 |

**第 12 题参考答案（20 分）**：4 处违规——① 背景写了四行（大模型火 / 教育提效 / 用户愿意 / 竞品在做），违反「背景一句」；②「我们团队」违反「说我」；③「负责需求整理和跟进」「参与了评测」是免责动词；④「效果很好 / 反馈不错 / 提升明显」是形容词、无量化、无口径基线。改正参考（教学示例）：「面向十名真实试用用户的 AI 学习助手，初期答案可用率不足六成（背景一句）；我主导五十条评测集构建与三款模型选型、基于试用反馈迭代两版知识库检索策略（动作两条）；同一评测集复测可用率提升至八成五（数据结果，带口径与基线）。」评分：每找出 1 处 2 分（共 8 分）+ 每改正 1 处 2 分（共 8 分）+ 改写后三段齐全且动词可验证 4 分。

**第 13 题参考答案（20 分）**：三层追问 = 怎么统计的（周期与样本）/ 口径是什么（分子分母定义）/ 跟什么基线比。缺的三样：统计周期与样本、指标口径、对比基线（另可答「局限说明」）。补写参考：「上线后一个完整月，XX 指标由 XX 提升至 XX（口径：XX / XX；基线：上线前同期；局限：单月样本、未剔除活动期）」，数字一律用 XX 占位。评分：三层追问各 3 分（9 分）+ 三样缺失各 2 分（6 分）+ 补写含口径与基线 5 分。

## 第四部分 · 第 3 层求职挑战

**第 14 题参考答案**：结构 = 背景（盘子与问题）→ 两条动作（我主导什么、怎么做的）→ 数据结果（量化变化）→ 收尾一句「这正好对应贵司 JD 里的 XX 能力」。30 秒内完成，全程有数字，说「我」不说「我们」。

| 档位 | 标准 |
|---|---|
| 合格（18–23 分） | 有背景、动作、结果三要素，逻辑通顺 |
| 良好（24–27 分） | 公式结构完整且动作可验证、数据量化；结尾能关联目标岗位 |
| 优秀（28–30 分） | 额外预埋一个「钩子」引导面试官追问自己准备最充分的一层（如评测方法或取舍逻辑） |

**第 15 题参考答案**：原因一，无岗位针对性——三个岗位的 JD 关键词、行业词完全不同，同一份简历对谁都不匹配，ATS 匹配分低；原因二，零面试邀请的直接后果链：机器筛掉 → HR 无感 → 无补投数据可分析。改进动作：① 拆三份 JD，各提取 8 个关键词，做三版微调（至少改定位行、技能区、项目侧重三处）；② 每版对应一条投递渠道策略；③ 建立投递漏斗记录（投递量 / 打招呼反馈 / 邀约情况，以个人真实记录为准，不编造回复率与通过率数字），用数据迭代下一版。

| 档位 | 标准 |
|---|---|
| 合格（18–23 分） | 指出「无针对性」这一核心原因并给出关键词微调动作 |
| 良好（24–27 分） | 原因两条以上且含 ATS 逻辑；改进动作落到「三版微调」的可执行层面 |
| 优秀（28–30 分） | 额外给出投递漏斗的数据化迭代思路，体现「求职即产品运营」的系统性 |

**第 16 题参考答案（20 分）**：教育 AI 产品岗——定位行目标改为「AI 学习产品」并写教育场景数据；技能区换成「教育场景理解 / 教研 / 学习场景评测」等 JD 词条并挂对应事实；项目侧重放到主项目的学习助手与十人试用。SaaS AI 产品岗——定位行改为「企业级 AI 产品」；技能区换成「需求分析 / PRD / 跨部门协作 / MVP 落地」等词条并挂对应事实；项目侧重放到 PRD 两轮评审与研发协作落地。为什么只改三处：这三处正是 ATS 关键词覆盖与 HR 首屏 1/3 读到的位置，改动性价比最高；全篇重写会破坏已验证的公式结构与成果证据链。评分：每岗 3 处各 2 分（共 12 分）+ 说明「为什么三处」5 分 + 每处均挂事实 3 分。

**第 17 题参考答案（20 分）**：删减优先级 = 自我评价 → 无关早期经历细节 → 重复项目 → 教育背景课程罗列 → 复杂图形排版改清晰文本。一页原则不是「排版好看」：它首先适配约 20 秒浏览（首屏 1/3 决定去留，二十秒的产品没有第二页）与 ATS 文本解析（图形 / 多栏 / 图片文字可能解析成乱码），所以结构清晰优先于视觉创意。评分：删减顺序 10 分（每答对 1 项 2 分）+ 一页原则两条理由各 5 分。
