一、为什么本课不设交互页（讲师须知，原文保留）

对比项 交互页适合 本课实际
内容类型 架构、流程、参数权衡等「可演示的机制」 项目经历的「个人化写作」，没有统一正确答案可演示
课堂价值 统一操作、统一观察 每人素材不同，写作本身即最佳交互
产出物 理解与判断 一份可交付的复盘文档初稿 + 一个上线链接 + 一套面试答法

结论：把时间全部交给「写 + 审 + 拼 + 练」，不做任何工具演示。PPT 第 19–24 页投屏显示六节模板与计时器即可。

2.2 写作计时规则（原文保留）

  1. 投屏倒计时（手机计时器投屏亦可），12 分钟与 8 分钟各一次，中途不打断。
  2. 剩余 3 分钟时口头报时一次：「还剩 3 分钟，没写完的先保数据结果节——它是本文档的命根子。」
  3. 到点强制停笔，写不完属正常——本环节定位是初稿，全文课后补齐（W7D3 早 9:00 前交）。
  4. 禁止「再给两分钟」式延时——工作坊的纪律感本身就是求职前的写作训练。

三、同伴互审规则（核心：陌生人 3 分钟测试，原文保留）

3.1 检验标准

一句话版本：假如我是一个陌生人，能不能 3 分钟看懂你做了什么、做成了什么？

3.2 三问检验清单（互审者逐条打勾，导学案有对应表格）

# 检验问题 通过标准 不通过时的定位
① 我能说出他做了什么吗 一句话说清产品与他的角色 背景 / 角色节写得含糊，或「我们」太多
② 我能记住至少 2 个数字吗 数字带对比基准（从 X 到 Y），且不是孤零零的绝对值 数据结果节只有绝对值或只有形容词
③ 我能说出一个他放弃过的方案吗 关键决策与取舍节有真实的岔路口 取舍节缺失，或写成了工作总结

3.3 互审行为规范（原文保留）

  1. 三问全部通过=合格；有任何一问不通过，互审者必须指出具体是哪一节没写清，禁止只说「挺好的」。
  2. 修改建议必须具体到节、到句，格式：「第 X 节，把『我们』改成『我负责 XX』」。
  3. 只用「陌生人能不能看懂」这一个标准评判，不评文风与口味，避免争执。
  4. 被审者只记录不辩解——辩解说明文档本身没写清，记下来回去改。

四、讲师巡场追问清单（写作与互审期间使用，10 条原文保留）

巡场时每人抽问 1–2 个，问题只往深里追，不强求当场答全：

# 追问 检验什么
1 「这个数字怎么来的？哪份报告、什么时候测的？」 数据来源意识（三原则第三条）
2 「90% 这个数，基准是多少？没有对比它什么都不是。」 对比基准意识（三原则第一条）
3 「当时放弃了什么方案？为什么选这条？」 Action 是否写出了决策而非流水账
4 「这句话里的『我们』，具体是谁做的？」 角色标注的真实性
5 「面试官问『你贡献了哪部分』，你现在答得上来吗？」 团队成果与个人贡献的边界
6 「如果你的 R 只有 68% 到 74%，你打算怎么写？」 诚实呈现 + 归因补充的意识
7 「假如我是陌生人，3 分钟读完，我能记住什么？」 陌生人测试的自我预演
8 「你的 S 里有核心矛盾吗，还是只有行业介绍？」 背景是否压到一句话且含矛盾
9 「这个项目重做一次，你最想改哪一步？」 反思与迭代节的素材储备
10 「你文档里哪个数字最经不起追问？现在就去补来源。」 自查习惯

对应板块两两模拟时，本清单第 1、3、4、6 条可直接当「追问链第 1 层」使用，与面试追问卡 Q1–Q7 对齐。

五、常见问题处理（原文保留并补 3 行）

问题 处理
学员 12 分钟写不完前三节 不延长；提醒课后用导学案模板补全，课上已写部分按「有无数字、有无角色」给口头反馈
学员说「我的数据不好看，不敢写」 回应口径：「有诚实基准的改进也是结果，配归因和迭代计划反而加分；一票否决的是造假，不是数字小。」
学员的数据素材包没带 / 缺项 让其先用「X」占位搭结构，课后补真实数据；绝不允许课上编数字
互审两人水平差距大，一方给不出建议 让高水平者只做「三问检验」并报通过与否；讲师巡到该组时代行深度点评
互审起争执（互审者坚持评文风） 中止争执，重申唯一标准：「陌生人 3 分钟能不能看懂，用这个标准谈。」
线上直播班分组不便 用会议软件两人 breakout（分组讨论）房间互审，共享屏幕代替交换导学案；三问检验改为口头互答
设计背景学员导语写不出来（新增） 「别写你做了什么，写谁被卡住了——先把『谁、什么卡住了』这句写下来，问题段就成了。」配合语音速记「当时为什么这么决策」
指标拿不到精确数据（新增） 按四选一走：真实统计 / 估算 / 替代指标 / 目标值，选一个如实标注；诚实标注的估算比凭空的精确数字可信
手机先行学员无电脑 / 排版溢出（新增） 先发 V0.5 占位，单张缩略图 + 图下文字说明代替多图对照；列 3 条电脑升级清单，不因设备停手

六、课后学员指引（发群文案，原文保留并按 本课口径补一句）

同学们，今天复盘写作工作坊的规则回顾：① 课后用导学案六节模板把文档补全为全文，明早 9:00 前交群；② 交前自查三件事——每个数字有「从 X 到 Y」的基准、有来源脚注、A 段落里至少一处「放弃了什么」；③ 找一位今天没互审过的同学，用「陌生人 3 分钟测试」再过一遍。周三简历课，你会把这份文档的 STAR 段落直接搬进简历黄金位。
