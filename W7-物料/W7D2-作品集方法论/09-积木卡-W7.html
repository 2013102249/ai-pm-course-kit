作品集积木卡 W7 · 整合页：六块积木拼成一座房子

八周作品集主线 · 第 7/8 块 ｜ 产出时点：W7D2 作品集整合日（课堂核心产出）+ W7D5 投递前终检 ｜ 拼入作品集：全册上线
本块与前六块不同：它不是「归档已有作业」，而是 W7D2 整合日的课堂产出——把 P1–P6 拼装、写叙事、发上线。

一、本块产出物

产出物来自哪里说明
在线作品集 V1.0（P1–P6 六页齐全）W7D2 整合日课堂唯一需要电脑集中完成的一块（🟡），见移动端通道
主项目深度复盘文档全文W7D2 课后作业六节齐全，作为 P2–P6 的深度附件
设计作品转产品作品 1–2 篇用《设计作品转产品作品》模板改写纯设计背景学员必做；零作品集学员可改用「产品分析集」补位
投递计划表（≥50 行）W7D5 作业作品集链接是投递表里的必填字段

二、判定标准（可验收）

  • P1–P6 六页齐全，每页页头有四段式导语（问题—方案—指标—复盘，每段 1–3 句）
  • 手机打开全册无版式崩坏（图不溢出、表不横向滚动、链接全部可点）
  • 通过「陌生人 3 分钟测试」：一个没见过你项目的人，3 分钟内能说出你做了什么、记住 ≥2 个数字、说出 1 个你放弃过的方案
  • 深度复盘文档全文完成（六节 + ≥3 组带基准数字）
  • 作品集链接已填入 W7D5 投递计划表与简历作品集位

三、进入作品集哪一页

全册结构（六页 + 两层附件）：

P1 起点页（转行宣言 + 提示词集 + 规划书）
P2 问题与立项页（立项报告 + 种子评测 + 四段式叙事）
P3 原型页（架构图 + 60 秒演示 + 评审闭环）
P4 方案页（PRD 链接 + 反直觉发现 + 意见闭环）
P5 数据与迭代页（基准→结果 + 假设-实验-结论 + 成本表）
P6 成品页（产品链接 + 30 秒 GIF + 验收摘要 + 用户声音）
附件层 A：主项目深度复盘文档（全文）
附件层 B：设计作品转产品作品 1–2 篇（纯设计背景学员）
自用层：面试弹药库（W8 产出，不对外）

上线工具任选其一：腾讯文档（最轻）、飞书知识库（团队感强）、Notion（外企风）、Canva（设计背景同学的主场）。判定只看结果：链接稳定、移动端可读、3 分钟测试通过。

四、设计背景学员转译提示

  • 整合日就是你的 作品集排版日——视觉规范（统一字体、间距、色板）你已经做了四年，今天唯一的新要求是：每页页头必须是四段式文字导语，图是证据不是主角。产品作品集的阅读顺序是「先读叙事、再看图」。
  • 三位设计背景同学各自的整合要点：视觉传达——警惕「太漂亮」，每页只留一个视觉重点；环境设计——把六页当「参观动线」设计，P6 是主展厅；动画——30 秒 GIF（动图）是全册的「预告片」，节奏感是你们的必杀技。
  • 零作品集（非设计背景）的同学：附件层 B 改放 产品分析集（2 篇结构化拆解，模板见 02-讲课稿）——证明思维可迁移，同样有效。

五、手机 / 平板可行路径（🟡 电脑一次 + 🟢 手机可冲刺 V0.5）

  • 标准路径（推荐）：W7D2 课堂用电脑完成拼装与上线（这是全八周唯一强制用电脑的作品集动作，2 课时够用）。
  • 罗思蕊通道（手机可走通）：
  1. 平时六块积木都用手机归档在腾讯文档（W1–W6 已做到）；
  2. 整合日用手机「腾讯文档 → 目录结构 + 分页」，先发布 V0.5（链接可用、排版朴素）——当天就能填进投递表占位；
  3. 之后任找一台电脑（机房 / 借同学）花 1 小时升级 V1.0；或全程用手机版 Canva 完成排版（App 免费模板够用）；
  4. 每步交付物都保留链接，避免「完美排版」拖垮「按时上线」。
  • 自测清单（手机完成）：逐页打开 → 图不溢出 → 链接可点 → 字号在手机上可读。

六、常见问题

  • Q：六块积木里有缺的怎么办？ A：整合日第一件事就是按积木清单盘点（导学案预习任务 1）。缺哪块，当堂按该块积木卡的最小验收线补齐——这就是「每周归档」的意义：缺口每周暴露，永远不会滚到最后一周。
  • Q：设计作品放不放？ A：放「转产品化」之后的版本（附件层 B），原始视觉稿可以缩略图形式附在文末。直接堆原始作品集等于告诉面试官「我还没转轨」。
  • Q：作品集要不要做成炫酷 H5（移动端网页）？ A：不要。面试官在手机上 3 分钟内要看的是叙事和证据，不是动效。克制、清楚、可验证，就赢过了 80% 的作品集。
