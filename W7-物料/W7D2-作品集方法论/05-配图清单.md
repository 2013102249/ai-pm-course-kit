## 图 1 · STAR 结构图（已制成，核心教具，原文完整保留）

### 版式规格

| 项目 | 规格 |
|---|---|
| 画布 | 1280 × 720（16:9），viewBox「0 0 1280 720」，SVG（可缩放矢量图形）源文件 + 导出 PNG（便携式网络图形） |
| 整体版式 | 四张字母卡片横向等宽排列（S / T / A / R），卡片间距 24px，圆角 16px |
| 卡片结构 | 自上而下四层：大字母（96px 加粗白字）→ 中文名（Situation · 一句话背景 等，18px）→ 一句话要领（16px）→ 正反例对照区 |
| 配色节奏 | 卡片底色 S、A 用紫 #7C3AED，T、R 用蓝 #2563EB，形成紫蓝交替节奏 |
| 正反例对照区 | 每卡片下半部分分两行：上行绿色对勾图标 + 正例文字（白底，绿 #059669 左边框）；下行红色叉图标 + 反例文字（白底，红 #DC2626 左边框）；正反例字号一致（13px），行数一致（各 ≤2 行） |
| 页脚 | 右下角来源标注：「示例数字均为教学示例」12px 灰色 #7A7590 |

### 正反例文案（教学示例，制作时照抄）

| 卡片 | 一句话要领 | 正例（绿） | 反例（红） |
|---|---|---|---|
| S · 一句话背景 | 行业+场景+核心矛盾，≤40 字 | 咨询量 200 条/天，60% 重复，人工响应超 4 小时 | 近年来 AI 发展迅速，各行各业积极探索应用…… |
| T · 可量化目标 | 范围/规模/周期/指标至少占两样 | 从 0 到 1 主导 8 周上线，目标正确率 85%+ | 负责知识库产品。 |
| A · 写决策 | 为什么这么做，放弃了什么 | 访谈推翻原假设，放弃换模型，改做分块+重排 | 负责需求调研、PRD 撰写、开发跟进、测试验收。 |
| R · 必须有数字 | 基准值→结果值+时间范围 | 引用正确率从 71% 提升至 90%（上线两周） | 产品效果显著，广受用户好评。 |

### 验收标准

1. 中文无错别字；四个字母卡片结构、字号、行距完全对齐。
2. 正反例各 1 条/字母，正例均含具体数字或明确决策，反例均为典型病句。
3. 只使用品牌紫 #7C3AED、蓝 #2563EB 与功能色绿 #059669、红 #DC2626，无其他彩色。
4. 页脚「教学示例」标注存在且可读。
5. SVG 在 720px 宽度下文字仍可辨认（投屏与手机端双验）。

### 讲法脚本

- **使用时机**：对应板块 STAR 逐字母精讲全程挂屏（70–92 min），逐卡片讲解，讲到哪个字母高亮哪个卡片（PPT 内可用局部放大替代高亮）。
- **讲法**：每个字母按「要领 → 先露反例让学员挑错 → 再露正例对照」的顺序讲，不要先给正例。
- **提问点**：S 卡片处问「为什么背景必须压到一句话」；A 卡片处问「把团队成果写成个人成果，风险是什么」（见 01-教案提问设计 C 类）。
- **过渡话术**：「四个字母四道坎，前两个决定面试官看不看，后两个决定面试官信不信。」

## 图 3 · 图表美化示例（已制成：改前改后三组对照，原文完整保留）

### 版式规格

| 项目 | 规格 |
|---|---|
| 画布 | 1280 × 720，两行三列网格：上行为「改前」，下行为「改后」，左→右三组 |
| 组一 | 改前：立体饼图 12 分块（彩色杂乱）；改后：横向条形图 Top 5（前五名，紫色强调第 1 名，其余灰），标题即结论「46% 咨询集中在 3 类高频问题」 |
| 组二 | 改前：无标注折线；改后：折线加基准虚线（71%）与终点标注（90%），关键节点圆点标数字 |
| 组三 | 改前：彩虹配色柱状图；改后：单强调色柱状图（紫），其余灰，标题写「分块+重排上线后正确率变化」 |
| 页脚 | 每组改后图右下角加来源示例脚注：「数据来源：教学示例」 |

### 内容要点（制图与讲解共用）

1. 一图一结论：结论写进图标题，不让读者自己找重点。
2. 趋势用折线、对比用横向条形、构成用堆叠柱状；禁用立体图与 3D（三维）透视（歪曲比例）。
3. 强调色最多一个：重点用紫 #7C3AED，其余统一灰 #C4C0D4。
4. 数字直接标注在数据点上，不依赖读者估读坐标轴。
5. 每图右下角标数据来源——「敢标来源的数字，面试官默认可信」。

### 讲法脚本

- **使用时机**：对应板块第二条原则处（约 104–112 min），上下对照讲，每组停留约 90 秒。
- **讲法**：先让学员看「改前」找问题（不先给答案），再露「改后」对照；三组讲完总结「改前让读者找结论，改后把结论递到眼前」。
- **提问点**：「回到你的主项目，测试报告里挑哪三个数字放进复盘文档？挑的依据是什么？」（衔接导学案对应板块《数据三数字表》）。
