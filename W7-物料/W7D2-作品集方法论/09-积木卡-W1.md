> 铁律：积木卡只定义「怎么归档、怎么算合格」，**零新增任务**——所有产出物都来自本周已有作业。

## 二、判定标准（可验收）

- [ ] 30 条提示词中 **≥24 条**五要素评分 ≥4/5（不达标的标黄，W3 周末前补齐——它们是面试「你怎么写提示词」的现场素材）
- [ ] 职业规划书是 **1v1 确认后**的版本（未确认 = 未定稿 = 不归档）
- [ ] P1 页面开头有一段 **80–120 字「我为什么转行 AI 产品」**，提到一次自己的原专业（设计 / 内容 / 其他），并把它说成资产而不是包袱
- [ ] 作品集草稿文档已建立，命名规范：`姓名-AI产品作品集-V1`

## 三、进入作品集哪一页

**P1 起点页**（全册第一页）：

| 板块 | 放什么 | 来源 |
|---|---|---|
| 页头 | 80–120 字转行宣言 | 本周新写（唯一的新增文字，30 分钟内） |
| 技能证明 | 提示词练习集链接 + 「8 条最佳」截图 | W1D3 作业 |
| 目标与路径 | 职业规划书链接（赛道、8 周目标） | W1D5 作业 |

命名规范：`W1-P1-起点页-姓名`。P1 的作用：面试官 30 秒内知道你是谁、从哪来、要去哪。

## 四、设计背景学员转译提示

- 视觉传达 / 环境设计 / 动画的同学：**审美和排版是你们作品集的先天优势**，但 P1 要证明的是「思维换轨」。写转行宣言时用一句句式：「我过去用＿＿回答＿＿问题，现在我要用产品回答用户的问题。」
- 把「我会做图」翻译成产品语言：**我能把信息组织到让人 3 秒看懂**——这句话 W7 整合日还会用到。

## 五、手机 / 平板可行路径（🟢 全程移动端可完成）

1. 新建腾讯文档 / 飞书文档（手机 App 即可）→ 命名为作品集草稿。
2. 提示词练习集在飞书学习档案里 → 复制链接粘贴进 P1。
3. 转行宣言用手机备忘录打草稿 → 粘贴进 P1。
4. 平板加分项：用备忘录 / GoodNotes 手绘一张 P1 排版草样（可选）。

## 六、常见问题

- **Q：现在作品集只有提示词和规划书，是不是太单薄？** A：不单薄，这是「学习轨迹的证据」。到 W6 你会拥有一个上线的产品——到时候面试官最想看的恰恰是「你是怎么一步步长出来的」，P1 就是这条轨迹的第一格。
- **Q：转行宣言写不好怎么办？** A：先写三句大白话（我从哪来 / 我发现了什么 / 我要去哪），再压缩到 100 字。不要写形容词。
