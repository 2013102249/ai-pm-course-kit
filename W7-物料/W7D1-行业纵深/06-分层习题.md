## 二、第 0 层 · 术语辨析（12 题；题型含判断 / 选择 / 改错 / 连线 / 简答，满足「至少两种」）

## 六、第 4 层 · 面试实战（8 题；每题含踩分点、追问链、失败答法、参考答案要点、评分表）

> 题型：行业认知 / 方法·行为 / 项目深挖 / 场景设计·追问防御。每题 10 分制评分表；完整 60 秒标准答法见 02-讲课稿 对应板块，此处给参考答案要点与判分规则。
> 通用兜底原则：**被追问到不会，不硬编；给查证路径和边界，比编一个数字更得分。** 凡出现编造规模数字 / 政策条款号 / 公司数据，该题直接扣 3 分并判「硬伤」。

### Q1 · 你对我们行业了解多少？（行业认知）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 不堆名词，先一句话定位客户与付费方 ② 用六件套 ≥3 件给结构化信息 ③ 关键信息带可回访来源 ④ 落到「对贵司产品意味着什么」 ⑤ 规模写「以最新公开报告为准」 |
| 追问链 | L1 谁付钱、谁使用？→ 拆客户画像四要素；L2 从哪查到的？→ 报官网定价页 / 年报行业章节 / W6 试用记录；L3 行业最近一个变化对产品意味着什么？→ 政策清单三列答法，讲查证方法 |
| 失败答法 | 「前景好、规模大、AI 是大趋势、我很有兴趣」——宏观口号、无可核验信息、一追问就空 |
| 参考答案要点 | 六件套讲一个具体问题：产业链三层 + 竞品 3 行带来源 + 1 个真实使用时刻，落到「产品先解决 ×× 痛点」；不口播数字（×× 为占位，教学示例） |
| 评分表 | ①2 分 ②3 分 ③2 分 ④2 分 ⑤1 分；满分 10 分；出现失败答法判 0–2 分 |

### Q2 · 一周补齐一个完全陌生的行业，你会怎么做？（方法 / 行为）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 可复用固定流程（六件套）② 信源白名单与官方原文优先 ③ 时间盒（每天两件、第 7 天串一页）④ 验收动作（每节一行「意味着什么」+ 外行复述） |
| 追问链 | L1 第一步查什么？→ 先产业链定位置不先背术语；L2 怎么判断可信？→ 官方原文 > 公开报告 > 二手解读；L3 一周后怎么证明真懂？→ 一页速写 + 向外行讲清 + 术语抽复述 |
| 失败答法 | 「上网多搜搜、看几篇公众号、把报告读一遍」——无结构、无信源分级、无验收 |
| 参考答案要点 | 七天六件套时间表：D1 产业链 → D2–4 政策 / 竞品 / 客户 → D5–6 场景 / 术语 → D7 一页速写 + 复述；规模统一写「以最新公开报告为准」 |
| 评分表 | ①3 分 ②2.5 分 ③2.5 分 ④2 分；满分 10 分 |

### Q3 · 给你一个竞品，你怎么分析它？（项目深挖 / 方法）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 先界定「同客户同场景」 ② 维度固定：目标客户 / 核心功能 / 定价模式 / 来源，≥3 行 ③ 末行留主项目找差异位 ④ 补一句护城河 |
| 追问链 | L1 怎么确定它算竞品？→ 同客户同场景 + 留意赛道外替代品；L2 比哪几项？→ 决策信息优先于功能罗列；L3 来源经得起当场核对吗？→ 现场打开官网定价页 60 秒对上 |
| 失败答法 | 「列 30 行功能大表，越全越认真」——体力活、无来源、无判断 |
| 参考答案要点 | 圈范围 → 四列 ≥3 行带来源 → 末行差异位 → 护城河；一句话「三行有来源的判断胜过三十行没来源的罗列」 |
| 评分表 | ①2.5 分 ②3 分 ③2.5 分 ④2 分；满分 10 分 |

### Q4 · 客户到底谁付钱、谁使用、决策链几层？（追问防御 / 行业纵深浅）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 不慌不硬编、给查证路径 ② 客户画像四要素拆开 ③ 区分付费方 / 使用方 / 拍板方 ④ 引一条真实来源 |
| 追问链 | L1 用的人还是买的人说了算？→ 企业采购常用的人没决策权；L2 痛点原话哪来的？→ W6 试用记录 / 公开访谈，禁止编引语；L3 没确定的部分怎么办？→ 说清边界与回哪类信源 |
| 失败答法 | 「应该是有需求的企业吧，大家都想降本增效，谁拍板没细究」——用「应该」糊弄、越追越空 |
| 参考答案要点 | 四要素 + 决策链至少三层 + 真实原话 + 未查实部分给路径；金句「给查证路径比编一个答案更得分」 |
| 评分表 | ①3 分 ②2.5 分 ③2.5 分 ④2 分；满分 10 分；硬编引语扣 3 分 |

### Q5 · 简历里那条行业洞察，哪条是你自己查证过的？来源是什么？（项目深挖 / 真实性）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 点名具体条目与具体来源 ② 区分一手 / 二手并说明取舍 ③ 承认「以最新公开报告为准」边界 ④ 现场可复述来源内容 |
| 追问链 | L1 官方原文还是二手解读？→ 政策回官网；L2 发布时间与口径？→ 报告标时间、规模不口播；L3 现在还能打开对上吗？→ 现场回访，打不开不计入 |
| 失败答法 | 「都是我查的，具体哪个链接记不清了」——无法举证，坐实百科摘抄 |
| 参考答案要点 | W6 试用记录（一手）+ 竞品官网定价页 + 政策回官网原文；随手挑一条能报出来源、时间、可否回访 |
| 评分表 | ①3 分 ②2.5 分 ③2 分 ④2.5 分；满分 10 分 |

### Q6 · 面试官说「你说的百科上都能查到」，你怎么接？（行为 / 压力追问）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 不辩解、先认同再转折 ② 从「知道什么」转到「判断什么」③ 举一条「对产品意味着什么」的转化 ④ 给可核验的下一步 |
| 追问链 | L1 你的判断和百科差在哪？→ 百科给定义，我给意义与差异位；L2 举个自己的结论？→ 差异位 + 护城河；L3 怎么证明不是背的？→ 现场打开来源、向外行复述 |
| 失败答法 | 「不会啊，我查了很多资料，您没听明白我再背一遍」——防御性辩解 + 重复罗列 |
| 参考答案要点 | 认同 → 转折到判断层 → 举产业链星标 / 竞品末行差异位 → 现场复述；金句「面试聊深度不聊广度」 |
| 评分表 | ①3 分 ②2.5 分 ③2.5 分 ④2 分；满分 10 分；出现辩解扣 2 分 |

### Q7 · 行业政策 / 合规变化，对你做产品意味着什么？（场景设计 / 合规）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 不编具体条款、先讲查证口径 ② 政策清单三列 ③ 只认官方原文、二手仅线索 ④ 产品动作标「教学示例」、按赛道分别查、不套用 |
| 追问链 | L1 原文还是解读？→ 官网原文；L2 具体怎么影响功能？→ 讲「意味着什么」一行、不编条款号；L3 不同赛道适用点一样吗？→ 教育 / 金融 / 出海分别查 |
| 失败答法 | 「国家出台 ×× 法第 × 条，要求所有 AI 产品必须 ××」——编造条款号，一追就穿，硬伤 |
| 参考答案要点 | 三列清单 3–6 条 + 回到原文逐条核对 + 不同赛道分别查；具体条款标「教学示例，以官方原文为准」 |
| 评分表 | ①3 分 ②2.5 分 ③2.5 分 ④2 分；满分 10 分；编造条款号直接扣 3 分并判硬伤 |

### Q8 · 你还没确定就业方向，为什么投我们这个行业？（行为题，呼应 4/6 方向未定）

| 项 | 内容 |
|---|---|
| 踩分点 | ① 坦诚未定但不随意 ② 用「一页速写」试选过若干候选行业 ③ 给可核验理由（客户 / 场景 / 来源，不编数据）④ 把六件套可复用转成学习能力证明 |
| 追问链 | L1 试选过哪些、怎么比？→ 一页速写按客户与场景对读、不比规模；L2 方向不对怎么办？→ 六件套可复用、补课有流程；L3 兴趣从哪来？→ 引一条真实用户原声 |
| 失败答法 | 「还没想好，先投着试试，看起来挺有前景」——暴露海投、零了解 |
| 参考答案要点 | 试选之后的选择：能查到具体付费方与真实使用时刻 + 一条带来源原声；六件套对任何行业可复用、一周补到能聊深度 |
| 评分表 | ①2.5 分 ②3 分 ③2.5 分 ④2 分；满分 10 分 |

**第 4 层评分与处置**：8 题 × 10 分 = 80 分；≥64 分（80%）达标。两两模拟时把每题得分、追问记录与自评分填进 03-导学案《面试模拟记录表》≥4 行。任一题出现「编造数据 / 条款」判硬伤，需按失败答法回炉重答。

## 七、行业手册验收清单（四条硬标准，原「习题位」全文保留，对应板块当堂验收）

### 标准 1 · 六节齐备

| 项目 | 内容 |
|---|---|
| 达标线 | 产业链图 / 政策清单 / 竞品对比表 / 典型客户画像 / 核心场景清单 / 行业术语表，六节全部有内容，且每节末尾有「这对我主项目意味着什么」一行 |
| 核验方式 | 对照导学案六节模板逐节打勾；抽 2 节读末尾那行，写不出的视为该节未完成 |
| 未达标补救 | 缺哪节补哪节：产业链照 05 配图框架图三层口径重画；客户画像回到 W6 试用访谈记录提取原话；48 小时内补交 |

### 标准 2 · 竞品对比表 ≥3 行且有来源

| 项目 | 内容 |
|---|---|
| 达标线 | 不少于 3 个竞品，每行「产品名 / 目标客户 / 核心功能 / 定价模式 / 来源」五列齐全；来源为可回访的具体页面（官网定价页、帮助中心、应用商店页），并含自己主项目一行差异位 |
| 核验方式 | 随机抽 1 行，现场打开其来源链接，60 秒内能对上所述内容即通过；打不开或对不上的行不计入行数 |
| 未达标补救 | 来源失效的行替换为备用竞品重填；未写定价模式的，现场查竞品官网定价页补齐 |

### 标准 3 · 术语表 ≥15 条且非百科摘抄

| 项目 | 内容 |
|---|---|
| 达标线 | 不少于 15 条，每条含「使用例句（什么时候说、对谁说）」；例句须落在具体场合，直接粘贴百科定义或纯名词解释判不合格 |
| 核验方式 | 讲师随机抽 3 条，要求学员向「非本组同学」口头讲清这条术语什么场合用；3 条中 2 条讲不清即退回 |
| 未达标补救 | 讲不清的术语回炉：回竞品帮助中心或财报原文找该词的真实用法，重写例句后重新抽验 |

### 标准 4 · 核心场景 ≥5 个且含用户原声或截图佐证

| 项目 | 内容 |
|---|---|
| 达标线 | 不少于 5 个场景，每个一句话（谁 + 什么处境 + 用它完成什么）；其中至少 3 个附佐证——用户原声注明出处（W6 试用记录 / 应用商店评论），或附截图 |
| 核验方式 | 抽 2 个带佐证的场景核对出处；无佐证的场景数若超过 2 个，整节退回 |
| 未达标补救 | 佐证不足的，去应用商店评论区补采本赛道竞品的真实用户评价并注明链接；禁止自编原话 |
