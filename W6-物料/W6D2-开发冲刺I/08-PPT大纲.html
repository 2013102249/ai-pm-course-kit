7第 2 节小调查：你的链路现在卡在哪① 现场举手：输入 / 处理 / 输出，你到哪一步了 ② 收集 3–4 个答案 ③ 结论「今天只求这一条线通」 ④ 抛出问题：什么叫「跑通」破冰，无论答案是什么都接住；为「真」与验收线做铺垫无（纯互动页）
8第 2 节今天只做一件事：跑通核心链路（原页 2）① 核心链路 = 输入 → 处理 → 输出，一次完整走通 ② 一个「真」字：真输入 / 真调用 / 真输出，不搬数据、不写死假数据 ③ 不属于今天：样式 / 登录 / 支付 / 历史记录 ④ 纪律「先跑通，再完美」念一遍纪律：允许丑，不允许没跑通；点明「假链路路演现场必穿」《核心链路检查清单》（投屏主图）
9第 2 节三个检查点（到点打卡，原页 3）① CP1 第 165 分钟：输入可提交，后端日志能看到收到 ② CP2 第 180 分钟：模型调用通，拿到真实响应 ③ CP3 第 195 分钟：全链路串联 + 日志可见 ④ 都在第 4 节（150–200 min）实操时段宣布接龙规则：到点自己在群里打卡，不催；时点已对齐 300 分钟口径检查点时点胶囊（165 / 180 / 195 min，蓝底白字）
10第 2 节完成标准：可运行 / 可演示 / 日志可见（原页 4）① 可运行 = 连续提交 3 次不报错、不白屏 ② 可演示 = 真实输入真实输出、无手动搬数据 ③ 日志可见 = 能指出时间 / token / 耗时 ④ 5 条硬标准全过才算跑通；2 条软标准（降级 / 日志规范）决定合格 vs 良好三条逐条念，强调「假数据不算通」「软标准不卡通过」5 硬 2 软对照表（待制）
11第 2 节正面案例 + 反面案例（新增案例页）① 正面：按「输入 → 处理 → 输出」三步走、检查点提前打卡，路演当场演示真输入真输出 ② 反面：先改两小时按钮圆角与字体，后端没接、Key 没验证，点一下就报错 ③ 对照：赢在按检查点分段、每段有打勾动作 ④ 一句话：把「完美」排在「跑通」前面双案例对照讲，请一位学员用一句话说「翻车的学员把什么排在了什么前面」案例对照图（待制，05 登记）；左右分栏紫 / 灰

13第 3 节API 接入三步① Key 放进 .env，代码读环境变量不是明文 ② 用最小请求直连验证一次，看返回 200 且有内容 ③ 验证通过再写业务代码 ④ 原稿金句：「先用最小请求验证 Key，再写业务代码，顺序反了你能查一小时」巡场会挨个问「Key 配在哪」；写在代码里的当场改，顺一句安全纪律API 接入三步流程图（待制）
14第 3 节超时 / 重试 / 状态码：三棒接力① 超时 = 主动划的等待上限，到点不再等，是时间边界不是失败 ② 重试 = 限 1 次、带间隔、只对超时 / 429 / 5xx；401 / 403 不重试 ③ 状态码 = 200 / 401 / 404 / 429 / 5xx 给简短结论 ④ 三棒有先后：先超时，才触发重试，靠状态码判「值不值得再试」提问「401 和 429 哪个该重试、哪个不该」；具体超时数值写「待教务补充」三棒接力时间线图（待制）
15第 3 节降级四层① 第 1 层超时：加载态 +「正在为你处理」② 第 2 层重试：标明「正在重试」③ 第 3 层缓存复用：结果 +「当前为缓存结果」明示 ④ 第 4 层静态兜底文案：说明 + 稍后重试入口，不伪装成模型输出一层一层往下指；放慢讲第 4 层「必须明示是降级结果」，别滑到造假《API 降级四层图》（待制，05 登记）
16第 3 节Mock 与真实调用 + 日志字段① Mock 是开发期替身，验收必须换回真实调用 ② 写死假数据按硬标准 2 判「未跑通」③ 兜底不能拿 Mock 冒充降级结果 ④ 日志六字段：时间 / 模型名 / 输入长度 / token / 耗时 / 状态码把「真」字从原页 2 接回来；日志字段让学员当场抄进导学案Mock 对照卡 + 日志字段表（待制）
17第 3 节正反面案例（接口挂了）① 正面：模型侧频繁 429，产品侧没等研发，超时 + 重试 + 缓存 + 兜底四层齐上，用户几乎无感，靠日志很快定位限流 ② 反面：没超时、转圈到死，报错只弹「服务异常」，还拿写死假结果冒充模型输出 ③ 对照：赢在把「研发修根因」和「产品兜当下」分成两条线 ④ 讨论：接手翻车产品第一步做什么双案例对照讲，小组讨论 2 分钟收 2 组发言案例对照图（待制，05 登记）
18第 3 节深化：为什么 / 边界 / 常见误解 + 面试连接① 为什么降级由产品定：研发修根因、产品管根因没好之前用户有没有得用 ② 边界：降级≠关功能 / 报错 / 造假；Mock 只在开发期；重试只对可重试状态码 ③ 常见误解：超时当失败、重试当无限、状态码当日志、Mock 当降级 ④ 联调纪律「先分后合」⑤ 这段在面试里怎么答：分两条线 + 四层降级 + 状态码日志这是四种深化方式的落点页；放慢讲，与第 5 节题 2 直接呼应边界三档缩略 + 面试气泡（待制）
