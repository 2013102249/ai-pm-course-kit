### 随堂填写

**① 今天的核心链路是什么（原有表格，保留）**

| 项目 | 定义 |
|---|---|
| 核心链路 | 一次完整的「输入 → 处理 → 输出」：用户在页面提交一条真实输入，后端收到并调用模型 API，模型结果展示回前端 |
| 输入 | 用户在你的产品上完成的第一个有效动作：填一个表单、传一个文件、或点一个预设示例按钮 |
| 处理 | 后端收到输入后，组织提示词、调用模型 API、拿到返回结果（允许有一次重试） |
| 输出 | 模型结果以产品形态展示在前端：文本、卡片、列表或结构化字段均可，**必须来自真实调用** |
| 不属于今天 | 样式美化、注册登录、支付、历史记录、多模型切换——这些留给 W6D3 之后 |

**② 完成标准（原有表格，保留，放学验收口径）**

| 维度 | 标准 | 自检问题 |
|---|---|---|
| 可运行 | 服务常驻不崩：连续提交 3 次不报错、不白屏 | 「我能连续点 3 次都出结果吗？」 |
| 可演示 | 一条真实输入 → 真实输出，全程无手动搬数据；路演时可当场演示 | 「敢不敢现在投屏给全班看一遍？」 |
| 日志可见 | 每次调用的请求时间、模型名、token 消耗、耗时，能在控制台或调用记录里指出 | 「刚才那次请求，日志在哪？」 |

> 三条全过 = 跑通。缺任何一条 = 未跑通，按第 6 节补救路径执行。

## 附录：各节自测 3 题参考答案（做完再看，勿提前偷看）

> 用法：每节自测先自己写，再对这里的一句话答案；写不全的回对应节次补一遍。完整术语定义与生活类比见 `02-讲课稿.md` 第 1 节，完整面试题踩分点与 60 秒答法见第 5 节。

**第 1 节**：1. 不是。降级是换个方式把事办成（换一碗面端上来），报错 / 关功能是「什么都不给」；降级一定有兜底产出。2. 不是，超时是「我主动不等了」的时间边界，不是结果判定；先有超时这条线，才有后面重试的动作。3. Mock 是开发期顶真数据的替身，给流程用、验收要换回真调用；日志是给排查者回查的逐笔记录（时间 / 模型名 / token / 耗时 / 状态码），不给用户看。

**第 2 节**：1. 输入 → 处理 → 输出。中间手动搬数据或写死假数据，链路就不是「一次完整走通」，路演真人一点就穿；Mock 只能开发期用。2. 5 硬 = 输入真实 / 调用真实 / 输出可见 / 日志可见 / 连续稳定；2 软 = 降级策略 / 日志规范。软标准只决定「合格 vs 良好」，不卡通过。3. 不是取消，是排期：完美落在 W6D3（功能与体验、三态设计），今天先保跑通。

**第 3 节**：1. 不是失败，是时间边界；不先划这条线，页面就转圈到死，也没有「到点再试一次」的触发点，所以超时在重试之前。2. 429（限流）可重试、降频或等 1 分钟；401 / 403 不重试，那是凭证问题，该查 Key 与请求头 Bearer 前缀。3. 缓存复用是拿上一次真实结果顶上并明示「当前为缓存结果」；静态兜底是给一段写好的说明加稍后重试入口、不假装结果。两者都要明示是降级结果，不能伪装成模型刚算出来的输出。

**第 4 节**：1. CP2 = 拿到一次真实模型响应、调用记录能看到本次请求、Key 配在环境变量非代码明文；Key 进代码库等于把密码发群里。2. 不看本机 F12，看讲师投屏的状态码截图，把四类首查动作口述成 60 秒语音、由同伴代填卡点记录表。3. 错在降级是「换方式把事办成」，不是什么都不给；弹错是报错、关功能是停业，降级必须有兜底产出。

**第 5 节**：1. ① 用 CP1/CP2/CP3 把大工程拆成可打勾三段，否定「跟进 = 催进度」；② 验收标准提前公布、可判过不过（5 硬 2 软）；③ blockers 每条有责任人 + 状态 + 时限，当天清；④ 求助三级制 + 带排查记录提问。2. 最忌讳「被追就改口 / 自我推翻」；正确姿势是接住 → 认下 → 补一层。3. 研发修的是「根因什么时候好」，产品管的是「根因没好之前用户有没有得用」，两件事时间尺度不同；只做前者，用户就在中间真空里干等。

**第 6 节**：1. ① 核心链路只取输入、处理、输出三段，一个「真」字是地基；② 接口会挂，超时是时间边界、重试 1 次只对可重试状态码、降级四层要明示，联调先分后合；③ 做过的事要变成面试里的一句话，讲人话、被追不改口、用验收标准说话。2. 核心链路跑通记录、术语自测表、面试模拟记录表；文件名 `W6D2-核心链路跑通记录` / `W6D2-术语自测表` / `W6D2-面试模拟记录表`。3. 输入真实 / 调用真实 / 输出可见 / 日志可见 / 连续稳定；缺一条不算通过，进补救路径（指定责任人 + 当晚 21:00 前复查），不降标准、不判失败。
