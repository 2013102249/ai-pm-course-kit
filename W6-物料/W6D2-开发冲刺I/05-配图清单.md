## 二、《核心链路检查清单》制图规格（已制成，规格留存备查）

### 1. 整体结构（从上到下四段式）

| 区段 | 内容 | 视觉权重 |
|---|---|---|
| 标题区 | 「核心链路检查清单」+ 副标题「W6D2 开发冲刺 I · 今天只做一件事：跑通」 | 紫底白字横幅，占高约 12% |
| 链路区 | 三个大节点横排：输入 → 处理 → 输出，箭头连接；节点下方各挂 2–3 条检查点 | 核心区，占高约 40% |
| 检查点区 | 6 个勾选框条目（详见下表），每行左侧方框 + 右侧文字 | 占高约 30% |
| 底部纪律条 | 「先跑通，再完美 · 今天允许丑，不允许没跑通」+ 三个检查点时点（165 / 180 / 195 分钟，均在对应板块实操时段） | 蓝底白字条，占高约 8% |

### 2. 检查点表（图上文字，逐字采用，不得改写）

| 节点 | 检查点 | 勾选框状态 |
|---|---|---|
| 输入 | 能提交一条**真实输入**（非测试文本） | 空框 □ |
| 输入 | 用户操作 ≤3 步，或有「一键示例」 | 空框 □ |
| 处理 | Key 配在**环境变量**，非代码明文 | 空框 □ |
| 处理 | 拿到一次**真实模型响应**（调用记录可见） | 空框 □ |
| 输出 | 结果展示回前端，全程无手动搬数据 | 空框 □ |
| 输出 | **日志可见**：能指出本次请求的时间 / token / 耗时 | 空框 □ |

### 3. 勾选框设计规范

| 项目 | 规格 |
|---|---|
| 形状 | 圆角矩形（圆角 3px），尺寸 28×28px（按 1920 宽画布等比缩放） |
| 边框 | 2px 实线，主检查点用紫 #7C3AED，降级与日志相关点用蓝 #2563EB |
| 填充 | 白底；「已勾选」状态为紫底白对勾（对勾为矢量路径，非 emoji） |
| 交互（手持版） | 竖版手持图不做交互，打印后用笔手勾；投屏版由讲师现场用标注工具打勾 |
| 排版 | 检查点文字 24–28px，关键字（真实、环境变量、日志可见）加粗并着色 |

### 4. 链路区箭头与节点规范

| 元素 | 规格 |
|---|---|
| 节点 | 圆角卡片，紫 #7C3AED 描边、白底、紫字；三卡等宽横排 |
| 箭头 | 粗 4px 实线箭头，蓝 #2563EB；箭头中点可加一枚小圆点强调流向 |
| 节点下挂点 | 每节点下方 2–3 条小字检查点，灰 #4A4560，18–20px |
| 检查点时点 | 底部纪律条右侧三个时间胶囊：165min 输入 / 180min 调用 / 195min 串联，蓝底白字（本课版口径） |

### 5. 禁用项

- 禁用 emoji、卡通人物、渐变阴影堆砌；冲刺日物料要「像作战地图」，不像招生海报
- 禁用红色系（避免与「错误 / 警告」语义混淆，课堂纠偏用口头不用颜色恐吓）；仅板书里的七个「≠」允许用红笔，不进配图
- 图上不得出现具体品牌 Logo，模型相关一律文字表述
- 新增的术语卡、追问卡、时间轴图同样遵守以上禁用项

## 三、讲法脚本（讲师照读，与 02-讲课稿对应板块宣讲段对应）

| 时机 | 动作 | 讲法要点 |
|---|---|---|
| 宣讲开场（对应板块） | 手指标题区 | 「今天只做一件事，就这六个字——跑通核心链路。其他事，一律不让它进门。」 |
| 过链路区 | 手指沿三个节点走一遍 | 「输入、处理、输出。你的项目再复杂，今天也就是这三个盒子。复杂的留到周五之前，今天只求通。」 |
| 过检查点区 | 逐条念，念到关键字放慢 | 「注意三个加粗的词：真实、环境变量、日志可见。这三条是硬标准，不是建议。写死数据的不算，Key 写代码里的当场改，日志指不出的不算通。」 |
| 到底部纪律条 | 停顿 2 秒 | 「这句话今天说三遍也不多：先跑通，再完美。允许丑，不允许没跑通。」 |
| 宣讲收尾 | 切到检查点时点 | 「165 分钟输入，180 分钟调用，195 分钟串联——都在对应板块实操时段。到点群里打卡，不用我催。」 |
| 对应板块巡场前（本课版补） | 切到实操任务三段图 | 「A 打勾、B 看状态码、C 写降级，做完一段勾一段；手机和平板的同学看结对替代动作，不让设备变成门槛。」 |
