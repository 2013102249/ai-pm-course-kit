# PPT 大纲 · W6 周二《开发冲刺 I：核心链路》

> 共 8 页 · 90 分钟 · 任务说明型 PPT：本课 PPT 只承担「宣布规则」职能，不承担知识讲解。
> 设计规范：白底 + 紫色 #7C3AED 主色 / 蓝色 #2563EB 辅色 + 左上角课程 Logo + 右下角页码；每页要点 ≤6 行。
> 使用方式：开场 10 分钟过完前 5 页即切走，后 3 页在检查点宣布时切回；每页停留 1–2 分钟，禁止逐页念。

| 页 | 标题 | 内容要点 | 讲师提示 | 配图 / 交互 |
|---|---|---|---|---|
| 1 | 封面：开发冲刺 I · 核心链路 | 课程名 + 周次（W6D2）+ 讲师名 + 一行定位「冲刺日：讲授让位于实操」 | 口播今天唯一目标：核心链路跑通 | 封面图（核心链路检查清单缩略） |
| 2 | 今天只做一件事：跑通核心链路 | 输入 → 处理 → 输出定义；不属于今天的事（样式 / 登录 / 支付 / 历史记录）；纪律「先跑通，再完美」 | 念一遍纪律：允许丑，不允许没跑通 | 核心链路检查清单（投屏主图） |
| 3 | 三个检查点（到点打卡） | CP1 第 40 分钟：输入可提交；CP2 第 70 分钟：模型调用通；CP3 第 80 分钟：全链路串联 + 日志可见 | 宣布接龙规则：到点自己在群里打卡，不催 | 检查点时点胶囊（40 / 70 / 80 min） |
| 4 | 完成标准：可运行 / 可演示 / 日志可见 | 可运行 = 连续 3 次不报错；可演示 = 真实输入真实输出无搬数据；日志可见 = 能指出时间 / token / 耗时 | 三条逐条念，强调「假数据不算通」 | 三条标准对照表 |
| 5 | 求助三级制（纪律同纪律） | L1 自查 5 分钟 → L2 举手叫助教（3 分钟到场）→ L3 升级讲师（带排查记录） | 强调：讲师只收「已排查过」的问题 | 三级阶梯图 |
| 6 | 三个最常卡住的点 | 环境配置 / API 密钥 / 联调 CORS 与权限；每类给一句首查动作 | 只讲索引，完整步骤在教案里，让学员自己翻 | 三类卡点速查表 |
| 7 | Blockers 清算（80–90 分钟切回） | 已跑通现场演示；未跑通指定责任人 + 今晚 21:00 复查；明日预告 W6D3 | 收尾时切回本页，逐条过卡点记录表 | 卡点记录表投屏 |
| 8 | 带走三句话 | 「冲刺日的对手不是技术，是完美主义」；输入要真、Key 进环境变量、日志必须可见；明天三态设计见 | 让学员跟着念第一句，放慢语速 | 无（文字收束页，紫底白字） |

## PPT 制作备注

| 项目 | 规范 |
|---|---|
| 母版 | 白底 + 左上角紫色课程 Logo + 右下角页码；页 8 用紫底白字全屏收束页 |
| 标题字 | 32–36px 加粗；正文 20–24px；一页不超过 6 个要点行 |
| 强调色 | 检查点时点用蓝色胶囊；纪律句（第 2、8 页）用紫色加粗；降级与日志相关点用蓝色 |
| 交互页 | 本课无交互工具页；第 2 页起直接用《核心链路检查清单》配图投屏，PPT 不放重复内容 |
| 动画 | 仅「淡入」；检查点宣布页（第 3 页）不加动画，避免计时干扰 |
| 使用纪律 | 前 5 页开场 10 分钟内过完即切走；后 3 页仅在检查点宣布与收尾时切回，总投屏时长 ≤12 分钟 |
