## 图 1 · 路演评分标准图（已制成，本课唯一新制图）

### 1.1 规格总览

| 项目 | 规格 |
|---|---|
| 文件名 | 路演评分标准图.svg（导出 PNG 1920×1080 供投屏，A3 打印版供评委席） |
| 尺寸比例 | 16:9（投屏版）；A3 竖版（评委席打印版） |
| 品牌色 | 主色紫 #7C3AED，辅色蓝 #2563EB；三档描述分别用紫 / 蓝 / 灰区分（优秀紫、良好蓝、合格灰） |
| 字体 | 标题加粗，正文 20–24px（投屏可读）；中文标注，无错别字 |
| 信息量 | 四维 + 三档 + 留言区示意，不超过一屏；拒绝小字堆砌 |

### 1.2 构图设计（左表右雷达）

| 区域 | 内容 |
|---|---|
| 标题条（顶部） | 「路演评分标准 · 四维各 25 分 · 总分 100 · 75 分通过」 |
| 左侧主区（约 60% 宽） | 四维评分表格：演示效果 / 数据支撑 / 思考深度 / 答辩表现，每维三档描述（与导学案评分表逐字一致，保证「图、表、宣讲」同源） |
| 右侧辅区（约 40% 宽） | 四维雷达示意：以满分轮廓（100% 处虚线）为参照，示意「优秀项目」与「合格项目」两条轮廓线，无真实数据，仅示意形状 |
| 底部通栏 | 评委留言区示意：三个横线框，分别标注「最大的亮点」「最需要改进的一点」「一句行业建议」+ 右下角「企业嘉宾面试意向：值得深聊 / 待定 / 暂不」 |
| 角落信息 | 左下角小字：「评委构成：讲师 + 往期学员 + 企业嘉宾；去最高最低取平均」 |

### 1.3 三档描述文案（图中文字，与 03-导学案评分表一致）

| 维度 | 优秀 22–25 | 良好 18–21 | 合格 15–17 |
|---|---|---|---|
| 演示效果 | 主流程 5 分钟完整跑通，节奏有设计 | 跑通但节奏前松后紧或路径绕 | 有明显卡顿跳步，靠讲解弥补 |
| 数据支撑 | ≥10 人试用 + 前后对比 + 用户原声 | 有数据但缺对比或缺原声 | 只有演示没有试用数据 |
| 思考深度 | 说清一次取舍及理由，反思到环节 | 取舍理由笼统，反思停在表层 | 只讲做了什么，无取舍无反思 |
| 答辩表现 | 结论先行，不会的说「不知道」+ 验证思路 | 能答但结构松，偶有防御辩解 | 答非所问、回避或争辩 |

> 制图注记：表格内三档文字用短句，每格 ≤2 行；图中另放一行小字「完整三档描述见评分表（导学案）」，避免图中文字过挤。

### 1.4 讲法脚本

- **讲法**：宣讲第二块「怎么评」时投屏本图。先指标题条讲通过线与去分规则；再从左到右逐维指读，每维只念三档的第一句差异（如演示维度：「跑通且有设计」是优秀，「跑通了但绕」是良好，「卡顿跳步」是合格）；然后指右侧雷达示意：「这不是今天的数据，是形状示意——优秀的项目四维都撑开，偏科的项目总有一维塌回去」；最后指底部留言区：「这三位评委每人写三句，颁奖时我念给你们听。」
- **提问点**：「四维里哪一维最容易被忽略？」（预期：数据支撑）
- **关键动作**：讲到「数据支撑」一维时，手势在图上停留 5 秒——这是全场最重要的一维。
- **复用场景**：颁奖前（约 70 分钟）复现本图 10 秒，对照评分结果讲一句「分数都来自这张表，没有人情分」。
