## 第 0 层 · 术语辨析（12 题，含选择 / 连线 / 改错 / 简答四种题型）

> 对应第 1 节术语精讲，建议 10 分钟当堂完成。总分 12 分，≥10 分为术语达标。

### 一、单项选择题（4 题，每题 1 分）

**0-1** 下列关于「总包」的说法，正确的是（　）
A. 总包就是月薪乘以 12
B. 总包是一份录用通知里全部报酬构成，月薪只是其中一项
C. 总包等于年薪，只算现金
D. 总包只含期权和签字费

**0-2** 关于「期权」，正确的是（　）
A. 期权是这个月能直接花掉的现金
B. 期权一到手就等于公司股票资产
C. 期权是未来按约定条件获得公司股权的权利，有归属期与行权条件
D. 期权和奖金是同一回事

**0-3** 「结营」的准确含义是（　）
A. 课程和求职支持全部结束
B. 只指颁发结业证书那一个动作
C. 课程授课结束、就业追踪正式开始的节点
D. 等于毕业，之后再无周报

**0-4** 「漏斗周报」的固定节奏是（　）
A. 拿到 offer 时写一次
B. 每天写一次日报
C. 结营后每周五提交、连续 3 个月
D. 只在卡住时才写

### 二、连线题（2 题，每题 2 分，错一连扣 1 分）

**0-5** 把「谈薪四步」与对应动作连线：

| 左栏 | 右栏 |
|---|---|
| ① 探区间 | A 报区间、锚上沿、带依据 |
| ② 给锚点 | B 不当场答应也不当场拒绝，给时间窗 |
| ③ 谈总包 | C 先问岗位带宽，先问再答 |
| ④ 留余地 | D 确认月数、签字费、期权、公积金基数、调薪节奏 |

**0-6** 把「术语」与「最容易混的邻居」连线：

| 左栏 | 右栏 |
|---|---|
| ① 底线卡 | A 一次性报价 |
| ② 谈薪节奏 | B 满意值 / 三值本身 |
| ③ offer 比较 | C 凭感觉选 / 只比钱 |
| ④ 入职准备 | D 入职后适应 / 背调 |

### 三、改错题（3 题，每题 1 分，改对得 1 分）

**0-7** 改错：「底线值就是我最想要的那个数。」
**0-8** 改错：「谈薪就是把月薪这个数字尽量往上抬。」
**0-9** 改错：「口头 offer 和书面 offer 都算正式承诺，先辞职没关系。」

### 四、简答辨析题（3 题，每题 1 分）

**0-10** 用一句话说清「总包」与「月薪」的区别，并列出至少 3 项总包构成。
**0-11** 「结营 / 校友机制 / 漏斗周报」三个词怎么连成一条线？
**0-12** 「放大亮点」和「虚构事实」的线在哪？对应哪条红线？

## 第 1 层 · 基础巩固（5 题）

> 对应第 2 节谈薪原理与第 3 节背调入职，建议 12 分钟。每题 4 分，总分 20 分，≥14 分达标。

**1-1** 按顺序默写谈薪四步，并标出哪两步「不是在抬价」。
**1-2** 三情境（心里有数 / 没底 / 被压价）各自的「第一动作」是什么？
**1-3** 被压价时，还价最多几次？到哪条线收场？为什么要「先确认总包构成」？
**1-4** 口头 offer 与书面 offer 的区别是什么？「留余地」话术给的 24–48 小时用来做哪两件事？
**1-5** 背调与入职准备：写出「履历真实性」红线的后果，并列出入职前 30 天四件事。

### 第 1 层 · 参考答案与评分标准

| 题号 | 参考答案 | 评分标准 |
|---|---|---|
| 1-1 | ①探区间 ②给锚点 ③谈总包 ④留余地；「谈总包」「留余地」两步不是抬价，是把信息问全、把决定权拿回 | 四步顺序 2 分（错一步扣 0.5）；标对两步 2 分 |

## 第 4 层 · 面试实战（8 题，每题含踩分点 / 追问链 / 评分表）

**4-1 ·「你期望薪资是多少？」**（场景设计 / 谈薪对话）

| 项目 | 内容 |
|---|---|
| 踩分点 | ① 不先报具体数字、先反问带宽 ② 报区间非单点且带一条依据 ③ 主动引到总包构成 ④ 给明确答复时间窗、不当场定 |
| 追问链 | 一层「先说个具体数」→坚持探一次转没底情境；二层「跨度有点大」→上沿理想值、下沿满意值、给依据；三层「今天能定吗」→留余地给答复日 |
| 典型失败答法 | 脱口报一个具体数字 /「随便看公司安排」；失分在把锚点送人，4 条踩分点 0 命中 |
| 参考答案要点 | 先探区间 → 带依据报区间 → 确认总包（月数 / 签字费 / 期权 / 公积金基数 / 调薪节奏）→ 周四前答复；含术语谈薪节奏 / 总包 / 底线卡 / 期权 |
| 评分表 | 不合格 1：报具体数或放弃探区间；合格 3–4：先探 + 带依据 + 留余地，接住一层；优秀 5：四条全中 + 主动引总包 + 两层不乱 |

---

**4-2 ·「这个数超我们预算了，能不能降一点？」**（场景设计 / 谈薪对话）

| 项目 | 内容 |
|---|---|
| 踩分点 | ① 不立刻还价、先确认总包构成 ② 带依据还价一次 ③ 给替代方案留台阶 ④ 还价最多两次、压到底线值收场 |
| 追问链 | 一层「月薪没空间」→转谈总包其他项；二层「最低能接受多少」→不报新单点、守底线卡；三层「先证明一下」→把还价挂到项目价值上 |
| 典型失败答法 | 「那再低一点也行」或「低于这个数免谈」；连让无依据 / 把价值沟通变对抗 |
| 参考答案要点 | 先确认总包（说不定整体不低）→ 替代方案（签字费 / 调薪评审 / 转正节奏）→ 用结果说话 → 到底线值坦诚收场 → 核对书面再答复；含术语总包 / 期权 / 底线卡 / 谈薪节奏 |
| 评分表 | 不合格 1：立刻让价或语气变硬；合格 3–4：先问总包 + 一次带依据还价 + 替代方案；优秀 5：四条全中 + 守住底线卡 + 两层不乱 |

**4-3 ·「你怎么理解一个 offer 的『总包』？除了月薪还看什么？」**（技术理解 / 概念）

| 项目 | 内容 |
|---|---|
| 踩分点 | ① 说清总包 ≠ 月薪 ② 列全构成 ③ 点出期权非当期现金、有归属与行权条件 ④ 落到「只比月薪会看走眼」 |
| 追问链 | 一层「12 薪和 16 薪差在哪」→月数放大现金基数；二层「期权能算进这个月到手吗」→不能、未归属未行权非到手资产；三层「怎么核实」→一切以书面条款为准 |
| 典型失败答法 | 「总包就是一年挣多少，跟月薪差不多」；混淆总包与年薪 / 月薪，漏非现金与未来项 |
| 参考答案要点 | 月薪 × 月数 + 签字费 + 期权 / 股票 + 补贴 + 公积金基数 + 调薪节奏；区分期权；书面为准；含术语总包 / 期权 / 谈薪节奏 |
| 评分表 | 不合格 1：等同月薪；合格 3–4：列全构成 + 区分期权；优秀 5：四条全中 + 三层追问全接住 |

**4-4 ·「你手里同时有几个机会，怎么选？」**（项目深挖 / 场景设计，offer 选择）

| 项目 | 内容 |
|---|---|
| 踩分点 | ① 不凭感觉、不只看钱 ② 给四维与权重 ③ 权重按个人处境设定 ④ 矩阵只做筛选、终审回到书面条款 |
| 追问链 | 一层「权重凭什么」→按处境（升职级加成长 / 现金流加薪资）；二层「算完一定听吗」→不，筛选与终审之分；三层「条款差不多呢」→回到长期成长，必要时用漏斗周报持续看 |
| 典型失败答法 | 「哪个给得多去哪个」/「感觉 B 氛围好」；纯凭感觉或只比钱，无可复核依据 |
| 参考答案要点 | 四维（薪资 / 成长 / 行业 / 团队）× 个人权重 × 1–5 打分 → 加权分做第一轮筛选；终审看书面职级 / 试用期 / 调薪条款；含术语 offer 比较 / 总包 / 漏斗周报 |
| 评分表 | 不合格 1：只比钱或凭感觉；合格 3–4：给四维权重 + 说明因人而异；优秀 5：四条全中 + 点明筛选非终审 + 两层不乱 |

**4-5 ·「上一轮面试你哪里最弱，这次改了什么？」**（行为题 / 二轮改进）

| 项目 | 内容 |
|---|---|
| 踩分点 | ① 说清具体薄弱题型（改进清单标红）② 说清改的动作而非感受 ③ 可核验证据（二轮评分 / 追问层级 +1）④ 承认仍存点并给下一步 |
| 追问链 | 一层「拿什么证明」→二轮评分对比、追问防御 +1；二层「怎么练的」→按标红题型各挑两题写 60 秒框架、结对重答；三层「还剩什么」→如实说一个卡点接追踪期加练 |
| 典型失败答法 | 「我更自信了，成长了很多」；只有感受、无动作无证据 |
| 参考答案要点 | 标红题型（项目深挖 / 数据题）+ 三动作（框架 / 互面重答 / 同表复测）+ 证据（层级 +1）+ 剩余点入加练；呼应「改进清单是得分地图」、漏斗周报 |
| 评分表 | 不合格 1：只讲感受；合格 3–4：给题型 + 动作 + 一项证据；优秀 5：四条全中 + 承认剩余点 + 两层不乱 |

**4-6 ·「我们做背调，你简历里这个项目，具体你负责哪部分？」**（行为题 / 压力，履历真实性）

| 项目 | 内容 |
|---|---|
| 踩分点 | ① 如实说明负责边界 ② 区分「参与」与「主导」不夸大 ③ 说清放大亮点与虚构事实的线 ④ 点出红线后果 |
| 追问链 | 一层「数据是你产出的吗」→如实区分自己做 / 协作 / 引用；二层「参与写成主导呢」→明确越线、背调一查就穿；三层「简历怎么还写得亮」→措辞可优化、事实不动 |
| 典型失败答法 | 把「参与」说成「主导」或含糊「基本都是我做的」；踩履历真实性红线，一票否决级 |
| 参考答案要点 | 负责调研与 PRD 主笔、MVP 为协作验收；线在事实是否真实存在；后果 offer 作废 / 解除合同；相关复盘文档留档；含术语入职准备 / PRD / MVP |
| 评分表 | 不合格 1：夸大或含糊；合格 3–4：如实说边界 + 区分参与/主导；优秀 5：四条全中 + 主动讲红线 + 三层不乱 |

**4-7 ·「口头 offer 今天能不能定？现在就答复我们。」**（场景设计 / 谈薪对话，留余地）

| 项目 | 内容 |
|---|---|
| 踩分点 | ① 不当场答应也不当场拒绝 ② 说清口头是意向、书面才是承诺 ③ 给 24–48 小时明确时间窗与答复日 ④ 说明窗口用途（核对条款 + 知会其他流程） |
| 追问链 | 一层「今天定再申请一点」→收下好意不当场承诺；二层「一两天干什么」→核对构成 / 职级 / 试用期 / 入职日 + 知会其他流程；三层「是不是在等别家」→坦诚统一窗口、体现职业做法 |
| 典型失败答法 | 「好，现在就答应」或「再考虑考虑」却给不出时间；前者可能冲动辞职，后者不专业 |
| 参考答案要点 | 不当场定 → 口头 vs 书面 → 周四前答复 → 窗口两用途 → 收下好意不承诺；含术语谈薪节奏 / 留余地 / 总包 / offer 比较 |
| 评分表 | 不合格 1：当场答应或无时间窗；合格 3–4：不当场定 + 给时间窗 + 说清书面才算；优秀 5：四条全中 + 三层追问全接住 |

| 项目 | 内容 |

### 验收补充说明（原文保留）

**1. 二轮评分提升（对应 W8D4–W8D5 闭环）**
- 评分表与一轮完全相同，保证可比性；
- 「定向」落实情况一并核对：二轮题目是否来自一轮改进清单标红题型（面试官在复盘表中留痕）；
- 特殊情况处理：若学员一轮分数已接近满档，二轮以「追问防御层级 +1」作为提升标准（一轮接到第一层追问，二轮须接到第二层）。

**2. 谈薪四步脱稿**
- 抽测时讲师演 HR，学员演求职者，只给情境不给提示；
- 判定口径：四步顺序不乱、关键动作（先探再报 / 留余地）不缺即为通过，话术不要求逐字背诵；
- 未通过者：当场重演一轮，仍未通过则记入 3 个月追踪期首个加练项，由就业服务组两周内补测。

**3. offer 决策矩阵**
- 常见错误与退回标准：权重合计不足或超过 100%、加权分未实算、结论只写公司名不写理由——三种情况任一退回重填；
- 学员尚无多个真实 offer 属正常情况：允许用「目标岗位的理想 offer vs 现实 offer」作为 A/B 演练对象，方法迁移即可。

**4. 就业追踪漏斗**
- 当天未投递任何简历的学员，已投递数可填 0，但方向、城市、层级三字段必须真实填写；
- 漏斗建档是 3 个月追踪期的起点档案，缺失者由就业服务组在 48 小时内电话补齐。

### 结营日不做的事（教研备注 · 原文保留）

1. 不布置新知识作业——今天之后只有求职动作，没有课程作业；
2. 不做排名公示——二轮分数只做个人前后对比，不做学员间横向排名；
3. 不把「验收未过」与结业证书挂钩——证书按综合评定发放，四项验收未过项转入 3 个月追踪期补测，不影响结营仪式的情绪完整性。

> 300 分钟版补充：上述「不布置新知识作业」指不再新增课后作业；第 1–5 节的 5 层习题均为**当堂完成**的验收性练习，第 6 节新增的「术语小测补测 / 积木归档 / 面试模拟记录」同属当堂验收，不占课后时间。数据口径一律「待教务补充」。
