# 交互使用说明 · W8 周五《模拟面试 II + 谈薪 + 结营》

> 本课**无专用交互网页**——结营日所有环节都是人与人面对面的现场动作，投屏只承担计时、配图与数据展示。
> 本文件替代交互页说明，写「结营日现场组织方案」：轮转规则、配对演练、仪式流程、3 个月追踪执行细则与情绪节奏控制。开课前请班务组对照「课前检查」逐项确认。

## 一、课前检查（开课前 30 分钟）

| 检查项 | 操作 | 责任人 |
|---|---|---|
| 场地分组 | 教室摆成两人一组的对坐位，组间距拉开，避免互面时互相干扰 | 班务组 |
| 计时器 | 投屏打开计时器，预置 13 分钟 / 8 分钟 / 4 分钟三档，试响一次 | 讲师 |
| 定向题卡 | 按组数打印五类薄弱题型题卡（项目深挖 / 场景设计 / 技术理解 / 数据 / 行为开放） | 班务组 |
| 证书与推荐信 | 按学员名册核对数量与姓名拼写；优秀学员推荐信单独装袋 | 班务组 |
| W8D4 改进清单 | 确认每位学员已带改进清单 V1，未带者由助教提供电子版 | 助教 |
| 合影物料 | 横幅或投屏结营页就位；确认摄影师 / 指定拍照学员 | 班务组 |

## 二、二轮定向模拟：轮转与定向规则（5–35 min）

### 轮转组织

| 时间 | 动作 | 组织要点 |
|---|---|---|
| 0–3 min | 规则宣讲 + 配对 | 两人一组（尽量与一轮互面不同的搭档），各自圈出对方标红题型 |
| 3–16 min | 轮次一：A 面 B | 面试 8 min（只问定向题卡 + 至少两层追问）→ 复盘 4 min（面试官先说观察）→ 换位定向确认 1 min |
| 16–29 min | 轮次二：B 面 A | 同构，计时器重置 |
| 29–30 min | 收束抽点 | 抽 1–2 人说「二轮比一轮好在哪」 |

### 定向规则（三条，宣讲时贴在投屏上）

1. **只问定向题**：题目必须来自被面者改进清单标红的薄弱题型，通用寒暄题不计入 8 分钟；
2. **追问至少两层**：「第一层答完 → 为什么 → 数据或取舍在哪」；
3. **复盘三问**：哪题稳了 / 哪题还卡 / 卡题现场重答一遍。

### 讲师巡场动作

- 每轮至少抽听 2 组，每人累计观察 ≥3 分钟；
- 发现敷衍互面（只问不追问、复盘只说「挺好」），当场介入示范一层追问；
- 记录 2–3 个「进步样本」，收束抽点时点名使用。

## 三、谈薪演练配对规则（49–59 min）

### 配对方式

延续上一环节的两人组，一人谈一人演 HR，四步各演练一轮，每轮约 2.5 分钟，两轮后互换角色。

### HR 角色卡（发给学员或投屏展示）

| 阶段 | HR 的标准动作 |
|---|---|
| 探区间时 | 「你先说你的期望。」（测试对方能否坚持先探） |
| 给锚点时 | 「X 到 Y 跨度有点大。」（测试对方能否守住锚点并给依据） |
| 谈总包时 | 「月薪就是全部了。」（测试对方能否礼貌追问总包构成） |
| 留余地时 | 「今天定的话我可以再申请一点。」（测试对方能否顶住当场承诺的压力） |

### 演练纪律

1. 每轮结束 HR 给一句真实反馈，禁止只说「不错」；
2. 求职者四步可换措辞，但「先探再报」「留余地」两个动作缺一不可；
3. 出现「语气变硬」「当场松口」，讲师喊停并现场示范纠正话术。

## 四、结营仪式流程（80–90 min）

| 顺序 | 时长 | 内容 | 执行细节 |
|---|---|---|---|
| 1 | 2 min | 成绩回顾 | 投屏数据页：40 次正课 / 主项目五里程碑 / 人均题库 ≥40 问 / 两轮模拟面试；数字真实，不夸大 |
| 2 | 4 min | 颁证 | 逐人叫全名 + 一句个人化评语（提前从各周 Rubric 摘）；优秀学员另发企业推荐信并单独介绍 |
| 3 | 2 min | 校友机制宣布 | 校友群长期保留 / 内推持续开放 / 资源包每年更新 / 下期路演可回任评委 |
| 4 | 1 min | 就业追踪说明 | 3 个月追踪期；每周五漏斗周报；就业服务组每周回访 |
| 5 | 1 min | 寄语与合影 | 寄语 ≤60 秒；合影前留 10 秒情绪空间 |

## 五、3 个月就业追踪机制执行细则

### 周报格式（每周五校友群接龙提交）

| 字段 | 填写说明 |
|---|---|
| 本周投递数 | 新投递公司数 |
| 进入面试数 | 约到面试的流程数 |
| offer 数 | 口头 / 书面分开写 |
| 当前卡点 | 一句话：简历 / 面试 / 谈薪 |
| 需要的支持 | 简历诊断 / 面试加练 / 谈薪陪练 / 内推 |

### 回访节奏

| 层级 | 节奏 | 动作 |
|---|---|---|
| 投递层 | 每周回访 | 简历诊断一次，对照投递清单调整方向 |
| 面试层 | 每周回访 + 面试前 48 小时一次 | 面试加练：按目标公司题型定向陪练 |
| offer 层 | 触发式（24 小时内响应） | 谈薪陪练 + 书面 offer 条款核对提醒 |
| 已入职 | 第 1 个月末一次 | 入职适应回访 + 邀请反哺校友机制 |

### 内推持续开放

- 合作企业内推渠道对校友长期开放，简历直推 HR；
- 内推请求按周报「需要的支持」字段触发，收到后 3 个工作日内匹配；
- 校友成功入职后，鼓励反哺：提供岗位信息、回校分享或担任下期评委。

## 六、情绪与节奏控制

| 场景 | 控制动作 |
|---|---|
| 二轮互面氛围松散 | 讲师提高介入频率：示范一层追问比讲十分钟规则有效 |
| 谈薪演练普遍紧张 | 全班齐读一遍探区间话术「热嘴」，先出声再上场 |
| 颁证环节冷场 | 评语提前写好逐人卡片，讲师绝不现场即兴发挥 |
| 结营情绪低落 / 不舍 | 用机制回应情绪：校友群、内推、周报——「不是散伙，是换一种方式同行」 |
| 个别学员求职焦虑外溢 | 课后单独 10 分钟一对一，按漏斗层级给具体下一步动作，不当众讨论 |
| 时间告急 | 优先压缩背调环节细节（结论已在导学案），仪式五步不可压缩 |
