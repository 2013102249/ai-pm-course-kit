# 交互使用说明 · W8 周三《高频题精讲 II》（无专用交互页 · 说人话训练环节组织方案）

> AI 产品经理就业训练营 · 第八周第三天 · 300 分钟（6 课时 × 50 分钟）· 交互使用说明
> 本课不设专用交互页——本课的「教具」是学员的嘴和手机录音。本文件说明第 2 节「说人话实战训练」（原有环节二）的组织方法，以及贯穿 6 节的计时与录音规则。
> 定位说明：本课属面试训练课，训练对象是「口头表达」而非「网页操作」，故按 W5D2 先例采用「无专用交互页 + 现场组织方案」口径；300 分钟版另补《6 节使用时机表》与《设备要求表》，保证手机 / 平板 / 电脑三档学员全程可执行。

## 一、环节目标与流程

| 项 | 内容 |
|---|---|
| 环节 | 第 2 节 · 说人话实战训练（50–100 min 节内，约 8 分钟；原有环节二） |
| 任务 | 把 RAG 用 30 秒讲给「完全不懂技术的人」听 |
| 产出 | 每人导学案上写下自己的 30 秒版；被抽中学员接受全班三问点评 |
| 流程 | 规则宣布 1 min → 首轮抽 2 人作答 + 点评 4 min → 讲师标杆版 1.5 min → 全员改写 1.5 min |

## 二、随机抽人规则

| 规则 | 操作 |
|---|---|
| 基础规则 | 按导学案页脚「学员代号 + 手机尾数」排序，讲师用手机随机数生成器（或让学员报一个 1–100 的数字）取模定位 |
| 公平性 | 每人本轮最多被抽 1 次；被抽过的代号划掉，下轮不重复 |
| 防逃避 | 不接受「我不会」弃权——可降级为「先说结论一个词」，说完再补；全课零弃权 |
| 线上班适配 | 直播间用连麦抽人：助教按评论区楼层号取模点名，未连麦者视为弃权处理一次警告 |
| 心理安全 | 抽人前宣布：「今天练的每一问，都是面试官下周要问的；现在卡壳成本为零，面试现场卡壳成本是 offer」 |

## 三、30 秒计时规则

| 项 | 规则 |
|---|---|
| 计时工具 | 讲师手机秒表投屏（或请一名学员担任「计时员」，锻炼参与感） |
| 起止判定 | 学员说出第一个字开始计时；说「答完了」或 30 秒铃响结束 |
| 超时处理 | 到 30 秒立即打断，话术：「时间到——注意，这就是面试现场。超时的答案不是加分，是扣分。」 |
| 严重不足（<10 秒） | 不判失败，追问一句「你的取舍呢？」引导补第三步；此过程计入选答时长 |
| 记录 | 助教记录每人用时（超时 / 达标 / 不足三档），课后发群，周四模拟面试 I 对照改进 |

## 四、点评维度（三问，全班参与 + 讲师收口）

学员答完后，先让全班用三问点评，讲师最后 30 秒收口定级。

| # | 点评问题 | 判断标准 | 典型问题话术 |
|---|---|---|---|
| 1 | 外行能懂吗？ | 全程无未解释的术语；若有术语，后面必须紧跟一句人话 | 「这句话，卖水果的大叔能听懂吗？」 |
| 2 | 有取舍吗？ | 是否提到代价 / 边界 / 适用条件，而非只说「是什么、有多好」 | 「你讲了它好在哪，它的代价是什么？」 |
| 3 | 有金句吗？ | 是否有一句可以直接搬进面试的可复用表达 | 「这句话明天面试你能原样说出来吗？」 |

讲师收口定级话术：三问全过=「这版可以直接进面试」；缺取舍=「结论有了，补一个『代价是』就满分」；堆术语=「每句术语后面跟一句人话，我们重来一遍」。

## 五、录音自测方法（课后延伸）

| 步骤 | 操作 | 标准 |
|---|---|---|
| 1 | 手机录音 App（或飞书语音），念题库题目，不看稿按 30 秒版作答 | 卡壳即停，重来，不续录 |
| 2 | 回放，用三问自评：外行能懂吗 / 有取舍吗 / 有金句吗 | 三问在导学案打勾 |
| 3 | 对照三问改写一版，重录 | 两版音频都保留，能听出差异 |
| 4 | 完成至少 5 问，标记最没把握的 2 问 | 周四带来，模拟面试官优先抽这些 |
| 提交 | 录音文件命名：学员代号-题号-版本，交飞书作业区 | 与分层习题提交合并，讲师抽 3 份匿名点评 |

## 六、常见问题处理

| 问题 | 处理 |
|---|---|
| 学员开口紧张说不出话 | 降级任务：「先只说第一步，一句结论。」说完立刻肯定，再逐步加第二步、第三步 |
| 学员答得很好但超时 | 表扬内容、指出纪律：「内容是 90 分，时控是 0 分，面试里时控先筛人」 |
| 全班气氛拘谨 | 讲师先自曝一个自己的「卡壳版本」，示范「卡壳不可耻，不练才可耻」 |
| 线上连麦无人响应 | 改为「评论区打字 30 秒版 + 讲师选 2 条朗读点评」，并要求该 2 位学员课后补录音 |
| 时间不够（前面超时） | 首轮抽人从 2 人减为 1 人，标杆版保留——标杆版是本环节不可压缩项 |
| 零基础学员怕技术题 | 「不用讲实现，就三句：一句结论、一个类比、一句『它做不到什么』。不懂不扣分，装懂才扣分。」 |
| 学员想用背来的术语遮掩 | 当场叫停并给合法句式：「具体实现请算法同学确认，产品侧我把口径、边界和验收标准定清楚」；明确不虚构经历 |
| 只有手机 / 平板，做不了表格整理 | 按《设备要求表》替代动作：纸质清单先写题目，≥20 问表格课后用公用机或家里电脑补，不影响当堂产出 |
