一、课前预习（上课前完成，约 25 分钟）

预习任务 1：复习 W2 / W3 金句索引（技术题的弹药库）

技术理解题的答案，80% 的素材来自第二、三周。逐条过一遍，答不出的条目回对应课的讲课稿复习。已掌握的打勾。

周次 课程 金句索引 掌握
W2D1 模型能力边界与选型 模型没有全能冠军；选型不是选最强，是选最合适；横评表会过期，方法不会 □
W2D2 训练与微调原理 基础模型是毛坯房；聪明与听话是两件事；Demo 是演员，评测集才是考卷 □
W2D3 模型评测体系 没评测集=开盲盒；负例是防翻车的，没有负例的评测集是自我表扬集；先查便宜的，再怀疑贵的 □
W2D4 AI 合规与安全 拒答设计得好就是专业度；合规口诀：备得上、审得出、收得少、护得住、标得清 □
W3D1 Agent 架构原理 Agent 是长着四肢的大模型；没有步数上限的 Agent 是拿用户的 token 赌运气；两个 Agent 能做的事，别用五个 □
W3D2 Agent 产品设计与工作流 能用工作流解决的事，别用 Agent——确定性是产品的好朋友；兜底设计是产品承诺 □
W3D3 RAG 架构与知识库 RAG 的本质，是给模型开卷考试的权利；分块策略决定了检索的天花板；检索求快，重排求准；加知识用 RAG，改行为用微调；没有更新机制的知识库，上线那天就开始腐烂 □
W3D4 多模态产品设计 形态没有高下，匹配才对；多模态三维度：成熟度、成本、合规 □
