二、教学目标（可测量）

  1. 【术语目标】 能准确写出当日 12 个术语的一句话定义（≤30 字），并完成《术语自测表》≥10 行自评、辨析 ≥6 组易混概念。验证：第 1 节当堂术语小测 10 题答对 ≥8 题，06-分层习题第 0 层得分 ≥80 分。
  2. 【面试目标】 能对 8 道高频面试题各写出 60 秒标准答法，每题标出 3–4 个踩分点与 2–3 层追问链应答要点。验证：《面试模拟记录表》≥4 行填写完整，两两模拟自评分达「合格」及以上。
  3. 能用「说人话三步法」（先给一句结论 / 再给一个生活类比 / 最后给一个取舍判断），在 30 秒内把 RAG（Retrieval-Augmented Generation，检索增强生成）讲给完全不懂技术的人听。验证：第 2 节实战训练现场 30 秒作答，三问点评（外行能懂 / 有取舍 / 有金句）全过。
  4. 能对 8 道高频技术题（RAG vs 微调 / 幻觉治理 / Agent 边界 / 模型选型 / 上下文窗口 / 评测 / 内容安全 / 多模态）各写出「30 秒版 + 90 秒版」两档答案，并预判至少 1 个高频追问。验证：导学案题库 A 组 8 问四栏填写完整。
  5. 能回答指标设计题：报出自己主项目的北极星指标与护栏指标，且口径完整（分母、采纳动作定义），符合「绑价值 / 可影响 / 可拆解」三标准。验证：导学案第 9–10 问 + 06-分层习题指标设计题。
  6. 能用 STAR（Situation / Task / Action / Result，情境 / 任务 / 行动 / 结果）结构在 60 秒内讲完一个项目经历，其中 Action 部分占比不低于一半。验证：导学案第 11–12 问 + 第 3 节结论先行版示范。
  7. 【边界表达目标】 零编程学员能用「结论 + 类比 + 边界 + 取舍」答技术题，主动说清「模型做不到什么」，且不虚构技术经历、不假装读过源码。验证：技术题答法中出现 ≥1 句「它在 X 条件下不成立 / 具体实现我会与算法同学确认口径」，且不出现本人未做过的伪技术细节。
  8. 【实操产出目标】 完成题库共建 ≥12 问与 ≥5 问录音自测，形成可归档的作品集积木。验证：录音文件命名规范 + 《录音自评记录表》+《本日作品集积木》完成度标注。

三、教学重难点

  • 重点一：技术题「说人话三步法」——技术题答的是深度，更是边界；能把术语讲成外行听得懂的话，本身就是技术理解力的证明。
  • 重点二：数据题两个模板——指标设计「先报口径再报数字」，异动分析「先拆样本结构、再查指标口径、最后下结论」。
  • 重点三（新增）：12 个术语的精确定义与易混辨析，尤其是「深度 / 边界 / 模型做不到什么」三者的区分，它们共同支撑本课主线「答深度更是答边界」。
  • 难点一：学员在技术题上「堆术语」——把背下来的词全倒出来，反而暴露理解不透。用三步法强制兜住。
  • 难点二：学员答「看场景」不给判断——必须训练「看场景」后面紧跟「我的场景是 X，所以选 Y，因为 Z」。
  • 难点三：行为题讲成小说——时间、人物、情节全上，60 秒讲不到点。用「结论先行版 STAR」纠正。
  • 难点四（新增 · 术语混淆）：学员把「深度」误当成「术语多」、把「边界」误当成「看场景不给判断」、把「归因」与「下结论」顺序颠倒、把「复盘」说成「更努力」、把 STAR 与「讲故事」划等号。对应第 1 节辨析练习与习题第 0 层改错题。
  • 难点五（新增 · 面试失分）：答技术题只讲「能做到什么」不讲「做不到什么」；零编程学员要么硬背术语、要么含糊装懂，追问链第二层即露怯；不会把「不知道」转成「我怎么查 / 找谁确认」的合法表达。对应第 5 节追问防御与「零编程学员站位」专栏。

六、高频技术题逐题精讲（8 题，讲师备课细案）

本节为原有版本核心内容，300 分钟版完整保留，按第 2 节（题 1–4）、第 3 节（题 5–8）分节讲授并各补案例与边界深化。

每题按「考察点 → 30 秒版答题骨架 → 90 秒版答题骨架 → 高频追问」四段备课。技术口径与 W1–W3 金句完全一致，可直接引用。

题 1 · RAG 和微调，怎么选？

维度内容
考察点技术选型的框架思维；是否理解「知识」与「行为」的本质区别
30 秒版结论：加知识用 RAG，改行为用微调；再补一句：大多数格式问题，先试提示词，微调是最后手段
90 秒版① 知识类需求（政策、手册、FAQ）选 RAG：改文档即生效，无需重训；② 行为类需求（语气、风格、固定格式）才考虑微调；③ 给出判断顺序：先提示词 → 再 RAG → 最后微调；④ 收在取舍：RAG 的隐性成本是知识库运维（更新、权限、溯源），微调的隐性成本是数据标注与每次更新的重训周期
高频追问①「两者能结合吗？」——能：RAG 供知识、微调或强约束固定输出格式，落地项目常见组合；②「微调能让模型记住我的文档吗？」——不能，微调调的是行为模式，不是资料存取

题 2 · 什么是幻觉？怎么治理？

维度内容
考察点对模型原理本质的理解（概率续写引擎）；治理思路是否成体系
30 秒版结论：幻觉不是模型的缺陷，是它的本能——概率续写引擎永远给你「最像答案的答案」；治理靠三层：给资料、给约束、给评测
90 秒版① 给资料：RAG，先查资料再回答，治本（回扣金句：RAG 的本质，是给模型开卷考试的权利）；② 给约束：提示词限定「只能基于资料回答，不知道就说不知道」+ 拒答兜底 + 引用溯源；③ 给评测：幻觉率进评测集与线上护栏指标，上线后持续监控（回扣金句：没评测集=开盲盒）
高频追问①「能治理到 0 吗？」——不能，只能压到业务可接受线，用幻觉率做护栏指标盯住；②「你项目里幻觉率多少？」——必须带口径回答（分母、判定标准），并接一句「我们的归因四类是解析 / 分块 / 检索 / 生成」

题 3 · Agent 和工作流的边界在哪？

维度内容
考察点是否理解两者的本质差异（路径确定性）与产品化代价
30 秒版结论：能用工作流解决的事，别用 Agent——确定性是产品的好朋友；路径可枚举用工作流，路径开放才用 Agent
90 秒版① 工作流：人预设路径，稳定、可测、成本可控；② Agent：模型自主规划，路径开放，代价是慢、贵、不稳（步数不可控）；③ 判断三问：任务路径可枚举吗？容错成本高吗？真的需要模型自主决策吗？④ 产品闸门：人工接管点 + 步数与成本上限 + 安全闸门（回扣金句：这件事什么时候交还给人类）
高频追问①「为什么 Agent 产品经常被吐槽不稳？」——自主规划导致步数与成本不可控，没有上限设计就是拿用户的 token 赌运气；②「多 Agent 什么时候用？」——两个 Agent 能做的事，别用五个；协作本身有协议、损耗、失败传播三个隐藏成本

题 4 · 模型选型，你主要看什么？

维度内容
考察点选型方法论是否结构化；是否有「自己动手测」的意识
30 秒版结论：模型没有全能冠军，选型不是选最强，是选最合适；看三角：先按场景定能力线，能力线之上比成本与延迟，合规一票否决
90 秒版① 能力线：把业务场景映射到能力维度（通用对话 / 复杂推理 / 长文本 / 多模态 / 代码 / 中文场景），够用即可；② 成本与延迟：单位成本 × 日均调用量，加上首 token 延迟对体验的影响；③ 合规：国内业务数据敏感时考虑私有化与备案，数据出境是红线；④ 收在方法：横评表会过期，方法不会——建自己的评测集，换季重跑
高频追问①「国产和海外模型怎么选？」——先过合规一票否决，再看能力线与成本；②「你项目里怎么选的？」——必须结合主项目真实任务答，展示评测集对比过程，不许空谈

题 5 · 上下文窗口不够，怎么办？

维度内容
考察点上下文工程的理解深度；是否有「先筛选再喂」的产品直觉
30 秒版结论：不硬塞，先筛选——把「记得住的」留给模型；三条路：精选（RAG 检索）、压缩（摘要与分块）、外置（记忆库按需取用）
90 秒版① 精选：用 RAG 检索 Top-K + 重排，只喂最相关的片段（检索求快，重排求准）；② 压缩：长对话做历史摘要，长文档分块处理，块间留重叠防切断；③ 外置：把不常变的信息放进记忆库或结构化存储，按需检索；④ 收在取舍：塞得满不如塞得准——准确率比长度重要，上下文越长成本越高、注意力越稀释
高频追问①「长上下文模型都到百万 token 了，RAG 还有价值吗？」——有：成本、时效（资料天天更新）、精度、权限隔离四条都还在；②「多轮对话越聊越跑偏怎么办？」——历史摘要 + 关键信息前置 + 定期回插最新结论

题 6 · 怎么评测一个 AI 功能？

维度内容
考察点是否有评测驱动的产品习惯；指标与归因是否具体
30 秒版结论：没评测集=开盲盒；先建评测集（真实用户问题 + 负例，≥50 条），再定指标，最后跑对比、定上线门槛
90 秒版① 评测集：来源是真实用户问题，必须包含负例——负例是防翻车的，没有负例的评测集是自我表扬集；② 指标：功能级（准确率 / 采纳率）+ 护栏（拒答恰当率 / 幻觉率 / 单次成本）；③ 归因：badcase 四类——解析 / 分块 / 检索 / 生成，归因对了改进才对；④ 门槛：达标数字 + P0 badcase 零容忍，上线后 badcase 回流进评测集闭环
高频追问①「开放生成场景没有标准答案怎么评？」——小规模人工标注 + 线上采纳率交叉验证；②「Demo 很好就够了吗？」——Demo 是演员，评测集才是考卷

题 7 · 内容安全怎么做？

维度内容
考察点合规意识（国内岗刚需）；方案是否分层
30 秒版结论：三道防线——机器审核 / 人工复审 / 拒答兜底；国内还必须做生成内容标识
90 秒版① 输入侧：敏感词与意图识别，拦在生成之前；② 生成侧：机器审核模型输出，高危领域加人工抽检；③ 输出侧：拒答兜底话术 + 显式与隐式生成标识；④ 收在合规口诀：备得上、审得出、收得少、护得住、标得清
高频追问①「拒答太严影响体验怎么办？」——灰度调阈值，把误杀率当护栏指标盯；②「为什么标识是强制的？」——生成式 AI 管理办法要求，隐式标识（水印 / 元数据）机器可验

题 8 · 多模态适用什么场景？

维度内容
考察点是否按「成熟度 × 成本 × 合规」理性判断，而非追新
30 秒版结论：三维度判断——成熟度、成本量级、合规风险；形态没有高下，匹配才对
90 秒版① 文生图：营销与素材场景，成熟度高，注意版权与标识；② 语音：陪伴与客服场景，注意录音合规与情绪边界；③ 数字人：播报与标准动作场景，注意「人工接管点」设计；④ 文生视频：成本最高、可控性最弱，先问「非用不可吗」；⑤ 收在取舍：先问这个场景非用多模态不可吗，再谈效果
高频追问①「数字人客服值得做吗？」——看解决率增量对比成本增量，不用多模态能解决的事别上多模态；②「版权风险怎么控？」——训练数据来源条款 + 生成标识 + 人工审核前置

七、数据题教学要点（第 9–10 问备课细案）

题 9 · 给你的主项目设计指标体系（指标设计题）

维度内容
考察点三层看板（北极星 / 一级 / 护栏）；口径意识
答题骨架① 先报北极星：用三标准自查（绑价值 / 可影响 / 可拆解）；② 再报一级过程指标：AI 五大指标中挑最相关的 2–3 个（采纳率 / 解决率 / 幻觉率 / 留存 / 单次成本）；③ 配护栏：防动作变形（回扣金句：北极星决定船往哪开，护栏指标防止你为了追星把船开翻）；④ 每个指标必带口径：分母是什么、采纳动作怎么定义
高频追问「采纳率 90% 说明什么？」——先反问口径：分母按次还是按会话？修改后采纳算不算？用户重试 10 次才采纳 1 次，单次质量其实很差

题 10 · 关键指标突然跌了 20%，你怎么排查？（异动分析题）

维度内容
考察点排查是否有序；是否先查便宜的原因
答题骨架① 先确认是不是真跌：口径变过没有、统计 bug、周日效应；② 拆样本结构：渠道 / 新老用户 / 平台 / 时段，看是整体跌还是局部跌（辛普森悖论意识）；③ 下钻归因：产品改动、模型版本、外部事件；④ 口诀收束：先拆样本结构，再查指标口径，最后下结论——先查便宜的，再怀疑贵的
高频追问「如果各分组都没跌，整体却跌了呢？」——样本结构变了，各组占比漂移，这就是辛普森悖论，按原占比重新加权再看

八、开放行为题教学要点（第 11–12 问备课细案）

维度内容
考察点STAR 结构化表达；Action 是否体现「产品经理的动作」
STAR 时间配比S 一句话交代背景；T 一句话说目标；A 占 60% 以上：你分析了什么、做了什么决策、协调了什么资源；R 收在数字与复盘
30 秒版（结论先行变体）先给 R（结果）→ 再给 A（我最关键的两个动作）→ S/T 压成一句背景
课堂 2 问第 11 问：「讲一个你主项目里推翻自己最初方案的经历」；第 12 问：「讲一次你和数据结论不一致的判断，最后怎么处理的」
高频追问「如果重来一次你会怎么做？」——必须答复盘，且复盘要落在可迁移的方法论上，不是「更努力」

九、课堂提问设计（21 问）

分类统计：术语辨析 6 问（第 8–13 问）、面试追问 8 问（第 3、4、14–19 问）、讲解与实操提问 7 问（第 1、2、5、6、7、20、21 问），合计 21 问。

#类别提问提问时机预设答案 / 引导方向
1讲解提问「把 RAG 讲给你妈听，30 秒，你会怎么开头？」第 2 节导入预设：从「开卷考试」类比切入——「妈，它答题前会先翻书，翻不到就老实说不知道」；引导方向：结论先行，术语后置
2讲解提问「候选人把 RAG、重排、Embedding 全背了一遍，面试官为什么还是摇头？」第 2 节导入预设：堆术语证明不了理解；引导到「技术题答的是深度，更是边界」——说不清边界，说明没真懂
3面试追问「幻觉能治理到 0 吗？」第 2 节题 2 精讲预设：不能；只能压到业务可接受线，用幻觉率护栏指标持续监控，同时设计拒答兜底
4面试追问「长上下文模型都到百万 token 了，RAG 还有价值吗？」第 3 节题 5 精讲预设：有——成本（不必全量塞）、时效（资料天天更新）、精度（检索聚焦）、权限（按用户隔离可检索范围）
5讲解提问「采纳率 90% 的产品，一定是好产品吗？」第 3 节数据题预设：不一定——口径问题：分母按次还是按会话、修改后算不算采纳；重试 10 次才采纳 1 次，单次质量其实很差
6讲解提问「留存跌了 20%，你的第一反应是什么？」第 3 节数据题预设：不急着归因产品——先拆样本结构（渠道 / 新老 / 平台），再查口径有没有变，最后才下结论；先查便宜的，再怀疑贵的
7讲解提问「STAR 四个字母里，哪个最重要？」第 3 节行为题预设：A——面试官只能通过 Action 判断「这件事是不是你干的」；A 必须占一半以上篇幅
8术语辨析「深度」和「堆术语」的区别是什么？为什么背得多反而减分？第 1 节术语精讲预设：深度是答到「为什么 / 代价 / 边界」这一层，堆术语只是「宽」；背得多却答不出代价，暴露没经手过
9术语辨析「边界」与「答『看场景』不给判断」是不是一回事？第 1 节术语精讲预设：不是——「看场景」是开头不是答案；边界要给出具体条件「X 成立，一旦 Y 就换 Z」
10术语辨析「模型做不到什么」和「治理手段」哪个更该先说？第 1 节术语精讲预设：先说做不到什么（定锚可信度），再说治理与兜底；只罗列手段不讲上限，显得没判断
11术语辨析「归因」和「下结论」在异动排查里谁先谁后？顺序错了会怎样？第 1 节术语精讲预设：拆解与查口径在前、归因最后；顺序错了会直接怀疑模型，先动最贵的，还容易误判
12术语辨析「指标拆解」里的口径，和「可信度」是什么关系？第 1 节术语精讲预设：口径是可信度的凭证；没分母、没判定动作的数字，面试官一追就穿
13术语辨析STAR 里的「复盘」和「结果 R」有什么不同？STAR 四个字母的全称是什么？第 1 节术语精讲预设：R 是数字结果，复盘是 R 之后那句「下次可迁移的方法」；全称是情境 / 任务 / 行动 / 结果
14面试追问「你说用 RAG，那微调能让模型记住我的文档吗？」第 5 节追问防御预设：不能；微调调行为模式，不是资料存取；想「知道」靠 RAG，想「说话像」才靠微调
15面试追问「Agent 产品经常被吐槽不稳，为什么？」第 5 节追问防御预设：自主规划让步数与成本不可控，没有上限设计就是拿用户的 token 赌运气
16面试追问「如果各分组都没跌，整体却跌了，怎么解释？」第 5 节追问防御预设：样本结构变了、各组占比漂移，即辛普森悖论；按原占比重新加权再看
17面试追问「你这数据是不是太好看了？」——压力题怎么接？第 5 节追问防御预设：不接情绪只给证据：口径 → 评测过程 → 线上验证逐条摆；不辩解、不自我否定
18面试追问「如果重来一次你会怎么做？」——行为题为什么必须答复盘？第 5 节追问防御预设：复盘要落在可迁移的方法论上（如「先补负例再调提示词」），不能答「更努力」
19面试追问「你不是技术背景，怎么判断这个方案靠不靠谱？」第 5 节零编程专栏预设：用口径、验收标准、边界与兜底来判断；具体实现请算法同学确认，不假装懂、不编造经历
20实操提问「30 秒版和 90 秒版，各自必须含哪几样？」第 4 节实操预设：30 秒=结论+类比，90 秒=结论+展开+取舍；把展开主动权交给面试官
21实操提问「今晚录音自测，你打算用哪三问自评自己的答案？」第 4 节实操预设：外行能懂吗 / 有取舍吗 / 有金句吗；三问打勾后才算完成一问

十一、学员易错点预判与应对

易错点表现应对
技术题堆术语把 Embedding、重排、双塔全倒出来，越答越乱训练「每句术语后面跟一句人话」；用三步法兜底：结论、类比、取舍，缺一步就重答
