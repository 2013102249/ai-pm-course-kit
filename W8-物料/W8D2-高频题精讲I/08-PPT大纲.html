8第 2 节面试官为什么追问① 不是刁难，是验证 ② 验证真实性 + 参与深度 ③ 追问到答不上为止就是他的工作方式 ④ 准备的不是答案，是「追问的尽头」点 1–2 名回答「他在验证什么」；投影全链路图定位AI 产品全链路图、追问防御链四连问板书
9第 2 节金句页：数据，不是形容词① 「项目深挖的答案是数据，不是形容词——要的是证据链，不是感动」② 紫底白字全屏 ③ 对应术语：项目深挖 / 指标 / 口径 ④ 本页不放其他文字放慢语速读两遍，学员抄进导学案—（金句全屏页）
10第 2 节追问防御链总览 + 第一问：数据怎么来的① 四连问：数据 → 取舍 → 失败 → 重来，各自验证什么 ② 防御 = 数据三件套：来源 / 口径 / 基线 ③ 示范「DAU 1,200 → 1,560 + 四周基线 + 打开即算」完整版 ④ 反例：只说「涨了三成」⑤ 三件套缺一即留一个追问口子手指沿链条走一遍；现场示范完整说法，让每人口头说一遍自己项目的一个数据三件套追问防御链四连问板书
11第 2 节数据背不准怎么办 + 第二问：为什么这么取舍① 兜底话术三选一：记不准 / 没埋点 / 被质疑 ② 红线：现场圆数一票否决，坦诚给口径不扣分 ③ 取舍三备件：备选项 / 放弃理由 / 验证结果 ④ 反例「说不出备选项 = 执行者」⑤ 深化：为什么（交叉验证）、边界（记不准 ≠ 没做过）、常见误解（报口径 = 不自信）强调「坦诚不扣分，编数扣大分」；投案例对照页讲 1 正 1 反；收口「这段在面试里怎么答」一句正 / 反面案例对照页、追问防御链板书
12第 2 节第三问 + 第四问：失败与重来 + 填库第 1 批① 失败三段式：真实失败 / 后果 / 改进动作 ② 重来与失败成对、具体到动作 ③ 讲「挺顺利的」学员故事：失败的答案是资产不是污点 ④ 案例：正面三件套齐全 / 反面两轮内口径自相矛盾 ⑤ 当堂填库前 4 问，3 分钟，证据列必须见数字计时巡视；挑 1 份投屏 10 秒；提醒「追问预案」列先空着正 / 反面案例对照页、导学案问答库投屏
13第 3 节场景设计题：为什么不能上来就给方案① 考的是结构化思维，不是灵感 ② 评分表上功能清单最不值钱 ③ 两个原因：无的放矢 / 对齐评分表 ④ 口诀：先站到用户站的地方，再动手做东西 ⑤ 六步 ≠ STAR（讲经历与设计产品的分工）提问「上来报功能会怎样」；请 1 名学员说两个原因6 节时间轴图（挂角）
14第 3 节六步框架总览① 人群 → 场景 → 痛点 → 方案 → 指标 → 风险 ② 前三步想清「给谁、在哪、解决什么」③ 后三步落定「做什么、怎么验收、哪里会出事」④ 六步是答题顺序也是检查清单 ⑤ 点评一律先查六步完整性再评内容手指沿六步走一遍；说明本图此后挂 PPT 侧栏全程场景设计六步框架图（全程侧栏）
15第 3 节六步逐步：人群 / 场景 / 痛点① 人群：可命名、可触达、带关键特征，忌「所有人」② 场景：时间 + 地点 + 频次，「常年每天 2–3 次」③ 痛点：真实问题 + 后果，最好观察而非猜测 ④ 每步配「产出物」与「常见跑偏」两卡 ⑤ 用药提醒示范句逐节点对齐跑偏卡加重读——「这一步，最常见的死法是这个」场景设计六步框架图
16第 3 节六步逐步：方案 / 指标 / 风险① 方案与痛点一一对应，界定 AI 边界（不替代医嘱）② 指标可量化可验证，「提升用户体验」不算 ③ 指标要能回答「三个月后怎么知道做没做成」④ 风险含技术 + 业务 / 合规两类各带应对 ⑤ 风险步最易漏，漏了＝产品不成熟提问「『提升用户体验』算指标吗」；追问「漏了会怎样」场景设计六步框架图
17第 3 节现场真题 10 道总览与骨架速览① A 组项目深挖 5 道 + B 组场景设计 5 道（标注教学示例题）② 每道约 100 秒：题目 → 考察点 → 骨架 → 高分要点 ③ 笔记只记骨架级要点 ④ A 组对应防御链 / B 组对应六步框架 ⑤ 详细版在 PPT 与导学案说明快节奏；B 组每道先让学员猜「坑在哪」再揭晓10 道真题总览页、场景设计六步框架图（侧栏）
18第 3 节填库第 2 批 + 正反案例与深化① 补 4 问：人群 / 痛点 / 指标 / 风险，3 分钟，只填前两列 ② 正面案例：宠物医院人群站「前台店员」③ 反面案例：上来报功能清单，五步全缺 ④ 为什么 / 边界（六步不适用于纯技术理解题）/ 常见误解 ⑤ 这段在面试里怎么答：先 30 秒说清前三步再给方案计时；先查六步完整性再评内容；投案例对照页正 / 反面案例对照页、导学案投屏、场景设计六步框架图
19第 4 节现场演练（集中抽演）① 规则：2 人各 1 题 + 追问 2 层 + 全班点评 ② 计分：框架 50 + 内容 50，编数 −10 / 扛住一层 +5 ③ 题 A 项目深挖 / 题 B 场景设计 ④ 今天在教室里被打穿，好过下周在面试间里被打穿按 07-组织方案执行；计时器就绪；作答过程离开 PPT 聚焦现场演练计分板投屏、面试追问卡
20第 4 节实操任务页 A：两两模拟面试分工① 两人一组，面试官 / 作答者强制轮换 ② 抽题 10 秒准备 / 90 秒作答 / 每层追问 60 秒 ③ 面试官持追问卡，不即兴加题 ④ 每人既被追也追人，无人旁观 ⑤ 答「记不准 + 给口径」即通过该层宣布分组，1 分钟定角色；线上课改连麦语音面试追问卡、面试追问链图
