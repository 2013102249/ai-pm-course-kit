# 分层习题 · W8 周一《AI PM 面试全景地图》

> 三层难度：基础巩固（概念）→ 进阶实操（应用）→ 求职挑战（面试实战）。
> 建议用法：基础层当堂测 10 分钟；进阶层当作业；求职挑战层自测，W8D4/D5 模拟面试前复用。
> 本课核心考点：**题型归类**——给 8 个面试问题归类到五大题型，并给答题框架索引。
> 所有题目附参考答案与评分标准。

---

## 第一层 · 基础巩固题（概念层）

### 一、选择题（每题 10 分，共 50 分）

**1. 关于面试五轮流程，理解正确的是：**
A. HR 初筛只是通知面试，不参与筛选
B. 五轮面试是同一个假设的五次验证：你能不能来干活
C. 交叉面是走形式，可以不用准备
D. HRD 面主要考技术深度

**2. AI PM 面试权重最高的一轮通常是：**
A. HR 初筛
B. 业务面
C. HRD 面
D. 每轮权重完全相同

**3. 业务面和总监面同样让你讲项目，两者的核心差别是：**
A. 业务面问「怎么做」验执行，总监面问「为什么这么做」验判断
B. 业务面看口才，总监面看学历
C. 总监面更简单，只要不紧张就行
D. 没有差别，准备一套话术就够

**4. 关于五大题型，归类正确的是：**
A. 「你项目采纳率 68% 是怎么统计的」→ 数据题
B. 「从 0 设计一款 AI 面试助手」→ 项目深挖题
C. 「和研发吵过架吗，怎么解决的」→ 开放行为题
D. 「RAG 和微调怎么选」→ 场景设计题

**5. 关于评分标准（示例框架，各公司自定），说法正确的是：**
A. 面试官全凭感觉打分，没有评分表
B. 项目真实度通常是权重最高的维度
C. 答不上来的问题硬编一个答案比说「不知道」扣分少
D. 表达与气场比项目真实度更重要

### 二、核心考点 · 题型归类题（每问 5 分 + 框架 1 分，共 50 分）

**6. 将下列 8 个面试问题归类到五大题型（项目深挖 / 场景设计 / 技术理解 / 数据 / 开放行为），并为每问写出答题框架索引。**

| # | 面试问题 | 归类 | 答题框架索引 |
|---|---|---|---|
| ① | 介绍一个你主导上线的功能，数据结果如何？ | | |
| ② | 如果让你从 0 设计一款 AI 面试助手，你怎么做？ | | |
| ③ | RAG 和微调在你的项目里是怎么选的？ | | |
| ④ | 你的产品 DAU 上周跌了 15%，你怎么排查？ | | |
| ⑤ | 讲一次你和研发意见冲突的经历，怎么解决的？ | | |
| ⑥ | 你说的采纳率 68%，分母是什么、怎么统计的？ | | |
| ⑦ | 如果预算砍半，你的方案里先砍什么？ | | |
| ⑧ | 为什么这个时间点想离开上家公司？ | | |

**归类判断标准**：看考察意图，不看字面。验真（数据口径、分工、细节）归项目深挖；拆没做过的题归场景设计；技术边界与选型归技术理解；定位问题与归因归数据；性格、自省、动机归开放行为。

## 第二层 · 进阶实操题（应用层）

**7. 一题三版讲法（50 分）**
你的主项目将在同一公司的三轮面试中被反复讲到：业务面、总监面、交叉面。请为这个项目设计三个版本的 1 分钟开场陈述提纲（每个版本写出：结论句 + 3 个要点关键词 + 这版重点防的追问方向），并说明三版为什么必须不同。

**8. 矩阵问法设计（50 分）**
针对你自己的五大题型弹药盘点结果，为「你最弱的那类题型」设计 4 个高频问法，并为每问写出答案骨架（只写关键词，不写全文）与待补强项。

## 第三层 · 求职挑战题（面试实战层）

**9. 面试实战：致命追问应对（30 分）**
面试官在业务面里连续追问：「你说采纳率提升了 15 个百分点——统计周期多长？分母包含未登录用户吗？提升是功能带来的还是渠道放量带来的？」你当时只记得「提升了 15 个点」，其余不确定。
要求：写出你的现场应答（口语句式），并说明这样答的理由。

**10. 面试实战：反问环节设计（30 分）**
假设你明天进入目标公司的总监面，面试官最后说「你有什么想问我的」。请设计 3 个反问（分别对应业务型 / 团队型 / 成长型），每个反问写出问法与「这个问题能帮我判断什么」。

## 参考答案与评分标准

### 第一层 · 基础巩固

| 题 | 答案 | 给分点 |
|---|---|---|
| 1 | **B** | 选 B 满分；选 C 得 3 分（知道交叉面存在但低估其权重） |
| 2 | **B** | 选 B 满分 |
| 3 | **A** | 选 A 满分 |
| 4 | **C** | 选 C 满分；能说明 A 是验真属项目深挖、D 属技术理解，各加 2 分 |
| 5 | **B** | 选 B 满分；能同时指出 C 反了（诚实优于硬编）加 3 分 |
| 6 | 见下表 | 归类 5 分/问 + 框架索引 1 分/问；⑦ 归「场景设计」或「场景设计（追问变体）」均可 |

**第 6 题参考答案：**

| # | 归类 | 答题框架索引 |
|---|---|---|
| ① | 项目深挖 | STAR + 追问防御链 |
| ② | 场景设计 | 人群-场景-痛点-方案-指标-风险 |
| ③ | 技术理解 | 加知识用 RAG / 改行为用微调（W1–W3 决策口诀） |
| ④ | 数据 | 北极星指标 + 异动排查（内外因 → 渠道分群 → 行动假设） |
| ⑤ | 开放行为 | STAR + 反思收尾 |
| ⑥ | 项目深挖（问分母口径是验真） | STAR + 追问防御链（数据统计段） |
| ⑦ | 场景设计（预算约束下的取舍变体） | 人群-场景-痛点-方案-指标-风险（取舍与优先级段） |
| ⑧ | 开放行为（动机与稳定性） | 一句话版转行/离职理由：从哪来、到哪去、为什么是现在 |

### 第二层 · 进阶实操（三档 Rubric）

**第 7 题参考要点**：三版结论一致但侧重不同——执行版讲「怎么做成的」（里程碑、协作、数据）；判断版讲「为什么这么做」（选型依据、取舍、代价、如果重来）；协作版讲「怎么与人做成」（需求表达、分歧解决、研发视角）。三版必须不同，因为三轮考察意图不同：验执行 / 验判断 / 验协作。

| 档位 | 标准 |
|---|---|
| 合格（30–39 分） | 三版提纲完整，各有侧重 |
| 良好（40–44 分） | 三版侧重点与对应轮次的考察意图精确对应，且写明各版防的追问方向 |
| 优秀（45–50 分） | 额外体现「同一数据在不同版本中承担不同论证作用」，或为每版标注了与矩阵的联动点 |

**第 8 题参考要点**：问法应贴合该题型的真实问法库；骨架为关键词而非全文；待补强项写到具体（「RAG 选型说不出代价」而非「技术弱」）。

| 档位 | 标准 |
|---|---|
| 合格（30–39 分） | 4 问完整，骨架可用 |
| 良好（40–44 分） | 问法难度有梯度（基础问 + 追问变体），骨架含结构词与数字 |
| 优秀（45–50 分） | 骨架体现框架索引的落地（如按六步框架逐项给关键词），待补强项带行动项 |

### 第三层 · 求职挑战（三档 Rubric）

**第 9 题参考答案**：口语句式示例——「这三个问题里，统计周期我记得是上线后四周对比前四周；分母口径我需要确认，我的印象是不含未登录用户，但如果现场不能确认，我不会猜一个数字给您——我可以在 24 小时内把口径查清楚发给您。至于归因，提升确实和渠道放量同期发生，我当时用分渠道数据做过拆分，结论是新功能在老渠道上带来了约 X 个点的净提升。」理由：不确定的数据不编（细节是诚实的，标准答案是可疑的）；给出确认动作和时限；展示归因意识。

| 档位 | 标准 |
|---|---|
| 合格（18–23 分） | 不编造数据，给出确认动作 |
| 良好（24–27 分） | 应答有结构：能答的先答、不能答的给确认时限、体现归因意识 |
| 优秀（28–30 分） | 额外把「这次暴露的口径盲区」转化为面试前的准备动作（核心数字写死进矩阵），体现开卷考试思维 |

**第 10 题参考答案**：业务型示例——「这个团队未来半年最重要的产品目标是什么？我入职后第一个季度最需要拿下的结果是什么？」（判断目标与自己的匹配）。团队型示例——「团队里 PM 和研发的协作方式是怎样的？需求评审一般怎么开？」（判断协作文化）。成长型示例——「在这个岗位上做得好的人，通常在一年后承担了什么？」（判断成长空间）。加分点：每个反问都要能反推出「我关心长期贡献，不只是待遇」。

| 档位 | 标准 |
|---|---|
| 合格（18–23 分） | 3 个反问类型齐全，问法得体 |
| 良好（24–27 分） | 每问写清「能帮我判断什么」，判断点与面试决策相关 |
| 优秀（28–30 分） | 反问能自然带出自己的优势或准备度（如结合自己项目经验发问），实现「提问即自我营销」 |
