## 图 1 · 面试流程图（制图规格 · 已制成）

**用途**：环节一「五轮流程逐轮拆解」主视觉；后续 W8D4/D5 模拟面试课复用。

**画面结构**（横向流程，左→右五个节点）：

| 节点 | 必含要素 |
|---|---|
| 第 1 轮 · HR 初筛 | 谁面：招聘 HR（10–20 分钟）；考察点：动机 / 稳定性 / 薪资口径；典型淘汰点：动机含糊 |
| 第 2 轮 · 业务面 | 谁面：直属上级 / 同级 PM（45–60 分钟）；考察点：项目真实度 / 方法体系；典型淘汰点：追问两层露馅 |
| 第 3 轮 · 总监面 | 谁面：部门总监（30–45 分钟）；考察点：判断力 /「为什么」层；典型淘汰点：只讲执行、失败全归外部 |
| 第 4 轮 · 交叉面 | 谁面：研发 / 设计 / 运营负责人（30–40 分钟）；考察点：协作性 / 需求表达；典型淘汰点：把协作方当执行资源 |
| 第 5 轮 · HRD 面 | 谁面：HR 负责人（20–30 分钟）；考察点：价值观 / 抗压 / 薪酬；典型淘汰点：态度反复、负面情绪 |

**设计要求**：
- 五节点横向箭头串联，节点用紫色 #7C3AED 描边圆角矩形，箭头用蓝色 #2563EB；轮次越靠右颜色越深，体现「越往后越接近 offer」。
- 每节点内三行小字：谁面 / 考什么 / 淘汰点（淘汰点用红色 #DC2626 小字标注）。
- 底部通栏一条横幅文字：「五轮面试 = 同一个假设的五次验证：你能不能来干活」。
- 右上角标注小字：「轮次为全集框架，不同公司会合并或增减」。
- 尺寸 1600×900，字号：标题 ≥32px、节点内正文 ≥18px，投屏可读。

**验收标准**：
1. 五轮顺序、时长、考察点与本课教案第六节表格完全一致，无错别字。
2. 只用紫 #7C3AED / 蓝 #2563EB / 红 #DC2626 / 黑灰文字四类颜色。
3. 手机端缩放至 400px 宽时，五轮名称与底部横幅仍可辨认。

**讲法脚本**（讲课稿对应段落）：
- 逐轮从左到右讲解，每轮按「谁面 → 考什么 → 怎么死 → 准备动作」四步走，用手指沿箭头移动。
- 讲完五轮后指底部横幅，抛出「五次验证」视角，让学员在导学案表格里逐轮写「我要防什么」。
- 提问点：「业务面和总监面都让你讲项目，问法有什么不同？」（预期：执行版 vs 判断版）

## 图 2 · 题型地图（制图规格 · 已制成）

**用途**：环节二「五大题型逐类精讲」主视觉；本周 W8D2 / D3 精讲课复用作导航页。

**画面结构**（2+3 卡片布局，上排 2 张大卡，下排 3 张，或五卡等宽横排）：

| 卡片 | 必含要素 |
|---|---|
| ① 项目深挖 | 典型问法 1 条：「这个数据怎么统计的？分母是什么」；考察本质：验真；框架：STAR + 追问防御链；高频失误：数据张口报不出 |
| ② 场景设计 | 典型问法 1 条：「从 0 设计一款 AI 面试助手」；考察本质：拆题方法论；框架：人群-场景-痛点-方案-指标-风险；高频失误：上来就讲功能 |
| ③ 技术理解 | 典型问法 1 条：「RAG 和微调怎么选」；考察本质：能与工程师对话；框架：加知识用 RAG / 改行为用微调；高频失误：装懂硬撑 |
| ④ 数据 | 典型问法 1 条：「DAU 跌了 15% 怎么排查」；考察本质：用数据定位问题；框架：北极星指标 + 异动排查；高频失误：「我会去问数据同学」 |
| ⑤ 开放行为 | 典型问法 1 条：「讲一次你最大的失败」；考察本质：自省与稳定；框架：STAR + 反思收尾；高频失误：只讲事件没有反思 |

**设计要求**：
- 每张卡片四行固定结构：典型问法（蓝色 #2563EB 引号体）/ 考察本质 / 答题框架 / 高频失误（红色 #DC2626）。
- 卡 ① 项目深挖 加紫色 #7C3AED 角标「权重最高·业务面主战场」，与其余四卡形成视觉差异。
- 顶部标题行：「五大题型地图——先归型，再调框架」；底部通栏小字归类口诀：「看考察意图，不看字面」。
- 尺寸 1600×900，卡片圆角 16px，投屏可读（卡内正文 ≥16px）。

**验收标准**：
1. 五类题型名称、典型问法、框架与本课教案第七节表格完全一致；框架名称须与 W8D2/D3 课名呼应（追问防御链 / 六步框架 / 决策口诀 / 异动排查 / STAR+反思）。
2. 卡片四行结构整齐对齐，无错别字，无 emoji。
3. 归类口诀字样完整可读——它是课堂快练的判断依据。

**讲法脚本**（讲课稿对应段落）：
- 逐卡讲解，每卡四步走：典型问法 → 考察本质 → 框架名字（点到即止，注明周二/周三详讲）→ 高频失误。
- 讲完五卡后收束到归类口诀，进入三问快练（采纳率统计 / 预算砍半 / 为什么敢上 RAG）。
- 提问点：「场景设计题，面试官真的在乎你的方案对不对吗？」（预期：不全在乎，在乎拆题过程）
