1第 1 节封面：AB 实验与数据决策① 课程名 + 第五周第二天 + 讲师名；② 300 分钟（6 课时 × 50 分钟）；③ 6 节：术语 / 原理 A / 原理 B+案例 / 实操 / 面试 / 复盘验收；④ 今日带走 2 个实验设计方案 + 3 张表口播产出目标；宣布 6 节一节一个产出封面图（能力画像）、6 节时间轴图（全暗）
2第 1 节本节目标与零层入口① 12 个术语各给 5 项；② 完全不了解技术的学员先走 W1-物料/W1D2-大模型原理通识/00-技术零层.md；③ 不推公式、不算 p 值；④ 时间盒：术语 25′+辨析 10′+小测 10′先安抚零基础学员，明确「只建语言系统」6 节时间轴图（点亮第 1 节）、术语卡目录
3第 1 节术语卡①：实验与分组① AB 实验（A/B Testing，对照实验）= 对照 + 随机；② 对照组（Control Group，控制组）= 旧版；③ 实验组（Treatment Group，处理组）= 新版；④ 假设（Hypothesis，可证伪假设）带打脸条件；⑤ 英文缩写首次给全称 + 中文用「试菜」生活类比，禁止用技术比喻技术术语卡 01–04（03-配图素材/术语卡/，待制）
4第 1 节术语卡②：度量与判据① 基线（Baseline，现状值）= 改动前实际值，非目标值；② 样本量（Sample Size，样本规模）= 人数账；③ 显著性（Statistical Significance，统计显著性）= 差异不像运气，≠ 幅度大；④ 决策阈值（Decision Threshold，判读标准）= 开跑前冻结；⑤ 四词各配一个反例重点辨析「基线 / 目标值」「显著性 / 幅度」术言卡 05–07、12（待制）
5第 1 节术语卡③：陷阱与放量① 偷看指标（Peeking，提前窥视）= 没跑满就下结论；② 辛普森悖论（Simpson's Paradox）= 整体涨分组跌；③ 分组数据（Segmented Data，分层数据）= 按平台 / 新老 / 渠道拆；④ 灰度（Gradual Rollout，灰度发布）= 小比例放量；⑤ 灰度 ≠ 全量用「先定判据，再看数据」串起四词术语卡 08–11（待制）
6第 1 节术语辨析练习 + 当堂小测① 四组快判：对照组 / 实验组、基线 / 目标值、显著性 / 幅度、灰度 / 全量；② 选择 / 连线 / 改错 5 题；③ 同桌互批、≥80 分达标；④ 待补术语圈出，第 4 节前补测举左手 / 右手全班快判，只讲错得最多的两题术语小测卷、《术语自测表》
7第 2 节昨天的问题，今天回答① 「增长方案里哪个动作你敢说一定有效？」；② 方案 = 猜测，验证 = 实验；③ 验证之前所有增长动作都只是猜测；④ 今日主线：猜测 → 可检验实验 → 数据决策抛问后停 10 秒，无人举手是预期效果6 节时间轴图（点亮第 2 节）
8第 2 节AB 实验本质与五步流程 + 四要素总览① 本质：对照 + 随机，同一时间锁死其他变量；② 为什么不能「今天 A 版明天 B 版」；③ 五步：假设→设计→灰度→全量→决策（回环）；④ 四要素总览：假设 / 指标 / 样本量 / 周期；⑤ 灰度是最容易漏的一步用手指沿流程走一遍；宣布「这就是周五评审要交的东西」实验流程图（已制成）
9第 2 节要素① 假设：可证伪① 模板：因为【洞察】，我们相信【改动】，会让【用户】的【指标】提升【幅度】；② 反例「新版更好看」不可证伪；③ 四个可检验点：改动 / 人群 / 指标 / 幅度（教学示例 25%→27%）；④ 「数据打脸时我承认什么」；⑤ 现场填表 3 分钟 + 同桌查证伪性巡场点破「活跃不是指标」「没有基线幅度是空话」导学案方案 A 表、术语卡 04
10第 2 节要素② 指标：1 成功 + 护栏① 一个实验只回答一个问题、只定 1 个成功指标；② 决策需要单一判据；③ 成功指标选离改动因果链最近的；④ 护栏防「赢了 A 输了 B」（推送案例：留存 +2 但退订 +3，教学示例）；⑤ 留存类护栏 = 加载时长 / 取消率，推送类 = 退订率 / 投诉率现场填表 2 分钟；抽查「指标离因果链远不远」导学案方案 A 表、术语卡 05
11第 2 节要素③ 样本量：够不够再开跑① 直觉三问：波动多大 / 提升多大 / 流量多大；② 规律：预期提升越小、波动越大，样本越大；③ 口径 = 在线样本量计算器，不给公式；④ 开跑前两笔账：需要多少样本 × 按日流量跑几天；⑤ 直觉锚点（20%→21% 需几万级，教学示例）现场投屏计算器演示；强调「样本量不是拍出来的」在线样本量计算器实时投屏、术语卡 06
12第 2 节要素④ 周期：完整周覆盖① 至少 1–2 个完整自然周；② 工作日与周末用户结构不同，只跑半周 = 只测半类用户；③ 避开大促 / 发版 / 节假日 / 运营活动；④ 新老用户分开看；⑤ 回扣「周一下午开跑错在哪」让学员写起止日期，同桌查「完整周 + 撞车」日历示意、案例对照页（预告）
13第 3 节被偷看指标毁掉的实验 + 金句① 教学示例：周一下午开跑，第 3 天 B 领先 8% 庆功全量，第 7 天反转；② 原因：周一上新用户集中落进 B 组，样本结构歪了；③ 半成品数据不可拍板；④ 金句「实验没跑完就下结论，等于没跑」；⑤ 写在导学案第一行讲故事节奏：先讲胜利再讲反转；金句放慢让学员抄三陷阱示意图（预告）、6 节时间轴图（点亮第 3 节）
14第 3 节陷阱一：偷看指标① 半成品 vs 成品数据；② 跑动中每天进来的用户结构都在变；③ 规避 = 开跑前冻结判读日期 + 成败标准（决策阈值）；④ 中途看数只排查故障、不进决策群；⑤ 「先定判据，再看数据」与 P13 呼应，点破故事完整逻辑三陷阱示意图（栏 1）
15第 3 节陷阱二：辛普森悖论① 教学示例：整体 B 5.2% 赢 A 5.0%；② 苹果端（iOS）A 8% vs B 7%、安卓端（Android）A 3% vs B 2.5%，分组 A 全赢；③ B 组 iOS 占六成、天然转化高 → 结构污染；④ 规避：先按平台 / 新老 / 渠道拆分组数据；⑤ 结构差异大先配平板书推演数字，给学员 20 秒心算三陷阱示意图（栏 2）、辛普森推演板书表
16第 3 节陷阱三：多重比较① 一次看 20 个指标，总有一个「显著」——像买 20 张彩票；② 复跑提升消失（教学示例）；③ 指标越多越易被运气命中；④ 规避：先定指标再看数；⑤ 指标多看时收紧显著性门槛用比喻不用统计术语，不推公式三陷阱示意图（栏 3）
17第 3 节正 / 反案例对照页① 左：合格方案（冻结判据 + 分层判读 + 先灰度）；② 右：不合格方案（4 天就全量 + 20 指标挑好的说 + 没拆分组）；③ 会话时长需配对护栏；④ 双案例差的到底是哪几条纪律；⑤ 数字均标教学示例组织讨论「两份方案差在哪」，引导说出四条纪律正 / 反案例对照页（待制，05-配图清单 第 8 行）
18第 3 节从数据到决策：三道闸 + 无实验条件怎么办① 三道闸：显著了吗 → 护栏守住了吗 → 成本与可逆性算过吗；② 证据不足 ≠ 证明无效；③ 替代法：前后对照 / 灰度观察 / 访谈三角验证；④ 每种都写明弱点；⑤ 数据答「能不能」，决策答「值不值」强调「每个替代方案都要诚实标注弱点」6 节时间轴图、替代法表（导学案）
19第 4 节实操任务页：本节怎么走① 4 段时间盒：说明 8′ + 实操 32′ + 讲评 10′；② 任务：2 个实验方案 1.0 版 + 互审 + 分层习题第 0–3 层；③ 产出清单；④ 手机 / 平板替代动作入口；⑤ 计时器投屏宣布「方案不是写出来的，是被挑战出来的」投屏计时器、6 节时间轴图（点亮第 4 节）
20第 4 节实验设计方案 A 填写示范① 合格方案 6 行逐行示范（教学示例）；② 假设 / 成功指标 / 护栏 / 样本量 / 周期 / 判读两分支；③ 常见不合格写法对照；④ 基线填现状值；⑤ 失败分支必填逐行念，让学员对照自己方案 A 补洞导学案方案 A 表
21第 4 节实验设计方案 B 与两笔账① 方案 B 结构同 A；② 两笔账分列：需要多少样本 / 按日流量跑几天；③ 「跑两周」是周期不是样本量；④ 基线查不到先写「待查」，不许编；⑤ 手机 / 平板看讲师投屏记结果巡场重点查「两笔账有没有混成一笔」导学案方案 B 表、计算器投屏结果
22第 4 节工作坊：互审你的实验设计① 时间盒 8 + 12 + 10；② 四要素挑战法 5 问（能证伪吗 / 指标近吗 / 算了吗 / 完整周吗 / 两分支都有吗）；③ 只挑战、不客套；④ 点评框架「先立再破后给路」；⑤ 互审记录写进导学案投屏计时器；巡场介入跑偏小组；挑 1 好 1 问题方案导学案 + 四要素挑战清单、计时器
23第 4 节四要素挑战法 5 问 + 常见卡点 3 条① 5 问逐项过，不许跳项；② 卡点 1：基线查不到 → 填「待查」先走逻辑；③ 卡点 2：样本量与周期混账 → 两行拆开重写；④ 卡点 3：判读只有成功分支 → 补失败分支；⑤ 三人组轮转规则巡场话术照读，卡点当场处理挑战清单投屏、导学案互审记录表
24第 4 节分层习题第 0–3 层 + 设备替代动作① 第 0 层术语辨析 / 第 1 层基础 / 第 2 层实操 / 第 3 层求职；② 做不完标出题号课后补；③ 只有手机：计算器看投屏、口述参数记结果；④ 只有平板：浏览器分屏 + 飞书文档评论互审；⑤ 无任务必须依赖电脑明确「需电脑更顺畅」的三类任务与替代路径分层习题（06 文件）、设备要求表（07 文件）
25第 5 节面试题页①：题型拆解 + 答法结构① 4 类题型：技术理解 / 项目深挖 / 场景设计 / 行为题；② 答法结构「结论 → 机制 → 动作 → 边界」；③ 三类失分：只背结论 / 被追就改口 / 证据不足说成证明无效；④ 8 道题覆盖 4 类高频题；⑤ 60 秒口播至少带 1 个当日术语先让学员猜踩分点条数，再对答案6 节时间轴图（点亮第 5 节）、面试追问链图
26第 5 节面试题页②：三个常见坑 / 没跑完能不能看数据① 三个坑按「机制 + 动作」说；② 偷看指标 = 冻结判据，辛普森悖论 = 拆分组数据，多重比较 = 先定指标；③ 没跑完：能看但只排查故障、不下结论；④ 给业务方明确判读日；⑤ 失败答法对照示范 60 稿，放慢语速面试追问链图、面试题页配图
27第 5 节面试题页③：整体涨分组跌 / 样本量不够① 整体涨分组跌 = 辛普森悖论，每层都对、错在加总；② 判读前拆分组数据、结构差异大作废重跑；③ 样本量不够：不硬跑，两笔账说话；④ 三条路：砍实验 / 换更大改动 / 走替代法并标注弱点；⑤ 给老板的诚实说法强调「不硬跑」结论不变面试追问链图、辛普森推演板书
28第 5 节面试题页④：其余 4 题速览① 一个实验只定 1 个成功指标 + 护栏；② 没跑出差异 ≠ 功能没用（证据不足 ≠ 证明无效）；③ 无实验条件：三种替代法各标弱点；④ 显著 + 护栏守住也不一定全量（成本 / 可逆性 / 机会成本）；⑤ 每题踩分点 3–4 条8 题全覆盖，点到为止，留时间给模拟面试追问卡 8 张（03-配图素材/面试追问卡/，待制）
29第 5 节追问链页：3 层追问防御① 横向 4 层：题目 → 第 1 层 → 第 2 层 → 第 3 层；② 每层标注应答要点；③ 失败答法：只报名字 / 一刀切不能看 / 说成数据 bug；④ 失分原因逐条对照；⑤ 练「结论不变、补充边界」面试官按卡连追，不许一层就停面试追问链图（待制，05-配图清单 第 5 行）
30第 5 节两两模拟 + 记录表 + 本日金句① 两两配对、10 分钟后互换角色；② 《面试模拟记录表》≥4 行，含追问记录与自评分；③ 踩分点自评 ≥3/4；④ 金句 3 条：先定判据再看数据 / 证据不足≠证明无效 / 数据答能不能、决策答值不值；⑤ 抄进导学案金句全班齐读一遍，第 6 节验收抽查《面试模拟记录表》、面试追问卡、金句页
