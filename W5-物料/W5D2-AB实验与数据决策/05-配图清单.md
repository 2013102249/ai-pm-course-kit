## 图 1 · 实验流程图（已制成）

### 内容结构（五步横向流程）

```
[假设] → [设计] → [灰度] → [全量] → [决策]
```

| 节点 | 图上主文字 | 图上辅助小字（≤12 字/条） |
|---|---|---|
| ① 假设 | 假设：可证伪 | 「数据打脸时我承认」 |
| ② 设计 | 设计：四要素 | 「假设 · 指标 · 样本 · 周期」 |
| ③ 灰度 | 灰度：小比例放量 | 「给 bug 留缓冲带」 |
| ④ 全量 | 全量：判读通过后放开 | 「三道闸过了才全量」 |
| ⑤ 决策 | 决策：进入下一轮假设 | 「增长是永不收敛的循环」 |

第 ⑤ 步向第 ① 步画一条回环虚线，标注「下一轮假设」，体现循环。

### 视觉规格

| 项目 | 规格 |
|---|---|
| 画幅 | 1920 × 1080（16:9，PPT 全屏用） |
| 布局 | 五节点等距横排，箭头连接；回环虚线沿顶部走弧线 |
| 配色 | 五个节点统一紫色 #7C3AED 描边、浅紫底；「灰度」节点用蓝色 #2563EB 实底白字（强调它是容易漏的一步） |
| 字号 | 节点主文字 ≥40px，辅助小字 ≥22px，投屏可读 |
| 风格 | 圆角矩形、扁平、无阴影堆叠；与既有素材（RAG（Retrieval-Augmented Generation，检索增强生成）架构图等）线宽一致 |

### 验收标准

- 五步顺序与教案「假设→设计→灰度→全量→决策」完全一致，无缺步、无换序。
- 每个节点辅助小字 ≤12 字，且与讲课稿表述不冲突。
- 仅出现紫 / 蓝 / 中性灰 / 警示红四类颜色，警示红在本图不使用（本图无陷阱内容）。
- 回环虚线存在且不与主流程箭头交叉遮挡。
- 中文标注零错别字；SVG 源文件 + 导出 PNG 各一份。

### 讲法脚本（对应对应板块 · 50–100 min）

- **讲法**：从左到右用手指沿箭头走一遍，每步念主文字 + 一句辅助小字；走完五步后指向顶部回环线：「决策不是终点，是下一轮假设的起点。」
- **重点强调**：讲第 ③ 步灰度时放慢——「很多同学以为实验跑完就直接全量，中间少了灰度这层保险。」
- **提问点**：「昨天你们的增长方案，今天走到五步里的第几步？」（预期：大部分停在第 1 步）
- **过渡话术**：「第一步假设，现在大部分同学还没站稳——怎么才算站稳？四要素，一个一个来。」

## 图 2 · 三陷阱示意图（已制成）

### 内容结构（三栏对照）

```
┌─────────────┬─────────────┬─────────────┐
│ 陷阱一        │ 陷阱二        │ 陷阱三        │
│ 偷看指标      │ 辛普森悖论    │ 多重比较      │
│ 一句话案例    │ 一句话案例    │ 一句话案例    │
│ 规避动作      │ 规避动作      │ 规避动作      │
└─────────────┴─────────────┴─────────────┘
```

| 栏 | 陷阱名 | 一句话案例（图上原文） | 规避动作（图上原文） |
|---|---|---|---|
| 1 | 偷看指标 | 第 3 天 B 组领先就庆功全量，第 7 天反转——样本结构歪了 | 开跑前冻结：判读日期 + 成败标准 |
| 2 | 辛普森悖论 | 整体 5.2% 赢 5.0%，但 iOS、Android 两个分组 A 版全赢 | 判读前先按平台 / 新老分层看一遍 |
| 3 | 多重比较 | 看了 20 个指标，总有 1 个「显著」——像买 20 张彩票 | 先定指标再看数；指标越多门槛越高 |

> 图上案例数字均为教学示例，非真实实验数据；数字不出现在图上、只出现在讲师板书。

三栏底部加一条通栏底部条：「三坑同源：先定判据，再看数据。」（紫底白字）

### 视觉规格

| 项目 | 规格 |
|---|---|
| 画幅 | 1920 × 1080（16:9） |
| 布局 | 三等宽竖栏；每栏四层：陷阱名 / 图标 / 案例 / 规避动作 |
| 配色 | 栏标题警示红 #DC2626；案例区白底灰字；规避动作区蓝色 #2563EB 浅底；底部通栏紫 #7C3AED |
| 图标 | 简笔线性图标各一：望远镜（偷看）、天平（悖论）、骰子（运气），线宽统一 2px |
| 字号 | 陷阱名 ≥36px，案例与规避动作 ≥22px |

### 验收标准

- 三个陷阱名称与教案一致：偷看指标 / 辛普森悖论 / 多重比较，无增加或替换。
- 每栏「一句话案例」与教案、讲课稿中的故事逻辑一致（数字例子 5.2% / 5.0% 与 8% / 7% / 3% / 2.5% 自洽，均为教学示例，数字不出现在图上，只出现在讲师板书）。
- 规避动作每条 ≤20 字，可在 5 秒内读完。
- 警示红仅用于陷阱名，不得用于规避动作区（规避动作用蓝色，传递「可解决」的正面感）。
- 中文标注零错别字；SVG 源文件 + 导出 PNG 各一份。

### 讲法脚本（对应对应板块 · 100–150 min 收束）

- **讲法**：三大陷阱已逐个用故事讲完，本图作为收束记忆页。逐栏指读：陷阱名 → 案例 → 规避动作，每栏不超过 30 秒。
- **提问点**：「三个陷阱里，哪个在你现在的工作流程里最容易发生？」（预期答案分散，顺势强调每个人的高危项不同）
- **记忆锚点**：最后指向底部通栏，全班齐读「先定判据，再看数据」。
- **过渡话术**：「陷阱防住了，数据齐了——从数据到决策，还有三道闸。」
