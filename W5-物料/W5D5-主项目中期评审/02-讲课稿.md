## 第 1 节 · 术语精讲与零层入口（0–50 min）

### 本节目标

评审日最容易出的问题，不是学员不会做项目，而是**听不懂规则里的词、说不清自己的决定**。今天先花整整一节课，把 11 个当日高频词建成都市可查、面试可用的语言系统，再进入答辩与清算。本节结束时，学员要能闭卷写出 ≥9 个术语的定义与易混辨析，并能把 ≥3 个术语自然说进一段 60 秒口述。

### 时间轴

| 时段 | 内容 | 方法 |
|---|---|---|
| 0–5 min | 开场：为什么评审日要先讲术语 | 讲授 + 提问 |
| 5–10 min | 技术零层入口（面向零基础学员） | 投屏 + 三句白话 |
| 10–35 min | 11 个术语逐词精讲，每个给全 5 项 | 术语卡投屏 + 逐词讲授 |
| 35–45 min | 四组易混辨析练习 | 两两互问 + 抢答 |
| 45–50 min | 当堂术语小测（11 题，参考答案见 01-教案第八节） | 闭卷自测 + 当堂对答案 |

### 讲师话术

同学们，今天是第五周周五，主项目第四个里程碑——中期评审。先说清楚一件反直觉的事：今天**先不讲流程，先讲词**。为什么？【问】评审日翻车，多数是翻在哪儿？【停】不是不会做项目，是三件事没对齐：把自己的「需求池」当成「V3 Scope」，把「用户视角」当成「投资人视角」，把「评分及格」当成「验收放行」。词不准，记录就写不对，Scope 就砍不动，面试里被追问两句就露怯。所以这一节，我们把 11 个词一次钉死。

【金句】先把词说准，才把事做对、把话说得分。

**技术零层入口**（面向本期零编程、技术概念「听过名词」及以下的学员，先走 `W1-物料/W1D2-大模型原理通识/00-技术零层.md`）。三句白话垫底：第一，今天不写一行代码，只做「决定哪些功能做、哪些不做」；第二，你手里的 PRD（Product Requirement Document，产品需求文档）、商业画布、增长方案、甘特图，是四份说明白项目的纸，不是程序；第三，凡听到不懂的英文缩写，先举手问全称，我们不带着模糊词进答辩。设备只有手机 / 平板也完全能上：术语卡拍照、计时用亮屏色、记录用备忘录四行文本，具体替代动作见 07-交互使用说明。

下面 11 个术语，每个我给全 5 项：一句话定义、生活类比、易混辨析、面试说法、术语卡链接。请把导学案翻到《术语自测表》，边听边填。

**【术语 1】中期评审（Mid-term Review，中期复核）**
- 一句话定义：项目过半时，用数据和工时复核方向、定下去留的评审。
- 生活类比：装修到一半，业主和工长对着预算单核对——哪些柜子照做、哪些先不做、钱还够不够，而不是等装完才发现超支。
- 易混辨析：最易混「结业路演」。中期评审考「方向对不对、盘子切得准不准」，是决策评审；结业路演考「做没做出来、讲不讲得清」，是结果验收。今天错了，下周还来得及改；路演错了，就没下周了。
- 面试说法：「我在项目中期做了一次正式评审，用答辩数据和两周工时上限复核方向，当场砍掉了数据最弱的功能。」
- 术语卡：`03-配图素材/术语卡/中期评审.svg`（待制，已在 05-配图清单登记）。

**【术语 2】里程碑（Milestone，阶段检查点）**
- 一句话定义：把长项目切成阶段、每阶段设一个可验收的检查点。
- 生活类比：长途自驾每开 200 公里进一次服务区，看油表、看导航、决定下一段走哪条路，而不是一口气开到终点才发现走错。
- 易混辨析：最易混「待办事项」。待办做完就划掉；里程碑必须有可验收产出 + 明确过关口径。今天是里程碑 ④，产出物是 V3 Scope 决策表，不是「开过一次会」。
- 面试说法：「我把八周主项目拆成八个里程碑，每个都绑定一份可验收产出，本周五里程碑 ④ 交付的是终版需求范围。」
- 术语卡：`03-配图素材/术语卡/里程碑.svg`（待制，已登记）。

**【术语 3】V3 Scope（Version 3 需求范围，第三版终版范围）**
- 一句话定义：中期评审后锁定的终版功能清单与优先级。
- 生活类比：旅行前定死的行李清单——带什么、不带什么、哪些是「如果还有空间再塞」，一旦出门就不再往箱子里加东西。
- 易混辨析：最易混「需求池 / 愿望清单」。需求池只进不出、越攒越多；Scope 是资源约束下的排序结果，核心动作是砍，且锁定后不再加。也易混 PRD 功能清单：PRD 描述「做成什么样」，Scope 决定「做不做、先做哪个」。
- 面试说法：「V3 Scope 就是中期评审后锁定的终版范围：P0（Priority 0，最高优先级）必做、P1 带条件、P2 进暂存池，W6 冲刺不再加需求。」
- 术语卡：`03-配图素材/术语卡/V3Scope.svg`（待制，已登记）。

**【术语 4】砍需求（Descoping，需求裁剪）**
- 一句话定义：依据数据和工时，把功能移出本期范围的决策。
- 生活类比：请客前按冰箱和预算删菜——不是这道菜不好吃，是这顿做不完、也摆不下，先记到「下次菜单」。
- 易混辨析：最易混「删功能 / 做不了」。删功能是能力问题，砍需求是主动取舍；也不等于「这功能没价值」，P2 功能往往有价值，只是本期数据弱或工时装不下。
- 面试说法：「我砍需求不凭感觉，只看两条硬依据：答辩数据撑不撑得住、两周工时上限装不装得下，砍掉的都写书面理由进暂存池。」
- 术语卡：`03-配图素材/术语卡/砍需求.svg`（待制，已登记）。

**【术语 5】投资人视角（Investor Perspective，出资方立场）**
- 一句话定义：用「值不值得投」的五问审项目的旁观立场。
- 生活类比：亲戚问你开店打算——谁会来买、凭啥选你家、账怎么算、本钱多久回、下月能不能开张；他不关心你多喜欢这店。
- 易混辨析：最易混「用户视角」。用户问「好不好用」，投资人问「值不值得投、能不能成、能不能上线」；也易混「挑刺」——投资人是帮你排雷的角色，本课要求质询人先夸一条再追问。
- 面试说法：「我会主动切到投资人视角自检五问：谁的问题、凭什么做成、数据在哪、成本怎么算、下周能不能上线。」
- 术语卡：`03-配图素材/术语卡/投资人视角.svg`（待制，已登记）。

**【术语 6】数据备齐（答辩材料四件套与数据出处）**
- 一句话定义：答辩前把四件套与每个论断的数据出处准备齐全。
- 生活类比：去医院复诊前把病历、化验单、用药记录、既往检查装一个文件袋，医生一问就能掏出来，而不是「我大概记得」。
- 易混辨析：最易混「数据好看」。备齐讲的是有出处、可复算、注明样本量；数据不好看也要如实带。评分卡「数据支撑」维度查的是出处完整，不是数值高低。
- 面试说法：「我答辩前做的是数据备齐：PRD、商业画布、增长方案、甘特图四件套，加上每个数字注明样本与来源。」
- 术语卡：`03-配图素材/术语卡/数据备齐.svg`（待制，已登记）。

**【术语 7】答辩（中期陈述 + 质询）**
- 一句话定义：限时陈述项目，并当场回应质疑的现场考核。
- 生活类比：驾照路考——你按路线开（陈述），考官随时发问、加指令（质询），看的不是背没背熟，是临场稳不稳。
- 易混辨析：最易混「演示 / 汇报」。演示只讲「做得多好」，答辩必须讲「依据是什么、被质疑怎么接」；答辩的核心产出是质询记录，不是掌声。
- 面试说法：「中期答辩我按四段八分钟陈述、五分钟质询来练，每句结论配一个数字，被问住就记下来进清算。」
- 术语卡：`03-配图素材/术语卡/答辩.svg`（待制，已登记）。

**【术语 8】风险预判（Risk，风险与应对）**
- 一句话定义：提前列出最可能出问题的点并给出应对动作。
- 生活类比：出门前看天气预报带伞——不是盼着下雨，是万一真下了不至于淋透、行程不至于取消。
- 易混辨析：最易混「问题清单 / 事后复盘」。风险是还没发生、提前预判；复盘是已经发生、事后归因。评分卡里「提了风险无应对」只给 3–4 分，必须带优先级和动作才给 5 分。
- 面试说法：「我在答辩里单独留一段讲风险：最大一条是什么、触发后我第一步做什么，而不是只报好消息。」
- 术语卡：`03-配图素材/术语卡/风险预判.svg`（待制，已登记）。

**【术语 9】复盘（Retrospective，事后归因转动作）**
- 一句话定义：评审后把意见逐条归因、转成下一步动作的收束。
- 生活类比：球赛后全队看录像——不争谁对谁错，只标记「下次这一球怎么处理」，写进训练清单。
- 易混辨析：最易混「总结感想」。感想是「今天收获很大」，复盘必须落到「哪条意见 → 改了什么 → 不改的理由」，且要进 PRD 变更记录才算闭环。
- 面试说法：「评审结束我不只看分数，会逐条复盘质询意见，把每条对应到 Scope 表的一次修改或一条不改的理由。」
- 术语卡：`03-配图素材/术语卡/复盘.svg`（待制，已登记）。

**【术语 10】决策记录（Decision Log，去留依据台账）**
- 一句话定义：把每个去留决定的判定依据当场写进表里的记录。
- 生活类比：家里装修每改一处都在预算本上记一行「几月几号、为什么改、多花了多少」，月底对账不靠回忆。
- 易混辨析：最易混「会议纪要」。纪要记「谁说了什么」，决策记录记「定了什么、凭哪条数据、凭多少工时」。本课要求质询意见当场誊入导学案，否则 Scope 清算无据可依。
- 面试说法：「我每个功能去留都留决策记录：等级、判定依据、工时，事后能逐条复述为什么这么定。」
- 术语卡：`03-配图素材/术语卡/决策记录.svg`（待制，已登记）。

**【术语 11】验收标准（Acceptance Criteria，放行口径）**
- 一句话定义：事先公示、逐项打勾的过关口径。
- 生活类比：交房时的验房单——墙面、水电、门窗逐项打勾，哪一项没过就先整改，不靠「看着差不多」收房。
- 易混辨析：最易混「评分 / 打分」。评分是「做得有多好」（0–5 分），验收是「能不能放行」（过 / 不过二值）。本课 V3 Scope 验收四项全过才进 W6，跟总分多少不是一回事。
- 面试说法：「我把验收标准提前公示给团队：五维过线、保留有依据、砍掉有理由、甘特图按 Scope 更新，四项全过才放行。」
- 术语卡：`03-配图素材/术语卡/验收标准.svg`（待制，已在 05-配图清单登记）。

好，11 个词过完。现在做辨析练习。【问】我说一个说法，你们抢答它混了哪两个词：第一，「我 Scope 里先攒 20 个功能，以后慢慢做」——混了 V3 Scope 和需求池；第二，「我总分 20，肯定能进 W6」——混了评分和验收标准；第三，「这个功能砍掉是因为没什么价值」——把砍需求混成了删功能；第四，「投资人问的其实是用户好不好用」——混了投资人视角和用户视角。【停】这四组，就是往年最容易在面试里露怯的四组，今天先钉死。

### 板书 / 投屏

投屏：11 张术语卡（逐张切换）；板书并排写「四组易混」：中期评审≠结业路演｜Scope≠需求池｜投资人视角≠用户视角｜评分≠验收标准。

### 互动设计

- 两两互问（5 min）：同桌互相抽 3 个术语，只准问「一句话定义 + 最易混哪个词」，答不出翻术语卡。
- 抢答（5 min）：上述四组混淆说法，抢答「混了哪两个词、为什么错」。
- 当堂小测（10 min）：闭卷填《术语自测表》11 题，当堂对 01-教案第八节参考答案，≥9 题达标；未达标的学员课间用术语卡补 3 分钟。

### 本节小结

11 个词分三组记：**评审类**（中期评审、里程碑、答辩、复盘）、**决策类**（V3 Scope、砍需求、决策记录、验收标准）、**视角与证据类**（投资人视角、数据备齐、风险预判）。记住一条主线：用投资人视角看项目、用数据备齐撑论断、用两条硬依据砍出 V3 Scope、用决策记录留住依据、用验收标准决定放不放行、用复盘把意见转成下一步。【面试】这套词，下一节讲答辩标准、第 5 节讲面试题时，会一个不落地用上。

## 第 2 节 · 核心原理讲授 A：中期答辩标准（50–100 min）

### 本节目标

把「怎么讲一次中期评审」拆成可执行的标准：评审性质、评分卡五维与及格线、8 分钟四段式陈述、投资人五问逐问示范。本节结束时，每人手里有一份四段式陈述提纲，以及五问各一版备答。

### 时间轴

| 时段 | 内容 | 方法 |
|---|---|---|
| 50–58 min | 评审性质与面试权重；评分卡五维与及格线 | 讲授 + 评分卡投屏 |
| 58–70 min | 8 分钟四段式陈述结构（对照基础轮 6 分钟三段） | 讲授 + 板书 |
| 70–90 min | 投资人五问逐问追问示范（追问链 + 差答案 vs 好答案） | 逐问示范 + 提问 |
| 90–96 min | 正面案例 1 个 + 反面案例 1 个 + 边界深化 | 双案例研讨 |
| 96–100 min | 本节小结 + 面试连接 | 收束 |

### 讲师话术

【串词】词准了，进场。先说清楚今天的性质：**今天没有新课，你们是主角**。今天要完成两件事：第一，每人一次中期答辩；第二，全班一起做一次「砍需求」，产出主项目终版需求范围 V3 Scope。这份 Scope 是下周开发冲刺的直接输入——下周每一行代码做什么，由今天决定。

为什么中期评审值得整整六节课？给你们一个真实视角：面试里权重最高的问题是「讲一个你做过的项目」，追问最狠的是「你砍过什么需求、为什么砍」。今天练的，就是这两个问题的答案。【面试】换句话说，今天你不是在交作业，是在攒两道面试题的素材。

先讲规则。【操作：投屏评审评分卡】评分五个维度，每维 0 到 5 分：问题真实度、方案完整度、数据支撑、成本可信度、风险预判。及格线两条：每维不低于 3 分，总分不低于 18。为什么不能只看总分？因为总分 18 但有一项只拿 2 分，说明你有明显短板——投资人不会因为你其他三项优秀，就放过那块短板。【停】这里埋一个第 6 节要考的词：及格线是**评分**，不是**验收标准**；V3 Scope 能不能进 W6，看的是四项验收全过，跟这 18 分不是一回事，别混。

流程：四人到六人一组，组内每人陈述 + 质询。质询人按「投资人角色卡」轮换，每轮至少从五问里选一问发起追问。讲师巡场，每组至少完整旁听一轮。计时规则：剩 1 分钟举黄牌，到时举红牌，红牌即停。

**陈述结构**：300 分钟版统一用**四段、每段 2 分钟，共 8 分钟**——问题与方案、数据验证、成本与计划、风险·里程碑·取舍。【操作：投屏四段结构】对照一下原 90 分钟轻量版是「三段 6 分钟 + 4 分钟质询」的基础轮；今天我们时间充裕，深化成「8 分钟四段 + 5 分钟质询 + 2 分钟评分 + 迭代复述」的**多轮演练**。多出来的第四段讲什么？讲风险预判、里程碑位置、以及你打算砍谁——正好把第 1 节的三个词用上。【金句】记住第一条纪律：每一句结论都要配一个数字——没有数字的观点，在投资人耳朵里等于没说。

第四段不是凑时间。它回答投资人最在意、学员最不爱讲的问题：这项目哪儿会翻车、你现在走到哪个里程碑、下周做不完先砍哪个。敢讲风险，比只报好消息更可信。

最后讲 Scope 规则，就三条。所有功能分三档：P0 保留，P1 有条件保留，P2 砍。判定依据只有两条：中期答辩里有没有数据撑它；两周工时上限——大约 80 小时——装不装得下。两条都过不了，就是 P2。P0 总工时不得超过上限的六成，为什么？因为冲刺周一定有联调、修 bug 和返工，按 100% 排期，等于第一天就注定延期。

【问】有没有同学想问：砍掉的功能是不是白做了？【停】不是。砍掉的功能进「暂存池」，路演时是「未来规划」的素材，面试时是你「做过取舍」的证据。好，规则先立到这儿。

### 投资人五问 · 逐问追问示范

五问是今天质询的骨架，也是你们将来真实融资和面试都会遇到的追问链。我逐问示范，质询人照着追，陈述人照着备。

**第一问：这事解决谁的问题？** 追问链：「这个人群现在怎么解决这个问题？」「你的方案好多少，好到值得换吗？」差答案长这样：「白领都需要效率工具」——人群没有边界，等于没有人群。好答案长这样：「25 到 30 岁、一年要投 50 份以上简历的留学生，现在用通用 AI 逐段改文书，一篇 40 分钟；我们的方案 5 分钟出三版可投稿。」有边界的人群、有数字的现状、有量级的差异，三样齐了，这问才算过。

**第二问：凭什么你能做成？** 追问链：「已经有人做了，差异在哪？」「你的独特积累是什么——数据、场景，还是分发？」差答案：「我们用了更强的模型。」模型人人买得到，不是壁垒。好答案要指向别人拿不走的积累：你攒的评测集、访谈挖出的场景细节、已经触达的种子用户。

**第三问：数据在哪？** 追问链：「这个数怎么来的？样本多少？」「如果有人说你样本有偏，你怎么回？」要求：价值判断用问卷和访谈数据，产品效果用评测集数据，市场判断用竞品数据。数据没有出处，这问按 0 分计。这一问正好是术语「数据备齐」的考场。

**第四问：成本怎么算？** 追问链：「单次对话 token（词元）成本多少？」「1000 个活跃用户一个月烧多少钱？毛利是正的吗？」这问直接回扣周三的单位经济模型，数字必须当场可复算——复算不出来，成本可信度掉到 2 分。

**第五问：下周就能上线吗？** 追问链：「你 P0 功能的工时加起来多少？」「做不完的时候，先砍哪个？」这是五问的落点：前四问证明价值，这一问检验你敢不敢取舍。它直接引出接下来的 Scope 清算，也就是术语「砍需求」与「V3 Scope」的入口。

### 正面案例 · 反面案例 · 边界深化

**正面案例（设计背景学员 · 一次过的中期陈述）**：一位设计背景学员做「考研笔记整理助手」，四段这样走——第一段：人群「二战考生、日均整理笔记 90 分钟」，现状数字来自 12 份访谈；第二段：15 份问卷里 11 人把「找不到旧笔记」排第一，评测集 30 条整理任务准确率有记录；第三段：单次调用成本可复算，1000 活跃用户月成本回扣单位经济模型；第四段：主动报「最大风险是长文档切分质量，触发后先降级为单章处理」，并说明本处里程碑 ④ 产出 V3 Scope、下周做不完先砍「社区分享」。评委五维均 ≥3，且每个论断都能翻到出处。它好在哪？【问】不是数据漂亮，是**数据备齐 + 敢讲风险 + 敢先报砍谁**。

**反面案例（零基础学员 · 失败的中期陈述）**：另一位零基础学员 8 分钟讲了 7 分钟功能演示，数据只有一句「用户反馈挺好的」；被问「样本多少」答「没细统计」；成本段 20 秒带过，报不出单次成本；风险段直接说「应该没什么风险」。对照评分卡：数据支撑 1 分、成本可信度 1 分、风险预判 1 分——三项短板，总分再高也按未过处理，进入下周一带材料重审。它错在哪？把**答辩**做成了**演示**，把「数据备齐」做成了「数据好看」，把「风险预判」做成了「不提风险」。

**边界深化：为什么 / 边界 / 常见误解**
- **为什么**每句结论要配数字？不是形式主义：投资人和面试官判断你「有没有真的做过」，靠的就是数字能不能追到出处、能不能当场复算。没有出处的数字，等于没有做过。
- **边界**：数据备齐 ≠ 数据必须好。实验没到周期，诚实标注「实验进行中，X 月 X 日出数」，给出前置数据与预期区间，是合格答法；编造数字按 0 分处理并重审。这是本课的硬边界。
- **常见误解**：「投资人五问是刁难」——不对。五问是**投资人视角**的自检清单，你陈述前自己先跑一遍，比被质询人问出来强十倍。评审不是考试，是拿别人的脑子帮自己的项目排雷。

### 板书 / 投屏

投屏：中期评审评分卡（五维 × 三档）、四段式陈述结构图、投资人五问总览页、正反面案例对照页。板书：「中期评审 = 数据答辩 + Scope 清算」「四段 × 2′」「五问」「每句结论配一个数字」。

### 互动设计

- 【问】五问里哪一问答不上最致命？引导到第 1 问或第 3 问（人群不成立则一切归零；数据缺失则所有论断等于没说）。
- 对着反面案例逐维举手表决打分，把「1 分」的理由说清楚。
- 每人当场在导学案写五问各一版答案（只写要点，不写全文），同桌互抽一问。

### 本节小结

三条带走：一，中期评审考决策、结业路演考结果；二，陈述按四段 8 分钟，每句结论配数字；三，五问既是质询骨架也是自检清单。【面试】**这段在面试里怎么答**：面试官问「你项目中期怎么汇报」，别从功能讲起，先说「我在里程碑 ④ 做了一次中期评审，按四段式陈述，每句结论都能追到数据出处，还主动报了风险和先砍谁」——这一句里就嵌了「中期评审、里程碑、答辩、数据备齐、风险预判」五个术语，是第 5 节 Q1 的标准答法骨架。

## 第 3 节 · 核心原理讲授 B + 案例反面：V3 Scope 决策与砍需求（100–150 min）

### 本节目标

把「怎么砍」从凭感觉变成可复算的规则：两条硬依据、P0/P1/P2 三档、60% 上限、P1 三件套、理由链「数据·竞争·工时」。用正面演示 + 反面案例双案例研讨，让学员能指出失败决策的违规点。本节结束时，全班对齐判定规则，为第 4 节各组清算做准备。

### 时间轴

| 时段 | 内容 | 方法 |
|---|---|---|
| 100–112 min | V3 Scope 决策规则逐条讲（两条依据 / 三档 / 60% / P1 三件套） | 讲授 + 板书 |
| 112–124 min | 正面演示：「留学文书助手」砍需求决策（F1/F2/F3 理由链） | 逐字示范 |
| 124–138 min | 反面案例：全是 P0 的失败 Scope 表 + 无数据答辩；双案例研讨 | 分组研讨 + 抢答 |
| 138–146 min | 边界深化：为什么 / 边界 / 常见误解 | 讲授 + 提问 |
| 146–150 min | 本节小结 + 面试连接 | 收束 |

### 讲师话术

【串词】上一节练「讲」，这一节练「砍」。先把规则立死。

**V3 Scope 决策规则**。判定依据只有两条：中期答辩数据 + 两周工时上限（W6 冲刺周至路演收尾，单人可投入约 80 小时）。两条依据逐条核对，不允许「凭感觉」。三档：P0 保留——有数据支撑（问卷 / 访谈 / 评测 / 试用数据至少其一）且工时在上限内，无条件保留，P0 总工时 ≤ 上限 60%；P1 有条件——数据部分支撑或依赖外部条件、全量做会爆工时，必须写明三件事：简化到什么程度、触发条件与检查点（建议 W6D2 中午核心链路跑通）、不过怎么办；P2 砍——无数据支撑、无差异化、或两周工时装不下，写入「暂存池」并附书面理由，一句话即可，不许空着。

【问】为什么 P0 要压在 60%？【停】冲刺周必然有联调、修 bug、试用反馈返工；按 100% 排期，等于第一天就注定延期。留 40% 不是保守，是给「一定会发生的事」留位置。【术语】这里每个去留都要落进**决策记录**：等级、判定依据、工时，事后能逐条复述。

### 砍需求决策演示（教学示例逐字稿）

注意，下面这个项目是教学示例「留学文书助手」，不是你们中任何人的项目，我们拿它练手。

它中期答辩后剩三个候选功能：F1 文书智能改写，F2 智能选校推荐，F3 简历一键生成。两周工时上限约 80 小时，三个全做要 64 小时——工时看起来装得下，是不是就都留？我们按理由链过一遍。

F1 文书改写：问卷里 82% 的目标用户把它排第一，5 个访谈全部提及，原型已有、只剩打磨，估时 12 小时。数据强、有基础、工时小——P0，保留，没有争议。

F3 简历一键生成：问卷里只有 9% 提到；竞品的简历模板遍地免费，做了也没有差异化；开发加模板维护要 24 小时。理由链走完：数据弱、竞争无差异、工时挤占 P0 的打磨——P2，砍。写进暂存池，路演可以当未来规划讲，不算白做。

F2 选校推荐最有意思，也最容易犹豫：访谈 5 人里 4 人提到选校焦虑，数据不弱；但要接外部选校数据，全量做要 28 小时，加上 F1 和基础联调，80 小时的盘子就爆了。怎么办？降级处理：P1，有条件保留。条件写死三件事：第一，把「全量选校报告」简化为「按背景推荐三档学校」，估时 8 小时；第二，触发条件是下周二中午核心链路跑通；第三，跑不通，它自动降为 P2。看到了吗，这就是「有条件」三个字的含义：不是含糊地「尽量做」，而是写清楚简化到什么程度、什么时间点检查、不过怎么办。

【金句】Scope 是砍出来的——什么都保留，等于什么都没有资源做好。【停】再补一句更狠的：【金句】现在砍需求是决策，上线之后砍需求是事故。

演示结论：三进二。F1 全力做，F2 简化版带条件做，F3 砍。每个决定后面都站着一条理由链——数据、竞争、工时，至少两条，缺依据就退回重判。

### 反面案例与双案例研讨

**反面案例一：全是 P0 的失败 Scope 表**。某零基础学员交上来的决策表，五个功能全标 P0，判定依据一栏统一写「都很重要」，P0 工时合计 96 小时——已超 80 小时上限，更别提 60% 红线。P1 栏空着，P2 栏空着，暂存池没建。【问】这张表有几处违规？【停】至少四处：① 无一条判定依据落到数据或工时；② P0 总工时超上限且远超 60%；③ 「都很重要」是价值判断，不是资源约束下的排序；④ 没有任何砍掉项与书面理由，等于没做决策记录。改法：把 80 小时盘子摆出来，逐功能问「答辩数据是什么、要多少工时」，超了就让数据最弱的让路，写进暂存池。

**反面案例二：无数据答辩引出的错误保留**。沿用第 2 节那位学员的「用户反馈挺好的」——因为数据支撑维度只拿 1 分，用它当依据保留的功能，判定依据自动作废，必须退回重判。更要命的是 P1 写「尽量做」：这不是条件，是没条件。合规写法是三件套（简化程度 / 检查点 / 不过怎么办），否则 W6 检查点无从执行。

**双案例研讨**：每组 4 分钟，对照「正面演示 F2 的 P1 三件套」与「反面案例一的 P1 空栏」，各写出 ≥3 处违规点与对应改法，填进导学案反面案例辨析记录。讲师抽两组口述，统一裁决口径：只认数据和工时，不认热情。

### 边界深化：为什么 / 边界 / 常见误解

- **为什么**每个决定至少要两条依据？单条依据最容易自欺：「数据还行」可以挑好看的说，「工时够」可以低估估时；两条交叉核对，才逼出真实取舍。
- **边界**：砍需求 ≠ 否定功能价值。P2 进暂存池，是「本期不做」，不是「永远不做」；也是 W6 锁定后唯一的新需求出口——谁提新功能，标准回应只有一句「先写进暂存池」。
- **常见误解**：「砍得越少说明项目越健康」——恰恰相反。一张全是 P0 的表，说明你没做资源约束下的排序；评审桌上砍得越狠，冲刺周越不容易翻车。

### 板书 / 投屏

投屏：V3 Scope 三档规则页、教学示例「留学文书助手」理由链三列图、正反案例对照页。板书：「判定依据 = 中期答辩数据 + 两周工时上限（约 80h）」「P0 ≤ 60%」「P1 三件套」「理由链：数据·竞争·工时，≥2 条」。

### 互动设计

- 【问】「我的功能个个都重要，一个都不能砍」，怎么反驳？反问两句：两周工时装得下吗？每个功能的答辩数据分别是什么？
- 【问】P1 的「有条件」写成什么样才合格？答三件套，「尽量做」不算。
- 【问】砍掉的功能是不是白做了？答：进暂存池，是路演未来规划素材，也是面试「你砍过什么需求」的答案。
- 双案例研讨填记录，抽两组汇报。

### 本节小结

规则一句话：两条硬依据、三档、60% 红线、P1 三件套、理由链至少两条；意见不落纸面等于没评，砍掉项不写理由等于没砍。【面试】**这段在面试里怎么答**：面试官问「你砍过什么需求，为什么砍」，标准结构就是「具体功能 + 中期评审 + 两条硬依据（带一个数字）+ 决策记录与暂存池 + 结果与复盘」，别只说「砍了一个不太重要的功能」。这正是第 5 节 Q2 的骨架，下一节先拿它练多轮实操。

## 第 4 节 · 实操演练与巡场：中期答辩多轮演练 + Scope 清算（150–200 min）

### 本节目标

把前两节的标准变成肌肉记忆：**多轮答辩演练**——讲 8 分钟 + 质询 5 分钟 + 评分 2 分钟 + 迭代复述；同一人讲两轮，看迭代后的评分涨幅，而不是一次定生死。随后各组完成 V3 Scope 决策表初稿。手机 / 平板学员全程有可执行替代动作。

### 时间轴

| 时段 | 内容 | 方法 |
|---|---|---|
| 150–158 min | 任务说明：多轮演练规则、迭代复述口径、Scope 清算任务卡 | 讲授 + 任务卡投屏 |
| 158–163 min | 讲师示范一轮完整「8′ 陈述 + 5′ 质询 + 评分 + 迭代」 | 示范 |
| 163–190 min | 学员实操：第 1 轮答辩打分 → 第 2 轮迭代复述再打分 → 各组 Scope 清算；讲师巡场 | 分组实操 + 巡场 |
| 190–200 min | 讲评：迭代前后评分对比、抽 2 组报 Scope 结论、争议裁决 | 讲评 + 汇报 |

### 讲师话术 · 任务说明

【串词】现在进入今天最值钱的 50 分钟。规则一句话：**同一个人讲两轮**。

**单轮 = 讲 8 分钟 + 质询 5 分钟 + 评分 2 分钟 + 迭代复述**。第 1 轮：陈述人按四段式讲 8 分钟，质询人按角色卡从五问里发起 5 分钟质询，全组按评分卡打五维分、记录员把每条质询意见誊进导学案质询记录栏。第 2 轮（迭代）：陈述人**只针对质询意见**复述——「哪条意见我认、改了什么；哪条不认、理由是什么；哪条进 Scope 清算」，再打一次五维分。我们看的是**涨幅**，不是绝对值。【金句】一次讲砸不叫失败，第二轮不改才叫失败。

【操作：投屏任务卡】三组同时推进，讲师巡场。

### 讲师示范一轮

我用教学示例「留学文书助手」走一遍，你们看节奏。陈述 8 分钟四段：问题与方案（人群、痛点数字）、数据验证（82% 问卷 / 5 人访谈 / 评测集）、成本与计划（单位经济模型、W6 工时）、风险·里程碑·取舍（外部选校数据依赖、里程碑 ④、先砍 F3）。质询 5 分钟：质询人问第三问「数据在哪」，追问「82% 的样本多少、怎么收的」，再追第二层「样本只覆盖一所学校，会不会有偏」。陈述人答：样本量、收集方式如实报，承认覆盖边界，说明补样计划——**承认边界、给补样方案，不硬顶、不编数**。评分 2 分钟：数据支撑给 4 分，因为出处完整但覆盖面有限。迭代复述：陈述人补一句「这条意见我认，进复盘：下一版补两所学校样本，并把 F2 的触发条件写得更严」——数据支撑复评给 5 分。看到了吗，涨的这 1 分，就是质询意见落纸面换来的。

### 讲师巡场话术

- 每组至少完整旁听一轮「陈述 + 质询 + 迭代」，对照评分卡记分，优先旁听自己不熟悉的项目。
- 听到「只讲功能不讲数据」，随时插入同一句话：「停一下——这个判断的数据是什么？」连续两次被问住的项目，标记为清算环节重点对象。
- 质询火药味过重、陈述人卡壳超 20 秒时介入：「这个问题很好，留到 Scope 清算环节——它正好是砍需求的输入。」并提醒：每轮质询结束，质询人先说一条本组认可的优点。
- 看到迭代复述在「重讲一遍功能」而非「回应意见」，插一句：「只讲改了什么，成绩不看复述流畅度，看意见有没有落地。」
- Scope 清算三连问：「工时上限摆了吗？依据对应哪条数据？P1 的检查点写了吗？」看到「全是 P0」，问「80 小时盘子摆出来算一遍，超了谁让路」；看到 P1 写「尽量做」，要求当场改写成三件套。
- 组内评分汇总 5 分钟：每人把两轮五维分与质询记录誊入导学案；每组选出「最狠的一问」，全班讲评备用。

### 常见卡点 3 条

**Q1 · 讲一下你项目中期是怎么向团队 / 投资人汇报的。**〔项目深挖〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 点明阶段与里程碑（里程碑 ④、中期评审）；② 说出结构化陈述（四段式 8 分钟）；③ 强调结论配数字、数据可追出处（数据备齐）；④ 收尾落到产出（V3 Scope / 决策记录），不是「汇报完就完了」 |
| 追问链 | 第 1 层「为什么用四段、不直接演示功能？」→ 第 2 层「每段的数字出处是什么，能当场复算吗？」→ 第 3 层「汇报里最不好讲的一段是哪个，你怎么处理的？」 |
| 失败答法 + 失分原因 | 「我做了一个 PPT，把功能一个个演示了一遍，大家反馈挺好。」——把答辩讲成演示，无阶段、无数据、无产出，踩分点 ①②③ 全丢；「反馈挺好」是无出处的主观判断，追一层就露怯 |
| 60 秒标准答法 | 「我在主项目里程碑 ④ 做了一次正式的**中期评审**，不是功能演示。陈述按四段八分钟：问题与方案、数据验证、成本与计划、风险与里程碑取舍，每段两分钟，每句结论都配一个能追到出处的数字——这是我理解的**数据备齐**。第四段我主动报最大风险和『下周做不完先砍谁』，因为投资人视角最在意这个。汇报的产出不是掌声，是一份带质询记录的**决策记录**，当天就用来定 **V3 Scope**。所以我的中期汇报，本质是拿数据和工时复核方向、定下去留。」 |

**Q2 · 你砍过什么需求？当时怎么定的，砍完后悔吗？**〔行为题 / 项目深挖〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 报出具体功能、所处阶段（中期评审）；② 明确两条硬依据（答辩数据 + 两周工时上限）且带至少一个数字；③ 提到决策记录与 P2 书面理由进暂存池；④ 收尾落到结果与复盘（W6 按 Scope 执行 / 下一版再评） |
| 追问链 | 第 1 层「凭什么砍它不砍别的？」→ 第 2 层「砍完数据后来变好了，你会不会加回来？」→ 第 3 层「如果团队有人反对，你怎么说服？」 |
| 失败答法 + 失分原因 | 「砍了一个不太重要的功能，因为时间不够。」——「不太重要」是价值判断不是依据，「时间不够」没数字，踩分点 ②③ 全丢；被追「凭什么不砍别的」立刻答不上，暴露没做过**决策记录** |
| 60 秒标准答法 | 「中期评审时我砍掉了『简历一键生成』。判定不凭感觉，只有两条硬依据：答辩数据里问卷只有 9% 提到它，竞品免费模板遍地没差异化；工时上开发加模板维护要 24 小时，会挤占 P0 的打磨，而两周上限约 80 小时。所以定 **P2**，写书面理由进暂存池——**砍需求**不是否定价值，是本期不做。每个去留我都留了**决策记录**：等级、判定依据、工时，事后能逐条复述。砍完不叫后悔：W6 按 **V3 Scope** 锁定执行，功能在暂存池里，下一版数据起来了再评——这叫按数据迭代，不叫反悔。」 |

**Q3 · 中期实验数据不好看、没达到预期，你怎么汇报？**〔场景设计〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 如实报「基准值 → 结果值」并标来源与时间；② 给归因（假设哪里错、样本 / 周期 / 链路），不藏不编；③ 给迭代计划（补样、调实验、下一版验证）；④ 把「不好看」转成「发现了真问题」，回扣复盘 |
| 追问链 | 第 1 层「是不是你实验设计本身错了？」→ 第 2 层「那这组数据还能不能用、要不要重跑？」→ 第 3 层「投资人说『数据不好还往下做』，你怎么回？」 |
| 失败答法 + 失分原因 | 「数据应该还不错吧，可能样本少了一点，后面会好起来的。」——含糊、无基准值、无归因、无计划，还带侥幸；「应该」二字直接坐实**数据备齐**没做，编造数字更是本课 0 分红线 |
| 60 秒标准答法 | 「我会如实报，不修饰：基准值多少、结果值多少，标清来源和时间，这是**数据备齐**的底线，数据不好看也一样。然后给归因：是样本覆盖窄、实验没到周期，还是链路本身有问题，我会说清哪一种。接着给迭代计划：补两所学校样本、把周期跑满，下一版验证。我不会编数——**中期评审**看的就是方向对不对，数据不好看恰恰说明发现了一个真问题，比一个漂亮但没出处的数更有价值。这条会进**复盘**，转成 PRD 变更记录里的一条动作。要重跑就重跑，但绝不把没出处的数写进答辩。」 |

**Q4 · 投资人当场质疑你样本有偏 / 数据不可信，你怎么接？**〔场景设计〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 先承认边界、不硬顶不辩解；② 说明样本构成、收集方式与适用范围；③ 给补样 / 交叉验证计划与时间点；④ 把质疑记为有效信息（进复盘 / 清算），不沉默、不冷场 |
| 追问链 | 第 1 层「那这数据还能用吗？」→ 第 2 层「补样要多久，会不会拖慢上线？」→ 第 3 层「如果补完结论反过来了呢？」 |
| 失败答法 + 失分原因 | 「不可能有偏，我们数据挺全的。」或干脆沉默。——硬顶等于拒绝验证，面试官会一路追到自相矛盾；沉默则直接丢「被质疑怎么接」整题；两者都没踩到 ①②③ 任一条 |
| 60 秒标准答法 | 「先接住，不硬顶：您这个提醒是对的，我这份样本主要来自一所学校，覆盖面确实有限。我说明三件事：样本量、收集方式、以及这个结论**只适用于哪类人群**——**数据备齐**本来就必须带边界。然后给动作：下一版补两所学校的样本做交叉验证，出数时间点写进计划。会不会拖上线？不会，因为它影响的是某个 P1 的触发条件，不占 P0 工时。补完如果结论反过来，那正好是该**砍需求**或降级的功能，我按检查点自动降 P2。这条质疑我会当场记进质询记录，进**复盘**——被问住也是有效信息，说明这里要么补数据，要么砍。」 |

**Q5 · 中期评审和结业路演，考察的东西有什么不同？**〔技术理解〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 中期评审考决策（方向、范围、取舍）；② 结业路演考结果（做没做出来、讲不讲得清）；③ 点明中期错了还来得及改、路演错了没有下次；④ 各举一个对应产出（V3 Scope / 可演示成品） |
| 追问链 | 第 1 层「那中期评审的产出到底是什么？」→ 第 2 层「为什么说中期错了还来得及？」→ 第 3 层「你自己的中期评审，产出的东西后来用上了吗？」 |
| 失败答法 + 失分原因 | 「差不多吧，都是讲一次项目，路演人多一点。」——把两个**里程碑**混成一个，踩分点 ①② 全丢；答不出产出，说明没建立「里程碑绑可验收产出」的概念 |
| 60 秒标准答法 | 「这是两个**里程碑**，考察的东西不一样。**中期评审**考决策：方向对不对、盘子切得准不准，产出是一份 **V3 Scope** 决策表和带质询记录的**决策记录**；**结业路演**考结果：做没做出来、讲不讲得清，产出是可演示的成品。最关键的区别是容错：中期错了，下周冲刺还来得及改；路演错了，没有下周了。我自己的中期评审产出当天就用了——按 Scope 更新 PRD 和甘特图，W6 直接照它开发，而且 Scope 锁定后不再加需求。所以我理解的中期评审，本质是一次**验收方向**的关口，不是一次预演。」 |

**Q6 · 为什么 P0 总工时要压在上限 60% 以内，而不是排满？**〔项目深挖 / 技术理解〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 说明冲刺周必有联调、修 bug、试用反馈返工；② 讲清按 100% 排期 = 第一天注定延期；③ 点出 60% 是给「一定会发生的事」留缓冲，不是保守；④ 关联 P1 检查点与风险预判 |
| 追问链 | 第 1 层「留 40% 会不会太浪费？」→ 第 2 层「真没返工，多出来的时间干嘛？」→ 第 3 层「P1 检查点没过怎么办？」 |
| 失败答法 + 失分原因 | 「老师 / 主管规定的，我们就照做。」——只有服从没有判断，踩分点 ①②③ 全丢，面试官要的是你对资源约束的理解，不是背规则 |
| 60 秒标准答法 | 「因为冲刺周一定有三件躲不掉的事：联调、修 bug、试用反馈返工。按 100% 排期，等于第一天就注定延期——这不是保守，是给**一定会发生的事**留位置。两周上限约 80 小时，P0 压在 60% 也就是 48 小时以内，剩下的留给返工和 P1。P1 不是『尽量做』，它有三件套：简化到什么程度、检查点（我们设在 W6D2 中午核心链路跑通）、不过怎么办——没跑通就**自动降 P2**，进暂存池，绝不占用冲刺工时。这其实就是**风险预判**：把『会返工』提前写进计划，而不是等它发生再救火。真没返工，多出来的时间用来打磨 P0，也不算浪费。」 |

**Q7 · 评审意见不落纸面会有什么后果？你怎么闭环？**〔行为题〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 讲清后果：Scope 清算无据可依、W6 复发；② 指出「意见落纸面 = 决策记录」；③ 给出闭环动作（逐条「改了什么 / 不改的理由」进 PRD 变更记录）；④ 关联复盘与验收标准 |
| 追问链 | 第 1 层「怎么保证记录员真记了？」→ 第 2 层「意见太多记不过来怎么办？」→ 第 3 层「不改的那条，怎么跟质询人交代？」 |
| 失败答法 + 失分原因 | 「大家当场都听到了，回去改就行。」——口头意见会散，踩分点 ①②③ 全丢；「回去改」没有可核对的载体，追一层就答不出「改了什么、凭哪条」 |
| 60 秒标准答法 | 「口头意见说完就散，最直接的后果是 **Scope 清算无据可依**：决策表的『判定依据』栏对应不到任何一条记录，只能凭感觉填，W6 同一个问题一定复发。所以我要求每条质询意见当场誊进导学案，这就是**决策记录**——记的不是谁说了什么，是定了什么、凭哪条数据、凭多少工时。闭环分两步：逐条写『改了什么 / 不改的理由』，同步进 PRD 变更记录；再在**复盘**里把它们转成下一步动作。最后用**验收标准**卡一道：保留有依据、砍掉有理由，四项全过才放行。意见不落纸面，等于没评——这条我是吃过亏才记住的。」 |

**Q8 · 如果重来一次，中期评审你会怎么准备？**〔行为题 / 场景设计〕

| 项 | 内容 |
|---|---|
| 踩分点 | ① 承认具体不足（不是空泛「准备不充分」）；② 给出可执行的准备清单（四件套、五问各一版、术语对齐）；③ 说明会提前跑一遍投资人视角自检；④ 落到复盘意识与下一版动作，不沉溺后悔 |
| 追问链 | 第 1 层「具体哪一环节最拖后腿？」→ 第 2 层「提前自检能拦住多少问题？」→ 第 3 层「这套准备你怎么用到下一次项目？」 |

| 60 秒标准答法 | 「最拖后腿的是**数据备齐**：上次答辩被问样本量，我答『没细统计』，数据支撑直接掉到 1 分。重来一次我会做三件事。第一，四件套——PRD、商业画布、增长方案、甘特图——提前一天自查，每个数字注明样本与出处，不好看的也如实带。第二，**投资人五问**各备一版答案，尤其『数据在哪』和『下周能不能上线』，并且自己先切到**投资人视角**跑一遍，别等质询人问出来。第三，把术语先对齐：分清**中期评审**和结业路演、**评分**和**验收标准**，记录才写得对。这不是后悔，是**复盘**——把一条质询意见转成一条下次能执行的准备动作，用到下一个**里程碑**上。」 |
