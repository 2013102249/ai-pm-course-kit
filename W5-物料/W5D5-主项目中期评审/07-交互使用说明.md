# 课堂交互使用说明 · W5 周五《主项目中期评审》——中期评审现场组织方案

> AI 产品经理就业训练营 · 第五周第五天 · 300 分钟（6 课时 × 50 分钟）· 讲师与助教开课前 10 分钟逐项检查
> 原有说明保留：本课无专用交互页，评审课的核心「交互」是答辩现场本身，工具需求为计时、角色卡与评分汇总，均为流程组织问题。本文件即评审现场的组织手册。300 分钟版在保留原有五节操作说明的基础上，把答辩规格由「6 分钟 + 4 分钟单轮」深化为「8 分钟 + 5 分钟 + 评分 + 迭代」多轮演练，并新增《6 节使用时机表》与《设备要求表》。

## 一、分组与计时（原有操作说明保留，计时口径对齐 8+5 多轮）

### 1. 课前检查（开课前 10 分钟）

| 检查项 | 操作 |
|---|---|
| 分组落位 | 按 4–6 人一组就座，围坐或圆桌；每组指定 1 名计时员、1 名记录员 |
| 计时工具 | 每组 1 套：手机计时 + 黄牌（剩 1 分钟）/ 红牌（到时）卡；无牌子可用手机亮屏色代替 |
| 纸质物料 | 评分卡每人 3 份、投资人角色卡每组 1 套、导学案每人 1 份 |
| 术语与面试物料（新增） | 术语卡每组 1 套（11 张）、四组易混辨析对照图、面试追问卡每组 1 套（8 题）、面试踩分点速查表 |
| 投屏 | PPT 36 页就绪；评分卡投屏版、6 节时间轴图已打开；讲师端备好教学示例卡与正反面案例卡 |
| 线上班替代 | 分组会议室 + 每组共享屏幕计时器；角色卡、评分表、术语卡发在线文档模板，记录员实时填写；手机档用语音条参与质询与口播 |

### 2. 计时规则（300 分钟版多轮口径）

| 规则 | 口径 |
|---|---|
| 陈述 | 8 分钟（四段 × 2 分钟）；黄牌提示剩 1 分钟，红牌即停。原 90 分钟轻量版「6 分钟三段 + 4 分钟质询」保留为基础轮对照 |
| 质询 | 5 分钟（6 人组压缩至 4 分钟）；质询人每轮至少发起 1 问，可追问 1–2 层 |
| 评分 | 2 分钟：全组按评分卡打五维分，记录员誊录质询意见，陈述人口头自评最弱一维 |
| 迭代复述 | 3 分钟要点版：只讲「认哪条 / 改了什么 / 不认的理由 / 哪条进清算」，然后同卡再打一次分算涨幅 |
| 转场 | 上一人迭代结束到下一人陈述开始，不超过 30 秒 |
| 评分汇总 | 每组答辩全部结束后 5 分钟：誊两轮分、誊质询记录、选出「最狠的一问」 |

## 二、投资人角色卡（每组 1 套，质询人按五问轮换，原有内容保留）

### 1. 轮换表（贴在每组桌面）

| 答辩轮次 | 质询人主问 | 其余组员 |
|---|---|---|
| 第 1 人 | 问 1：这事解决谁的问题 | 自由补充 ≤1 问 |
| 第 2 人 | 问 2：凭什么你能做成 | 同上 |
| 第 3 人 | 问 3：数据在哪 | 同上 |
| 第 4 人 | 问 4：成本怎么算 | 同上 |
| 第 5 人 | 问 5：下周就能上线吗 | 同上 |
| 第 6 人 | 自选五问中最狠的一问 | 同上 |

### 2. 质询三条纪律

1. 每轮质询结束，质询人**先说一条本组认可的优点**，再给建议——防止评审变批斗。
2. 追问不超过两层，把话说完的机会留给陈述人；第 5 节面试模拟时才连追 2–3 层。
3. 每条质询意见必须被记录员写进陈述人的评审记录表——**意见不落纸面等于没问**；这条同时也是「决策记录」术语的现场落点。

### 3. 陈述人义务

被质询时若答不上，说「这个点我记下来，进 Scope 清算 / 复盘」即视为有效应对，不扣分；沉默或放弃答辩才扣方案完整度分。想编一个没出处的数字，按数据支撑 0 分计并列入重审名单。

## 三、评分汇总与 Scope 清算流程（原有步骤表保留，时间对齐第 4 节 50 分钟）

| 步骤 | 节次 / 时间 | 动作 | 产出 |
|---|---|---|---|
| 1 | 第 4 节 · 单轮内 | 组内誊分：五维分入评分卡（第 1 轮），质询记录入导学案；陈述人口头自评五维中最弱一项 | 评分卡第 1 轮分 + 记录表 |
| 2 | 第 4 节 · 单轮内 | 迭代复述 3 分钟 + 第 2 轮打分，算涨幅；「看涨幅，不看绝对值」 | 两轮分 + 涨幅 |
| 3 | 第 3 节 · 100–124 min | 讲师用教学示例「留学文书助手」走三功能理由链（F1 保留 / F2 降级有条件 / F3 砍） | 全班对齐判定规则 |
| 4 | 第 3 节 · 124–138 min | 反面案例研讨：全是 P0 的失败 Scope 表 / P1 写「尽量做」，各组写 ≥3 处违规点与改法 | 反面案例辨析记录 |
| 5 | 第 4 节 · 清算段 | 各组/每人填 V3 Scope 决策表：等级、判定依据（答辩数据 + 工时）、本周工时；P0 总工时 ≤ 上限 60%；P1 写三件套（简化程度 / 检查点 / 不过怎么办）；P2 写书面理由进暂存池 | Scope 决策表初稿 |
| 6 | 第 4 节 · 讲评段 | 抽 2 组各 90 秒报结论；争议项当场裁决，裁决口径 = 只认数据和工时 | 争议清零或标注遗留 |
| 7 | 第 5 节 · 200–250 min | 两两模拟：面试官 / 候选人轮换，从 8 题抽 ≥4 题，连追 2–3 层，填《面试模拟记录表》并自评分 | 面试模拟记录表 |
| 8 | 第 6 节 · 250–300 min | 三句收束 + 质询意见逐条闭环 + P5 迭代页归档 + V3 Scope 验收四项当堂过审 | 验收结论 + 归档件 |
| 9 | 课后 | 按 Scope 更新 PRD V2.1 与甘特图 V2，周日 22:00 前提交，讲师逐份确认 | V3 Scope 定稿 |

## 四、超时与冷场预案（原有预案保留 + 300 分钟版新增 3 条）

| 状况 | 预案 |
|---|---|
| 陈述严重超时 | 红牌即停，话术：「没讲完的部分，质询人会替你问出来。」规则对所有人一致 |
| 质询冷场、组员问不出 | 记录员翻开角色卡念下一问；讲师巡场补问教学示例中的追问链 |
| 陈述人被问住冷场 | 讲师介入：「答不上来也是有效信息——正好说明这里要砍或要补数据。」引导记入清算清单 |
| 火药味过重 | 启动「先夸一条再继续」纪律；仍失控则该问题移入清算环节处理 |
| 数据被质疑造假 | 当场声明口径：编造数字按数据支撑 0 分计并列入重审名单；实验未出数的，标注「进行中 + 出数日期」 |
| 清算时间被压缩 | 启动降级流程：只裁决 P0 与争议项，P2 默认成立课后书面确认，周一晨会补过审 |
| 助教分工 | 助教任第 2 巡场评委，负责 2 组旁听记分 + 全场计时提醒 + 纸质物料补给 |
| 迭代复述变成「再讲一遍」（新增） | 打断并给句式：「三句话——认第几条、改了什么、哪条进清算」，只给 3 分钟要点版 |
| 面试模拟里硬顶或编数（新增） | 叫停并回到三步：「承认边界 → 说明适用范围 → 给验证计划」；编数按 0 分红线处理，当场重答 |
| 手机档学员掉队（新增） | 按《设备要求表》执行替代动作：备忘录四行文本、亮屏色计时、同组电脑共享投屏；不降低验收标准，只换载体 |
