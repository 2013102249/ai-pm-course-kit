# 分层习题 · W5 周五《主项目中期评审（里程碑 ④）》——评审日不设习题

> 说明件：本课为里程碑评审日，当天全部训练量已投入「答辩 + 质询 + Scope 清算」，且主项目产出本身就是最大的作业。按评审日轻量口径，本课不设传统三层习题，改为「V3 Scope 验收清单」——它是 W6 开发冲刺的放行门槛，性质为**通关式验收**而非练习题。

## 一、为什么不设传统习题

| 原因 | 说明 |
|---|---|
| 当天已有高强度实战 | 每人完成 6 分钟陈述 + 4 分钟质询 + Scope 决策表，训练量超过常规习题 |
| 考点即产出 | 本课考点「Scope 决策分析」不通过选择题考，而通过真实项目决策表考——后者更接近面试与工作实况 |
| 验收必须服务 W6 | V3 Scope 是 W6 冲刺的直接输入，验收标准提前公示，学员清算时即按标准自查 |

## 二、V3 Scope 验收清单（四项全过 = W6 放行）

**通过口径：四项全部通过方可进入 W6 开发冲刺；任一项未过，下周一带全套材料找讲师重审。**

| # | 验收项 | 达标标准 | 核验方式 | 未过补救 |
|---|---|---|---|---|
| 1 | 评审五维过线 | 五维评分每维 ≥3 分，且总分 ≥18/25 | 查评分卡（本人 + 组内互评交叉）；讲师抽查 1/3 学员的评分卡与质询记录是否对得上 | 未过维度对照档位描述补证据：缺数据则补样本量与出处，缺成本则重算单位经济模型；**下周一带材料重审** |
| 2 | 保留功能有判定依据 | 每条 P0/P1 功能的「判定依据」栏均落到具体条目：答辩数据（注明样本量/出处）+ 工时测算，两项至少其一且不空泛 | 逐条核对 Scope 决策表；抽查判定依据能否对应到质询记录或四件套材料中的具体数字 | 依据空泛的条目退回重写，讲师逐条批注；**重审时逐条复述依据** |
| 3 | 砍掉项有书面理由 | 每条 P2 功能在决策表「暂存池」中有 ≥1 句书面理由（数据弱 / 无差异化 / 工时装不下三者之一），且 PRD V2.1 中已移入暂存池章节 | 查决策表暂存池栏 + PRD V2.1 变更记录；核对「砍掉的功能 ≠ 消失无踪」 | 补写理由并同步 PRD V2.1；连续两项无理由砍掉的，视为未认真清算，**整表重审** |
| 4 | 甘特图按 Scope 更新 | W6 甘特图 V2 仅含 P0/P1 功能；P0 总工时 ≤ 上限 60%；每条 P1 标注检查点（建议 W6D2 中午）与自动降级条件；预留 ≥20% 缓冲 | 查甘特图 V2 与 Scope 决策表一致性，工时逐项加总复算 | 重排甘特图并重报工时；周日 22:00 截止未交或未过，**周一晨会带材料重审，过审前不进入 W6D1 开发** |

## 三、重审流程（统一口径）

| 环节 | 说明 |
|---|---|
| 时间 | 下周一 12:30–13:30 午间，或当天晚自习，由讲师指定 |
| 材料 | 四件套 + 评分卡 + Scope 决策表 + 更新后的 PRD V2.1 与甘特图 V2 |
| 形式 | 10 分钟重述（针对未过项）+ 10 分钟讲师质询 + 当场裁决 |
| 结果 | 过 → 进入 W6 正常节奏；仍不过 → 项目降级为「保 P0 最小闭环」，砍至 1–2 个核心功能后放行，避免拖垮冲刺周 |
| 记录 | 重审结论写入个人学习档案，W7 简历诊断时作为项目迭代素材 |

## 四、自测附录：Scope 决策口测三题（自查用，不交作业）

1. 面试官问：「你中期评审时砍掉了什么功能，为什么？」——用「数据 + 工时」各一句话作答，30 秒内说完。（对照：本课教学示例中 F3 的砍法。）
2. 你的 P1 功能检查点到了但核心链路没跑通，按规则应该怎么办？（答：自动降 P2，进暂存池，不得占用冲刺工时。）
3. 同学说「这功能投资人一定会喜欢，加进来吧」，Scope 锁定后的正确回应是什么？（答：写进暂存池，结业路演后再议；W6 不再加需求。）
