2第 1 节今天的三件事 + 6 节时间轴① 8 分钟陈述 + 5 分钟质询（多轮迭代）② 接住投资人五问 ③ 产出 V3 Scope 决策表 ④ 六节：术语 / 答辩标准 / 反面案例 / 多轮实操 / 面试 / 验收 ⑤ 对应面试两问：「讲一个你的项目」「你砍过什么需求」指时间轴图说明当前节次；每节转场回切本页6 节时间轴图（常驻）

4第 1 节术语卡 A · 评审类 4 词① 中期评审：项目过半用数据与工时复核方向；≠ 结业路演 ② 里程碑：可验收产出 + 过关口径；≠ 一条待办 ③ 答辩：限时陈述 + 当场回应质疑；产出是质询记录 ④ 复盘：逐条归因转动作，落到「改了什么 / 不改的理由」 ⑤ 每词配生活类比与面试说法逐词投屏术语卡；让学员在《术语自测表》上边听边填03-配图素材/术语卡/中期评审.svg 等 4 张
5第 1 节术语卡 B · 决策类 4 词① V3 Scope：终版功能清单与优先级，核心动作是砍、锁定后不加 ② 砍需求：依据数据和工时移出本期；≠ 功能没价值 ③ 决策记录：等级 / 判定依据 / 工时，事后可逐条复述；≠ 会议纪要 ④ 验收标准：事先公示的过 / 不过放行口径；≠ 0–5 分评分 ⑤ 每词配生活类比与面试说法重点讲「Scope ≠ 需求池」「验收 ≠ 评分」两组，第 6 节还要考03-配图素材/术语卡/V3Scope.svg 等 4 张
6第 1 节术语卡 C · 视角与证据类 + 四组易混 + 当堂小测① 投资人视角：五问审「值不值得投」；≠ 用户视角 ② 数据备齐：出处 / 样本量 / 可复算，数据不好看也如实带 ③ 风险预判：提前给应对动作；≠ 事后复盘 ④ 四组易混辨析对照 + 抢答 ⑤ 当堂术语小测 11 题，≥9 题达标抢答四组混淆说法；小测当堂对 01-教案第八节答案四组易混辨析对照图 + 术语自测表投屏
7第 2 节评审规则与评分卡（原页 3）① 五维：问题真实度 / 方案完整度 / 数据支撑 / 成本可信度 / 风险预判 ② 每维 0–5 分 ③ 及格线 = 每维 ≥3 且总分 ≥18/25 ④ 强调短板规则：任一维 <3 视为未过，不是只看总分 ⑤ 补一句：这是评分，不是验收标准口播 90 秒讲法脚本见 05-配图清单；宣讲落在 50–58 min中期评审评分卡（投屏版）
8第 2 节答辩流程与计时（原页 4）① 分组 4–6 人 ② 单轮 = 8 分钟陈述（四段 × 2 分钟）+ 5 分钟质询 + 2 分钟评分 + 迭代复述 ③ 黄牌剩 1 分钟，红牌即停 ④ 组内 5 分钟评分汇总 ⑤ 原 90 分钟版「6 分钟三段 + 4 分钟质询」为基础轮对照说明「同一个人讲两轮，看涨幅不看绝对值」评分卡 + 计时牌示意 + 多轮演练任务卡
9第 2 节8 分钟四段式陈述结构① 问题与方案：人群有边界 + 痛点现状数字 ② 数据验证：问卷 / 访谈样本量、评测集、竞品数字 ③ 成本与计划：单次成本 × 1000 活跃用户月成本，可复算 ④ 风险·里程碑·取舍：最大风险 + 应对、里程碑位置、先砍谁 ⑤ 每句结论配一个数字第四段是 300 分钟版新增，正好用上「风险预判」「里程碑」「砍需求」三个词8 分钟四段式陈述结构图
10第 2 节投资人五问（总览，原页 5）① 这事解决谁的问题 ② 凭什么你能做成 ③ 数据在哪 ④ 成本怎么算 ⑤ 下周就能上线吗质询人按角色卡轮换主问；陈述人五问各备一版答案；答辩期间可切回本页常驻投资人角色卡
11第 2 节五问追问示范（原页 6）① 每问一条追问链 + 差答案 vs 好答案各一例 ② 人群边界：「白领都需要」是差答案 ③ 独特积累：「模型更强」不是壁垒 ④ 样本出处 / 成本可复算 / 工时与取舍顺序 ⑤ 五问也是自检清单，不是刁难重点示范问 1 与问 3 的差答案；补边界：实验未出数标「进行中 + 出数日期」，编数按 0 分五问追问链示意
12第 2 节正面案例 vs 反面案例（答辩）+ 本节面试连接① 正面：四段齐全、每个论断可追出处、敢先报砍谁 ② 反面：7 分钟讲功能、无出处数据、不报风险（数据 / 成本 / 风险三维各 1 分）③ 边界深化：为什么 / 边界 / 常见误解 ④ 对照评分卡逐维举手表决打分 ⑤ 「这段在面试里怎么答」：Q1 骨架引导说出「把答辩做成了演示、把数据备齐做成数据好看」正反面案例对照页
13第 3 节V3 Scope 决策规则（原页 7）① 三档：P0 保留 / P1 有条件 / P2 砍进暂存池 ② 判定依据 = 中期答辩数据 + 两周工时上限（约 80h）③ P0 总工时 ≤ 上限 60% ④ P1 必须写三件事 ⑤ 解释 60%：冲刺周必有联调返工，按 100% 排期第一天就注定延期逐条核对，不允许「凭感觉」；本页为紫底白字强调块V3 Scope 三档规则图
14第 3 节两条硬依据与 60% 红线① 依据一：答辩数据（问卷 / 访谈 / 评测 / 试用，注明样本量与出处）② 依据二：两周工时上限约 80h ③ P0 合计 ≤48h ④ 每个决定至少站两条理由链 ⑤ 「都很重要」是价值判断，不是排序摆 80 小时盘子现场复算一遍工时上限算例图
15第 3 节P1 三件套与暂存池① 简化到什么程度 ② 触发条件与检查点（建议 W6D2 中午核心链路跑通）③ 不过怎么办：自动降 P2 ④ P2 书面理由一句话，不许空着 ⑤ 暂存池 = 路演未来规划素材 + 面试「砍过什么需求」的答案「尽量做」不算条件，要求当场改写成三件套P1 三件套卡片图
16第 3 节砍需求决策演示（教学示例，原页 8）①「留学文书助手」三进二 ② F1 改写 P0（82% 问卷 + 12h）③ F2 选校 P1（全量 28h 爆盘 → 简化 8h + 检查点 W6D2 中午）④ F3 简历 P2（9% + 竞品免费 + 24h）⑤ 理由链：每个决定至少两条依据（数据 / 竞争 / 工时）理由链做成横向三列 + 底部「三进二」结论条，不堆大段文字；投屏金句V3 Scope 理由链图 + 教学示例卡
17第 3 节反面案例：全是 P0 的失败 Scope 表① 五功能全 P0、依据统一写「都很重要」② P0 合计 96h 超 80h 上限且远超 60% ③ P1 空栏、P2 空栏、无暂存池 ④ 至少四处违规点 + 对应改法 ⑤ 附例：P1 写「尽量做」、无数据答辩引出的错误保留双案例研讨 4 分钟：各组写 ≥3 处违规点与改法，抽两组口述正反面案例对照页
18第 3 节理由链 · 双案例研讨 · 本节面试连接① 数据 · 竞争 · 工时，每个决定 ≥2 条 ② 为什么至少两条：单条依据最容易自欺 ③ 边界：砍需求 ≠ 否定价值，P2 是本期不做 ④ 常见误解：「砍得越少越健康」恰恰相反 ⑤「这段在面试里怎么答」：Q2 骨架裁决口径只认数据和工时，不认热情理由链小结图
19第 4 节多轮演练规则① 单轮 = 讲 8′ + 质询 5′ + 评分 2′ + 迭代复述 ② 第 1 轮打分并誊录质询意见 ③ 第 2 轮只针对意见复述后再打分 ④ 看涨幅，不看绝对值 ⑤ 金句：一次讲砸不叫失败，第二轮不改才叫失败任务说明 8 分钟；确认每组计时员与记录员就位多轮演练任务卡
20第 4 节讲师示范一轮 + 迭代三句式① 示范 8 分钟四段陈述（用教学示例）② 质询第三问「数据在哪」追两层 ③ 陈述人承认样本边界 + 给补样计划，不硬顶不编数 ④ 第 1 轮数据支撑 4 分 → 迭代后 5 分 ⑤ 三句式：认哪条 / 改什么 / 哪条进清算强调涨的 1 分是「意见落纸面」换来的迭代复述句式图
21第 4 节实操任务卡（分步骤）① 第 1 轮陈述 8′ ② 质询 5′，记录 ≥3 条 ③ 第 1 轮评分 2′ ④ 迭代复述 3′（要点版）⑤ 第 2 轮评分算涨幅 + 转下一人实操 32 分钟，讲师巡场；手机档按设备要求表执行替代动作实操流程条 + 导学案记录表投屏
22第 4 节Scope 清算任务卡（原页 9）① 各组填决策表（功能 / 等级 / 判定依据 / 本周工时）② P0 总工时 ≤ 上限 60% ③ 每条 P1 写三件套 ④ 砍掉项书面理由必填，P2 进暂存池 ⑤ 完成后 2 组各 90 秒过审巡场口径三连问：工时上限摆了吗？依据对应哪条数据？P1 检查点写了吗？导学案决策表投屏
23第 4 节常见卡点 3 条 + 巡场三连问① 卡点 1：迭代复述变成「再讲一遍」→ 只给三句式 ② 卡点 2：质询意见没落纸面 → 暂停补誊 ③ 卡点 3：被追问就编数 → 0 分并重审 ④ 巡场三连问 ⑤ 每轮质询先夸一条再追问巡场随时插入「停一下，这个判断的数据是什么？」常见卡点对照卡
