# 播客稿 · W5 周五《主项目中期评审》——本课不设播客

> 说明件：本文件用于记录「评审日不产播客」的决策依据，并提供替代性的 60 秒群发口播要点。

## 一、为什么不设播客

| 原因 | 说明 |
|---|---|
| 无新知识点可复述 | 本课为里程碑评审日，不讲授新概念；播客的核心价值（课余复述知识点）在本课不成立 |
| 答辩能力无法靠收听获得 | 中期答辩是现场训练项：陈述结构、临场追问、控时，都必须当面练；音频替代不了开口 |
| 评审材料有时效与私密性 | 各组项目内容互为答辩素材，不宜转为全员公开音频 |
| 生产资源让位给评审物料 | 本日工时集中投入评分卡制作、评审记录表与现场组织方案 |

**结论**：本课不录制第 7 期播客，栏目顺延至 W6D1。替代动作是课前 60 秒群发口播（文本见下），由讲师或助教以语音条形式发班群。
