# 课堂交互使用说明 · 商业画布工作坊组织方案（W5 周三专用）

> 说明：本课无专用交互网页（生产卡标注「交互=无」），课堂动手环节以「商业模式画布工作坊」承担，学员在导学案画布九格模板上填写。
> 本文件是工作坊的组织方案：填写顺序、互审规则、时间盒与故障预案。

## 一、课前准备（开课前 10 分钟）

| 检查项 | 操作 |
|---|---|
| 导学案 | 确认每人持有 W5D3 导学案（含画布九格模板与单位经济测算表） |
| 分组 | 按 W1 主项目赛道分组，3–4 人一组，组内成员互相知道彼此项目 |
| 飞书模板 | 群里发布「商业画布九格」飞书多维表格模板链接（周五答辩材料统一收集用） |
| 计时 | 讲师大屏放倒计时（工作坊各环节用手机计时亦可） |
| 板书区 | 白板留出「凭什么」三字提问区，互审时把答不上依据的格号写上去 |

## 二、填写顺序：先成本，后收入

画布九格分三批填写，顺序是刻意设计的——先写「算得出来」的，再写「想得清楚」的，最后写「收得回来」的：

| 批次 | 格子 | 为什么这个顺序 |
|---|---|---|
| 第一批（课上启动） | ① 成本结构 ② 关键资源 ③ 关键活动 | 今天刚算完 token 成本，成本侧数字是热的、扎实的；先落袋，防止「只算收入不算成本」的老毛病 |
| 第二批（周四前完成） | ④ 价值主张 ⑤ 客户细分 ⑥ 渠道通路 ⑦ 客户关系 | 这四格回答「为谁创造什么价值、怎么触达」，依据在 W4 调研报告和 W5 周一增长方案里 |
| 第三批（周四前完成） | ⑧ 重要伙伴 ⑨ 收入来源 | 收入来源放最后：等价值主张与客户想透，再对照单位经济测算表填写，避免拍脑袋定价 |

讲师启动话术：「先填成本三格——你今天刚算的 token 成本、获客成本，直接抄进成本结构。收入那格现在不许填，填了就是拍脑袋。」

## 三、投资人视角互审规则

**核心规则一句话：你写完的每一格，都要能扛住同伴的一句「凭什么？」**

| 互审项 | 规则 |
|---|---|
| 提问方式 | 互审者对每一格只问「凭什么」，不聊天、不夸奖、不建议 |
| 应答标准 | 被审者必须说出该格的**依据出处**：调研报告（W4）、增长方案（W5 周一）、单位经济测算（今天）、行业参考值（需注明「假设」） |
| 判定 | 答得出依据 → 该格通过；答不出 → 格号写上白板「凭什么区」，打回重填 |
| 轮次 | 课上互审一轮（第一批三格）；周四组内预审全部九格；周五答辩评委用同样规则追问 |
| 示例 | 收入来源写「订阅 19.9 元」→ 问「凭什么 19.9」→ 合格答案：「成本底线 4.8 元 + 竞品主流档锚位 + 目标用户调研可接受区间」；不合格答案：「我觉得差不多」 |

## 四、时间盒

| 时间 | 动作 | 产出 |
|---|---|---|
| 今天课上 10 min | 填第一批三格（成本结构 / 关键资源 / 关键活动） | 三格初稿 |
| 今天课上 2 min | 组内快速互审三格，每格一句「凭什么」 | 白板记下打回格号 |
| 周三课后–周四 | 完成第二批四格 + 第三批两格；同步填入飞书多维表格模板 | 九格全量完成 |
| 周四组内预演 | 全格互审一轮 + 用单位经济测算表过一遍「毛利怎么算」 | 打回格清零 |
| 周五中期答辩 | 画布九格作为「投资人视角」第一页材料上台 | 里程碑 ④ 材料 |

**讲师控场要点**：课上 10 分钟只盯一件事——成本结构格里有没有出现具体数字（token 成本、获客成本）。出现「待定」「视情况」的，当场要求换成今天的测算数字或注明「假设」。

## 五、常见问题与处理

| 问题 | 处理 |
|---|---|
| 学员问「九格顺序能倒着填吗」 | 可以最终一起提交，但课上必须按先成本后收入走一遍——这是防「拍脑袋」的训练动作，周五答辩讲画布时也按这个叙事顺序讲 |
| 组内无人敢互审 | 讲师示范一轮：拿自己的「伪案例」故意写一个没有依据的收入格，问「凭什么」，演示打回 |
| 有人项目还没算出单次成本 | 先用行业参考值填写并标注「假设」，课后补算；不许空格也不许编造精确数字 |
| 填得慢的小组 | 允许只写关键词，不追求句子完整；画布是弹药库不是作文 |
| 飞书模板打不开 | 先用导学案纸质版填写，课后誊入飞书；答辩以飞书版为准 |
