## 二、教学目标（可测量）

1. **【术语目标】** 能准确说出本日 12 个术语（Token、推理成本、订阅制、按次计费、毛利、单位经济模型、LTV、CAC、定价档位、免费层、升级钩子、盈亏平衡）的一句话定义，能在《术语自测表》完成不少于 10 项「能讲清」自评，且当堂术语小测 10 题答对不少于 8 题（验证：术语小测卷 + 自测表）。
2. **【面试目标】** 能针对「AI 产品怎么赚钱」「毛利怎么算」「免费层怎么设计」「该不该烧钱」四类追问，给出含至少一个当日术语、结构完整的 60 秒答法，两两模拟中每题踩分点命中不少于 3 / 4 条（验证：《面试模拟记录表》含追问记录与自评分）。
3. 能手算一个 AI 产品的单次对话成本（输入 token 费 + 输出 token 费），并推算月度成本与订阅毛利，计算过程可复算（对应作业：单位经济模型测算表；验证：当堂测换组数字 1 分钟内算对）。
4. 能针对给定产品场景，从四大变现模式（订阅 / 按量 / 席位 / API）中选出匹配的收费方式，并各说出一条优势与一条劣势（对应课堂判断 + 习题第 1 层；验证：4 个场景匹配全对）。
5. 能用三心理锚点（锚定 / 分档 / 免费层边界）为主项目设计一套定价方案，并填完商业模式画布九格（对应周五中期答辩材料；验证：三档含价格、用量边界与依据三维）。
6. 能完整推演单位经济模型，LTV（Life Time Value，用户生命周期价值）使用毛利口径而非收入口径，并据 LTV / CAC（Customer Acquisition Cost，单客获客成本）判断能否放大投放（验证：测算表红笔自查行 + 当堂验收口述）。
7. 能把当日全部产出归入《本日作品集积木》，逐项标注完成度与归档位置，缺项当场补齐（验证：当堂验收清单逐项打勾）。

## 三、教学重难点

- **重点**：token 成本核算模型——「输入 token × 单价 + 输出 token × 单价 = 单次成本」必须让每个学员亲手算一遍，这是 AI PM 面试高频考点。
- **难点一**：从「单次成本」到「单位经济」的推演（单次 → 月成本 → 毛利 → LTV / CAC），学员容易只算收入不算成本，或 LTV 用收入而非毛利计算。
- **难点二**：定价的心理账户——学员易犯「定价拍脑袋」错误，需要用三锚点（锚定 / 分档 / 免费层边界）建立定价依据感。
- **难点三【术语混淆】**：本日 12 个术语里存在四组高危混淆——毛利 / 净利、订阅制 / 按次计费、收入口径 LTV / 毛利口径 LTV、免费层 / 试用期。零基础学员常把「收了多少钱」直接当成「赚了多少钱」，须在第 1 节用生活类比一次性切开，并在第 3 节回扣。
- **难点四【面试失分】**：学员答「AI 产品怎么赚钱」时只背四种模式名、不给匹配条件；答「毛利怎么算」时漏掉推理成本或漏乘毛利率；答「免费层」时喊「越多越好」；答「该不该烧钱」时不引 LTV / CAC 就下结论。第 5 节须用「踩分点 + 追问链 + 失败答法」逐题矫正。

## 六、四大变现模式逐个教学详案（归入第 2 节）

每模式统一三段式：怎么收费 / 适合什么产品 / 优劣。收束进对比图。本节全部价格与档位数字均为教学示例。

### 模式一：订阅制（Subscription）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 月费 / 年费固定，按档位区分功能与用量上限（如入门档 / 主流档 / 专业档）；教学示例：AI 助手会员月费 19.9–39.9 元档（真实产品价格以官网实时价格为准） |
| 适合什么产品 | 高频、持续价值、使用可预期的 C 端产品：AI 写作助手、AI 学习陪伴、日程与效率类 |
| 优势 | 收入可预测、现金流稳定；续费本身就是留存指标 |
| 劣势 | 续费压力大，一旦某月没被用起来就掉订阅；重度用户成本倒挂（用量大的用户，token 成本可能超过订阅费） |

教学追问：「重度用户一天聊 200 次，订阅制下会发生什么？」→ 引出「订阅制必须设用量上限或降速」的产品设计。

### 模式二：按量计费（Usage-based，含按次计费）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 按次 / 按 token / 按张数 / 按分钟计费，充值制或月结后付费 |
| 适合什么产品 | 用量波动大、低频高价值的场景：AI 生图、视频生成、法律文书单次起草、翻译 |
| 优势 | 收入与成本同步增长，毛利天然安全；用户「用多少付多少」进入门槛低 |
| 劣势 | 收入不可预测，财务模型难做；用户有「计价焦虑」——每次用都在花钱，抑制使用频次，伤害留存 |

教学追问：「按量计费为什么伤留存？」→ 每次使用都有付费决策，摩擦点从「要不要订阅」变成「每次要不要花钱」。

### 模式三：席位制（Per-seat License，按席位授权）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 按坐席 / 账号数 × 年费打包，B 端合同制，功能全家桶 |
| 适合什么产品 | 团队协作型 B 端产品：企业知识库、AI CRM（Customer Relationship Management，客户关系管理）、AI 客服工作台 |
| 优势 | 客单价高、客户粘性强（换系统成本高）、收入集中在少数大客户 |
| 劣势 | 决策链长、销售驱动、增长非线性；收款周期长，对现金流要求高 |

教学追问：「为什么 B 端愿意按席位付年费，C 端个人却嫌月费贵？」→ B 端是「组织付钱解决组织问题」，可报销、可计入人力效率预算；C 端是「个人钱包」，价格敏感度完全不同。

### 模式四：API 调用（Application Programming Interface，应用程序编程接口）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 按 token 千次批发价计费，开发者充值接入，量越大折扣越大 |
| 适合什么产品 | 平台型公司、有技术团队的中大客户，把自己的能力卖给开发者 |
| 优势 | 规模效应最强、客户替换成本高（换 API 要改代码）、一块模型服务多行业 |
| 劣势 | 大客户议价能力强，毛利率通常低于 C 端；同质化竞争，容易被价格战拖入「卖水内卷」 |

教学追问：「API 生意的护城河是什么？」→ 不是价格，是稳定性 + 生态绑定（文档、工具链、迁移成本）。

### 收束：四大模式对比（投屏配图）

| 模式 | 收费方式 | 适合产品 | 一句话优劣 |
|---|---|---|---|
| 订阅 | 固定月费 / 年费 | 高频 C 端助手类 | 收入稳，但要防重度用户成本倒挂 |
| 按量 | 按次 / 按 token | 低频高价值生成类 | 毛利安全，但计价焦虑伤留存 |
| 席位 | 坐席 × 年费 | B 端团队协作 | 客单高粘性强，但增长靠销售 |
| API | 批发价按量结算 | 平台与开发者 | 规模最大，但毛利低打价格战 |

## 七、token 成本核算教学设计（核心环节，归入第 2 节）

### 1. 教学逻辑链

token（词元）是什么（模型的计量单位，1 个汉字约 1–2 个 token）→ 计价公式 → 全班手算 → 月度推演 → 毛利。

### 2. 计价公式（板书）

```
单次对话成本 = 输入 token 数 ÷ 1000 × 输入单价 + 输出 token 数 ÷ 1000 × 输出单价
```

### 3. 现场手算示例（全部为教学示例，以官网实时价格为准）

| 步骤 | 计算式 | 结果 |
|---|---|---|
| 输入费用 | 800 token ÷ 1000 × 0.008 元/千 token（教学示例） | 0.0064 元 |
| 输出费用 | 400 token ÷ 1000 × 0.024 元/千 token（教学示例） | 0.0096 元 |
| 单次对话成本 | 0.0064 + 0.0096 | 0.016 元 |

关键提示点：输入单价与输出单价不同，输出通常更贵（生成比理解更耗算力）；本例输出只占 token 数的 1/3，却占成本的 60%（均为教学示例）。

### 4. 从单次到月度（同一套示例数字推演，均为教学示例）

| 步骤 | 计算式 | 结果 |
|---|---|---|
| 人均月对话次数 | 日均 10 次 × 30 天 | 300 次 |
| 人均月成本 | 300 次 × 0.016 元 | 4.8 元 |
| 订阅定价（示例） | — | 19.9 元/月 |
| 人均月毛利 | 19.9 − 4.8 | 15.1 元 |
| 毛利率 | 15.1 ÷ 19.9 | 约 76% |

### 5. 教学动作要求

- 全班同步用手机计算器算，讲师在白板同步写算式；算错学员当场暴露「÷1000 漏掉」「单价乘反」两类典型错误。
- 收尾当堂测：分层习题第 1 层换一组数字复算，1 分钟完成，举手示意。
- 反复口播：所有数字均为教学示例，真实价格以各模型官网实时价格为准。

## 八、定价策略与三心理锚点教学详案（归入第 3 节）

| 锚点 | 内容 | 教学要点 | 案例（教学示例） |
|---|---|---|---|
| 锚定效应 | 用户对价格没有绝对感知，只有相对感知 | 先给一个「贵」的参照（划线价 / 专业档 / 企业版「联系销售」），主流档就显便宜；「联系销售」本身就是价格锚——用户会脑补「很贵很专业」 | 教学示例：同一款产品 99 元显得贵，29 元显得便宜，取决于旁边放的是 199 还是 9.9 |
| 分档设计 | 三档结构：入门档（低门槛）/ 主流档（设计上最划算）/ 专业档（利润担当） | 主流档是「被设计出来的选择」：档位差故意让主流档性价比最优；分档同时是用户分层和重度用户封顶手段 | 教学示例：19.9 / 39.9 / 99 三档中，39.9 标「最受欢迎」 |
| 免费层边界 | 免费层是获客渠道，也是成本中心 | 边界三问：①免费到多少次？②限什么（次数 / 质量 / 速度）？③升级钩子放在哪一刻（用户刚体验到价值时）？ | 教学示例：免费层每天 3 次 + 排队慢通道，付费免排队即插队体验差 |

教学强调：定价三问法（面试可用）——成本底线（算出来的）、竞品锚位（看出来的）、用户感知价值（调研出来的），三者取交集。

## 九、单位经济模型与毛利视角教学详案（归入第 3 节）

### 推演链（领填导学案测算表，示例行，均为教学示例）

| 项目 | 示例行 | 计算口径 |
|---|---|---|
| 单次对话成本 | 0.016 元 | 输入 + 输出 token 费（教学示例） |
| 人均月频次 | 300 次 | 日均 10 次 × 30 天 |
| 人均月成本 | 4.8 元 | 单次成本 × 月频次 |
| 定价 | 19.9 元/月 | 订阅主流档（示例） |
| 月毛利 | 15.1 元 | 定价 − 月成本 |
| 毛利率 | 约 76% | 月毛利 ÷ 定价 |
| LTV | 约 121 元 | 定价 × 平均生命周期 8 个月 × 毛利率 76% |
| CAC | 40 元 | 获客投放 + 渠道成本分摊（示例） |
| LTV / CAC | 约 3.0 | 大于 3 视为健康，小于 1 烧钱换量 |

### 教学强调三点

1. **LTV 必须乘毛利率**：用收入算 LTV 是最常见的自欺——收了 159 元不等于赚了 159 元（教学示例）。
2. **LTV / CAC ≈ 3 是及格线**（教学示例经验值）：大于 3 说明模型健康可以放大；小于 1 说明每拉一个用户亏一个。
3. **规模化路径**：先在百人级证明单位经济为正，再谈投放放大；毛利为负时放大 = 加速亏损。这也是周五中期答辩「投资人视角」的第一个追问点。

## 十、课堂提问设计（20 问：术语辨析 7 + 面试追问 7 + 原理理解 6）

| # | 类型 | 提问 | 提问时机 | 预设答案 / 引导方向 |
|---|---|---|---|---|
| 1 | 术语辨析 | 「Token（词元）和『汉字数』是一回事吗？一次对话有几笔 token 账？」 | 第 1 节 | 不是；1 汉字约 1–2 token；一次对话含输入、输出两笔，且单价不同 |
| 2 | 术语辨析 | 「推理成本和训练成本差在哪？为什么定价只盯推理成本？」 | 第 1 节 | 训练是一次性投入，推理是按次持续烧的算力；边际成本来自推理 |
| 3 | 术语辨析 | 「订阅制和按次计费，谁的收入更可预测？谁的毛利更安全？」 | 第 1 节 | 订阅收入可预测但要防倒挂；按次毛利天然安全但收入波动、伤留存 |
| 4 | 术语辨析 | 「毛利和净利差在哪一笔钱？收了 19.9 元等于赚了 19.9 元吗？」 | 第 1 节 | 毛利只扣直接成本（推理成本），净利还扣研发 / 获客 / 管理；不等于（教学示例） |
| 5 | 术语辨析 | 「LTV 为什么必须乘毛利率？用收入算会把结论带偏到哪？」 | 第 1 节 | 收入含要付给模型方的成本；用收入会高估 LTV、误判 LTV / CAC 可放大 |
| 6 | 术语辨析 | 「单位经济模型和公司总账有什么区别？」 | 第 1 节 | 前者以单个用户看边际赚亏，后者看整体营收；规模化前先看前者 |
| 7 | 术语辨析 | 「免费层和试用期是一回事吗？升级钩子和付费墙呢？」 | 第 1 节 | 试用常限时间、免费层长期限量 / 限速 / 限质；钩子是顺势引导，付费墙是拦路 |
| 8 | 面试追问 | 「30 秒说清：AI 产品到底怎么赚钱。」 | 第 5 节 | 四种模式 + 各自匹配条件 + 一句「没有最好只有匹配」 |
| 9 | 面试追问 | 「你的毛利怎么算？下个月模型涨价 50%，产品会死吗？」 | 第 5 节 | 先给结论，再分成本侧 / 商业侧两层，补压力测试观点 |
| 10 | 面试追问 | 「免费层怎么设计？给你一个产品，说出边界三问。」 | 第 5 节 | 免费到多少次 / 限什么 / 升级钩子放在哪一刻 |
| 11 | 面试追问 | 「LTV / CAC = 1.5，该不该继续烧钱放大投放？」 | 第 5 节 | 不该先放大；先优化单位经济，毛利为正再谈规模 |
| 12 | 面试追问 | 「追问二：你说 LTV 121 元，这个数乘毛利率了吗？」 | 第 5 节 | 乘了；口径是定价 × 生命周期 × 毛利率，不是收入 |
| 13 | 面试追问 | 「追问三：重度用户一天聊 200 次，订阅制怎么防倒挂？」 | 第 5 节 | 用量上限 / 降速 / 分档封顶，分档同时是成本保险 |
| 14 | 面试追问 | 「追问四：免费用户越多越光荣吗？它的成本谁承担？」 | 第 5 节 | 不是；每个免费用户都烧 token，是获客预算也是成本中心（教学示例） |
| 15 | 原理理解 | 「你手机里正在付费（或曾付费）的 AI 产品，它是哪种收费模式？」 | 第 2 节导入 | 大概率答订阅；引导区分「会员月费」与「充值按量」 |
| 16 | 原理理解 | 「同样一次对话，输入 800 token、输出 400 token——哪部分花的钱多？」 | 第 2 节 | 输出；输出单价通常是输入的数倍（教学示例 3 倍），占成本 60% |
| 17 | 原理理解 | 「输出只占 1/3 token 却占 60% 成本，给产品经理哪两个省钱抓手？」 | 第 2 节 | 压输入（上下文别乱塞）、控输出（别让模型喋喋不休） |
| 18 | 原理理解 | 「10 万免费用户、人均月 5 次、单次 0.016 元，月成本多少？」 | 第 3 节 | 8000 元/月纯成本（教学示例），引出免费层必须有边界 |
| 19 | 原理理解 | 「为什么 B 端愿意按席位付年费，C 端个人却嫌月费贵？」 | 第 2 节 | B 端组织预算可报销、算人力效率账；C 端个人钱包，心理账户不同 |
| 20 | 原理理解 | 「定价三问法是哪三问？为什么说三者取交集？」 | 第 3 节 | 成本底线 / 竞品锚位 / 用户感知价值；单取任一都会拍脑袋 |

## 十一、板书要点（按 6 节重排）

```
【第 1 节 · 术语精讲】零层：AI 每答一次都烧算力
  12 术语：Token / 推理成本 / 订阅制 / 按次计费 / 毛利 / 单位经济模型
           LTV / CAC / 定价档位 / 免费层 / 升级钩子 / 盈亏平衡
  四组辨析：毛利≠净利｜订阅≠按次｜LTV 要乘毛利率｜免费层≠试用期

【第 2 节 · 原理 A】收入侧：订阅（稳）/ 按量（安全）/ 席位（大单）/ API（规模）
  成本侧：单次成本 = 输入 token ÷ 1000 × 输入单价 + 输出 token ÷ 1000 × 输出单价
  示例：800÷1000×0.008 + 400÷1000×0.024 = 0.0064 + 0.0096 = 0.016 元/次（教学示例）
  月账：300 次 × 0.016 = 4.8 元   定价 19.9   毛利 15.1   毛利率约 76%（教学示例）

【第 3 节 · 原理 B】定价三锚：锚定（给参照）/ 分档（造主流）/ 免费层（画边界）
  单位经济：LTV = 定价 × 生命周期 × 毛利率 ≈ 121 元   LTV/CAC ≈ 3.0（教学示例）
  规模化：先证单位经济为正，再放大；毛利为负时放大 = 加速烧钱

【第 4 节 · 实操】任务一 测算表｜任务二 三档定价｜任务三 画布前三格
  顺序：先成本后收入；每格被问「凭什么」；手机 / 平板替代动作照表执行

【第 5 节 · 面试】四问：怎么赚钱 / 毛利怎么算 / 免费层怎么设计 / 该不该烧钱
  答法骨架：结论先行 → 分两层 → 引术语 → 补边界
  金句：不懂 token 成本的产品经理，管不好 AI 产品的毛利。

【第 6 节 · 复盘】三句收束 → 积木归档 → 当堂验收 → 周四预告
  作品集积木：术语自测表 / 面试模拟记录表 / 测算表 / 定价方案 / 画布九格
```

## 十三、学员易错点预判与应对（9 条：原 5 条 + 术语混淆 2 条 + 面试失分 2 条）

| # | 易错点 | 表现 | 应对 |
|---|---|---|---|
| 1 | 只算收入不算成本 | 测算表只填定价 × 用户数，兴奋宣布「月入百万」 | 强制过「成本关」：先算单次 token 成本再谈收入；课堂手算环节不许跳过；周五答辩材料缺成本行直接退回 |
| 2 | 免费层给太多 | 「免费用户越多越好，先做大再赚钱」 | 现场算免费层账：教学示例 10 万免费用户、人均月 5 次，月成本 10 万 × 5 × 0.016 = 8000 元/月；引出免费层必须有边界三问 |
| 3 | 定价拍脑袋 | 「我觉得 29.9 挺合适的」 | 追问三个依据：成本底线是多少？竞品锚位在哪？用户调研怎么说？给「定价三问法」框架，写进答辩材料 |
| 4 | LTV 用收入算不用毛利算 | LTV = 定价 × 生命周期，漏乘毛利率 | 公式板书时把「× 毛利率」用红笔圈出；回扣「收 159 不等于赚 159」（教学示例）；当堂测里设一个陷阱数字验证 |
| 5 | 混淆订阅档位与用量上限 | 把「分档」只当价格歧视，忘记它同时是成本封顶手段 | 讲三档时明确：档位差不仅卖功能，更是给重度用户的成本上保险——订阅制的自我保护机制 |
| 6 | **【术语混淆】** 把「毛利」当「净利」、把「收入」当「赚到的钱」 | 「毛利率 76% 就是公司净赚 76%」 | 第 1 节用面馆类比一次切开：毛利只扣原料（推理成本），房租水电（研发 / 获客 / 管理）还没扣；第 3 节回扣 LTV 口径 |
| 7 | **【术语混淆】** 订阅制与按次计费、免费层与试用期混用 | 「按次计费也是订阅，免费层就是 7 天试用」 | 术语卡「易混辨析」逐对对照；当堂小测设连线题；错一次抄一遍定义 |
| 8 | **【面试失分】** 答「怎么赚钱」只背模式名、不给匹配条件 | 「四种：订阅、按量、席位、API」然后卡住 | 第 5 节强制答法骨架「结论 + 匹配条件 + 优劣 + 一句收束」，两两模拟按踩分点打分，缺匹配条件扣 2 分 |
| 9 | **【面试失分】** 答「该不该烧钱」不引术语、直接下结论 | 「我觉得可以烧，先做大规模」 | 要求回答必须含 LTV / CAC 与「先证单位经济为正」，否则按失败答法处理；补「毛利为负时放大 = 加速烧钱」金句 |
