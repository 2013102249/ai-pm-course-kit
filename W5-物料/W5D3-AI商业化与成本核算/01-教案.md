## 二、教学目标（可测量）

1. 能手算一个 AI 产品的单次对话成本（输入 token 费 + 输出 token 费），并推算月度成本与订阅毛利，计算过程可复算（对应作业：单位经济模型测算表）。
2. 能针对给定产品场景，从四大变现模式（订阅 / 按量 / 席位 / API）中选出匹配的收费方式，并各说出一条优势与一条劣势（对应课堂判断 + 习题）。
3. 能用三心理锚点（锚定 / 分档 / 免费层边界）为自己的主项目设计一套定价方案，并填完商业模式画布九格（对应周五中期答辩材料）。

## 三、教学重难点

- **重点**：token 成本核算模型——「输入 token × 单价 + 输出 token × 单价 = 单次成本」必须让每个学员亲手算一遍，这是 AI PM 面试高频考点。
- **难点一**：从「单次成本」到「单位经济」的推演（单次 → 月成本 → 毛利 → LTV/CAC），学员容易只算收入不算成本，或 LTV 用收入而非毛利计算。
- **难点二**：定价的心理账户——学员易犯「定价拍脑袋」错误，需要用三锚点（锚定 / 分档 / 免费层边界）建立定价依据感。

## 六、四大变现模式逐个教学详案

每模式统一三段式：怎么收费 / 适合什么产品 / 优劣。每段讲授约 5 分钟，收束进对比图。

### 模式一：订阅制（Subscription）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 月费 / 年费固定，按档位区分功能与用量上限（如入门档 / 主流档 / 专业档）；典型如 AI 助手会员月费 19.9–39.9 元档（真实产品价格以官网实时价格为准） |
| 适合什么产品 | 高频、持续价值、使用可预期的 C 端产品：AI 写作助手、AI 学习陪伴、日程与效率类 |
| 优势 | 收入可预测、现金流稳定；续费本身就是留存指标 |
| 劣势 | 续费压力大，一旦某月没被用起来就掉订阅；重度用户成本倒挂（用量大的用户，token 成本可能超过订阅费） |

教学追问：「重度用户一天聊 200 次，订阅制下会发生什么？」→ 引出「订阅制必须设用量上限或降速」的产品设计。

### 模式二：按量计费（Usage-based）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 按次 / 按 token / 按张数 / 按分钟计费，充值制或月结后付费 |
| 适合什么产品 | 用量波动大、低频高价值的场景：AI 生图、视频生成、法律文书单次起草、翻译 |
| 优势 | 收入与成本同步增长，毛利天然安全；用户「用多少付多少」进入门槛低 |
| 劣势 | 收入不可预测，财务模型难做；用户有「计价焦虑」——每次用都在花钱，抑制使用频次，伤害留存 |

教学追问：「按量计费为什么伤留存？」→ 每次使用都有付费决策，摩擦点从「要不要订阅」变成「每次要不要花钱」。

### 模式三：席位制（Per-seat）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 按坐席 / 账号数 × 年费打包，B 端合同制，功能全家桶 |
| 适合什么产品 | 团队协作型 B 端产品：企业知识库、AI CRM、AI 客服工作台 |
| 优势 | 客单价高、客户粘性强（换系统成本高）、收入集中在少数大客户 |
| 劣势 | 决策链长、销售驱动、增长非线性；收款周期长，对现金流要求高 |

教学追问：「为什么 B 端愿意按席位付年费，C 端个人却嫌月费贵？」→ B 端是「组织付钱解决组织问题」，可报销、可计入人力效率预算；C 端是「个人钱包」，价格敏感度完全不同。

### 模式四：API 调用（Platform）

| 维度 | 内容 |
|---|---|
| 怎么收费 | 按 token 千次批发价计费，开发者充值接入，量越大折扣越大 |
| 适合什么产品 | 平台型公司、有技术团队的中大客户，把自己的能力卖给开发者 |
| 优势 | 规模效应最强、客户替换成本高（换 API 要改代码）、一块模型服务多行业 |
| 劣势 | 大客户议价能力强，毛利率通常低于 C 端；同质化竞争，容易被价格战拖入「卖水内卷」 |

教学追问：「API 生意的护城河是什么？」→ 不是价格，是稳定性 + 生态绑定（文档、工具链、迁移成本）。

### 收束：四大模式对比（投屏配图）

| 模式 | 收费方式 | 适合产品 | 一句话优劣 |
|---|---|---|---|
| 订阅 | 固定月费 / 年费 | 高频 C 端助手类 | 收入稳，但要防重度用户成本倒挂 |
| 按量 | 按次 / 按 token | 低频高价值生成类 | 毛利安全，但计价焦虑伤留存 |
| 席位 | 坐席 × 年费 | B 端团队协作 | 客单高粘性强，但增长靠销售 |
| API | 批发价按量结算 | 平台与开发者 | 规模最大，但毛利低打价格战 |

## 七、token 成本核算教学设计（核心环节）

### 1. 教学逻辑链

token 是什么（模型的计量单位，1 个汉字约 1–2 个 token）→ 计价公式 → 全班手算 → 月度推演 → 毛利。

### 2. 计价公式（板书）

```
单次对话成本 = 输入 token 数 ÷ 1000 × 输入单价 + 输出 token 数 ÷ 1000 × 输出单价
```

### 3. 现场手算示例（全部为教学示例，以官网实时价格为准）

| 步骤 | 计算式 | 结果 |
|---|---|---|
| 输入费用 | 800 token ÷ 1000 × 0.008 元/千 token | 0.0064 元 |
| 输出费用 | 400 token ÷ 1000 × 0.024 元/千 token | 0.0096 元 |
| 单次对话成本 | 0.0064 + 0.0096 | 0.016 元 |

关键提示点：输入单价与输出单价不同，输出通常更贵（生成比理解更耗算力）；本例输出只占 token 数的 1/3，却占成本的 60%。

### 4. 从单次到月度（同一套示例数字推演）

| 步骤 | 计算式 | 结果 |
|---|---|---|
| 人均月对话次数 | 日均 10 次 × 30 天 | 300 次 |
| 人均月成本 | 300 次 × 0.016 元 | 4.8 元 |
| 订阅定价（示例） | — | 19.9 元/月 |
| 人均月毛利 | 19.9 − 4.8 | 15.1 元 |
| 毛利率 | 15.1 ÷ 19.9 | 约 76% |

### 5. 教学动作要求

- 全班同步用手机计算器算，讲师在白板同步写算式；算错学员当场暴露「÷1000 漏掉」「单价乘反」两类典型错误。
- 收尾当堂测：分层习题第一层第 3 题（换一组数字复算），1 分钟完成，举手示意。
- 反复口播：所有数字均为教学示例，真实价格以各模型官网实时价格为准。

## 八、定价策略与三心理锚点教学详案

| 锚点 | 内容 | 教学要点 | 案例 |
|---|---|---|---|
| 锚定效应 | 用户对价格没有绝对感知，只有相对感知 | 先给一个「贵」的参照（划线价 / 专业档 / 企业版「联系销售」），主流档就显便宜；「联系销售」本身就是价格锚——用户会脑补「很贵很专业」 | 同一款产品 99 元显得贵，29 元显得便宜，取决于旁边放的是 199 还是 9.9 |
| 分档设计 | 三档结构：入门档（低门槛）/ 主流档（设计上最划算）/ 专业档（利润担当） | 主流档是「被设计出来的选择」：档位差故意让主流档性价比最优；分档同时是用户分层和重度用户封顶手段 | 19.9 / 39.9 / 99 三档中，39.9 标「最受欢迎」 |
| 免费层边界 | 免费层是获客渠道，也是成本中心 | 边界三问：①免费到多少次？②限什么（次数 / 质量 / 速度）？③升级钩子放在哪一刻（用户刚体验到价值时）？ | 免费层每天 3 次 + 排队慢通道，付费免排队即插队体验差 |

教学强调：定价三问法（面试可用）——成本底线（算出来的）、竞品锚位（看出来的）、用户感知价值（调研出来的），三者取交集。

## 九、单位经济模型与毛利视角教学详案

### 推演链（领填导学案测算表，示例行）

| 项目 | 示例行 | 计算口径 |
|---|---|---|
| 单次对话成本 | 0.016 元 | 输入 + 输出 token 费（教学示例） |
| 人均月频次 | 300 次 | 日均 10 次 × 30 天 |
| 人均月成本 | 4.8 元 | 单次成本 × 月频次 |
| 定价 | 19.9 元/月 | 订阅主流档（示例） |
| 月毛利 | 15.1 元 | 定价 − 月成本 |
| 毛利率 | 约 76% | 月毛利 ÷ 定价 |
| LTV | 约 121 元 | 定价 × 平均生命周期 8 个月 × 毛利率 76% |
| CAC | 40 元 | 获客投放 + 渠道成本分摊（示例） |
| LTV / CAC | 约 3.0 | 大于 3 视为健康，小于 1 烧钱换量 |

### 教学强调三点

1. **LTV 必须乘毛利率**：用收入算 LTV 是最常见的自欺——收了 159 元不等于赚了 159 元。
2. **LTV/CAC ≈ 3 是及格线**：大于 3 说明模型健康可以放大；小于 1 说明每拉一个用户亏一个。
3. **规模化路径**：先在百人级证明单位经济为正，再谈投放放大；毛利为负时放大 = 加速亏损。这也是周五中期答辩「投资人视角」的第一个追问点。

## 十、课堂提问设计（7 问）

| # | 提问 | 提问时机 | 预设答案 / 引导方向 |
|---|---|---|---|
| 1 | 「你手机里正在付费（或曾付费）的 AI 产品，它是哪种收费模式？」 | 导入 | 大概率答订阅；引导区分「会员月费」与「充值按量」，自然引入四大模式 |
| 2 | 「重度用户一天聊 200 次，订阅制下会发生什么？」 | 订阅环节 | 成本倒挂——重度用户 token 成本超过订阅费；产品对策：用量上限 / 降速 / 分档封顶 |
| 3 | 「按量计费的用户为什么总有『计价焦虑』？它伤产品什么？」 | 按量环节 | 每次使用都是付费决策，摩擦点变成「每次要不要花钱」；伤使用频次与留存 |
| 4 | 「为什么 B 端愿意按席位付年费，C 端个人却嫌月费贵？」 | 席位环节 | B 端是组织预算、可报销、能算人力效率账；C 端是个人钱包，价格敏感度高 |
| 5 | 「同样一次对话，输入 800 token、输出 400 token——哪部分花的钱多？」 | token 核算 | 输出：输出单价通常是输入的数倍，本例输出占成本 60%；生成比理解更耗算力 |
| 6 | 「免费用户越多越光荣吗？」 | 免费层边界 | 不是——每个免费用户都在消耗 token 成本；免费层规模要和「付费转化率 × 客单」一起看 |
| 7 | 「LTV/CAC 等于多少才敢投放放大？」 | 单位经济 | 经验值大于 3；小于 1 意味着每拉一个用户亏一个，毛利为负时放大等于加速亏损 |

## 十一、板书要点

```
收入侧：订阅（稳） / 按量（安全） / 席位（大单） / API（规模）
成本侧：单次成本 = 输入 token ÷ 1000 × 输入单价 + 输出 token ÷ 1000 × 输出单价
示例：800÷1000×0.008 + 400÷1000×0.024 = 0.0064 + 0.0096 = 0.016 元/次（教学示例）

月账：300 次 × 0.016 = 4.8 元   定价 19.9   毛利 15.1   毛利率约 76%
单位经济：LTV = 定价 × 生命周期 × 毛利率 ≈ 121 元   LTV/CAC ≈ 3.0

定价三锚：锚定（给参照） / 分档（造主流） / 免费层（画边界）
金句：不懂 token 成本的产品经理，管不好 AI 产品的毛利。
```

## 十二、课堂练习参考答案（模式匹配判断）

| 场景 | 匹配模式 | 关键理由 |
|---|---|---|
| AI 写作助手，用户每天打开 | 订阅 | 高频持续价值，订阅收入可预测；需设用量上限防倒挂 |
| AI 生成产品宣传视频，低频重投入 | 按量 | 用量波动大、单次价值高，按量毛利安全 |
| 企业 AI 知识库，30 人团队使用 | 席位 | B 端团队协作，坐席 × 年费，粘性强 |
| 模型能力开放给开发者接入 | API | 规模效应与生态绑定，按批发价结算 |

## 十三、学员易错点预判与应对（5 条）

| 易错点 | 表现 | 应对 |
|---|---|---|
| 只算收入不算成本 | 测算表只填定价 × 用户数，兴奋宣布「月入百万」 | 强制过「成本关」：先算单次 token 成本再谈收入；课堂手算环节不许跳过；周五答辩材料缺成本行直接退回 |
| 免费层给太多 | 「免费用户越多越好，先做大再赚钱」 | 现场算免费层账：假设 10 万免费用户、人均月 5 次，月成本多少（10 万 × 5 × 0.016 = 8000 元/月，教学示例）；引出免费层必须有边界三问 |
| 定价拍脑袋 | 「我觉得 29.9 挺合适的」 | 追问三个依据：成本底线是多少？竞品锚位在哪？用户调研怎么说？给「定价三问法」框架，写进答辩材料 |
| LTV 用收入算不用毛利算 | LTV = 定价 × 生命周期，漏乘毛利率 | 公式板书时把「× 毛利率」用红笔圈出；回扣「收 159 不等于赚 159」；当堂测里设一个陷阱数字验证 |
| 混淆订阅档位与用量上限 | 把「分档」只当价格歧视，忘记它同时是成本封顶手段 | 讲三档时明确：档位差不仅卖功能，更是给重度用户的成本上保险——订阅制的自我保护机制 |

## 十四、与周五中期答辩的衔接（宣布）
