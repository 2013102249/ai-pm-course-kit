### 2. token 成本核算——现场手算（跟讲师同步算）

**公式**：单次对话成本 = 输入 token 数 ÷ 1000 × 输入单价 + 输出 token 数 ÷ 1000 × 输出单价

**课堂示例**（教学示例，以官网实时价格为准）：

| 步骤 | 计算式 | 我算的结果 |
|---|---|---|
| 输入费用 | 800 ÷ 1000 × 0.008 元/千 token | |
| 输出费用 | 400 ÷ 1000 × 0.024 元/千 token | |
| 单次对话成本 | 上两行相加 | |
| 人均月对话次数 | 日均 10 次 × 30 天 | |
| 人均月成本 | 单次成本 × 月次数 | |
| 订阅定价（示例） | 19.9 元/月 | |
| 人均月毛利 | 定价 − 月成本 | |
| 毛利率 | 月毛利 ÷ 定价 | |

**观察题**：输出 token 数不到输入的一半，为什么花的钱更多？

### 4. 单位经济模型测算表（主项目用，示例行仅作格式参考）

| 项目 | 示例行（教学示例） | 我的主项目 | 计算口径 / 数据来源 |
|---|---|---|---|
| 单次对话成本 | 0.016 元 | | 输入 + 输出 token 费 |
| 人均月频次 | 300 次 | | 日均次数 × 30 天 |
| 人均月成本 | 4.8 元 | | 单次成本 × 月频次 |
| 定价 | 19.9 元/月 | | 订阅档位 |
| 月毛利 | 15.1 元 | | 定价 − 月成本 |
| 毛利率 | 约 76% | | 月毛利 ÷ 定价 |
| 平均生命周期 | 8 个月 | | 行业参考值需注明「假设」 |
| LTV | 约 121 元 | | 定价 × 生命周期 × 毛利率 |
| CAC | 40 元 | | 获客投放与渠道成本分摊 |
| LTV / CAC | 约 3.0 | | 大于 3 健康，小于 1 烧钱 |
