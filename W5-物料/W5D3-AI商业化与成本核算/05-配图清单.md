### 2. 主体结构：四行对比表（每行一个模式）

| 行 | 列 1 · 模式 | 列 2 · 收费方式 | 列 3 · 适合产品 | 列 4 · 优势 | 列 5 · 劣势 |
|---|---|---|---|---|---|
| 1 | 订阅制 | 固定月费 / 年费，档位区分功能与用量 | 高频 C 端助手类（写作 / 学习 / 效率） | 收入可预测，现金流稳 | 重度用户成本倒挂 |
| 2 | 按量计费 | 按次 / 按 token / 按张数，充值或月结 | 低频高价值生成类（图 / 视频 / 文书） | 收入与成本同步，毛利安全 | 计价焦虑伤留存 |
| 3 | 席位制 | 坐席数 × 年费，B 端合同全家桶 | B 端团队协作（知识库 / CRM / 工作台） | 客单高、粘性强 | 决策链长，增长靠销售 |
| 4 | API 调用 | 按 token 千次批发价，量大折扣大 | 平台型公司 / 开发者生态 | 规模效应最强，替换成本高 | 毛利低，易陷价格战 |

### 4. 验收标准

1. 四行五列完整，文案与本清单逐字一致，无错别字。
2. 品牌色正确（紫 #7C3AED / 蓝 #2563EB），无其他高饱和杂色。
3. SVG 源文件可在无网络环境打开；PNG 导出 1920×1080 清晰无锯齿。
4. 每格文字 ≤2 行，手机竖屏缩放后仍可辨认行标题。
5. 底部注脚齐全；整体无 emoji、无衬线混排错乱。

### 5. 讲法脚本（讲师投屏时照读）

- **开图时机**：四大模式逐个讲完后，此图作为收束总览投屏。
- **讲法**：不逐格念。用手指沿四行从上到下走一遍，每行只念「模式名 + 一句话优劣」；最后横向比一次「劣势」列——四条劣势里三条与成本或毛利有关，顺势引出环节二：「所以接下来，我们必须学会算成本。」
- **提问点**：「这四种模式里，哪一种最难被价格战打穿？为什么？」（预期：席位制或 API——分别对应协作沉淀与生态绑定；引导到「护城河不靠价格」）
- **过渡话术**：「模式选得再对，不知道自己花多少钱，都是空谈。下一环节，全班一起算一笔账。」
- **停留时长**：约 3 分钟收束 + 引出下一环节。
