7第 2 节四大变现模式总览① 订阅 / 按量 / 席位 / API 四象限一句话 ② 没有最好只有匹配 ③ 判断锚：使用频次与成本结构只报模式名，逐个精讲在后—
8第 2 节模式一：订阅制 + 模式二：按量计费① 订阅：固定月费 / 年费、档位区分，适合高频 C 端 ② 订阅优势：收入可预测；坑：重度用户成本倒挂 ③ 按量：按次 / 按 token，适合低频高价值 ④ 按量优势：毛利安全；坑：计价焦虑伤留存两次追问连发：重度用户 200 次/天会怎样？计价焦虑伤什么？—
9第 2 节模式三：席位制 + 模式四：API + 对比收束① 席位 = 坐席 × 年费，B 端团队协作标配 ② API = 批发价按量卖给开发者 ③ 追问：B 端为何愿付年费、API 护城河是什么 ④ 四行对比：模式 / 收费 / 适合 / 一句话优劣手指沿四行逐行走；提问「哪种最难被价格战打穿」四大变现模式对比图
10第 2 节成本侧：一个公式① 单次成本 = 输入 token ÷ 1000 × 输入单价 + 输出 token ÷ 1000 × 输出单价 ② 除以 1000 是千 token 报价惯例 ③ 输入输出两个单价、输出更贵 ④ token（词元）与推理成本回扣板书同步；强调「÷1000」与「两个单价」两个细节白板公式
11第 2 节现场手算 + 从单次到月度① 输入 800×0.008 = 0.0064 元（教学示例）② 输出 400×0.024 = 0.0096 元 ③ 单次合计 0.016 元 ④ 月账：300 次 × 0.016 = 4.8 元；定价 19.9；毛利 15.1；毛利率约 76%全班手机计算器同步算；数字可复算——周五答辩核心行示例数字卡
12第 2 节当堂测 + 【案例页】模式错配① 当堂测：输入 500 token@0.01、输出 500 token@0.03 → 0.02 元 ② 典型错误：漏 ÷1000、单价乘反 ③ 正面案例：订阅 + 用量上限、先算成本再定价 ④ 反面案例：高频写作助手错配按量、留存下滑 ⑤ 深化：为什么输出更贵 / 边界：价格动态1 分钟测完举手；案例只做定性描述，不引真实市场数据分层习题投屏 + 案例对比图
13第 3 节定价三心理锚点① 锚定（给参照：划线价 / 联系销售）② 分档（造主流：三档 + 最受欢迎）③ 免费层（画边界三问）④ 定价三问法：成本底线 / 竞品锚位 / 用户感知价值取交集强调免费层成本：教学示例 10 万免费用户 ≈ 8000 元/月三档定价示意
14第 3 节单位经济模型：LTV 与 CAC① LTV = 定价 × 生命周期 × 毛利率 ≈ 121 元（教学示例）② CAC 40 元 ③ LTV / CAC ≈ 3.0 ④ 大于 3 健康、小于 1 烧钱 ⑤ 红笔圈「× 毛利率」回扣「收 159 不等于赚 159」；英文缩写给全称与中文单位经济测算表
15第 3 节规模化路径：先证模型再放大① 先在百人级验证单位经济为正 ② 毛利为负时放大 = 加速烧钱 ③ 投资人视角：不怕慢，怕不知赚亏 ④ 盈亏平衡：单客打平 ≠ 公司打平结论先行，再给路径；预告周五答辩第一问—
16第 3 节【案例页】正反面案例对照① 正面：免费层当获客预算、算转化率盈亏平衡点、升级钩子绑价值瞬间 ② 反面：LTV 写成收入 159 元、比值虚高约 4、误判可放大 ③ 正确口径：乘毛利率后约 121 元、比值约 3.0 ④ 数字均为教学示例请学员找出反面案例错在哪一步；对照讲课稿第 3 节正反面案例对比图
17第 3 节【深化页】常见误解与边界① 误解一：token 数少就花钱少（错，看 token 数 × 单价）② 误解二：毛利 = 净利 ③ 误解三：LTV / CAC 大于 3 永远安全（CAC 会随规模上升）④ 边界：所有单价动态，以官网实时价格为准每条误解给一句纠正；强化「教学示例」口径—
18第 3 节商业画布九格：先成本后收入① 填写顺序 ①②③ → ④⑤⑥⑦⑧ → ⑨ ② 成本三格先落袋（刚算完的数字）③ 收入来源放最后 ④ 互审规则：每格被问「凭什么」⑤ 依据出处：W4 调研 / 周一增长 / 今天测算为第 4 节实操铺垫，只讲规则不动手商业模式画布九格模板
