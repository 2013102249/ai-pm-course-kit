| 时间 | 动作 | 组织要点 |

## 四、互评规则（检验问题只有一句，原文保留）

> **「前 1000 个用户看到这套计划，会不会信？」**

| 规则 | 说明 |
|---|---|
| 只用一个问题检验 | 不评文笔、不评完整度，只回答：这 1000 个用户会不会信这套计划会真的发生 |
| 必须指出「最不信的一条」 | 互评者要说出具体是哪一栏、哪个表述让人不信，并写出理由——不接受「整体还不错」 |
| 至少给一条修订建议 | 建议要可执行（如「渠道收敛到一条」），不接受「再多想想」 |
| 双向都过一遍 | 每人 3 分钟，先读对方方案再讨论；时间到强制换人 |
| 书面留痕 | 结论写进导学案「互评记录」栏，课后修订以此为准 |

**互评示范话术（讲师可先带全场演示 30 秒）**：
「我读了你的方案，最信的是冷启动计划——你写了先服务 100 个用户、人工兜底，这步是真的会发生。最不信赖的是裂变那一页——你的留存抓手还空着，这时候上裂变，我不信用户会转发。我的建议是：先把留存那条补上，裂变缩成两行并写明上线条件。」

## 五、讲师巡场追问清单（原文保留，用于卡壳或写得太虚的学员）

按模板栏目逐项追问，每次只问一个问题：

| 学员卡在哪里 | 追问 |
|---|---|
| aha 时刻写不出 | 「你的用户第一次拿到可用的产出，是哪一步？用『第几次、用什么功能、觉得值了』的句式说一遍。」 |
| aha 时刻写成功能名 | 「如果只看后台数据，你通过哪个行为能知道用户已经『值了』？」 |
| 激活路径下不去笔 | 「从打开产品到刚才那个动作，中间有几步？哪一步删掉用户照样能到达？」 |
| 冷启动计划太泛 | 「你的目标用户这个周末会在哪里？你下周一能做的第一个动作是什么？」 |
| 渠道铺了五六个 | 「如果这周你只有精力做一个渠道，留下哪个？为什么是它？」 |
| 留存抓手空白 | 「用户明天再来一次的理由是什么？后天呢？」 |
| 裂变写得最起劲 | 「你的留存还没验证，现在做裂变，放大的是什么？」 |
| 前 1000 用户计划没节奏 | 「第一个 100 人和后面的 900 人，你的做法有什么不同？」 |

## 六、异常处理（原文保留并补 本课版条目）

| 情况 | 处理 |
|---|---|
| 学员项目方向还不清晰，无法填写 | 让其借用教案第十一节的「某 AI 简历工具」教学示例预填一版走完流程，课后换回自己项目重填 |
| 两人一组但人数落单 | 拆成三人组，互评改为每人 2 分钟 |
| 互评变成互相客气 | 讲师插入示范：现场挑一份方案（征得同意）用「会不会信」追问 30 秒，示范怎么「指出最不信的一条」 |
| 时间不够，展示环节放不下 | 取消小组展示，只保留讲师统一点评三个高频问题（讲课稿对应板块末段）；展示改到课后社群进行 |
| 线上授课 | 分组用讨论室；互评结论仍要求写回导学案；巡场改为随机进房追问 |
| 对应板块术语卡未制成（本课版新增） | 用板书「12 术语 + 7 组易混对照」代替投屏，术语自测表照常填写；课后补看术语卡 |
| 对应板块两两模拟不敢追问（本课版新增） | 照追问卡念：第一层问「去哪找」、第二层问「拿什么切入」、第三层问「怎么算服务好了」 |
| 手机 / 平板学员卡在大表录入（本课版新增） | 启用第七节替代动作：语音口述 + 同伴代填、手写拍照、互评录音，不因设备降标准 |

## 七、设备要求表（本课版新增：手机 / 平板 / 电脑三档）

| 档位 | 可独立完成的任务 | 受限任务 | 替代动作 |
|---|---|---|---|
| **电脑** | 全部：术语自测表、导学案五项方案、习题作答、术语卡浏览、面试模拟记录、作品集归档、投屏互评 | 无 | — |
| **平板** | 术语自测表、术语卡浏览、两人互评、习题作答、拍照归档、面试口播录音 | 增长方案五项大表逐格录入较慢、多窗口对照不便、留存曲线手绘不便 | 用分屏或打印版导学案手写后拍照归档；投屏内容与同组电脑学员共用；留存曲线纸上画好拍照上传 |
| **手机** | 术语自测、看术语卡缩略图、面试 30 秒 / 60 秒口播录音、互评口述、拍照归档、群内接龙 | 增长方案五项大表、多列对照表录入、留存曲线与激活路径手绘、追溯投屏表格逐格对照 | ① 方案五项改为「语音口述 + 同伴代填」或手写拍照；② 激活路径 / 留存曲线纸上画好拍照，旁注一行「删了哪步、为什么」；③ 互评口述录音，课后补写「最不信的一条 + 一条建议」；④ 与同组电脑学员共用一屏，或看讲师发的模板缩略图；⑤ 归档拍照命名「W5D1-增长方案」存相册，对应板块登记归档位置 |

**分节受限任务与替代动作对照**：

| 板块 | 需电脑的任务 | 手机 / 平板替代动作 |
|---|---|---|
| 对应板块 | 术语自测表 12 行逐格录入 | 口述给同伴代填，或纸质术语卡旁手写定义后拍照；小测可口答 |
| 对应板块 | AARRR 笔记表、aha 三步表 | 手写拍照；三步用三张便签纸分别写 |
| 对应板块 | 留存曲线两分支手绘 | 纸上画两条曲线拍照，标注「差值显著 / 不显著」两种结论 |
| 对应板块 | 增长方案五项大表 | 语音口述五项 + 同伴代填；手写拍照；互评录音 |
| 对应板块 | 面试模拟记录表逐格记录 | 用手机录音代替书面追问记录，课后补一行「卡在第几层、自评分」 |
| 对应板块 | 作品集积木在线归档 | 拍照存相册并命名，归档位置写「手机相册 / 课后上传课程群」 |

> 口径：替代动作只改变「记录形式」，不改变「产出标准」——五项齐全、aha 落到行为、渠道收敛 1 条、留存 ≥2 条、裂变写上线性条件，手机 / 平板同学同样要达标。

### 课堂交互与投屏动作（讲稿原文）

- 给大家 24 分钟，我先巡场，不集中讲。手机 / 平板的同学看替代动作卡，别卡在表格上。
- | 投屏模板对照 | 看大屏 | 与同组电脑学员共用一屏，或看讲师发的模板缩略图 |
- 手机 / 平板同学把拍照件命名「W5D1-增长方案」存相册，在归档位置一栏写「手机相册 / 课后上传课程群」也算完成。归档动作 20 分钟，讲师巡场逐行看「完成度」有没有空着。

### 常见问题（答疑口径）

- 1. 结论：增长期也不能先不管成本。 护栏要在放量前设好。
- 2. 结论：效果不确定时用有效回答率做留存代理。 打开率反映不了答得稳不稳。
- 3. 结论：飞轮转不起来先推价值验证环。 第一次没帮上忙，后面四环都空转。
