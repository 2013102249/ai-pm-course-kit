交互使用说明 · W3 周二《Agent 产品设计与工作流实操》

本课无专用交互网页：本课为 Dify / Coze（扣子）平台实操课，学员直接在真实产品中动手，「交互」就是平台本身。投屏演示对象是 Dify / Coze 的编排画布，而非课件页面。
本文件定位为「Dify / Coze 实操课组织方案」，覆盖课前检查、投屏演示要点、助教巡场分工、故障预案四部分。
教学红线：所有操作描述均为通用化口径（节点类型、连线逻辑），不绑定特定版本界面细节，统一说「以当前版本界面为准」。

一、课前账号检查表（开课前 1 天 + 开课前 10 分钟）

开课前 1 天（讲师 / 班主任发群核对）

检查项 标准 未达标处理
Dify 云端版或 Coze 注册 学员按导学案预习任务 1 完成注册并登录截图接龙 未注册学员私聊，给 10 分钟教程 + 助教一对一；课上安排两人共用一台备用
平台可访问性 讲师和助教在教室内网实测登录 Dify / Coze 各一次 如教室网络封锁海外服务，全体统一改用 Coze（扣子），并提前通知
讲师演示账号 一个已建好半成品工作流的账号（演示可省时） 提前 1 天搭好「售后助手-workflow-demo」半成品
备用账号 助教持有 1 个干净账号，供临时借用的学员 —
平台政策 不承诺任何价格与功能细节；涉及额度问题统一口径「以官方当前说明为准」 —

开课前 10 分钟（助教逐项打勾）

检查项 操作
投屏 投屏讲师浏览器，画布区域清晰可读；浏览器缩放 100%，必要时放大至 125%
讲师账号 登录成功，半成品工作流可打开
网络 讲师机跑通一次工具节点试运行
学员端 随机请 2 名学员现场登录确认（重点看预习截图接龙缺席者）
备用方案 打开《工作流编排示意图.svg》备用标签页；打印 2 份纸质流程图

二、讲师投屏演示要点（通用化步骤，与教案环节三五步对应）

实操步骤 投屏演示要点（通用口径） 演示时长 红线提醒
① 建应用（30–38 min） 演示「新建应用 → 选工作流类型 → 命名 → 进入画布」的通用路径；命名规范「主项目名-workflow-v1」 3–4 min 不逐个介绍平台按钮，只走通一条最短路径
② 加节点（38–48 min） 演示四类节点（开始 / LLM / 条件分支 / 输出）的添加与连线；强调「连线 = 输出变量传给输入参数」 4–5 min 界面术语不同时统一切换：「有的版本叫xx，逻辑一样，以当前版本界面为准」
③ 配工具（48–58 min） 演示挂载工具 / 插件的通用四件事：选工具 → 填凭证或启用插件 → 参数映射 → 单节点试运行 4–5 min 凭证类演示用讲师预置账号，不展示任何密钥
④ 调提示词（58–68 min） 演示 LLM 节点内「角色 + 任务 + 输出格式约束」三段式；必做反面演示：先跑一次不限格式的版本让下游报错，再改强约束版本跑通 4–5 min 反面演示不可省略，这是本课最有效的记忆点
⑤ 测运行（68–80 min） 演示整条运行 + 故意制造失败（断工具 / 乱输入），展示失败分支接住异常 5 min 制造失败前先跑通一次正常输入，避免学员误以为「本来就不行」

每步演示节奏固定：投屏 3–5 分钟 → 学员动手 → 助教巡场 → 宣布完成标志 → 进下一步。

三、助教巡场分工（50 分钟实操段）

分区与优先级

分工 负责人 巡场范围
A 区（前排） 助教 1 学员座位前半区，兼顾进度落后者
B 区（后排） 助教 2 学员座位后半区，兼顾进度超前者（给加餐任务：补接管点）
机动 讲师 主投屏；举手求救超 2 人时停下统一讲

卡壳优先级（先处理谁）

账号登录问题 > 连线找不到节点 > 工具配置报错 > 提示词效果不理想
  • 账号问题：机动处理，单人不超 3 分钟，超时换备用账号，课后再补
  • 连线问题：只指路不代做——「你的下游输入，需要哪个上游变量？」
  • 工具报错：先看是否凭证 / 参数映射两类高频原因
  • 提示词问题：降级处理，用附录一巡场提问引导自查

巡场统一节奏

每步动手段巡场 2 圈：第 1 圈看「谁还没开始」（解决启动卡点），第 2 圈看「谁卡在中间」（解决技术卡点）。每步结束前 1 分钟统计完成率，低于 60% 则延长该步 2 分钟，从下一演示段压缩补回。

四、账号 / 网络故障预案

故障 处理
个别学员账号登录不上 助教给备用账号先跟上进度；课后凭注册截图补课
教室网络整体不稳 / 平台无法访问 降级方案 A：全员切换备用平台（Dify 与 Coze 二选一切换）；降级方案 B：讲师投屏演示全程，学员两两一组在手机端协作，导学案设计表照填，课后自行补实操
平台加载极慢 课前已跑通渲染缓存；仍慢则「先讲思路等加载」——用《工作流编排示意图》讲当前步骤的逻辑，画布转出来再操作
讲师投屏故障 纸质流程图 + 学员端手机直播屏幕（投屏软件预装）；讲解逻辑不变
平台限额 / 额度不足提示 统一口径「以官方当前说明为准」，课程只使用免费可复现的基础能力；确实受限的学员用备用账号或与邻座合跑
实操整体进度严重落后（第⑤步来不及） 保底目标调整为：主链路四类节点连完 + 异常输入口头设计（写进导学案失败分支栏），失败分支课后补；不影响周五评审验收标准宣贯

五、课后学员指引（发群文案）

同学们，今天的实操五步（建应用 → 加节点 → 配工具 → 调提示词 → 测运行）如果课上没跑完，请今天之内补完。作业：主项目工作流 V1 四项截图（画布全貌含失败分支 / 正常输入结果 / 异常输入结果 / 接管点说明）归档到项目文件夹，命名 W3D2-工作流V1。周五原型评审 I 按三条线验收：主链路跑通、失败分支存在、接管点明确。卡住的同学把报错截图发群里，助教在线答疑。
