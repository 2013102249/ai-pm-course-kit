8第 2 节决策框架：三个维度（原 4）① 任务确定性：流程图画得出吗 ② 步骤数：数得出来吗（3–8 步）③ 容错要求：错了代价是什么 ④ 三维一起量逐维讲透，每维配一个反例工作流编排示意图（主链路部分）
9第 2 节现场快判：4 个场景（原 5）① 新闻抓取 → 工作流 ② 安排出差 → Agent ③ 工单分类 → 工作流 ④ 竞品调研 → Agent快节奏问答让学员喊答案；答案页动画淡入场景卡片版式
10第 2 节口诀页（金句全屏，原 6）① 能用工作流解决的事，别用 Agent ② 确定性是产品的好朋友 ③ 面试被问先反问确定性 ④ 抄进导学案放慢语速，重复一遍，让学员抄录紫底白字全屏金句页
11第 2 节正面案例：难但确定的报销审核（新增，案例页）① 规则细、识别难 ② 用三刻度尺量：画得出 / 数得清 / 低容错 ③ 结论：固定工作流 + 人工确认 ④ 难点不是难度是路径强调「难 ≠ 路径不定」，破「Agent 更高级」误解案例卡：三刻度尺打勾示意
12第 2 节反面案例：把工单分类做成 Agent（新增，案例页）① 为「以后好扩展」上 Agent ② 同一工单两次分类不一致 ③ 路由错团队、无法对账 ④ 为未发生的灵活性丢掉可控性放慢讲复盘一句话；引「这段在面试里怎么答」失败链路红标示意
13第 3 节人机接管点：三种类型（原 7）① 审批型（事前）② 纠错型（事中）③ 兜底型（事后）④ 接管成本对冲风险损失用「退款」案例贯穿三型（教案提问 10）工作流编排示意图（接管点标注）
14第 3 节失败兜底三件套（原 8）① 重试（瞬时失败）② 降级（持续失败）③ 转人工（最终出口）④ 顺序不可乱、重试要幂等沿图上失败分支虚线走一遍；转人工必带完整上下文三级流程图示
15第 3 节反面案例：无限转圈的客服工作流（原 9）① 无失败分支 ② 工具超时 → 全链路中断 ③ 用户端无限转圈 ④ 投诉翻倍、紧急下线放慢讲故事；落金句「兜底设计是产品承诺」失败链路红标示意
