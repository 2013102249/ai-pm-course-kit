# 交互使用说明 · W3 周二《Agent 产品设计与工作流实操》

> 本课**无专用交互网页**：本课为 Dify / Coze（扣子）/ 豆包平台实操课，学员直接在真实产品中动手，「交互」就是平台本身。投屏演示对象是编排画布，而非课件页面。
> 本文件定位为「300 分钟（6 课时 × 50 分钟）实操课组织方案」，覆盖 6 节使用时机、课前检查、投屏演示要点、助教巡场分工、故障预案、设备要求、课后指引七部分。
> 平台双路径：路径 A「Dify 云端版 / Coze 境外版」、路径 B「扣子国内版 / 豆包」，二选一，界面细节统一口径「以当前版本界面为准」。
> 教学红线：所有操作描述均为通用化口径（节点类型、连线逻辑），不绑定特定版本界面细节；不编造性能数据，涉及额度、价格、响应表现一律写「以官方当前说明为准」；不出现真实学员姓名。

## 三、讲师投屏演示要点（通用化步骤，与教案第 4 节五步对应）

| 实操步骤（第 4 节 150–200 min） | 投屏演示要点（通用口径） | 演示时长 | 红线提醒 |
|---|---|---|---|
| ① 建应用（158–164 min） | 演示「新建应用 → 选工作流类型 → 命名 → 进入画布」的通用路径；命名规范「主项目名-workflow-v1」；路径 A / B 并列展示入口差异 | 2 min | 不逐个介绍平台按钮，只走通一条最短路径；两条路径不比较优劣 |
| ② 加节点（164–171 min） | 演示四类节点（开始 / LLM / 条件分支 / 输出）的添加与连线；强调「连线 = 输出变量传给输入参数」；提醒条件分支与失败分支分两行 | 2 min | 界面术语不同时统一切换：「有的版本叫法不同，逻辑一样，以当前版本界面为准」 |
| ③ 配工具（171–178 min） | 演示挂载工具 / 插件的通用四件事：选工具 → 填凭证或启用插件 → 参数映射 → 单节点试运行 | 2 min | 凭证类演示用讲师预置账号，不展示任何密钥 |
| ④ 调提示词（178–184 min） | 演示 LLM 节点内「角色 + 任务 + 输出格式约束」三段式；**必做反面演示**：先跑一次不限格式的版本让下游报错，再改强约束版本跑通 | 2 min | 反面演示不可省略，这是本课最有效的记忆点 |
| ⑤ 测运行（184–190 min） | 演示整条运行 + 故意制造失败（断工具 / 乱输入），展示失败分支接住异常；跑正常 / 边界 / 异常三类输入 | 2 min | 制造失败前先跑通一次正常输入，避免学员误以为「本来就不行」 |

每步演示节奏固定：投屏约 2 分钟 → 学员动手 → 助教巡场 → 宣布完成标志 → 进下一步。第 150–158 min 先讲规矩与双路径 / 设备分档，第 190–200 min 讲评。

## 四、助教巡场分工（第 4 节 150–200 min 实操段）

### 分区与优先级

| 分工 | 负责人 | 巡场范围 |
|---|---|---|
| A 区（前排） | 助教 1 | 学员座位前半区，兼顾进度落后者与手机 / 平板轻量线学员 |
| B 区（后排） | 助教 2 | 学员座位后半区，兼顾进度超前者（给加餐任务：补接管点） |
| 机动 | 讲师 | 主投屏；举手求救超 2 人时停下统一讲 |

### 卡壳优先级（先处理谁）

```
账号登录问题 > 连线找不到节点 > 工具配置报错 > 提示词效果不理想
```

- 账号问题：机动处理，单人不超 3 分钟，超时换备用账号或转路径 B，课后再补
- 连线问题：只指路不代做——「你的下游输入，需要哪个上游变量？」
- 工具报错：先看是否凭证 / 参数映射两类高频原因
- 提示词问题：降级处理，用 02-讲课稿附录一巡场提问引导自查
- 手机 / 平板学员：不按卡壳处理，直接引导走「轻量线」四件套（纸面设计表 / 浏览模板 / 术语自测表 / 60 秒口播）

### 巡场统一节奏

每步动手段巡场 2 圈：第 1 圈看「谁还没开始」（解决启动卡点），第 2 圈看「谁卡在中间」（解决技术卡点）。每步结束前 1 分钟统计完成率，低于 60% 则延长该步 2 分钟，从讲评段压缩补回。

## 五、账号 / 网络故障预案

| 故障 | 处理 |
|---|---|
| 个别学员账号登录不上 | 助教给备用账号先跟上进度；课后凭注册截图补课 |
| 教室网络整体不稳 / 路径 A 无法访问 | 降级方案 A：全员切换路径 B「扣子国内版 / 豆包」；降级方案 B：讲师投屏演示全程，学员两两一组在手机端协作，导学案设计表照填，课后自行补实操 |
| 平台加载极慢 | 课前已跑通渲染缓存；仍慢则「先讲思路等加载」——用《工作流编排示意图》讲当前步骤的逻辑，画布转出来再操作 |
| 讲师投屏故障 | 纸质流程图 + 学员端手机直播屏幕（投屏软件预装）；讲解逻辑不变 |
| 平台限额 / 额度不足提示 | 统一口径「以官方当前说明为准」，课程只使用免费可复现的基础能力；确实受限的学员用备用账号或与邻座合跑 |
| 手机 / 平板学员无法编辑画布 | 不勉强：按第六节「设备要求表」走轻量线，产出纸面设计表 + 60 秒口播 + 自测表，课后借电脑补截图 |
| 实操整体进度严重落后（第⑤步来不及） | 保底目标调整为：主链路四类节点连完 + 异常输入口头设计（写进导学案失败分支栏），失败分支课后补；不影响周五评审验收标准宣贯 |

## 六、设备要求表（新增）

| 设备档 | 可独立完成 | 受限任务 | 替代动作（第 4 节轻量线） |
|---|---|---|---|
| 电脑（推荐） | 五步全流程：建应用、加节点、配工具、调提示词、测运行；正常 / 边界 / 异常三类输入测试 | 无 | — |
| 平板 | 浏览器登录路径 B、建应用与命名、浏览 3–5 个官方模板、填写导学案与术语自测表、面试模拟记录表 | 画布拖拽连线、多窗口参数映射不稳定、单节点试运行不可靠 | 与电脑学员结对，口述节点与失败分支设计由对方操作；在纸质《工作流编排示意图》上手画主链路 + 失败分支并拍照归档 |
| 手机 | 登录扣子国内版 / 豆包移动端、浏览官方模板、看讲师投屏、完成术语自测表与面试模拟记录表、录制 60 秒面试口播 | 无法可靠编辑编排画布、无法多窗口配工具、无法单节点试运行 | 走「路径 B 移动端轻量线」：完成《工作流设计表》纸面版（含节点 / 变量 / 失败分支三列）+ 60 秒口播；课后借电脑补实操，补完截图计入第 6 节作品集积木 |

> 口径说明：受限任务一律不勉强、不降低验收标准，只延后完成时间；第 6 节验收三条线对轻量线学员改为「纸面设计表 + 60 秒口播 + 术语自测表达标，实操截图课后补」，并登记补交日期。
