第 3 节 · 核心原理讲授 B + 案例：三要点 · 成本 · 版权（100–150 min，页 13–18）

页所属节次页标题内容要点（3–5 条）讲师提示配图 / 交互
13第 3 节交互设计三要点（原页 10）① 会等待（进度 / 低保真 / 可取消 / 兜底）② 可微调（描述 → 预览 → 微调 → 确认）③ 选对模态（自然交互 + 降级路径）④ 禁忌：强制语音念银行卡号回扣刚亲历的等待与失败体感；评委按这三条挑方案图 3 传统 vs AI 产品对比图
14第 3 节成本测算：按次计费口径（原页 11）① 日成本 = 日调用次数 × 单次价格 ×（1 + 失败重试率）② 价格以官网实时价格为准 ③ 四步法 ④ 截图存档可回溯现场板书演算一遍；DAU 给全称与中文板书（成本公式）
15第 3 节为什么单价低还会失控（原页 12）① 量大 / 重试 / 免费额度被薅 / 缺护栏 ② 隐性成本四项：审核、存储、并发、风控 ③ 单价低 ≠ 总成本低 ④ 重试系数 1.2–1.5提问：几毛钱一次为什么还失控；引出护栏设计板书（隐性四项勾选）
16第 3 节成本 × 体验权衡 + 版权三步（原页 13）① 钱花在用户感知得到的地方 ② 授权与合规最不能省 ③ 口诀：先问授权、再问归属、最后再谈商用 ④ 以法务意见和平台授权条款为准 ⑤ 回扣 W2D4 清单宣布合规清单自查为评审硬门槛；显著标识 / 备案要求以最新监管口径为准图 8（右栏预告）+ W2D4 清单
17第 3 节反面案例①：等 30 秒没反馈用户就走（新增案例页，指定场景）① 场景：无进度、无占位、无取消 ② 违反「会等待」，漏反馈进度与失败兜底 ③ 整改：真实进度 / 低保真预览 / 可取消 / 兜底 ④ 收口：延迟客观，不知情地等是设计失误与「会等待」要点对照讲；不写死具体秒数，记原则不记数字图 8 反面案例对照图（左栏）
18第 3 节反面案例②：生成内容拿去商用惹版权纠纷（新增案例页，指定场景）① 场景：生成图投广告被指侵权、三方扯皮 ② 跳过「再问归属」「最后谈商用」两步 ③ 整改：输入端 / 输出端 / 商用链路三段 ④ 收口：用户可以对结果不满意，但不能不知情与三步口诀对照；不给「能 / 不能商用」法律结论图 8 反面案例对照图（右栏）
