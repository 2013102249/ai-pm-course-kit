# 分层习题 · W3 周四《多模态产品设计》

> 配套教学日 300 分钟（6 课时 × 50 分钟）。五层难度：第 0 层术语辨析 → 第 1 层基础巩固 → 第 2 层进阶实操 → 第 3 层求职挑战 → 第 4 层面试实战。
> 建议用法：第 0 层在第 1 节当堂测 10 分钟；第 1 层随堂测；第 2 层当作业（与主项目方案合并提交）；第 3 层自测、第 4 层在第 5 节两两模拟，第八周面试课复用。
> 所有题目均附参考答案与评分标准。考点：多模态场景设计（给场景选形态并设计交互）、体验三要点、成本测算、版权风险判断。
> 统一口径：价格一律「以官网实时价格为准」，版权一律「以法务意见和平台授权条款为准」，不给法律结论，不写死生成时长数据。

## 第 0 层 · 术语辨析（10 题，含选择 / 连线 / 改错三种题型）

### 一、选择题（T1–T4，每题 10 分）

**T1. 关于「多模态」，下列说法正确的是：**
A. 产品里塞的模态越多越好
B. 在文本之外，给用户加上图像、声音等更自然的输入输出方式
C. 就是文生图和文生视频的统称
D. 必须同时用上图、视频、语音、数字人四种形态

**T2. 「会等待」和「可微调」的关系，正确的是：**
A. 是同一件事的两种说法
B. 会等待管结果出来之后，可微调管结果出来之前
C. 会等待管结果出来之前，可微调管结果出来之后
D. 两者都属于「选对模态」这一个要点

**T3. 关于「生成延迟」与「反馈进度」，正确的是：**
A. 生成延迟是因为没做进度条
B. 做了反馈进度就能消除生成延迟
C. 生成延迟是客观耗时，反馈进度是产品给用户的告知设计
D. 两者是同义词

**T4. 关于「版权」与「商用授权」，正确的是：**
A. 两者完全等价
B. AI 生成的没有版权，可以随便商用
C. 版权关注归属与权利，商用授权关注能否用于商业用途；判断以法务意见和平台授权条款为准
D. 用户协议里写一句「后果自负」就免除了平台责任

### 二、连线题（T5，10 分）

**T5. 把左列术语与右列一句话定义连起来（6 组）。**

| 左列 · 术语 | 右列 · 定义 |
|---|---|
| ① 多模态 | A. 把文字转成可播放的人声 |
| ② 文生图 | B. 结果出来后支持局部修改，不从头重来 |
| ③ 语音合成 | C. 在文本之外给产品加上眼睛和耳朵 |
| ④ 数字人 | D. 为场景决定用哪种输入输出形态的动作 |
| ⑤ 模态选择 | E. 输入一段文字，输出一张图片 |
| ⑥ 可微调 | F. 形象、语音、动作合体的虚拟出镜者 |

### 三、改错题（T6–T10，每题 10 分，写出正确表述）

**T6.** 「AI 生成的没有作者，所以没有版权，可以随便商用。」

**T7.** 「多模态就是把图、视频、语音、数字人全堆进产品，功能越全越好。」

**T8.** 「生成慢就换一个更快的模型，进度条之类的等待设计可以不做。」

**T9.** 「文生视频和数字人是一回事，都是按次计费、生成一段画面。」

**T10.** 「价格写死在方案里更清楚，版权结论产品经理自己拍板就行。」

## 第 3 层 · 求职挑战题（原有 2 题保留 + 新增 2 题，共 4 题，每题 30 分）

**14.（原有第 10 题）面试真题：给场景选形态并设计交互**
面试官：「我们是一家在线教育公司，想给课程配一个『数字老师』：既能出镜讲课，又能回答学生提问。你会怎么设计这个功能？交互上要注意什么？」
要求：先给形态选择与理由，再指出该方案最大的一个风险，最后按交互三要点给两条设计建议。

**15.（原有第 11 题）案例分析：数字人冒充风波**
某数字人产品允许用户上传少量真人照片生成个人形象视频。上线两个月后，有用户上传他人照片生成冒充本人的发言视频并传播，引发舆情，平台被要求整改。请分析：① 产品在授权与审核链路上漏了哪几步（按事前 / 事中 / 事后排序）；② 如果你是产品经理，写出整改方案的三条核心动作；③ 说明该风险与 W2D4《AI 产品合规检查清单》中哪类条目对应。

**16.（新增）案例分析：生成内容拿去商用惹版权纠纷**
某商家把文生图生成的商品宣传图直接投了广告，随后被指与某插画师系列作品高度相似；平台援引用户协议里「仅供个人使用」的条款，三方扯皮。请分析：① 按三步口诀指出跳过了哪两步；② 写出整改三条动作；③ 写出本题统一采用的边界口径，并说明为什么不给「能 / 不能商用」的法律结论。

**17.（新增）案例分析：等 30 秒没反馈用户就走**
某文生图功能点下生成后，页面无进度、无占位、无取消入口；用户等了一段没有反馈的等待后离开，性子急的还连点几次，导致后台重复提交、成本翻倍。请分析：① 违反三要点中的哪一条、具体漏了哪两个动作；② 写出四条整改动作；③ 说明「生成延迟」与「反馈进度」为什么不是一回事。

## 第 4 层 · 面试实战（6 题，每题含踩分点 / 追问链 / 失败答法 / 60 秒标准答法 / 评分表）

> 题型覆盖：技术理解、场景设计、项目深挖、行为题。统一评分档：优秀 9–10 分、合格 6–8 分、待改 ≤5 分；两两模拟时把得分填入《面试模拟记录表》。

### M1 · 三要点是什么（题型：技术理解）

- **踩分点**（3–4 条，可判分）：① 准确报出会等待 / 可微调 / 选对模态（3 分）；② 每个要点各配一条具体设计动作（3 分）；③ 至少用到一个当日术语，如反馈进度、生成延迟（2 分）；④ 主动补一个反面案例（2 分）。
- **追问链**：第 1 层「只报三个名词够不够？」→ 不够，要配动作；第 2 层「会等待和可微调是不是一回事？」→ 不是，一个管结果前、一个管结果后；第 3 层「只能先做一个呢？」→ 先做反馈进度，成本最低、见效最快。
- **典型失败答法**：「就是等待、微调、选模态嘛。」失分原因：只有名词、没有动作、没有术语，被追问一层就答不下去。
- **60 秒标准答法（参考答案）**：「多模态交互设计我按三要点讲。第一会等待，生成是异步慢响应，体验一半在设计等待，做真实反馈进度、低保真预览、可取消和失败兜底；第二可微调，生成结果天然不确定，流程设计成描述、预览、微调、确认，支持局部重绘、换音色，而不是只给重新生成按钮；第三选对模态，让用户用最自然的器官和产品说话，双手被占用用语音、视觉信息用图，识别失败要能降级回文字。反过来，没有反馈的等待让用户直接走掉，就是漏掉会等待的典型翻车。」

|---|---|---|
| 报出三个要点 | 3 | |
| 每要点配一条动作 | 3 | |
| 用到当日术语 | 2 | |
| 补反面案例 | 2 | |
| 合计 | 10 | |

### M2 · 为什么模态不是越多越好（题型：技术理解 / 场景设计）

- **踩分点**：① 点出每个模态都有成本、等待、合规三笔代价（3 分）；② 给出判断标准「每个模态都要回答用户为什么要它」（3 分）；③ 举出正例或反例（2 分）；④ 回扣选型三问或三维度（2 分）。
- **追问链**：第 1 层「按什么决定加不加？」→ 先问价值、再问形态、最后问边界；第 2 层「组合什么时候合理？」→ 每个模态有独立不可替代的价值；第 3 层「评委说你太保守只用一种？」→ 用三维度说明其它不划算，而非不敢用。
- **典型失败答法**：「模态多显得功能全，用户会觉得厉害。」失分原因：把堆料当价值，没提成本与合规，正是本课反复纠的错。
- **60 秒标准答法（参考答案）**：「我不认为模态越多越好。每加一个模态，都要多付一份成本、多一段生成延迟、多一类合规风险，这三笔账都会放大。判断标准很简单：每个模态都要能回答『用户为什么要它』，回答不出就不加。比如电商选品，文生图用来看商品摆进场景的效果，语音用来让开车巡店的人听结论，两个模态各有独立价值，是合理组合；但把文生视频和数字人也堆进去，用户找不到入口、成本按最贵的算，就是为多模态而多模态。所以选型我按三问走：先问价值、再问形态、最后问成本与合规边界。」
- **评分表**：

| 踩分点 | 分值 | 得分 |
|---|---|---|
| 点出三笔代价 | 3 | |
| 给出判断标准 | 3 | |
| 举正例或反例 | 2 | |
| 回扣三问 / 三维度 | 2 | |
| 合计 | 10 | |

### M3 · 生成慢怎么办（题型：场景设计）

- **踩分点**：① 先做等待体验设计而非直接换模型（3 分）；② 给出四个动作中至少三个：真实反馈进度 / 低保真预览 / 可取消 / 失败兜底（3 分）；③ 再谈异步化、队列、缓存复用（2 分）；④ 最后才谈模型与算力，且不当唯一答案（2 分）。
- **追问链**：第 1 层「换更快的模型不就行了？」→ 模型只是一层，等待体验与架构层先做，且更快模型往往更贵；第 2 层「用户等不及走了怎么办？」→ 可取消 + 后台完成后通知 + 先给低清预览确认方向；第 3 层「怎么证明不是拍脑袋？」→ 埋点看放弃率、失败率，重试系数进成本测算。
- **典型失败答法**：「换一个更快的模型 / 加机器。」失分原因：把产品问题当成纯技术问题，漏了体验设计与成本权衡，也没用到生成延迟、反馈进度这类术语。
- **60 秒标准答法（参考答案）**：「生成延迟是客观的，产品能控的不是让它消失，而是别让用户不知情地等。我分三层：体验层做真实反馈进度、低保真预览、可取消、失败兜底，而不是白屏或无限转圈；架构层做任务异步化、排队、相同输入命中缓存复用，顺带给重试次数封顶，别让失败重试把成本打穿；第三层才是模型与算力，而且要结合成本测算看值不值。同样的耗时，有没有进度设计，留存完全不同，所以第一反应不该是换更快的模型。」
- **评分表**：

| 踩分点 | 分值 | 得分 |
|---|---|---|
| 先做等待体验设计 | 3 | |
| 四个动作写出 ≥3 个 | 3 | |
| 异步化 / 队列 / 缓存 | 2 | |
| 模型算力放最后且不唯一 | 2 | |
| 合计 | 10 | |

### M4 · 版权怎么判断（题型：技术理解 / 场景设计）

- **踩分点**：① 报出三步口诀「先问授权、再问归属、最后再谈商用」（3 分）；② 每步各给一个自查问题（3 分）；③ 明确边界「以法务意见和平台授权条款为准，不自行下法律结论」（2 分）；④ 关联 W2D4 合规检查清单或内容审核 / 显著标识（2 分）。
- **追问链**：第 1 层「能不能直接说 AI 生成的可以商用？」→ 不能，能生成不等于能商用，个人使用与可商用常被条款分开写；第 2 层「产品经理具体做什么？」→ 排查三步并留痕，结论交给法务与条款；第 3 层「涉及数字人、声音克隆呢？」→ 加本人授权核验、内容审核、算法备案与显著标识，具体要求以法务意见和平台授权条款以及最新监管口径为准。
- **典型失败答法**：「AI 生成的没有作者，所以没有版权，可以随便商用。」失分原因：既给了错误的法律结论，又跳过授权与归属两步，是本课明令纠偏的答法。
- **60 秒标准答法（参考答案）**：「版权我不下法律结论，按三步排查。先问授权：输入端合法吗，克隆声音有没有本人授权、上传的参考图有没有版权、真人形象有没有肖像授权。再问归属：输出端说清楚了吗，生成内容归谁、平台条款怎么约定、可商用范围写进用户协议了吗。最后谈商用：商用链路有没有内容审核、要不要备案、会不会被拿来冒充他人。三步都过一遍并留痕，最终能不能商用、怎么约定，一律以法务意见和平台授权条款为准。行业里生成内容拿去商用惹版权纠纷，就是跳过了后两步。方案我还会对照 W2D4 合规检查清单再勾一遍。」

### M5 · 给场景选形态并设计交互（题型：场景设计）

- **踩分点**：① 形态选择正确并给两条理由（3 分）；② 指出最大风险（身份 / 内容 / 成本）（3 分）；③ 交互建议对应三要点（2 分）；④ 回扣三维度或 RAG 知识库（2 分）。
- **追问链**：第 1 层「在线教育做『数字老师』，出镜讲课又能答疑，怎么设计？」→ 数字人出镜 + 对话答疑（可挂 RAG 知识库）；第 2 层「最大风险是什么？」→ 身份混淆、讲错知识、成本随时长持续产生；第 3 层「怎么避免学生当真人？」→ AI 身份显性化、明确告知、内容审核。
- **典型失败答法**：「做个数字人就行，效果很炫。」失分原因：没给风险、没给交互、没过三维度。
- **60 秒标准答法（参考答案）**：「形态上用数字人出镜讲课，答疑挂对话能力并结合 RAG（Retrieval-Augmented Generation，检索增强生成）课程知识库。最大风险是身份与内容：学生可能误当真人，讲错知识影响更大，而且成本随形象驱动时长持续产生。交互按三要点：会等待——课程视频分段生成时给进度与预览；可微调——形象、音色、台词可调可回改；选对模态——答疑默认文字、语音可选，并明确告知这是 AI 数字人，避免身份混淆。相关授权与审核要求以法务意见和平台授权条款为准。」

### M6 · 方案被质疑「太保守 / 太激进」怎么应对（题型：行为题）

- **踩分点**：① 不慌、先复述对方关切（2 分）；② 用三维度或三要点给依据而非情绪辩解（3 分）；③ 给出可验证的下一步（补测算 / 补自查 / 小流量验证）（3 分）；④ 体现「价值先于形态」（2 分）。
- **追问链**：第 1 层「评委说你只用一种模态，是不是不敢用？」→ 不是不敢，是其它模态按成本与合规不划算；第 2 层「那什么时候会加？」→ 出现独立不可替代的用户价值且边界算得过来；第 3 层「怎么让评委信？」→ 拿埋点数据、成本测算、合规自查三样说话。
- **典型失败答法**：「那我回去把视频和数字人也加上。」失分原因：被一追就改方案，没有判断依据，暴露「为多模态而多模态」。
- **60 秒标准答法（参考答案）**：「我会先复述关切：您担心的是形态选得不够、漏了用户价值。然后用框架回应，不做情绪辩解——我按先问价值、再问形态、最后问成本与合规边界走，其它模态不是不敢用，是成熟度、成本量级或合规风险在这个场景里不划算，多模态不是功能堆料。最后给可验证的下一步：补一版成本测算、过一遍 W2D4 合规清单、必要时用小流量验证用户到底用不用得上；测算价格以官网实时价格为准，版权结论以法务意见和平台授权条款为准。如果数据说某个模态有独立价值，我再加，顺序还是价值先于形态。」
