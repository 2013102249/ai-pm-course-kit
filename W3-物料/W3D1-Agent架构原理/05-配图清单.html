逐图讲法脚本（原有 4 图，全部保留）

图 1 · LLM 原理架构图（对应板块衔接）

  • 讲法：只讲一句话定位——「这是 W1D2 讲过的大脑：看懂指令、续写答案的概率引擎。它只动嘴不动手，所以只能答题。今天这节课，就是给它装上四肢。」不再展开链路细节，防止回锅。
  • 提问点：「这个大脑缺什么，导致它只能答题不能办事？」（预期：没有手——不能调工具、不能执行）
  • 过渡话术：「缺的四肢，就是今天的四要素。看下一张图。」

图 2 · Agent 四要素架构图（本课主图）

  • 讲法：三段讲法。第一段讲结构：中间 Agent 核心（大脑，负责规划调度），四周四要素——上：规划、记忆；下：工具、执行。第二段讲连线：核心到四要素分别是任务分解、经验调用、能力扩展、落地执行；执行回到核心有一条「环境反馈」虚线——这是 ReAct 循环的伏笔。第三段讲产品视角：每个要素旁边标一句「产品经理管什么」（规划管步数上限、记忆管遗忘与隐私、工具管权限与描述文案、执行管人工确认与留痕），让学员抄在导学案笔记表上。
  • 提问点：「四要素里，哪一个动了就收不回来？」（预期：执行——引出人工确认闸门）
  • 关键板书：在黑板上同步画「核心 + 四框 + 反馈虚线」，学员在导学案画骨架。
  • 对应板块复用：画主项目草图时作为底图投屏，学员对照补齐四框、接管点、上限与工具清单；只有手机 / 平板的学员看投屏后画纸质四框图。

图 3 · 交互式架构图 · Agent Tab（节点细讲主教具）

  • 讲法：点击节点展开右侧「是什么 / 产品经理要关心什么 / 面试怎么答」三段式。本课建议点击 5 个节点，顺序与教案板块对应： 1. 「规划」——讲步数上限与重试策略（对应金句「拿 token 赌运气」）； 2. 「记忆」——讲遗忘策略与隐私可见性； 3. 「工具」——讲权限最小化与「工具描述文案是提示词的一部分」； 4. 「执行」——讲不可逆动作人工确认； 5. 「多 Agent 协作」——讲复杂度黑洞与三个信号。 每个节点停留 3–4 分钟，先让学员读右侧「面试怎么答」一栏，再口头展开。
  • 提问点：每个节点一问（见教案提问设计 2–5、8）。
  • 注意事项：投屏前确认已切到「Agent 架构」Tab（默认打开是 LLM Tab）；详细演示脚本与故障处理见《07-交互使用说明.md》。讲师照读的话术不出现代码与架构图内部实现细节，操作指令见讲课稿各节「板书 / 投屏」。

图 4 · AI 产品全链路图（对应板块收尾定位）

  • 讲法：一句话定位——「Agent 是应用开发环节的一种技术选型，它前面有数据准备和模型选型，后面有评测验收和上线监控。今天画的是架构图，别忘了它是整条链路的一环，周五评审时会用全链路的视角看它。」
  • 用途：把本课放回课程全景，防止学员「学了 Agent 就言必称 Agent」；同时预告 W3D2 场景适配判断——「甚至这个环节本身都可能不需要 Agent」。

新增素材逐图讲法

图 5 · 术语卡 12 张（对应板块主教具）

  • 讲法：每张卡正面只印「英文全称 + 中文 + 一句话定义（≤30 字）」，背面印「生活类比 / 易混辨析 / 面试说法」。讲师按五步读：定义全班齐读 → 讲一个生活比方 → 点出一组易混词 → 给一句能说出口的面试话 → 指一下卡片链接。
  • 适用板块：对应板块 12–32 min；对应板块归档前复核再快速过一遍。
  • 提问点：「这一张最容易和哪个词混？」（对应术语自测表第 4 列）。
  • 状态：12 张全部待制，链接 03-配图素材/术语卡/，已在本表登记。

图 6 · 6 节时间轴图（对应板块开场）

  • 讲法：指图念六段——「0–50 攒词，50–100 讲前半原理，100–150 讲后半原理加案例，150–200 画你自己的图，200–250 换成面试话，250–300 收束归档验收」。让零基础学员先看清全天节奏，降低焦虑。
  • 适用板块：对应板块 0–5 min；每次节间休息后可回看一眼。
  • 状态：待制，登记于 03-配图素材/术语卡/6节时间轴图.svg。

图 7 · 面试追问链图（对应板块主教具）

  • 讲法：中间一道题，向右分出三层追问箭头，最右端统一收回到「接管点 / 步数上限 / 人工确认」。示范时先走一遍题 3「什么时候不该用 Agent」：一问结论 → 追「业务方要全自动怎么办」→ 再追「怎么度量」→ 落回可靠性表述。
  • 适用板块：对应板块 200–215 min；对应板块末缩略预告一次。
  • 状态：待制，登记于 03-配图素材/术语卡/面试追问链图.svg。
