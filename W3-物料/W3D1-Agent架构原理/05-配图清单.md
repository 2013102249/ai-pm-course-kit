## 逐图讲法脚本

### 图 1 · LLM 原理架构图（开场衔接）

- **讲法**：只讲一句话定位——「这是 W1D2 讲过的大脑：看懂指令、续写答案的概率引擎。它只动嘴不动手，所以只能答题。今天这节课，就是给它装上四肢。」不再展开链路细节，防止回锅。
- **提问点**：「这个大脑缺什么，导致它只能答题不能办事？」（预期：没有手——不能调工具、不能执行）
- **过渡话术**：「缺的四肢，就是今天的四要素。看下一张图。」

### 图 2 · Agent 四要素架构图（本课主图）

- **讲法**：三段讲法。第一段讲结构：中间 Agent 核心（大脑，负责规划调度），四周四要素——上：规划、记忆；下：工具、执行。第二段讲连线：核心到四要素分别是任务分解、经验调用、能力扩展、落地执行；执行回到核心有一条「环境反馈」虚线——这是 ReAct 循环的伏笔。第三段讲产品视角：每个要素旁边标一句「产品经理管什么」（规划管步数上限、记忆管遗忘与隐私、工具管权限与描述文案、执行管人工确认与留痕），让学员抄在导学案笔记表上。
- **提问点**：「四要素里，哪一个动了就收不回来？」（预期：执行——引出人工确认闸门）
- **关键板书**：在黑板上同步画「核心 + 四框 + 反馈虚线」，学员在导学案画骨架。

### 图 3 · 交互式架构图 · Agent Tab（节点细讲主教具）

- **讲法**：点击节点展开右侧「是什么 / 产品经理要关心什么 / 面试怎么答」三段式。本课建议点击 5 个节点，顺序与教案环节对应：
  1. 「规划」——讲步数上限与重试策略（对应金句「拿 token 赌运气」）；
  2. 「记忆」——讲遗忘策略与隐私可见性；
  3. 「工具」——讲权限最小化与「工具描述文案是提示词的一部分」；
  4. 「执行」——讲不可逆动作人工确认；
  5. 「多 Agent 协作」——讲复杂度黑洞与三个信号。
  每个节点停留 3–4 分钟，先让学员读右侧「面试怎么答」一栏，再口头展开。
- **提问点**：每个节点一问（见教案提问设计 2–5、8）。
- **注意事项**：投屏前确认已切到「Agent 架构」Tab（默认打开是 LLM Tab）；详细演示脚本与故障处理见《07-交互使用说明.md》。

### 图 4 · AI 产品全链路图（收尾定位）

- **讲法**：一句话定位——「Agent 是应用开发环节的一种技术选型，它前面有数据准备和模型选型，后面有评测验收和上线监控。今天画的是架构图，别忘了它是整条链路的一环，周五评审时会用全链路的视角看它。」
- **用途**：把本课放回课程全景，防止学员「学了 Agent 就言必称 Agent」；同时预告 W3D2 场景适配判断——「甚至这个环节本身都可能不需要 Agent」。
