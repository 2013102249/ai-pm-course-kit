3第 1 节零层入口：3 个必懂词① Agent（智能体）= 会办事的 AI ② API（Application Programming Interface，应用程序接口）= 软件里的服务员 ③ MCP（Model Context Protocol，模型上下文协议）= 统一插头标准 ④ 只用生活类比，不展开原理保留概念补丁原讲法；每个词让学员跟读一句；「原稿内容一字未动」术语卡（Agent / MCP）待制
4第 1 节术语卡（一）：Agent · 四要素 · 自主性 · 边界① 每张给全 5 项：一句话定义 / 生活类比 / 易混辨析 / 面试说法 / 术语卡链接 ② Agent = 会自己拆任务、用工具、把事办完的 AI ③ 四要素 = 规划 / 记忆 / 工具 / 执行 ④ 自主性按动作可逆性分档 ⑤ 边界 = 该做什么、做到哪、何时停术语卡页；每张投屏约 90 秒，定义全班齐读；术语卡链接 03-配图素材/术语卡/术语卡 4 张（待制，05 已登记）
5第 1 节术语卡（二）：ReAct · 规划 · 记忆 · 工具调用① ReAct（Reasoning + Acting，推理与行动交替）= 想一步做一步看一眼再想 ② 规划 ≠ 固定工作流（谁拆步骤） ③ 记忆要设计「记什么、忘什么」 ④ 工具调用 = 借外部能力，描述文案是提示词的一部分每张强调一个易混辨析；缩写首次给全称 + 中文术语卡 4 张（待制）
6第 1 节术语卡（三）+ 术语辨析当堂小测① MCP = 统一插口，M×N 变 M+N ② Multi-Agent（多智能体）= 分工协作，复杂度黑洞 ③ 幻觉 = 一本正经编造 ④ 可观测性 ≠ 运行日志 ⑤ 小测：3 缩写连线 + 2 改错 + 3 定义，只自评不排名术语卡页 + 小测页；改错题带全班齐答，不公布个人结果术语卡 4 张 + 《术语自测表》投屏
7第 2 节导入：从答题到办事① 左「写旅游攻略」右「订机票酒店」 ② 交付物：答案 vs 结果 ③ 责任主体：用户 vs 产品 ④ 金句：答题给答案，办事拆任务、用工具、拿结果、担责任提问 1：本质差别在哪？点 1–2 名；落到「责任」二字—
8第 2 节Agent 是什么① 长着四肢的大模型 ② 大脑（LLM，Large Language Model，大语言模型）+ 四肢（四要素） ③ 回扣 W1D2：大脑只动嘴不动手 ④ 先泼冷水：不是所有产品都需要 Agent金句前置；提醒「明天才有资格决定不用它」LLM原理架构图
9第 2 节四要素总览① 核心 + 规划 / 记忆 / 工具 / 执行 ② 上：规划、记忆；下：工具、执行 ③ 环境反馈虚线（ReAct 伏笔） ④ 每要素旁标「产品经理管什么」让学员在导学案画骨架：中间一核心、四周四框、连线Agent四要素架构图
10第 2 节要素一：规划① 拆任务；任务边界与成功标准 ② 步数上限（max steps 必填） ③ 重试策略：失败几次、何时交还人类 ④ 常见坑：只画流程、不定边界和上限金句「token 赌运气」；提问 2：为什么一步错步步错交互（Agent Tab·规划）
11第 2 节要素二：记忆① 短期上下文 / 长期存取 ② 写入与遗忘策略 ③ 隐私可见可删（合规底线） ④ 差旅 Agent「靠过道」例子金句「会遗忘才是产品设计」；提问 3：记忆越多越好吗交互（Agent Tab·记忆）
12第 2 节要素三：工具① 最小工具集，不是全家桶 ② 权限最小化，逐个授权 ③ 描述文案 = 提示词的一部分 ④ 「search：搜索」vs 合格描述对比提问 4：为什么描述文案是提示词的一部分；不展开接口格式交互（Agent Tab·工具）
13第 3 节要素四：执行① 真正发起调用、与环境交互 ② 不可逆动作人工确认 ③ 回滚与补偿 ④ 执行日志留痕 ⑤ 承接：环境反馈回到核心 → ReAct 循环提问 5：哪些动作必须确认；判断标准只一条「不可逆」交互（Agent Tab·执行）
14第 3 节ReAct：把思考摊开给用户看① 四拍：思考—行动—观察—再思考 ② 全称 Reasoning + Acting，推理与行动交替 ③ 摊开换来信任 / 可中断 / 可纠偏 ④ 反面案例：黑箱转圈、用户刷新关掉强调：产品讲法不是背术语；反面案例只讲体验，不编效果数字—
15第 3 节ReAct 呈现设计 + 正 / 反案例① 默认步骤清单，一行一句 ② 点开看完整推理（可展开的透明） ③ 反思机制：换方式再来，次数也要上限 ④ 正面：差旅助手步骤清单 + 暂停选项 ⑤ 反面：全量展示造成信息过载案例页；强调「是信任设计，不是 debug 界面」正 / 反案例对照页（待制）
16第 3 节MCP：工具的 USB 接口① M×N 适配爆炸 → M+N ② Anthropic 2024.11 发布开放协议 ③ USB 类比：统一插口、即插即用 ④ 3 模型 ×10 工具 = 30 套 vs 13 套类比：USB 统一外设接口；不展开协议规范—
17第 3 节产品经理的新杠杆① 工具接入成本下降、试错变快 ② 工具生态成为选型正式考量 ③ 便宜 ≠ 多接，仍守最小集与权限最小化 ④ A2A（Agent-to-Agent）一句前瞻「工具侧 MCP，Agent 互联侧 A2A」；只报名字不展开—
18第 3 节Multi-Agent：复杂度黑洞① 分工形态：调研 / 写作 / 审校 ② 三个隐藏成本：协作协议 / 消息损耗 / 失败传播 ③ 三个信号：可并行 / 上下文装不下 / 需隔离 ④ 决策三问：单 Agent → 要不要 Agent → 要不要多个金句「两个能做别用五个」；案例页预告五 Agent 方案翻车交互（Agent Tab·多Agent协作）+ 面试追问链图缩略
19第 4 节场景适配：该不该上 Agent① 三问：单 Agent 能不能解决 → 要不要 Agent → 要不要多个 ② 路径固定用工作流 ③ 单一查询用检索问答 ④ 不可逆动作 AI 建议、人类拍板预告 W3D2 实操判断；齐读决策三问—
20第 4 节产品三道闸门① 人工接管点（何时交还人类） ② 步数与成本上限 ③ 安全闸门（不可逆必确认） ④ 接管呈现：暂停 + 选项，不是弹窗打断金句「第一问题」；宣布草图任务交互（Agent Tab·Agent核心）
21第 4 节现场作画：主项目架构草图① 32 分钟；四要素 + 接管点 + 上限 + 工具清单 ② 中间核心、四周四框 ③ 至少 1 个三角接管点、1 个上限数字 ④ 草图自查清单四项计时巡视；投影导学案自查清单；优先看手机 / 平板学员导学案（草图区 + 自查清单）
22第 4 节实操任务五步 + 巡场话术① 读场景 → 画四框 → 标接管点与上限 → 列工具清单 → 自查 ② 巡场三看：四要素 / 接管点 / 上限与工具 ③ 三条现场纠正话术 ④ 同伴互查 3 分钟实操任务页；只讲产品动作，不出现代码实操任务单（待制）
23第 4 节常见卡点 3 条 + 手机 / 平板替代动作① 画不出完整图：先摆四个空框 ② 不知哪个不可逆：问「做完能撤回吗」 ③ 工具写不具体：写名字 + 权限 ④ 手机替代：纸质四框 + 拍照归档 ⑤ 平板替代：讲师代点节点、纸质填表设备替代页；确认三档学员产出一样不少设备要求表（07 同款）
24第 4 节当堂练：第 0 层术语辨析① 改错「记忆越多越好」 ② 连线「可观测性 ≠ 运行日志」 ③ 缩写全称连线 ReAct / MCP / API ④ 只自评不排名，画圈的第五节前补掉讲评挑两张草图后带做；不点名、只讲图分层习题第 0 层
25第 5 节面试讲解：四类题型与答法骨架① 题型：技术理解 / 项目深挖 / 场景设计 / 行为题 ② 统一骨架：先结论 → 三踩分点 → 一术语 → 一项目例 ③ 三类空话扣分：更智能 / 都能上 / 技术做不到 ④ 追问落回：接管点 / 步数上限 / 人工确认题型拆解 15′；示范「空话 vs 得分话」面试追问卡（8 张，待制）
26第 5 节面试题① Agent vs Chatbot（聊天机器人）① 题目 + 题型：技术理解 ② 踩分点：交付物 / 责任主体 / 拆任务动作 / 项目例 ③ 追问链：带插件算吗 → 只查一条政策呢 → 界面变什么 ④ 失败答法「更智能」面试题页；先讲师示范 60 秒，再点追问链面试追问链图
27第 5 节面试题② ReAct 怎么工作① 题目 + 题型：技术理解 ② 踩分点：四拍 / 全称 / 摊开给用户看 / 信任可中断可纠偏 ③ 追问链：信息过载 → 反思几次 → 看不见会怎样 ④ 60 秒标准答法要点面试题页；强调「可观测性不是 debug 界面」面试追问链图
