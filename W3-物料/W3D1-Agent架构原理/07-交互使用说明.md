# 交互使用说明 · 《交互式架构图》Agent Tab（W3 周一专用）

> 用途：本课环节二至环节五（15–75 分钟）核心教具。工具位置：02-交互工具/交互式架构图.html
> 本课只用「Agent 架构」一个 Tab；LLM / RAG / 全链路 Tab 分别属于 W1D2、W3D3、收尾定位。
> 使用前请完成「课前检查」，故障处理见文末。

## 一、课前检查（开课前 10 分钟）

| 检查项 | 操作 |
|---|---|
| 初始 Tab | 工具默认打开「LLM 基础链路」Tab——务必先点一下「Agent 架构」Tab，确认图切换为「核心 + 四要素」布局 |
| 节点点击 | 点一次「规划」节点，确认右侧出现三段式讲解，再点「返回总览」 |
| 投屏分辨率 | 浏览器窗口 ≥1180px 宽，确保左右两栏布局不堆叠；SVG 图完整可见 |
| 渲染缓存 | 提前完整点开 5 个节点（规划 / 记忆 / 工具 / 执行 / 多 Agent 协作），完成首屏渲染 |
| 备用方案 | 另开一个标签页打开《Agent四要素架构图.svg》，工具卡住时切换讲解 |
| 学员端 | 群里发布工具链接（见文末群发文案），让学员课后自学 |

## 二、讲师 5 步演示脚本（与讲课稿对应）

| 步骤 | 讲师操作 | 讲解要点 | 对应环节 |
|---|---|---|---|
| 第 1 步：切到 Agent Tab | 点击顶部「Agent 架构」标签 | 读底部一句话讲法：「给模型配上规划、记忆、工具和执行力，让它从答题变办事——但闸门必须握在产品经理手里」 | 环节一（8–15 min） |
| 第 2 步：总览一分钟讲法 | 不点节点，指图整体讲 | 中间核心（大脑），四周四要素（四肢）；指六条连线：任务分解 / 经验调用 / 能力扩展 / 落地执行，以及「环境反馈」虚线——预告 ReAct 循环 | 环节一 |
| 第 3 步：点击核心节点讲三段式 | 依次点击「规划 → 记忆 → 工具 → 执行 → 多 Agent 协作」5 个节点 | 每个节点让学员先读右侧三段式（是什么 / 产品经理要关心什么 / 面试怎么答），再口头展开 3–4 分钟；每节点对应导学案笔记表一行 | 环节二至五（15–75 min） |
| 第 4 步：突出人工接管点 | 回到「Agent 核心」节点，指着「设计人工接管点」一条 | 收束三道闸门：接管点、步数上限、安全闸门；追问学员「你的主项目里哪个动作必须人工确认」 | 环节六（75–85 min） |
| 第 5 步：返回总览收尾 | 点击「← 返回总览」 | 用总览的三段式做 30 秒全图复述，请 1 名学员照着右侧「整条链路」讲一遍——当场检验输出 | 总结（85–90 min） |

### 关键演示动作（不可省略）

1. **5 个节点逐个点开**：不要一键跳过。每个节点的「面试怎么答」一栏，让学员齐读一遍——这是本工具对就业最直接的价值。
2. **「多 Agent 协作」节点必讲**：指着「先问单 Agent 能不能解决」一条，落到金句「两个 Agent 能做的事，别用五个」。这是本课防跑偏的关键一讲。

## 三、常见故障处理

| 故障 | 处理 |
|---|---|
| 切 Tab 无反应 | 刷新页面（工具为单文件零依赖，刷新即恢复）；若仍异常，切换备用 SVG 继续讲 |
| 点击节点右侧不更新 | 先点「返回总览」再重新点击节点；讲解不中断，用「工具也会卡，产品要有兜底」带过 |
| 投屏字太小 | 浏览器 Ctrl/Cmd + 「+」放大至 125%；或临时收起浏览器侧边栏 |
| 学员端打不开 | 无需等待——本工具课堂以讲师演示为主，学员课后可凭链接自学 |
| 断网 | 不受影响。本工具为单文件 HTML、零外部请求，本地双击打开即可用 |

## 四、学员课后自学指引

| 任务 | 操作 | 检验标准 |
|---|---|---|
| ① 通览 | 切到 Agent Tab，不点节点，读一遍底部一句话讲法与右侧「整条链路」 | 能口头复述四要素名称与各自职责 |
| ② 逐节点 | 依次点击 6 个节点，读完每段三段式讲解 | 每个节点的「面试怎么答」能背出 1 句 |
| ③ 对照 | 对照导学案的草图自查清单，检查自己的主项目架构图 | 四要素 / 接管点 / 步数上限 / 工具清单四项齐全 |
