# 交互使用说明 · 《交互式架构图》Agent Tab（W3 周一《Agent 架构原理》专用）

> 300 分钟（6 课时 × 50 分钟）教学日配套说明。用途：本课第 2、3 节（50–150 分钟）核心教具；第 4 节实操、第 6 节收尾各复用一次。工具位置：02-交互工具/交互式架构图.html
> 本课只用「Agent 架构」一个 Tab；LLM / RAG（Retrieval-Augmented Generation，检索增强生成）/ 全链路 Tab 分别属于 W1D2、W3D3、第 6 节收尾定位。
> 使用前请完成「课前检查」，故障处理见文末；只有手机 / 平板的学员走第七节替代动作，产出一样不少。

## 一、课前检查（开课前 10 分钟，原有说明保留）

| 检查项 | 操作 |
|---|---|
| 初始 Tab | 工具默认打开「LLM 基础链路」Tab——务必先点一下「Agent 架构」Tab，确认图切换为「核心 + 四要素」布局 |
| 节点点击 | 点一次「规划」节点，确认右侧出现三段式讲解，再点「返回总览」 |
| 投屏分辨率 | 浏览器窗口 ≥1180px 宽，确保左右两栏布局不堆叠；SVG 图完整可见 |
| 渲染缓存 | 提前完整点开 5 个节点（规划 / 记忆 / 工具 / 执行 / 多 Agent 协作），完成首屏渲染 |
| 备用方案 | 另开一个标签页打开《Agent四要素架构图.svg》，工具卡住时切换讲解 |
| 学员端 | 群里发布工具链接（见文末群发文案），让学员课后自学 |
| 三档设备清点 | 开课前确认手机 / 平板 / 电脑各几人；只有手机 / 平板的学员提前拿到纸质导学案与四要素图打印件 |

## 二、讲师 5 步演示脚本（原有说明保留，节次与时间改为 6 节口径）

| 步骤 | 讲师操作 | 讲解要点 | 对应节次（300 分钟口径） |
|---|---|---|---|
| 第 1 步：切到 Agent Tab | 点击顶部「Agent 架构」标签 | 读底部一句话讲法：「给模型配上规划、记忆、工具和执行力，让它从答题变办事——但闸门必须握在产品经理手里」 | 第 2 节（58–66 min） |
| 第 2 步：总览一分钟讲法 | 不点节点，指图整体讲 | 中间核心（大脑），四周四要素（四肢）；指六条连线：任务分解 / 经验调用 / 能力扩展 / 落地执行，以及「环境反馈」虚线——预告 ReAct 循环 | 第 2 节 |
| 第 3 步：点击核心节点讲三段式 | 依次点击「规划 → 记忆 → 工具 → 执行 → 多 Agent 协作」5 个节点 | 每个节点让学员先读右侧三段式（是什么 / 产品经理要关心什么 / 面试怎么答），再口头展开 3–4 分钟；每节点对应导学案笔记表一行 | 第 2、3 节（66–145 min） |
| 第 4 步：突出人工接管点 | 回到「Agent 核心」节点，指着「设计人工接管点」一条 | 收束三道闸门：接管点、步数上限、安全闸门；追问学员「你的主项目里哪个动作必须人工确认」 | 第 3 节（135–145 min） |
| 第 5 步：返回总览收尾 | 点击「← 返回总览」 | 用总览的三段式做 30 秒全图复述，请 1 名学员照着右侧「整条链路」讲一遍——当场检验输出 | 第 6 节收束（250–260 min） |

### 关键演示动作（不可省略，原有说明保留）

1. **5 个节点逐个点开**：不要一键跳过。每个节点的「面试怎么答」一栏，让学员齐读一遍——这是本工具对就业最直接的价值。
2. **「多 Agent 协作」节点必讲**：指着「先问单 Agent 能不能解决」一条，落到金句「两个 Agent 能做的事，别用五个」。这是本课防跑偏的关键一讲。

> 300 分钟口径补充：讲师照读的话术里不出现代码、接口格式与架构图内部实现细节；点节点属于投屏动作，只有电脑 / 平板可做，手机学员看讲师投屏、填纸质表即可。

## 三、常见故障处理（原有说明保留）

| 故障 | 处理 |
|---|---|
| 切 Tab 无反应 | 刷新页面（工具为单文件零依赖，刷新即恢复）；若仍异常，切换备用 SVG 继续讲 |
| 点击节点右侧不更新 | 先点「返回总览」再重新点击节点；讲解不中断，用「工具也会卡，产品要有兜底」带过 |
| 投屏字太小 | 浏览器 Ctrl/Cmd + 「+」放大至 125%；或临时收起浏览器侧边栏 |
| 学员端打不开 | 无需等待——本工具课堂以讲师演示为主，学员课后可凭链接自学；只有手机 / 平板的学员直接走纸质替代 |
| 断网 | 不受影响。本工具为单文件 HTML、零外部请求，本地双击打开即可用 |

## 四、学员课后自学指引（原有说明保留）

| 任务 | 操作 | 检验标准 |
|---|---|---|
| ① 通览 | 切到 Agent Tab，不点节点，读一遍底部一句话讲法与右侧「整条链路」 | 能口头复述四要素名称与各自职责 |
| ② 逐节点 | 依次点击 6 个节点，读完每段三段式讲解 | 每个节点的「面试怎么答」能背出 1 句 |
| ③ 对照 | 对照导学案的草图自查清单，检查自己的主项目架构图 | 四要素 / 接管点 / 步数上限 / 工具清单四项齐全 |
| ④ 术语与面试（300 分钟新增） | 对照导学案《术语自测表》12 行复核缩写全称；跟读播客附录 B「面试 30 秒口播」 | 缩写全称连线全对；四道必答题能各说 30 秒 |

## 七、《设备要求表》（新增，手机 / 平板 / 电脑三档）

> 本期 6 名学员中 5 名零编程、3 名设备不足。三档设备只影响「用不用工具」，不影响「有没有产出」；全课任何任务都不要求写代码、不要求读懂架构图内部实现细节。

| 档位 | 可独立完成的任务 | 受限任务 | 替代动作（必须可执行） |
|---|---|---|---|
| **电脑** | 全部：交互工具点 6 个节点、画图工具出正式架构图、在线填三张表、看播客与全套图片 | 无 | — |
| **平板** | 看讲师投屏、手绘草图拍照、纸质填表、两两模拟、听播客附录 | 交互工具左右两栏在窄屏可能堆叠、不便自己点节点；在线表格输入较慢 | 节点讲解由讲师投屏代点，学员在纸质四要素笔记表填空；草图画纸上四框 + 三角接管点 + 上限数字，拍照归档；三张表纸质手写 |

**讲师执行要点**

1. 第 4 节巡场优先走到只有手机 / 平板的学员身边，确认纸上有「四框、三角、数字」三样。
2. 第 1、5 节凡涉及投屏（术语卡、追问链图、追问卡），一律由讲师逐张念题目与要点，不要求学员自己打开。
3. 第 6 节归档：只有手机 / 平板的学员把三样产出拍照存进手机相册同一个文件夹，命名「W3D1 + 项目名」，归档位置写该文件夹名，同样算通过验收。
4. 不编造任何效果数字；涉及 offer、薪资、就业率的数据一律写「待教务补充」。
