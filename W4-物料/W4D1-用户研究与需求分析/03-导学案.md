## 一、课前预习（上课前完成，约 25 分钟）

### 预习任务：找 1 位目标用户，完成 15 分钟非正式聊天

这不是正式访谈，目的只有一个：在你学方法之前，先获得一次「和真实用户说话」的体感。

**怎么找人**：从你的主项目目标用户画像出发，在身边找一位符合条件的人（社群好友、同事、家人都可以，但必须真的有那个问题）。判断标准三条线：他真的会遇到这个问题吗？他主动找过办法吗？他符合你的产品定位吗？

**聊什么**（用你自己的话问，不用照稿）：
1. 你上次遇到（主项目的核心问题）是什么时候？当时发生了什么？
2. 这个问题后来怎么解决的？
3. 有没有什么办法是你试过又放弃的？为什么？

**访谈记录表**（课前填好，课上要用）：

| 记录项 | 内容 |
|---|---|
| 受访者身份（一句话，不写姓名） | |

## 二、课堂笔记（课上填写）

### 1. 访谈提纲模板 V1（为自己主项目填写）

五段结构，每段至少写 1 个问题；「场景还原」段必须写一个「最近一次」问题。

| 段落 | 目的 | 我的问题（写在本行） |
|---|---|---|
| ① 暖场 | 放松 + 说明来意 + 告知「说实话更有用」 | |
| ② 背景 | 确认对方是否目标用户（几人 / 频率 / 现状） | |
| ③ 场景还原 | 让对方讲一个具体的最近事件（黄金段） | |
| ④ 痛点挖掘 | 卡点 + 努力史 + 为什么放弃（追问「当时发生了什么」） | |
| ⑤ 收尾 | 开放题：有什么我没问到的 + 道谢留联系方式 | |

**提问自查**（写完提纲后逐条打勾）：
- [ ] 全部问题中没有「你是不是、你会不会」（引导式 / 预测式提问）
- [ ] 至少 2 个开放题
- [ ] 「场景还原」段问了「最近一次」
- [ ] 我没有在任何位置介绍自己的产品功能

### 2. 需求真伪四问评估表（对自己主项目的核心需求评估）

| 四问 | 判据 | 我的评估（写论据，不写感觉） |
|---|---|---|
| ① 痛点真不真 | 用户为这个问题做过什么努力？（搜索过 / 付过费 / 手搓过土办法） | |
| ② 场景有没有 | 最近一次发生在什么时候？频率多高？ | |
| ③ 现有方案是什么 | Excel / 微信群 / 人肉 / 忍着，都算方案；现有方案的弱点在哪？ | |
| ④ 替换成本高不高 | 数据迁移 / 使用习惯 / 协作链 / 价格 | |

**结论**：我的核心需求 □ 四问全过，进入优先级排序　□ 挂在第 ______ 问，需要重定义为：________________

## 三、课后巩固（本周执行）

### 本周调研里程碑说明

本周目标：产出支撑 PRD 的真实调研——**≥5 个真实访谈 + ≥30 份有效问卷**（验收标准：禁止编造，讲师将抽查访谈记录与问卷后台数据）。

| 时间 | 任务 | 产出物 |
|---|---|---|
| W4D1 晚 | 修完访谈提纲 V1 + 问卷初稿，发到小组群 | 提纲 V1、问卷链接 |
| W4D2–D3 | 执行 5 个访谈（每位 20–30 分钟，用五段结构），同步投放问卷 | 5 份访谈记录（用「场景还原 + 现有方案」格式记） |
| W4D3–D4 | 问卷投放到真实目标用户社群，回收 ≥30 份 | 问卷后台数据截图 |
| W4D4 晚 | 用四问框架汇总调研结论，写进用户调研报告 | 用户调研报告 V1 |
| W4D5 | PRD 评审大会上，用调研数据回答「需求有调研支撑吗」 | 答辩证据 |

**提醒**：调研数据直接决定你周二 PRD「背景与目标」章节的说服力，也决定你 RICE 打分时 Confidence 的底气。
