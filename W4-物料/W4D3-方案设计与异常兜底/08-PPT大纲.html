8第 2 节（50–100）金句页：AI 产品的体验，一半在兜底（原页 4）① 正常路径大家都会写；② 翻车路径才见功力；③ 模型会错 / 会慢 / 会拦是必然；④ 产品设计的活儿是设计「发生之后怎么办」紫底白字全屏页；放慢语速重复一遍；回扣 W4D2 PRD 五处差异—
9第 2 节（50–100）三层设计表达（原页 5）① 功能结构图：有什么；② 业务流程图：怎么走；③ 状态机：此刻在哪、卡住怎么办；④ 三张图不是替代关系，是三个视角同步板书三层对比表；学员在导学案记对照表—
10第 2 节（50–100）为什么 AI 产品必须状态机（原页 6）① 结果是概率的；② 过程是异步的；③ 路径不是直线的；④ 传统产品画流程就够，AI 产品可能停在任何一步三条特性逐条讲；结尾抛问「超时值谁来标」—
11第 2 节（50–100）对话产品状态机全图（原页 7）① 空闲 → 理解中 → 生成中 → 完成 / 异常 → 恢复；② 每状态标超时值与异常出口；③ 「完成 → 理解中」回路：对话是环；④ 异常是分流站不是终点先沿主干讲，再讲异常分流；学员照画草图；回扣术语 T01 / T05 / T09状态机示意图（05 图 1）
12第 2 节（50–100）画图三条纪律 + 正 / 反案例（原页 8 深化）① 每状态标超时值；② 每异常有出口；③ 恢复指回具体状态；④ 正面：分阶段加载 + 断网保留原文；⑤ 反面：转圈三分钟 → 白屏 → 错误码 → 草稿丢失现场检查学员草图；不合规当场指出；反面案例在第 3、4 节继续拆反面案例时间线图（缩略）
13第 3 节（100–150）四件套总览（原页 9）① 降级 / 澄清 / 拒答 / 转人工；② 每件四要素：触发条件 · 产品动作 · 文案 · 升级路径；③ 顺序即升级成本递增；④ 三态落点：加载态→等待、错态→异常、空态→空闲宣布核心环节开始；强调「触发条件必须带数字」；补一条三态落点承接第 5 页四件套四要素板书投屏
14第 3 节（100–150）第一件 · 降级 + 第二件 · 澄清（原页 10）① 降级：超时 >10 秒 / 连续失败 ≥2 次 / 敏感词拦截 → 规则话术 + 缓存答案；② 重试限 1 次；③ 澄清：置信度 <0.6 → 追问 1 次必带选项；④ 文案拆：认账 / 给预期 / 给出路文案示例逐句拆；讲完各填设计表一行—
15第 3 节（100–150）第三件 · 拒答（原页 11）① 命中违规 / 超出边界 / 高风险域；② 固定文案 + 替代出路 + 申诉复核；③ 拒答文案写死走审核，禁止模型现场生成；④ 辨析：拒答是设计动作，不是模型临场的礼貌辨析「拒答 vs 我不知道」；点出合规边界—
16第 3 节（100–150）第四件 · 转人工（原页 12）① 连续 2 轮未解决 / 情绪负面 / 主动要求 / 高价值标记；② 带上下文摘要转接；③ 转多成本爆炸、转少用户流失；④ 金句：「之前的对话我都带过去了」讲顺序即优先级；强调「可恢复」最值钱的落地—
17第 3 节（100–150）兜底决策树（原页 13）① 四连问：能理解吗 → 能答吗 → 答得出吗 → 用户满意吗；② 四件套落点 + 成本自上而下递增；③ 叶子节点不悬空；④ 每叶子触发条件各写量化值手指沿树走一遍；金句「能用便宜的办法解决，绝不启动贵的」兜底决策树（05 图 2）
18第 3 节（100–150）Prompt 即需求（原页 14）① 一句 Prompt 定产品行为：语气 / 格式 / 边界 / 拒答策略；② 改 Prompt = 改行为 = 改需求；③ 三机制：版本 / 评审 / 回归；④ 没有回归的 Prompt 调优等于裸奔回扣 W2 评测集；异常表与 Prompt 同走版本、评审、回归—
19第 4 节（150–200）实操任务总览 · 四步打勾（新增 · 实操任务页）① 画状态机草图；② 填兜底设计表五行；③ 决策树四连问自查；④ 案例卡讨论 + 四句话汇报；⑤ 用时：任务说明 8′ + 实操 32′ + 讲评 10′投四步清单；产物按真项目标准做，直接进 PRD6 节时间轴图（第 4 节高亮）
20第 4 节（150–200）反面案例页：只做正常态、异常态一片空白（新增 · 案例页）① 9:12 转圈无进度 → 缺加载态 / 超时；② 9:18 刷新白屏 → 缺空态；③ 9:19 错误码 → 缺错态 / 提示文案；④ 9:20 历史空白草稿丢失 → 缺可恢复；⑤ 结论：无一条是模型不够强逐节点问「用户此刻屏幕上是什么、下一动作是什么」；收在「先补超时值 + 出口」的成本逻辑反面案例时间线图（05 素材 6）
