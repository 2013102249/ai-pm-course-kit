图 1 · 状态机示意图（对话产品）

制作规格

项目 规格
画布 1280 × 720，白底，四周留白 40px
布局 主干横向流：空闲 → 理解中 → 生成中 → 完成；异常态与恢复态置于下方
必含元素一：正常流转 五个状态节点全部出现：空闲 / 理解中 / 生成中 / 完成 / 恢复；主干箭头单向向右
必含元素二：异常分支 「异常」作为分流节点单独绘制，四条出口分别标注：澄清 / 拒答 / 降级 / 转人工；异常出口箭头用橙色 #EA580C 区分正常流转
必含元素三：循环与恢复 「完成」到「理解中」的用户追问回路箭头必须画出（对话是环不是线）；「恢复」节点必须画两条回指箭头：指回「空闲」（降级成功）与「挂起」标记（转人工成功）
必含元素四：超时值 每个状态节点内标注超时基准值：理解中 3 秒 / 生成中 10 秒 / 异常态停留 ≤30 秒
配色 正常状态节点：紫色 #7C3AED 描边、浅紫底；异常节点：橙色 #EA580C 描边；箭头文字：蓝 #2563EB
字体 中文标注，节点名 20px 加粗，超时值 14px；禁止英文标注
其他 图右下角标注「AI 产品经理就业训练营 · W4D3」；导出 PNG 备用，分辨率 2 倍

验收标准

  1. 五个正常状态 + 1 个异常分流节点 + 4 条异常出口，一个不少。
  2. 每个状态节点均有超时值标注（空闲与完成可标「—」）。
  3. 「完成 → 理解中」回路箭头存在——缺失即为不合格（这是本图教学核心）。
  4. 恢复路径指回具体状态，不是悬空箭头。
  5. 全图无错别字；颜色不超过规范三种主色。

讲法脚本

  • 讲法：先沿主干从左到右讲五个状态（手指沿箭头走）；再单独指异常分流节点讲四条出口；最后用手指强调「完成 → 理解中」回路，说出「对话是环，不是线」。
  • 提问点：「每个状态我标了几个超时值？不标会怎样？」（预期：用户疯狂点、直接退、打差评）
  • 过渡话术：「骨架有了，四条异常出口就是今天的重头戏——翻车四件套。」
  • 学员动作：在导学案状态机草图区照画，并补全自己项目的超时值。

图 2 · 兜底决策树

制作规格

项目 规格
画布 1280 × 800，白底，四周留白 40px
布局 树状自上而下分四层判断，对应四件套分层
必含元素一：四层判断 第一层「能理解吗？」→ 第二层「能答吗？」→ 第三层「答得出吗？」→ 第四层「用户满意吗？」；每层左侧「否」分支引出兜底动作，右侧「是」分支继续向下
必含元素二：四件套落点 四个叶子节点分别标注：澄清（追问 1 次 + 选项）/ 拒答（固定文案 + 替代出路）/ 降级（规则话术 / 缓存答案）/ 转人工（带上下文摘要）；叶子节点用四件套对应色块
必含元素三：成本标注 四个叶子节点旁标注升级成本：澄清（零成本）/ 拒答（低成本）/ 降级（低成本）/ 转人工（人力成本）；自上而下成本递增
必含元素四：正常出口 每层「是」最终汇入「正常回答」绿色叶子节点
配色 判断节点：蓝 #2563EB 描边；兜底叶子：紫 #7C3AED 浅底；正常回答叶子：绿 #16A34A；成本标注：灰 #7A7590
字体 中文标注，判断问题 20px 加粗，兜底动作与成本 14px；禁止英文标注
其他 图左下角标注口诀「能用便宜的办法解决，绝不启动贵的」；导出 PNG 备用，分辨率 2 倍

验收标准

  1. 四层判断问题齐全且顺序正确（能理解 → 能答 → 答得出 → 用户满意），顺序错即为不合格。
  2. 每个叶子节点落在四件套之一或「正常回答」，不存在悬空分支。
  3. 成本标注自上而下递增——缺失即为不合格（本图教学核心是升级成本最小化）。
  4. 转人工叶子节点必须含「带上下文摘要」标注。
  5. 全图无错别字；颜色不超过规范四种色。

讲法脚本

  • 讲法：从顶端用户输入开始，逐层向下讲四个判断问题；每层先讲「否」走哪件套、再讲「是」往下走；最后收在成本标注——「顺序即优先级」。
  • 提问点：「为什么『能理解吗』排第一，『用户满意吗』排最后？」（预期：成本递增，便宜的先用）
  • 过渡话术：「决策树是判断顺序，可别忘了一件事—— Prompt 也在决定这些判断本身。它也是需求的一部分。」
  • 学员动作：导学案「决策树四连问」表格逐问对照自己项目打勾、写缺口。

本课无需复用素材的说明

本课刻意不依赖既有交互工具与配图：异常兜底是学员第一次把「抽象设计」落到「自己项目的 PRD 章节」，全课视觉锚点是板书 + 两张图 + 导学案表格，避免学员注意力被工具演示分走。两张图已制成（见 03-配图素材），讲师可先手画、再投影对照；必要时可用教案第七、八节的 ASCII 结构板书替代。
