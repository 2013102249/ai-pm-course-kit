### 二、版式结构：北极星—一级—护栏三层金字塔

```
┌────────────────────────────────────────────────┐
│  顶部标题：AI 产品指标体系（三层金字塔）              │
│                                                │
│              ┌──────────────┐                  │
│   第一层      │  北极星指标    │  （1 个数，全屏最高亮）│
│              │ 「每周生成并被采纳≥3 次的用户数」│   │
│              └──────┬───────┘                  │
│        ┌───────────┼───────────┐              │
│   ┌────┴───┐  ┌────┴───┐  ┌────┴───┐          │
│   │ 一级指标 │  │ 一级指标 │  │ 一级指标 │          │
│   └────────┘  └────────┘  └────────┘          │
│   第二层（一级指标 5 格，即五大核心指标）             │
│                                                │
│   第三层（护栏指标横条，垫底）：                     │
│   重试率 ｜ 单次成本 ｜ 幻觉率抽检 ｜ 退订率          │
└────────────────────────────────────────────────┘
```

1. **第一层 · 北极星**：单个高亮卡片，占画面宽度约 40%，居中置顶。示例文案「每周生成并被采纳 ≥3 次的用户数」，卡角标注「教学示例」。向下三条细箭头指向第二层。
2. **第二层 · 一级指标**：五张等宽卡片横排，即五大核心指标，每张卡两行文字——指标名 + 一句话定义：
   - 采纳率：被采纳生成 / 总生成
   - 解决率：无人工介入自然结束会话 / 总问题会话
   - 幻觉率：幻觉判定数 / 抽检总数
   - 留存：第 N 日仍活跃新增 / 当日新增
   - 单次成本：当期成本 / 有效请求次数
3. **第三层 · 护栏指标**：一条通栏深色卡片垫底，文案「护栏指标——防止北极星被『歪』着做上去」，列出重试率、单次成本、幻觉率抽检、推送退订率四个示例，与上方用虚线连接（虚线=约束关系，非分解关系）。
4. **侧边注**：右下角小图例——实线箭头=拆解关系，虚线=护栏关系；左下角标注「示例值需按业务校准」。

### 四、文字与验收标准

| 验收项 | 标准 |
|---|---|
| 层级正确 | 三层结构完整：北极星 1 个、一级 5 个、护栏 4 个示例；虚线与实线不混用 |
| 指标准确 | 五大核心指标名称与公式与教案第六节完全一致，公式自洽（分母分子对应） |
| 标注合规 | 健康线不在图中出现（图只讲结构，不背数字）；北极星卡角必须带「教学示例」小标 |
| 品牌色 | 仅使用上表色值，主紫辅蓝，无其他色相 |
| 文字 | 全中文，无错别字；每张卡片文字不超过 2 行；最小字号导出 PNG 后 100% 缩放可读 |
| 复用性 | SVG 源文件文字可编辑（非曲线化），便于后续周次微调复用 |

### 五、讲法脚本（配图使用时机与话术）

| 时机 | 讲法 | 提问点 |
|---|---|---|
| 环节一开头（约 9 min） | 先只讲结构不讲内容：「最上面一个数，中间五个格子，最下面一条护栏——今天下课之前，你们每个人都会有一张自己的这个图。」随后逐格精讲五大指标，讲一个点亮一格 | 「你怎么知道你的 AI 产品是好是坏？看 DAU 够吗？」 |
