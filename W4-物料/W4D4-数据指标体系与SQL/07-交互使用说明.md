# 交互使用说明 · W4 周四《数据指标体系与 SQL 实战》（300 分钟版）

> 本课无专用交互式网页。300 分钟（6 课时 × 50 分钟）教学日中，**第 3 节（100–150 min）**以「讲师投屏 SQL 环境 + 教学数据集」讲产品读法与口径，**第 4 节（150–200 min）**以「学员本机 / 在线 SQL 环境 + 教学数据集」为实操载体；本文件规定这两节的组织方案：6 节使用时机、设备要求、环境预检、题目下发、卡壳求助、手机 / 平板替代。
> 数据集：`smallpen.sql`（建表 + 插入语句见《01-教案.md》附录 A，随导学案提前一天发群，全部标注「教学示例」）。
> 口径说明：原 90 分钟版「环节三 56–81 min」「休息 46–51 min」「56 min 节点」等时间字段，已统一对齐 6 节结构——SQL 读法在第 3 节、上机实操在第 4 节（150–200 min），节间休息 10 分钟不计入 300 分钟教学时长。

## 二、《设备要求表》（新增，手机 / 平板 / 电脑三档）

> 本期 6 名学员中设备不足 3/6。下表写明每档「可完成任务 / 受限任务 / 替代动作」，替代动作均为当堂可执行、计入产出，不需课后补设备。

| 设备档位 | 可完成任务 | 受限任务 | 替代动作（当堂可执行、计入产出） |
|---|---|---|---|
| **电脑** | 全流程：本地 SQLite 或在线平台跑通 `smallpen.sql`、练习 1–3 上机、看板表电子版、作品集归档、10 题练习集 | —（无） | 无需替代；提前一天完成预习方案 A / B 环境安装 |
| **平板** | 浏览器在线 SQL 平台粘贴运行教学示例数据集、跑 SELECT / WHERE / GROUP BY、看板表用文档 App 模板填、术语卡浏览、观看投屏、拍照归档 | 本地 SQLite 安装不便；多窗口切换与大段 SQL 输入吃力；JOIN 长语句易输错 | ① 用在线平台做「只读验证」：把讲师给的查询粘进去，核对是否返回 8 行 / 13 行 / 3 条渠道，验证「读懂」对不对；② JOIN 关改为「读懂投屏查询 + 口头核对分母」，不自己从零敲；③ 配外接键盘或分屏；④ 看板表用纸质导学案手写后拍照上传群相册 |
| **手机** | 术语卡 / 自测表浏览、面试 30 秒口播录音、观看回放、群内打卡、读 SQL 查询卡、结对当「审稿人」、拍照归档 | 跑 SQL 不便、填复杂表格不便、无法投屏操作 | ① **读**：打开导学案第 4 节三张查询卡，逐行口述「在算什么、分母是谁」，旁边写「分母 = ______」；② **审**：与带电脑同学结对，只提问不代写——「分号呢？」「日期加引号了吗？」「这条分母和整体那条一致吗？」；③ **说**：用手机录音录 30 秒数据故事，回放自查有没有形容词、是不是「数字 + 动作」；④ **验**：手机端在线平台浏览器只读跑 `SELECT * FROM users;` 看是否 8 行；⑤ **交**：群内打卡交录音 + 口径批注 + 纸质表照片 |

**通用达标线（三档一致）**：SQL 部分只要求「读懂一条查询在算什么、分母是谁、结论能不能信」，不要求写开发代码；能说清整数除法陷阱（比率必乘 1.0）即算过关。三档产出在《本日作品集积木》里等价归档（电脑 = 查询文件 / 平板 = 只读验证截图 / 手机 = 录音 + 批注照片）。

**受限任务汇总（需电脑、且已给替代）**：
| 受限任务 | 涉及节次 | 需电脑原因 | 替代动作索引 |
|---|---|---|---|
| 本地 SQLite 安装与建表 | 第 3 / 4 节 | 需本地客户端 | 在线平台（平板）/ 只读验证（手机） |
| JOIN 长语句输入与调试 | 第 4 节练习 3 | 多表连接语句长、易输错 | 读懂投屏查询 + 口头核对分母 |
| 看板表电子版填写 | 第 4 节 | 多列表格输入 | 纸质导学案手写 + 拍照归档 |
| 10 题练习集上机 | 课后 | 需连续跑数 | 手机端在线平台只读验证 / 「读懂 + 写分母」版 / 自习室电脑 |

## 三、环境预检清单（开课前 10 分钟，原第一节保留并改时间口径）

| # | 检查项 | 操作方式 | 不通过的处理 |
|---|---|---|---|
| 1 | 讲师端环境 | 讲师本机打开 SQL 环境，依次跑通教案附录 B 三条查询，**截图留存**作为现场故障的兜底素材 | 使用截图版结果继续上课，不现场排错 |
| 2 | 学员端覆盖 | 课前一天预习任务已要求安装（方案 A 本地 SQLite / 方案 B 在线平台二选一）；助教对照群内「已完成打卡」名单核对，并登记每人的设备档位（电脑 / 平板 / 手机） | 未完成者由助教在各节间休息（10 min，不计入教学时长）一对一补装，用方案 B 在线平台最快 3 分钟；手机 / 平板同学直接登记为「只读验证」档，不强制安装 |
| 3 | 数据集就位 | 学员执行 `SELECT * FROM users;` 应返回 8 行；`SELECT * FROM gen_records;` 返回 13 行 | 行数不符说明 `smallpen.sql` 未跑完整，重跑整个脚本（脚本可重复执行前先 `DROP TABLE` 或换新库） |
| 4 | 投屏可读 | 投屏 SQL 字号 ≥20px；深色主题时确认对比度；手机 / 平板同学确认能看清投屏或回放 | 浏览器 / 编辑器 Ctrl+「+」放大；为手机同学提供查询卡纸质版 |
| 5 | 备用通道 | 群内预置在线平台链接 + 数据集文件 + 查询卡，防本机故障 | 学员临时切换方案 B / 只读验证档 |

> 预检纪律：第 4 节实操开始前（150 min 节点）必须完成检查 2–3 项。仍无法就绪的学员直接走《设备要求表》对应档位的替代动作（第四节详述），不拖慢全班进度。

## 五、卡壳求助规则（「三分钟三步走」，原第三节保留）

1. **先自查 1 分钟**：报错先读第一行——行号（line N）与 near 附近的词，九成错误是：漏分号、字符串没用单引号、表名拼写错误。
2. **同桌互救 1 分钟**：把报错截图给同桌看一眼，两个人的眼睛比一个人快；结对的「审稿人」只提三句问（分号 / 引号 / 分母一致吗），不代写。
3. **举手求助 1 分钟**：助教到场处理；若 1 分钟内无法解决，贴一张黄色便签（线上课：群内发「卡住+题号」）后先旁观讲师演示，课后由助教跟进，**不占用全班时间**。

讲师口径（可直接照读）：「SQL 的报错信息比大多数软件诚实，它不怪你，它直接告诉你错在哪一行。学会读报错，本身就是今天的教学目标之一。」

高频报错速查（助教手持）：

| 报错/现象 | 原因 | 一句话解法 |
|---|---|---|
| `no such table` | 表名拼错或建表脚本没跑 | 先跑 `SELECT name FROM sqlite_master;` 看库里有哪张表 |
| `syntax error near ","` | 漏写关键字或多逗号 | 检查 SELECT 与 FROM 之间的列名列表 |
| 采纳率恒为 0 | 整数除法 | `SUM(is_accepted) * 1.0 / COUNT(*)` |
| 日期过滤查不到数据 | 日期没用单引号 | `WHERE gen_date = '2026-09-03'` |
| `ambiguous column name: user_id` | JOIN 后两表同名列没加表前缀 | 写成 `g.user_id` / `u.user_id` |
| 切片结果与整体对不上 | 口径漂移（WHERE 改了分母却没改注释） | 切片前后先对齐分母定义，口径注释跟着 WHERE 一起改 |

## 六、无电脑学员的替代方案（原第四节保留并扩充为三档，重点：手机 / 平板可执行）

适用：学员未带电脑、设备临时故障，或线上课网络不支持在线平台。本节是《设备要求表》替代理念的落地动作表，按设备档位取用。

| 环节 | 电脑 | 平板 | 手机 |
|---|---|---|---|
| 听讲（第 3 节） | 跟投屏同步跑数 | 看投屏 / 回放，在线平台只读验证行数 | 看投屏 / 回放，读导学案查询卡 |
| 练习（第 4 节） | 练习 1–3 上机跑通 | 跑 SELECT / WHERE / GROUP BY；JOIN 关读懂 + 口头核对分母 | 逐行口述查询在算什么、写「分母 = ___」；手写完整语句后口述给同伴「执行」，两人核对推演 |
| 结对 | 可当「执行者」 | 与电脑同学结对互查 | 固定当「审稿人」，只提三句问、不代写 |
| 数据故事 | 直接写 | 文档 App 写 | 手机录音 30 秒，回放自查「数字 + 动作、无形容词」 |
| 看板设计 | 电子版填 | 文档模板 / 纸质手写 | 纸质导学案手写 + 拍照 |
| 讲师兜底 | 三道课堂练习参考答案讲解时，讲师投屏逐行执行并口播中间结果，三档同学均可完整跟上推演 | 同左 | 同左，另发查询卡纸质版 |
| 课后 | 10 题上机 | 在线平台只读验证 + 讲清错因 | 手机端在线平台只读跑 `SELECT * FROM users;` / 完成「读懂 + 写分母」版 / 自习室电脑补做；群内交批注照片 |

> 结对纪律：审稿人不许代写，只许提问「你这行的分号呢？」「日期加引号了吗？」「这条的分母和整体那条一致吗？」——教别人的过程本身就是复习。
> 手机方案说明：在线平台浏览器直接可用，数据集脚本粘贴运行即可，无需安装 App；即便只做只读验证，也能确认「读懂」是否准确。
