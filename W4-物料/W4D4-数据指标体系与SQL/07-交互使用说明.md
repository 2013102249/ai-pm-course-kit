# 交互使用说明 · SQL 上机环节组织方案（W4 周四专用）

> 本课无专用交互式网页。环节三（56–81 分钟）以「学员本机 SQL 环境 + 教学数据集」为上机载体，本文件规定该环节的组织方案：环境预检、题目下发、卡壳求助、无电脑替代。
> 数据集：`smallpen.sql`（建表 + 插入语句见《01-教案.md》附录 A，随导学案提前一天发群）。

## 一、环境预检清单（开课前 10 分钟）

| # | 检查项 | 操作方式 | 不通过的处理 |
|---|---|---|---|
| 1 | 讲师端环境 | 讲师本机打开 SQL 环境，依次跑通教案附录 B 三条查询，**截图留存**作为现场故障的兜底素材 | 使用截图版结果继续上课，不现场排错 |
| 2 | 学员端覆盖 | 课前一天预习任务已要求安装（方案 A 本地 SQLite / 方案 B 在线平台二选一）；助教对照群内「已完成打卡」名单核对 | 未完成者休息时段（46–51 min）由助教一对一补装，用方案 B 在线平台最快 3 分钟 |
| 3 | 数据集就位 | 学员执行 `SELECT * FROM users;` 应返回 8 行；`SELECT * FROM gen_records;` 返回 13 行 | 行数不符说明 `smallpen.sql` 未跑完整，重跑整个脚本（脚本可重复执行前先 `DROP TABLE` 或换新库） |
| 4 | 投屏可读 | 投屏 SQL 字号 ≥20px；深色主题时确认对比度 | 浏览器 / 编辑器 Ctrl+「+」放大 |
| 5 | 备用通道 | 群内预置在线平台链接 + 数据集文件，防本机故障 | 学员临时切换方案 B |

> 预检纪律：环节三开始前（56 min 节点）必须完成检查 2–3 项。仍无法就绪的学员直接走「无电脑替代方案」（第四节），不拖慢全班进度。

## 二、课堂练习题下发方式

| 事项 | 规则 |
|---|---|
| 题目载体 | 三道题印在导学案（03-导学案 第二部分第 4 节），含答题空位；不在群内滚动发题，避免学员低头找消息 |
| 下发节奏 | 闯关到哪关，讲对应题：第一、二关讲完发练习 1；第三关讲完发练习 2；第四关讲完发练习 3。每题限时 3 分钟，讲师计时并口头报时 |
| 参考答案 | 随堂不公布完整答案，讲师巡视后投屏「一位学员的解法」讲解；完整参考查询在课后随《06-分层习题.md》答案一起发群 |
| 作业衔接 | 课后 10 题练习集与课堂同一数据集，导学案注明「课堂环境继续用，零切换成本」 |

## 三、卡壳求助规则（「三分钟三步走」）

1. **先自查 1 分钟**：报错先读第一行——行号（line N）与 near 附近的词，九成错误是：漏分号、字符串没用单引号、表名拼写错误。
2. **同桌互救 1 分钟**：把报错截图给同桌看一眼，两个人的眼睛比一个人快。
3. **举手求助 1 分钟**：助教到场处理；若 1 分钟内无法解决，贴一张黄色便签（线上课：群内发「卡住+题号」）后先旁观讲师演示，课后由助教跟进，**不占用全班时间**。

讲师口径（可直接照读）：「SQL 的报错信息比大多数软件诚实，它不怪你，它直接告诉你错在哪一行。学会读报错，本身就是今天的教学目标之一。」

高频报错速查（助教手持）：

| 报错/现象 | 原因 | 一句话解法 |
|---|---|---|
| `no such table` | 表名拼错或建表脚本没跑 | 先跑 `SELECT name FROM sqlite_master;` 看库里有哪张表 |
| `syntax error near ","` | 漏写关键字或多逗号 | 检查 SELECT 与 FROM 之间的列名列表 |
| 采纳率恒为 0 | 整数除法 | `SUM(is_accepted) * 1.0 / COUNT(*)` |
| 日期过滤查不到数据 | 日期没用单引号 | `WHERE gen_date = '2026-09-03'` |
| `ambiguous column name: user_id` | JOIN 后两表同名列没加表前缀 | 写成 `g.user_id` / `u.user_id` |

## 四、无电脑学员的替代方案（纸面 SQL）

适用：学员未带电脑、设备临时故障，或线上课网络不支持在线平台。

| 环节 | 替代做法 |
|---|---|
| 听讲 | 与带电脑学员两两结对：看同伴屏幕，负责「读题 + 检查语法」（结对角色固定为「审稿人」） |
| 练习 | 在导学案空白处**手写完整查询语句**，写完后口述给同伴「执行」——同伴逐行口头报出他认为的结果，两人核对谁的推演对 |
| 讲师兜底 | 三道课堂练习的参考答案讲解时，讲师投屏逐行执行并口播中间结果，纸面学员可完整跟上推演 |
| 课后 | 作业仍需上机完成（自习室电脑 / 手机端在线 SQL 平台均可）；手机方案说明：在线平台浏览器直接可用，数据集脚本粘贴运行即可，无需安装 App |

> 结对纪律：审稿人不许代写，只许提问「你这行的分号呢？」「日期加引号了吗？」——教别人的过程本身就是复习。
