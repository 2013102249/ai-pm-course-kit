4第 1 节术语卡（一）· 6 个词① 北极星指标＝唯一对齐方向的数（≠KPI）② 采纳率＝被采纳生成 / 总生成 ③ 幻觉率＝判定幻觉 / 抽检总数 ④ 幻觉率口径＝抽检与判定规则 ⑤ 指标口径＝分母 / 周期 / 来源；基线＝上线首周起点每词先给全称与中文（本页暂无缩写）；率类三词圈分母术语卡页：03-配图素材/术语卡/01–05、11 逐张点亮
5第 1 节术语卡（二）· 6 个词① DAU＝Daily Active Users 日活跃用户数（计数无分母）② 留存＝第 N 天仍活跃新增 / 当日新增 ③ 漏斗＝生成→采纳的流失视角 ④ SQL＝Structured Query Language 结构化查询语言 ⑤ 聚合（含分组）先分组后聚合；看板＝三层 + 口径英文缩写首次出现必须给全称与中文；分组 vs 聚合重点辨析术语卡页：03-配图素材/术语卡/06–10、12 逐张点亮
6第 1 节重点辨析：率类指标的分子分母① 对照表 5 行：采纳率 / 解决率 / 幻觉率 / 留存 / 单次成本 ② 幻觉率分母＝抽检回答总数、留存分母＝当日新增 ③ DAU 是计数无分母（反例）④ 口诀「凡是率，先问分子是谁、分母是谁」⑤ 当堂小测 12 题连线 + 改错练习；小测答对 ≥10 题达标率类指标分子分母对照图 + 术语自测表（03-导学案）

第 2 节 · 核心原理讲授 A（P7–P12，50–100 min）

页节次页标题内容要点讲师提示配图 / 交互
7第 2 节导入：黑盒里开飞机① 教学示例：A 团队吵一个月 vs B 团队两周找回数字 ② A 看 DAU / 账单 / 老板心情，数字只反映「发生了什么」③ B 只盯「每周生成并被采纳 ≥3 次用户数」④ 没有指标＝黑盒开飞机讲故事节奏：先讲混乱再讲仪表盘无（原 P3 内容保留）
8第 2 节从「有多少人用」到「用得值不值」① 传统指标＝流量视角（DAU / MAU / 下载量）② AI 产品多了「生成→采纳」关键一步 ③ 传统指标完全看不见这一步 ④ 核心问题＝用得值不值提问：看 DAU 够吗？（教案提问 1）无（原 P4 内容保留）
9第 2 节指标体系三层结构① 北极星（1 个）→ 一级指标（支撑分解）→ 护栏（防做歪）② 实线＝拆解、虚线＝护栏约束 ③ 五大核心指标是中间一层的五个格子 ④ 「下课每人都会有一张自己的图」先讲结构不讲内容AI 产品指标体系图（原 P5）
10第 2 节五大核心指标① 采纳率 / 解决率 / 幻觉率① 采纳率：被采纳 / 总生成，口径必写、基线对比法 ② 解决率：无人工介入自然结束 / 总问题会话，基线＝人工坐席 ③ 幻觉率：判定幻觉 / 抽检总数，不量化≠不管理、拒答单独统计 ④ 三者常见误读各 1 条原 P6/7/8 合并，三指标公式与提问点全保留；回扣 P6 分母指标体系图（点亮前三格）
11第 2 节五大核心指标② 留存 / 单次成本① 留存：第 N 天仍活跃新增 / 当日新增，看习惯用户占比 ② 单次成本：当期成本 / 有效请求次数，与单次价值比 ③ AI 尝鲜用户多、DAU 天然虚高 ④ AI 边际成本视角原 P9/10 合并；提问「DAU 涨 30% 说明变好吗」指标体系图（点亮后两格）
12第 2 节北极星指标三标准① 绑价值 / 可影响 / 可拆解，各配自检问句 ② 用三标准逐条拆 DAU（三条全灭）③ 正例教学示例：改北极星后动作从拉新转留存 ④ 金句：北极星一换，全团队的动作跟着换金句页；标注「教学示例」指标体系图（指向北极星，原 P11）

页节次页标题内容要点讲师提示配图 / 交互
13第 3 节双案例：DAU vs 采纳型北极星① 正面案例：改「每周生成并被采纳 ≥3 次用户数」后动作转留存 ② 反面案例：DAU 三标准逐条拆 + 堆九个指标、口径两页对不上 ③ 北极星定义三零件：核心行为 / 质量门槛 / 频次阈值 ④ 宣布主项目看板要求案例页（原 P12 升级为正反双案例）；标注「教学示例」指标体系图 + 双案例对照卡
14第 3 节护栏指标：防止把指标做歪① 三组搭档：采纳↔重试率、增长↔幻觉率+成本、留存↔退订率 ② 护栏是并列约束、不是拆解（虚线）③ 金句：北极星决定船往哪开，护栏防止把船开翻金句页（原 P13 保留）指标体系图（护栏条亮起）
15第 3 节SQL：AI 产品经理的硬技能① 三个理由：不排队 / 不被糊弄 / 会讲故事 ② 产品读法定位：只要求读懂与核对口径，不写开发代码 ③ 「小笔」教学示例数据集两表结构（users 8 行 / gen_records 13 行）④ 环境确认 SELECT 出 8 行即就绪原 P14 保留并补「产品读法」定位；未就绪举手数据表结构图 + 6 节时间轴角标
16第 3 节第一关 SELECT + 第二关 WHERE① SELECT 管列（要看哪几列）、WHERE 管行（只看哪部分）② = / AND / OR 与单引号 ③ 分母从这里开始变：加 WHERE 要改口径注释 ④ 学员做练习 1（3 分钟）投屏逐条跑；三档设备分层达标投屏 SQL 环境（原 P15）
17第 3 节第三关 GROUP BY + 第四关 JOIN① 分组（GROUP BY 定维度）vs 聚合（COUNT/SUM/AVG 算值），先分组后聚合 ② JOIN 连表、ON 靠 user_id 对上 ③ 整数除法陷阱 ×1.0、聚合列加 AS 别名 ④ 练习 2、3先跑错误版本让学员抓 bug；回扣 P5 术语卡投屏 SQL 环境（原 P16）
18第 3 节现场跑数：整体 → 切片 → 归因① 查询 1 整体健康 0.54 / 查询 2 异常日 0.00 / 查询 3 渠道归因 ② 金句：整体看健康，切片找异常，归因给动作 ③ 小样本先看次数再看比率（referral 1.00 仅 3 次）④ 看板三件事：抬头看什么 / 跌了往哪查 / 每个数怎么算金句页（原 P17 保留）；强调口径不漂移投屏 SQL 环境 + AI 产品全链路图（数据回流定位）
