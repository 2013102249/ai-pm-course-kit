本课共使用 2 张配图，均为本课新制素材（已制成），归入《03-配图素材》。

图 1 · PRD 结构图（十章骨架版式）

制图规格（已制成）

项目 规格
版式 纵向四组分区。顶部标题「AI 产品 PRD 十章骨架」；主体为四行分组，每组一个色带标签 + 章节卡片
分组一「为什么做」（蓝色 #2563EB 标签） ① 背景 ② 目标 ③ 用户与场景
分组二「做什么」（紫色 #7C3AED 标签） ④ 功能需求 ⑤ AI 能力需求（卡片角标注「AI 产品特有」）
分组三「怎么算好」（紫色 #7C3AED 标签） ⑥ 评测标准 ⑦ 容错兜底 ⑧ 成本预算 ⑨ 数据回流（卡片角标注「五处差异落点」）
分组四「怕什么」（蓝色 #2563EB 标签） ⑩ 风险
底部注脚 「评测标准三要素：指标名 + 数字门槛 + 数据来源」
尺寸 1600 × 1000 px，16:9，适配投屏
字号 标题 ≥40 px，章节卡片文字 ≥24 px，投影可读

验收标准

  1. 十章齐全且序号正确，四组分区与教案「六、十章结构」完全一致。
  2. 「AI 产品特有」「五处差异落点」两处标注清晰，这是本图区别于传统 PRD 模板的核心信息。
  3. 仅使用紫 / 蓝两主色及其浅色底（紫 #F1EBFD / 蓝 #E8EFFD），无第三方色相。
  4. 中文无错别字；导出 SVG + PNG 双格式。

讲法脚本（对应讲课稿环节二）

  • 开场指图：手指从上往下走一遍四组——「前三章讲为什么做，四五章讲做什么，六到九章讲怎么算好，第十章讲怕什么。」
  • 重点停留：在分组二「⑤ AI 能力需求」停 15 秒，强调「这是传统 PRD 里没有的一章，提示词初稿放附录」。
  • 提问点：「评审大会上评审最爱问哪一组的问题？」（预期：分组三「怎么算好」——六到九章是 AI 产品的懂行证明）
  • 过渡话术：「接下来 35 分钟，我们按这张图逐章写，我讲 2 分钟，你写 1.5 分钟。」

图 2 · 五处差异对比表

制图规格（已制成）

项目 规格
版式 表格版式，五行三列。表头：维度 / 传统 PRD / AI 产品 PRD。表头底色紫 #7C3AED 白字
行 1 评测标准：功能验收（逐条打勾）→ 效果验收（指标 + 数字 + 来源）
行 2 容错兜底：异常提示（请重试）→ 四级降级（澄清 / 拒答 / 转人工 / 降级）
行 3 幻觉控制：（不存在此章）→ 引用来源 + 阈值拒答 + 幻觉率红线
行 4 成本预算：服务器粗估 → 单次调用成本 + 日上限 + 月预算
行 5 数据回流：埋点看数 → badcase 回流评测集闭环
差异列配色 「传统 PRD」列灰底 #F0EEF7 墨字；「AI 产品 PRD」列紫浅底 #F1EBFD 紫深字 #5B21B6，形成「旧 vs 新」视觉反差
尺寸 1600 × 900 px，16:9
字号 表头 ≥36 px，单元格 ≥22 px

验收标准

  1. 恰好五行，与教案第五节五处差异一一对应，措辞一致（评测标准 / 容错兜底 / 幻觉控制 / 成本预算 / 数据回流）。
  2. 「幻觉控制」行传统列必须写「（不存在此章）」，不得留空或写「无要求」——这是教学重点。
  3. AI 列每格不超过 20 字，保证投屏可读；行 3 的三道防线（引用 / 拒答 / 红线）完整。
  4. 仅用品牌两色系；中文无错别字；SVG + PNG 双格式。

讲法脚本（对应讲课稿环节一）

  • 开场指图：「五处差异，就是面试官判断『你做没做过 AI 产品』的五个探针。」逐行讲，每行按「传统怎么写 → 为什么改 → 改后长什么样」三步走。
  • 重点停留：行 3 幻觉控制停留最久——先问「传统 PRD 有没有这一章」，停 3 秒，再讲三道防线。
  • 提问点：行 5 处提问「数据回流和普通埋点有什么区别？」（预期：埋点是看数据，回流是喂产品）
  • 收尾指图：「这五行，就是周五评审大会的评分重点。现在用 1 分钟把它抄进导学案速记表。」
  • 课后用途：本图随 shownotes 发给学员，作为 PRD 写作时的桌面对照卡。
