13第 3 节往届 PRD 翻车集锦（原 P3 并入）① 目标无指标无数值 ② 访谈 3 人 / 问卷 12 份被问穿 ③ 评测章只写「效果要好」④ 成本章整章空缺 ⑤ 修订要求写「优化完善」丑话说在前面；逐条问「你的 PRD 中了几条」，举手自查并记数翻车集锦页（原 P3 视觉）；五条勾选表
14第 3 节反面案例拆解①：目标章 / 数据章① 目标章：「提升效率」不可验收，补指标 + 数值 + 取舍 ② 数据章：样本底线访谈 ≥5 / 问卷 ≥30 ③ 低于底线＝证据链不完整，数据支撑最高 3 分 ④ 边界：低于底线不等于结论错强调「验收标准要能逐条打勾」；回扣第 5 页术语反面案例对照卡（新增案例页）
15第 3 节反面案例拆解②：评测 / 成本 / 修订① 评测三件套：评测集来源与条数 / 指标定义 / 门槛数值 ② 成本：token 用量 × 模型单价 + 用户量假设 ③ 修订要求三要素：改哪章 / 改成什么 / 截止时间 ④ 「下周」「尽快」不算日期常见误解纠正：评测是写进 PRD 的，不是上线之后的事三要素改写练习纸（新增案例页）
16第 3 节正反终审裁定对照① 反例：目标 2 / 方案 2 / 数据 2 / 风险 1 → 退回，4 条修订全带周一 12:00 ② 正例：4 / 5 / 4 / 4 → 过审，仍带 2 条修订 ③ 过审不等于零意见 ④ 三档：过审 / 有条件通过 / 退回【金句】通过是共识，驳回也是共识，有条件通过同样是共识终审三档对照表；四维得分雷达
17第 3 节修订要求改写练习（三要素）① 原句「优化目标章」② 原句「完善评测」③ 原句「下周尽快补数据」④ 改成合格修订要求（现场派工）两组各派一人上台改写，全班按三要素判分；缺日期该条 0 分改写擂台投屏版（新增练习页）
18第 3 节为什么 / 边界 / 常见误解 + 估时再练① 为什么：主动讲风险通过率高（替质询人完成最费力一步）② 边界：对方案不对人管措辞，不回避尖锐问题 ③ 常见误解：终审退回 = 失败 ④ 估时接龙凑 13–18 人日收口「这段在面试里怎么答」：把五条翻车讲成检查表，别讲成吐槽三段深化卡片（新增深化页）；人日基准表回切
