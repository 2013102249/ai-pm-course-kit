PPT 大纲 · W4 周五《PRD 评审大会（里程碑 ③）》

共 10 页 · 90 分钟 · 设计规范：紫色 #7C3AED 主色 / 蓝色 #2563EB 辅色 / 白底 / 每页不超过 6 行要点
本课为评审日任务说明型课件：PPT 只承担「讲清规则与方法」，不做知识讲授页；答辩全程投屏计时器与评审记录表，不用静态页。
页数口径：约 4–5 分钟/页有效使用时长（宣讲 10 分钟集中用前 7 页，后 3 页在终审与收尾段回切）。

页 标题 内容要点 讲师提示 配图 / 交互
1 封面：PRD 评审大会 · 里程碑 ③ 课程名 + 周次 + 「主线项目里程碑 ③」角标 口播今天终点：一次答辩 + 一份修订要求清单 + V2.0 过审口径 封面图（复用能力画像）
2 今天你能带走什么 ① 一次 5 分钟结构化答辩 ② 一份带截止时间的修订要求清单 ③ 答辩技巧与研发评估方法（面试可讲） 明确「今天不学新知识」，降低笔记焦虑 —
3 往届 PRD 翻车集锦 往期常见：目标无指标无数值 / 访谈仅 3 人被问穿 / 评测章只写「效果要好」 / 成本章整章空缺 / 修订要求写「优化完善」 丑话说在前面；逐条问「你的 PRD 中了几条」，举手自查 —
4 评审流程与规则 四段流程：陈述 → 质询 → 修订 → 终审；每人 5 分钟陈述 + 5 分钟质询，组内轮值三角色；三档裁定：过审 / 有条件通过 / 退回 强调硬切规则与轮值表；投屏计时器 PRD 评审流程图
5 四维评分标准 目标清晰度 / 方案完整性 / 数据支撑 / 风险识别，各 0–5 分；每维附档位描述（2 分及以下 / 3 分 / 4–5 分） 提醒打分前先对档位表；演示「指标无目标值最高 3 分」怎么判 导学案评审记录表（投屏版式）
6 答辩技巧：三段式陈述 背景 1 分钟（调研数据说话）→ 方案 2 分钟（链路与取舍）→ 数据与风险 2 分钟（评测门槛 + 最大风险与兜底）；禁照读 PRD 现场用第 3 页反例演示「错误开场 vs 数据开场」 —
7 被质询怎么办：应答公式 三步：复述问题 → 给答案 → 给依据；质询三类问题（目标类 / 方案类 / 数据类）各至少 1 问；铁律：对方案不对人，只提问不下结论 示范一轮「估时一问」的错误与正确答法 —
8 研发评估模拟 人日基准表：对话链路 3–5 / 知识库 2–3 / 界面 3–5 / 评测 3 / 埋点看板 2，合计 13–18 人日 ≈ 1–2 名工程师 × 2 周；风险三高发：幻觉率 / 单次成本 / 数据回流 强调「先拆任务再估时」；此表投屏常驻供质询收尾对照 研发评估人日基准表
9 修订要求与 V2.0 硬标准 修订要求三要素：改哪章 / 改成什么 / 截止时间；V2.0 五条硬标准：调研数据支撑 / 十章完整 / 评测可执行 / P0 兜底全覆盖 / 成本可复算；提交截止周日 24:00 页 4–8 评审期间退后台；清算环节（65–85 min）主讲此页；强调过审 = 中期答辩入场券 导学案修订要求清单模板截图
10 收尾：金句 + 预告 金句「评审是共识会不是考试——通过是共识，驳回也是共识」；本周五件综合输出清单；预告 W5：增长 / AB 实验 / 商业化 金句页紫底白字全屏，放慢语速念两遍；宣布里程碑 ③ 达成口径 —

四维评分档位表（第 5 页备注，供 PPT 制作时排版）

维度 2 分及以下 3 分 4–5 分
目标清晰度 说不清目标用户 / 场景，或「所有人都能用」 用户与场景明确，但指标无目标值 用户、场景、指标、目标值齐全且能说明取舍
方案完整性 核心链路讲不清，或缺评测 / 兜底 / 指标任一章 十章齐全但评测 / 兜底不可执行 链路清楚，评测可执行、兜底覆盖 P0、估时有依据
数据支撑 关键结论无数据，或引不出原始记录 有引用但样本低于底线（访谈 <5 或问卷 <30） ≥5 访谈 + ≥30 问卷，关键结论可回溯到原声 / 原表
风险识别 无风险章或只写「有风险」 列了风险但无应对 风险分级（P0 / P1），P0 全部有兜底与触发条件
