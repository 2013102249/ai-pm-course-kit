## 一、课前预习（评审日前一晚完成，约 30 分钟）

### 预习任务：5 分钟答辩准备清单

你明天有 5 分钟陈述 + 5 分钟质询。按下面三步准备，缺一项明天上台就会露怯。

**第 1 步 · 写陈述脚本（三段结构，合计 5 分钟）**

| 段落 | 时长 | 要回答的问题 | 我的脚本要点 |
|---|---|---|---|
| 背景 | 1 分钟 | 谁在什么场景下遇到什么问题？调研数据怎么证明？ | |
| 方案 | 2 分钟 | 我们做什么？核心链路怎么走？为什么这么设计？ | |
| 数据与风险 | 2 分钟 | 方案凭什么行（评测标准与目标值）？最大风险是什么？兜底在哪？ | |

**第 2 步 · 预判质询 3 问（每问写出你的答案）**

| 类别 | 质询问题 | 我的准备 |
|---|---|---|
| 目标类 | 目标用户与场景一句话是什么？成功指标和目标值是多少？ | |
| 方案类 | 核心功能研发要几个人日？怎么排期？最大风险与兜底是什么？ | |
| 数据类 | 关键结论的数据来自哪次调研？样本量多少？有没有反例数据？ | |

**第 3 步 · 材料检查（上台前一晚逐项打勾）**

| 检查项 | 状态 |
|---|---|
| PRD V1.0 十章齐全，页码目录可快速跳转（质询时会现场翻） | □ |
| 调研原始记录在手：访谈笔记或录音 5 份、问卷原始数据表 | □ |
| 兜底设计文档与 PRD 异常章条款一致 | □ |
| 单次对话成本复算过一遍：token 用量 × 模型单价 | □ |
| 修订留白页已备（质询与终审意见当场记，不靠脑子） | □ |
