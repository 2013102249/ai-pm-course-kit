## 图 2 · 预训练→SFT→LoRA→RLHF 流程图（已制成，本课核心图）

### 制图规格（已制成）

| 规格项 | 要求 |
|---|---|
| 画幅 | 横版 16:9，适配 PPT 全屏（1920×1080 出图） |
| 总体结构 | 四段横向流程，从左到右依次为：预训练 → SFT → LoRA → RLHF；段与段之间用大箭头连接，箭头上标注输出物（基础模型 / 会听话的模型 / 行为定制版 / 对齐成品） |
| 每段构成 | 每段三行内容：阶段名（大字）、实习生类比（胶囊标签）、产品经理关注点（小字一行） |
| 各段类比标注 | 预训练=「读完全部教科书」；SFT=「岗位培训」；LoRA=「贴一张便利贴微调习惯」；RLHF=「师傅带教打分」 |
| 各段产品经理关注点 | 预训练=「不参与，选型即可」；SFT=「行为差异的来源」；LoRA=「产品经理唯一可能出手的环节」；RLHF=「对齐人类偏好，厂商主战场」 |
| 强调设计 | LoRA 段加描边高亮框（品牌紫），右上角加角标「够用原则的主场」，视觉权重最高 |
| 量级标注 | 预训练段标「数以万亿计 Token · 以月计」；SFT 段标「数以千计到万计示范」；LoRA 段标「数以百计示例 · 开销小可插拔」；RLHF 段标「人类偏好打分排序」——只用量级表述，禁止出现具体成本、显卡、周期数字 |
| 品牌色 | 主色紫 #7C3AED（段名与高亮框）、辅色蓝 #2563EB（箭头与关注点文字）、白底、正文深灰 #221E33；禁用其他色相 |
| 字体标注 | 全部中文；阶段名 28px 加粗，类比标签 20px，关注点 16px；导出前逐字校对错别字 |
| 落款 | 右下角小字「AI 产品经理就业训练营 · W2D2」 |

### 验收标准

1. 四段顺序正确，箭头方向从左到右，无交叉无回流。
2. 每段三要素齐备：阶段名 / 类比标注 / 产品经理关注点，一行不多一行不少。
3. LoRA 段视觉权重最高（高亮框 + 角标），与「多数场景不该微调」的课程主线一致。
4. 量级表述合规：只出现「数以万亿计 / 以月计 / 数以百计」等量级词，无编造的具体数字。
5. 全图中文无错别字；投影 3 米距离可读（导出 PNG 后在 1080p 缩放检查）。
6. 品牌色仅紫 #7C3AED 与蓝 #2563EB，无渐变色相漂移。

### 讲法脚本

- **讲法**：沿四段从左到右逐段讲，手指沿箭头走；每段先读类比标签，再讲关注点。全程用「实习生入职培训」串联：读到第四段收口——「四个环节里，前三步都不归我们管，只有 LoRA 这张便利贴，是产品经理唯一可能出手的——而且多数时候连它都不需要。」
- **提问点**：「SFT 和预训练都在喂数据，差别在哪？」（预期：量级不同、目的不同）；「LoRA 为什么是便利贴而不是重写笔记？」（预期：只改行为不改底子、可插拔）。
- **过渡话术**：「链路清楚了。但今天这节课真正的落点不是『怎么微调』，而是『该不该微调』——接下来 20 分钟，给你们一张五问清单。」

## 图 3 · 微调必要性五问判断卡（已制成，轻量辅助卡）

- **规格**：竖版卡片式（适配导学案与手机分享），五问纵向排列，每问一行：问句 + 考察点小字；底部一行结论规则「任何一问不过 = 不该微调」；品牌色同上（紫 #7C3AED 问句、蓝 #2563EB 小字）。
- **用途**：环节二板书替代 + 导学案第 2 栏配图 + 学员社群分享物料（本课传播件）。
- **讲法**：不逐字读，每问只补一个课堂例子（例：第一问配「三种结构提示词都试过吗」）。
- **验收标准**：五问措辞与教案、讲课稿、导学案完全一致；单屏手机可读；无错别字。
