# 课堂交互使用说明 · LoRA 旁观实验组织方案（W2 周二专用）

> 本课**无专用交互网页**（生产卡标注：交互 = 无）。
> 本课的核心体验环节是「LoRA 旁观实验」：讲师演示、学员观察记录，学员全程不亲手跑训练（教学红线）。
> 本文件说明演示什么、学员记录什么、出问题怎么办。与教案环节三（46–62 分钟）、讲课稿对应段落配套使用。

## 一、为什么是「旁观实验」而不是动手实操

| 理由 | 说明 |
|---|---|
| 岗位定位 | 产品经理的职业动作是「定义、供给、验收」，不是跑训练；动手跑训练会引导学员错误投入 |
| 课堂效率 | 训练等待与排障时间不可控，90 分钟课堂塞不下；旁观可把 16 分钟全部用在「看懂」上 |
| 考点对齐 | 本课考点是「微调必要性判断」，实验只服务于「亲眼看见微调改了什么、没改什么」这一观察目标 |

## 二、实验设定（概括性描述）

- **任务**：在开源小模型上，用少量示例（数以百计量级）做一次「公司品牌口吻」风格微调，对比微调前后的同题输出。
- **方式**：LoRA 微调；示例数据为品牌口吻文案范例，含正例与负面示例。
- **呈现**：三幕式——数据准备 → 训练过程 → 前后对比。学员按导学案记录表逐幕填写。
- **红线**：不展示、不讲解任何代码与数学细节；量级数字只说「数以百计」「以周计」等量级词，不编造具体成本与周期。

## 三、课前准备（开课前一天完成）

| 准备项 | 要求 |
|---|---|
| 实验环境 | 讲师本地或云上实验环境跑通一次全流程，确认三幕均可投屏展示 |
| 兜底录屏 | 提前录制完整实验过程（三幕 + 前后对比），现场失败即切录屏，讲解脚本不变 |
| 对比样本 | 预先准备微调前后各 3 组同题输出（含 1 组「副作用」样本：通用问题回答变差），现场即时对比之外另有备份 |
| 导学案 | 确认学员人手一份，第 3 栏「LoRA 旁观实验记录表」未提前填写 |

## 四、演示脚本（与讲课稿对应，16 分钟）

| 幕 | 时长 | 讲师演示与口播要点 | 学员记录 | 提问 |
|---|---|---|---|---|
| 第一幕：数据准备 | 4 min | 滚动展示示例数据集：任务 + 品牌口吻示范；指出负面示例的位置；追问「标注口吻标准一致吗」 | 示例数量量级、有无负面示例、标注是否一致 | 「这一幕里产品经理的主场在哪？」（预期：数据标准由业务方定义） |
| 第二幕：训练过程 | 5 min | 启动训练，指损失曲线向下；强调「动的只是一小片新增参数，原模型纹丝没动」；等待期抛问「效果不好的损失是什么」 | 原模型参数动没动、损失曲线方向 | 「如果便利贴贴坏了，我们的损失是什么？」（预期：撕掉重来，原模型还在） |
| 第三幕：前后对比 | 5 min | 并排展示同题输出的微调前后版本，让学员先自己看 30 秒再讨论；收口「变了口吻，没变智力」 | 变了什么、没变什么、有无副作用 | 「变了什么，没变什么？」（预期：行为变了，能力没变） |
| 收口 | 2 min | 引导每人在记录表写一句话结论；点 2 名学员朗读 | 一句话结论 | 「这个实验改变了你对微调的哪一条认识？」 |

## 五、失败预案

| 故障 | 处理 |
|---|---|
| 环境无法启动 / 训练排队 | 直接切兜底录屏，讲解脚本完全不变；口播补一句「真实工程里训练排队是常态，这就是第四问『时效』的日常体现」 |
| 训练效果不明显（前后差异小） | 不硬解释，改用预置对比样本讲解；顺势强调第五问「评测」的价值——差异小不小，评测集说了算，不靠肉眼 |
| 出现明显副作用样本 | 不回避，当作教学素材现场讲「顾此失彼」，回扣验收清单要含通用回归题 |
| 投屏字太小 / 数据集太长 | 提前把关键样本做成 PPT 备份页；实验环境仅作「真实感」佐证，讲解以 PPT 备份页为准 |
| 时间不够 | 三幕可压缩为「数据 + 对比」两幕（训练过程改看录屏快进），最低保住第三幕对比——它是考点（微调改行为不改智力）的唯一可视化证据 |
