## PPT 制作备注（时间口径已对齐 300 分钟版）

| 项目 | 规范 |
|---|---|
| 页数 | 36 页 = 6 节 × 6 页；原 16 页内容按主题并入对应节次，不丢页 |
| 母版 | 白底 + 左上角紫色课程 Logo + 右下角页码（标注「第 X 节 / 共 6 节」） |
| 标题字 | 32–36px 加粗，正文 20–24px，一页不超过 6 个要点行 |
| 强调色 | 金句 / 关键认知页（第 13、18、30、34 页）用紫底白字全屏页；五问清单页（第 14 页）用蓝色编号 |
| 高亮规则 | 第 9–12 页复用同一张全链路流程图，仅切换高亮段，保持视觉连续性 |
| 术语卡页 | 第 3–6 页每页切对应术语卡，卡片 5 区块固定；英文缩写首次出现给全称 + 中文 |
| 实验页 | 第 20–21 页以投屏与现场演示为主，PPT 只放标题与记录指引，避免重复；另备大字样本页供手机 / 平板 |
| 面试页 | 第 25–30 页统一套「面试追问链图」版式；60 秒答法页只放关键词提词，不放全文 |
| 动画 | 仅用「淡入」，禁用飞入弹跳类动画（课堂严肃感） |
| 导出 | 另存 PDF 版发学员复习（去掉讲师备注页）；竖版术语卡单独导出供手机阅读 |
