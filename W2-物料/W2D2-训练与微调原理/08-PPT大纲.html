PPT 大纲 · W2 周二《训练与微调原理（够用原则）》

AI 产品经理就业训练营 · 第二周第二天 · 300 分钟（6 课时 × 50 分钟）· 共 36 页（6 节 × 6 页）
设计规范：紫色 #7C3AED 主色 / 蓝色 #2563EB 辅色 / 白底 / 每页不超过 6 行要点。
配图列标注了所用素材；「实验」页表示该页以现场演示代替静态内容。原有 16 页内容已按主题并入对应节次、不丢页；新增页重点为术语卡页、案例页、实操任务页、面试题页、追问链页、验收页。

1第 1 节（0–50 min）封面：训练与微调原理（够用原则）① 课程名 + 周次 + 讲师名 ② 副标「300 分钟（6 课时 × 50 分钟）」③ 今日主线：多数场景不该微调 ④ 不讲数学与代码口播今天终点：能与算法团队对话 + 知道什么时候该微调；明确 6 节结构LLM 原理架构图（弱化为底纹）
2第 1 节今天你能带走什么（6 节版）① 12 个术语能说会分 ② 四步培养链路类比 ③ 五问判断清单 ④ 协作接口（交付 / 验收）⑤ 7 道面试题 60 秒答法明确目标、降低焦虑；强调「不讲数学与代码」；用时间轴图预告 6 节6 节时间轴图（全程导航）
3第 1 节术语精讲 · 12 词总览① 预训练 / 微调 / SFT / LoRA / RLHF ② 提示词工程优先 / 标注数据 / 训练集 ③ 过拟合 / 灾难性遗忘 / 五问清单 / 成本 ④ 一词五件：定义 / 类比 / 辨析 / 面试说法 / 术语卡先说明「术语只从当日内容来」；英文缩写首次出现给全称 + 中文术语卡 12 张缩略（03-配图素材/术语卡/）
4第 1 节术语卡（一）：五个核心阶段词① 预训练：海量文本养通识底子 ② 微调：只改具体行为的小调整 ③ SFT：成对示范教「这样问就这样答」④ LoRA：原参数不动加可插拔增量 ⑤ RLHF：人类打分学「什么算好」逐词切卡，先读生活类比再读面试说法；纠正「LoRA 是小模型」误解术语卡 5 张（预训练 / 微调 / SFT / LoRA / RLHF）
5第 1 节术语卡（二）：七个判断与数据词① 提示词工程优先：先试低成本路 ② 标注数据：带标准答案、口径一致 ③ 训练集：拿来「教」的样本 ④ 过拟合 / 灾难性遗忘：太死 vs 顾此失彼 ⑤ 五问清单 / 成本：闸门与相对代价强调「成本」不写具体数字，涉及数据写「待教务补充」术语卡 7 张（提示词工程优先 / 标注数据 / 训练集 / 过拟合 / 灾难性遗忘 / 五问清单 / 成本）
6第 1 节易混三对辨析 + 当堂小测① 微调 ⊃ {SFT、LoRA} ② 训练集 ≠ 评测集 ③ 过拟合 ≠ 灾难性遗忘 ④ 小测 12 题、≥10 题达标 ⑤ 未达标第 6 节补测辨析练习 15′ + 小测 10′；错的当场用一句话纠偏易混三对对照页 + 习题第 0 层答题卡
7第 2 节（50–100 min）从「挑人」到「培养」+ 概念补丁三词① 昨天选型=挑现成的人 ② 今天讲人怎么被培养 ③ 训练 / 参数 / 微调三个词垫底 ④ 两个目的：接得住算法的话、知道该不该微调回顾周一决策树，抛成长经历问题；金句 1「不训练但要知道怎么被训练」LLM 原理架构图（开场定位）
8第 2 节全程类比：实习生入职培训① 教科书 → 岗位培训 → 便利贴 → 师傅打分 ② 四步对应预训练 / SFT / LoRA / RLHF ③ 类比先行，之后每页只强化一段 ④ 时间轴拉长看「成长经历」类比先行；本页只给总览，不展开节点预训练→SFT→LoRA→RLHF 流程图（四段全览）
9第 2 节第一步 预训练：读完全部教科书① 数以万亿计 Token · 以月计 ② 反复做「预测下一个词」③ 产物=基础模型（毛坯房）④ 产品经理不参与，选型即可金句「毛坯房」；量级表述不用具体数字；强调这是周一选型课的前提流程图（预训练段高亮）
10第 2 节第二步 SFT：岗位培训① 数以千计到万计高质量示范 ② 一问一答成对样本 ③ 学会「像样地干活」④ 行为差异的来源 ⑤ 数据脏了学的就是坏习惯展示一条真实 SFT 示范样本；金句「预训练决定聪明，SFT 决定听话」流程图（SFT 段高亮）+ SFT 示范样本页
11第 2 节第三步 LoRA：贴一张便利贴① 只训练一小片新增参数 ② 原模型纹丝不动 ③ 数以百计示例、开销小 ④ 可插拔、试错成本低、敢贴敢撕本页视觉权重最高；角标「够用原则的主场」；不说具体成本数字流程图（LoRA 段高亮框）
12第 2 节第四步 RLHF：师傅带教打分① 人类对多个回答打分排序 ② 学出「好答案的尺子」③ 对齐：有用 / 诚实 / 无害 ④ 学到的是偏好不是新知识用「新手怎么开始健身」三答案排序举例；收口「产品经理大概率只碰 LoRA」流程图（RLHF 段高亮）
13第 3 节（100–150 min）关键认知：多数场景不该微调① 先给结论再给证据 ② 微调改行为不改智力 ③ 补知识走 RAG、改文档即生效 ④ 错误微调=把应用层问题按到模型层制造认知张力；回扣第 1 节「知识 vs 行为」案例与关键认知页（紫底白字全屏条）
14第 3 节微调必要性判断清单：五问① 提示词到头了吗 ② 知识还是行为 ③ 有数以百计高质量示例吗 ④ 需求常变吗 ⑤ 说得清验收吗本课最值钱一页，放慢逐问讲；底部「任何一问不过 = 不该微调」微调必要性五问判断卡
15第 3 节五问实战：两个场景过清单① 每月更新的售后政策 → 卡第二问，走 RAG ② 严格 JSON 输出 → 先卡第一问 ③ 逐问打勾 ④ 结论：清单不是不让调，是让调只发生在对的地方请学员口答「卡在第几问」；金句 3 原样背下来五问判断卡（逐问打勾版）
16第 3 节正反面案例（一）：五问全过 vs 把知识当行为① 正面：口吻规范文档 → 口径一致示范 → LoRA → 含通用回归题的评测集 ② 反面：把整本产品手册微调进模型 ③ 手册一改就过期、口径打架 ④ 病根：把知识当行为只讲做法错在哪，不评价团队；效果数值写「待教务补充」案例与关键认知页（左正面 / 右反面）
17第 3 节正反面案例（二）：无评测集上线翻车① 现场 Demo 惊艳全票通过 ② 上线一周边界场景出错 ③ 根因：第五问被跳过、无评测集 ④ 为什么第五问最致命讲返工故事；讨论「只能留一问留哪问」，收口到评测先行返工故事时间线页
18第 3 节与算法团队的协作接口① 交付四件：需求文档 / 评测集 / 数据标准 / badcase 回流 ② 验收三关：对比基线 / 评测跑分 / 上线门槛 ③ 不看 Demo ④ 一句话原则：定义问题、供给数据、主持验收金句 4「Demo 是演员，评测集才是考卷」；强调「没有评测集一律不签字」协作接口对照页（四件 / 三关）
19第 4 节（150–200 min）第 4 节任务说明与分步骤① 步骤 1 旁观实验三幕 ② 步骤 2 四场景过五问 ③ 步骤 3 分层习题第 0–3 层 ④ 红线：只观察不跑训练 ⑤ 时间：说明 8′ + 实操 32′ + 讲评 10′发布导学案任务单；按设备分档；宣布「没有任何任务非电脑不可」6 节时间轴图（当前节高亮）
20第 4 节LoRA 旁观实验：看什么① 三幕：数据准备 / 训练过程 / 前后对比 ② 只观察不动手 ③ 导学案记录表逐幕填 ④ 重点找「有没有变得更差的地方」宣布红线；提醒记录「副作用观察」一栏导学案《LoRA 旁观实验记录表》
21第 4 节实验进行时：三幕① 第一幕数据：量级、负面示例、标注一致性 ② 第二幕训练：原模型不动、损失曲线向下 ③ 第三幕对比：变了口吻没变智力 ④ 留意灾难性遗忘温和版投屏演示为主，PPT 仅作标题过渡页；第三幕先静看 30 秒实验环境投屏 + PPT 大字备份样本页
22第 4 节小组练习：四个场景过五问① 售后政策 / JSON / 品牌口吻 / 老板拍板微调 ② 讨论 5 分钟 ③ 每组给判断 + 至少两条理由 ④ 汇报后给参考答案计时；巡视听讨论；要求结论后必须写「卡在第几问」导学案《场景判断表》
23第 4 节分层习题第 0–3 层 + 常见卡点 3 条① 第 0 层术语辨析 + 第 1 层选择当堂做 ② 第 2、3 层留作课后 ③ 卡点一：分不清变没变 ④ 卡点二：不给第几问 ⑤ 卡点三：手机看不清投屏同桌互批；共性错误记入讲评；卡点给现成解法习题第 0 层答题卡 + 常见卡点提示条
24第 4 节手机 / 平板替代动作 + 讲评收口① 看投屏 / 兜底录屏 + 填记录表 ② 群内 3 组对比样本逐条比对 ③ 习题用纸质 / 备忘录作答 ④ 收口「变了口吻、没变智力」按三档各抽一人复述替代动作；确认产出等同设备要求表 + 微调前后 3 组对比样本（含 1 组副作用）
25第 5 节（200–250 min）面试讲解：通用打法与四类高频题① 先给框架 → 报术语 → 留边界 ② 什么时候该微调 ③ 微调 vs 提示词 ④ 微调 vs RAG ⑤ 怎么判断有没有效果点出卷首「为什么没微调」挂掉的故事；说明「懂 ≠ 能得分」面试追问链图（7 题总览）
26第 5 节面试题 1–2：该不该调 / 和提示词怎么选① 题 1：五问清单逐项过、任何一问不过不调 ② 题 2：提示词工程优先、试到头才升级 ③ 各附踩分点 4 条 ④ 各附 60 秒答法关键词先示范拆题，再让学员跟读起手式「先给框架」面试追问链图（题 1、题 2）
27第 5 节面试题 3–4：微调 vs RAG / 怎么判断效果① 题 3：补知识走 RAG、改行为才微调 ② 会过期 / 可叠加 ③ 题 4：冻结评测集 + 基线对比 + 上线门槛 ④ 金句「Demo 是演员，评测集是考卷」强调一票失分「看 Demo」；追问「评测集只测口吻够不够」面试追问链图（题 3、题 4）
28第 5 节面试题 5–7：老板要求 / 为什么没调 / 上线下滑① 题 5：不盲从不硬顶、三问转译 ② 题 6：不答「觉得没必要」、给框架 ③ 题 7：三条线排查 + 灾难性遗忘 ④ 行为题要体现向上管理提醒数据写「待教务补充」，不编数字；行为题练「不被动」面试追问链图（题 5–7）
29第 5 节追问链拆解示范（2–3 层）+ 失败答法对照① 第 1 层：判据类追问 ② 第 2 层：反例 / 老板类追问 ③ 第 3 层：机制 / 重评类追问 ④ 失败答法：看情况 / 看 Demo / 直接重训 / 预算够就微调单题放大示范；全班按踩分点给失败答法打分面试追问链图（单题放大）+ 一票失分条
