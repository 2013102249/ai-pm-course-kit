# 课堂交互使用说明 · 《AI 产品评估打分工具》（W2 周三专用）

> 用途：本课环节三（50–68 分钟）核心教具 + 环节四报告讲解（约 75 分钟）。
> 工具位置：02-交互工具/AI产品评估打分工具.html（单文件 HTML，断网可用，与 W6D4 复用）。
> 使用前请完成「课前检查」，故障处理见文末。

## 一、课前检查（开课前 10 分钟）

| 检查项 | 操作 | 通过标准 |
|---|---|---|
| 投屏与分辨率 | 浏览器窗口 ≥1080px 宽 | 统计区四个指标卡、雷达图与通过率面板同屏可见 |
| 示例数据预载 | 点击「加载示例数据」 | 出现 3 条用例（TC-001 / TC-002 / TC-003），TC-002 带「badcase」橙色角标 |
| 统计数字核对 | 看统计区 | 用例总数 3、badcase 数 1、badcase 率 33.3%（红色危险色）、综合均分 3.6、通过率 33.3%（红色进度条）；自动结论点名「准确性」均分 3.3 为最大短板并提示暂缓上线 |
| 导出功能预检 | 点击「导出评测报告」再关闭 | Markdown 报告弹窗正常，Esc 或「关闭」可退出 |
| 清空确认预检 | 点击「清空数据」后点「取消」 | 页面顶部出现橙色确认条（不弹系统对话框），取消后数据仍在 |
| 学员端 | 群里提前发工具链接 | 学员手机打开正常；本工具支持 ≤720px 单栏布局 |
| 备用方案 | 将示例统计区截图存本机 | 工具异常时投截图讲，破案逻辑不中断 |

注意：数据存浏览器 localStorage，刷新不丢失。若课前用过本机其他班级数据，先「清空数据」再「加载示例数据」，避免统计数字对不上讲课稿。

## 二、讲师演示脚本（5 步，与讲课稿环节三 / 四对应）

| 步骤 | 讲师操作 | 讲解要点 | 提问 / 互动 |
|---|---|---|---|
| ① 加载示例数据，读体检报告 | 点击「加载示例数据」；指统计区四个指标卡逐一念数 | badcase 率 33.3% 超 30% 警戒线（卡片变红）；综合均分 3.6；通过率 33.3%；自动结论已点名「准确性」短板——工具出报告，治病靠人 | 「工具已经告警了，接下来怎么破案？」 |
| ② 展开案发现场 TC-002 | 点击 TC-002 行展开 | 带学员读三栏：测试输入（无理由退款吗）、期望输出（7 天无理由政策）、实际输出（编造 72 小时无条件退款）；准确性 1 分，badcase 开关为「是」 | 「先别看答案——你怀疑哪个环节？」 |
| ③ 逐维打分演示（可让学员口报分值） | 在 TC-003 上演示：展开后逐维点击星星，从「格式规范性 2 分」逐个点起，其他维度现场让学员口报分值后点击 | 每点一次星星，维度 chip 均分、雷达图、综合均分实时刷新——打分不是拍脑袋，是逐维对照期望输出 | 「按我们的锚点定义，帮助性你给几分？为什么？」 |
| ④ badcase 标记与统计联动 | 在 TC-003 上把「是否 badcase」从「否」切到「是」，再看统计区变化 | badcase 数变 2、badcase 率变 66.7%、通过率下降——一条标记牵动全局指标；再切回「否」复原；同时演示备注栏写归因结论（现象→主因→次因→修复→回归）后点「保存」 | 「标记 badcase 影响了哪几个数字？」 |
| ⑤ 导出评测报告 | 点击顶部「导出评测报告」，滚动展示四段结构后点「复制到剪贴板」 | 报告四段：任务信息 / 各维度均分 / badcase 清单 / 结论与建议；强调「给结论也给门槛，给问题也给动作」；宣布：这份 .md 模板主项目直接复用，W6D4 验收报告就是它 | 「这份报告发给你老板，他下一步该做什么？」 |

**两个不可省略的动作**：

1. **逐维打分必须现场点**——星星点亮的实时刷新是「维度可判断」最直观的证据，只口头讲学生记不住。
2. **badcase 开关必须现场切**——66.7% 的红色数字冲击是讲「负例防翻车」的最好素材。

## 三、常见故障处理

| 故障 | 处理 |
|---|---|
| 加载示例后统计数字对不上讲稿 | 先「清空数据」再重新「加载示例数据」；仍异常则用课前截图投屏 |
| 雷达图不显示 | 说明尚无用例打分——这是正常空态；重新加载示例数据即可 |
| 星星点击无反应 | 刷新页面（localStorage 不丢）；或换浏览器（推荐 Chrome / Edge / Safari 最新版） |
| 导出弹窗卡住或复制失败 | 点「下载 .md」走文件下载；复制失败时手动选中报告文本复制 |
| 学员端打不开 | 不等待，本工具以讲师投屏为主；课后学员用链接自学 |
| 误点「清空数据」 | 确认条点「取消」即恢复；若已确认清空，重新「加载示例数据」即可还原演示环境 |

## 四、学员课后自学指引（发群文案）

> 同学们，今天课上的《AI 产品评估打分工具》链接已发群。课后请大家完成三个动作：① 点击「加载示例数据」，把 TC-002 的归因结论按「现象—主因—次因—修复—回归」句式补进备注栏，点保存；② 自己新增 1 条用例（用你预习时为主项目写的测试问题），逐维打分并标记是否 badcase，看统计区怎么联动；③ 导出你的第一份评测报告并下载 .md 存档。这份工具 W6D4 主项目测试验收还要用，本周 ≥50 条评测集建议直接录进它，提前跑通全流程。周五课前抽查：随机点 2 位同学展示自己导出的报告。
