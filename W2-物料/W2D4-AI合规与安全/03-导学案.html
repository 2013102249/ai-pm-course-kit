一、课前预习（上课前完成，约 25 分钟）

预习任务 1（必做）：任选一款你常用的国内 AI 产品，查一查它的备案信息，把结果填进下表。

查询项 我的查询结果
我查的产品名称
在哪查到的（官网底部 / 关于页 / 应用商店详情页 / 其他）
备案信息长什么样（备案号 / 名称 / 抄录关键内容）
我的疑问

提示：算法备案信息通常在产品官网页面底部、「关于我们」或应用商店详情页公示；也可以在网信部门的备案系统官网查询公示信息。如果这款产品查不到备案信息，如实记录「未找到」，课上我们一起分析为什么。

4. 合规检查清单 · 五模块（对照自己的主项目逐项过）

每项标注状态：已具备 / 待补齐 / 不适用（标「不适用」必须写理由）

模块 自查项 我的状态 待补齐的动作 / 不适用理由
一、算法备案 我用的模型是否已备案
应用是否需要登记
二、内容安全 是否计划接入机器 + 人工双审核

评测集是否包含内容安全负例

是否提供删除 / 注销通道
