## 新制图规格：《合规检查清单图》（原规格保留，时间口径改 6 节）

### 一、用途与版式

- **用途**：对应板块五模块精讲的讲授主图，学员对照它填写导学案五模块清单；对应板块实操全程作为任务挂图；对应板块复盘收束再整图露出一次；同时是 36 页体系对应板块清单页主视觉、课后资料封面图。
- **版式**：五模块 checklist 版式，建议 1240 × 860px 竖向五横条结构：

| 版式元素 | 规格 |
|---|---|
| 标题区 | 顶部通栏，标题「AI 产品合规检查清单」+ 副标题「五模块 · 主项目全周期自查」 |
| 模块横条 ×5 | 每条 = 左侧色块（模块序号 + 名称）+ 右侧 3 条 checklist 项（方框 + 产品动作短句） |
| 模块一 | 算法备案：模型是否已履行手续 / 应用是否需登记（待确认）/ 公示信息可查 |
| 模块二 | 内容安全：双审核机制 / 拒答与转人工 / 投诉通道 |
| 模块三 | 数据合规：数据清单梳理 / 最小必要 / 单独授权与删除通道 |
| 模块四 | 未成年人保护：用户画像判断 / 适龄与分级 / 防沉迷 |
| 模块五 | 责任标识：「内容由 AI 生成」标注 / 显式 + 隐式标识 / 免责声明与客服 |
| 底部口诀条 | 通栏色带：「备得上 · 审得出 · 收得少 · 护得住 · 标得清」 |

- 图内固定小字（新增）：「具体条款、适用与结论以现行法规与法务意见为准」。

### 二、品牌与配色（原表保留）

| 元素 | 规范 |
|---|---|
| 主色 | 紫 #7C3AED（标题、模块一 / 三 / 五色块） |
| 辅色 | 蓝 #2563EB（模块二 / 四色块、checklist 方框边线） |
| 深色 | 紫 #5B21B6（底部口诀条底色，白字） |
| 底色 | 白 #FFFFFF，卡片间分隔用浅灰 #F0EEF7 |
| 字体 | 中文黑体系（PingFang SC / 思源黑体），标题加粗 |
| 禁用 | 禁 emoji；禁渐变滥用；禁超过两种强调色 |

### 三、验收标准（原 6 条保留 + 合规口径 1 条）

1. 五模块名称与教案「附 5-1」表格完全一致，无错别字（质检人逐字核对）。
2. 每模块恰好 3 条 checklist 项，文案 ≤14 字，与教案「产品动作」语义一致。
3. 配色严格使用上表色值，紫色出现次数 ≥3 处、蓝色 ≥3 处。
4. 底部口诀 15 字完整无误，与讲课稿金句一致。
5. 纯 SVG（Scalable Vector Graphics，可缩放矢量图形）源文件，导出 PNG 不小于 2 倍图；手机端 720px 宽度下文字可读。
6. 图中无具体公司名、无处罚细节、无条款编号、无施行日期、无 emoji。
7. **（新增）** 图内标注「以现行法规与法务意见为准」，无「必须 / 应当 / 违法」等结论化措辞。

### 四、讲法脚本（原脚本保留，时间改 6 节相对口径）

- **入场（对应板块五模块精讲开始）**：先只投标题区和五个模块名，不展开条目——「这一段，就是把这张图填满。」
- **逐模块（每模块约 3 分钟）**：手指沿当前模块横条从左到右走，每念一条 checklist 就让学员在导学案对应行写状态；讲完补一句「具体是否适用，以现行法规与法务意见为准」。
- **提问挂点**：讲到模块三时停，抛「证件照片必须存吗」；讲到模块五时抛「生成内容出了错责任归谁」。
- **对应板块实操**：整图常驻投屏，学员按图逐格填清单，讲师巡场按图指格。
- **收束（对应板块复盘）**：整图露出，指底部口诀条带读一遍——「备得上、审得出、收得少、护得住、标得清」，宣布这就是金句第 6 条。
- **过渡话术**：「一线讲的是做法，这张图是把做法变成你们每天能用的自查工具——明天它就进你们的立项报告。」

### 五、复用图讲法：《AI 产品全链路图》（对应板块，原讲法保留）

- **讲法**：一句话定位——「合规卡在两端一门：数据进模型的左端是数据合规，内容出模型的右端是内容安全，手续管的是这门生意能不能开门。」
- **提问点**：无（定位图，停留 2 分钟即切走）。
- **口径补充**：讲完补一句「哪些算、怎么办，以现行法规与法务意见为准」。
