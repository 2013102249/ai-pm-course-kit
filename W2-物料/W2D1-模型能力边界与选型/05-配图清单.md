## 核心制图规格（已制成）：模型横评表

> 以下为原有规格，全部保留；仅把「环节」表述按 6 节口径对齐。

### 一、表格结构（维度行 × 模型列）

- **列（6 列）**：GPT 系列、Claude 系列、Gemini 系列、DeepSeek、Qwen 系列、GLM 系列。列头放模型名，不加厂商 Logo（避免版权与时效问题）。
- **行（8 行维度）**，自上而下：
  1. 通用对话质量
  2. 复杂推理
  3. 长文本处理
  4. 多模态支持
  5. 代码能力
  6. 中文场景适配
  7. 接入与生态（API（Application Programming Interface，应用程序编程接口）、工具链、社区）
  8. 合规与部署便利性（备案路径、私有化支持、国内可用性）
- **左侧首列**：维度名称 + 每行配一个 16px 线性小图标（对话气泡、齿轮、文档、图片、代码括号、中文「中」字、插头、盾牌）。

### 二、单元格填写规则（防时效性翻车的核心设计）

- 只填**定性标签 + 一句话说明**，禁填任何分数、参数量、价格数字。
- 标签三档：**「强项」／「均衡」／「需实测」**。
- 涉及动态信息的维度（接入与生态、合规与部署），一律填「需实测」，并在表格底部加固定脚注：「本表为公开客观定位梳理，模型能力与政策动态变化，选型时以各官网实时信息与自测为准。」
- 严禁出现「最强」「第一」「遥遥领先」等比较级断言；「强项」仅表示该维度是其公开公认的擅长方向。

### 三、品牌色与视觉规范

| 元素 | 规范 |
|---|---|
| 表头底色 | 紫 #7C3AED，白字，字号加粗 |
| 左列维度名 | 白底，深蓝 #2563EB 字色，加粗 |
| 「强项」单元格 | 蓝 #2563EB 的 10% 透明度底纹 + 深蓝文字标签 |
| 「均衡」单元格 | 白底 + 中性灰标签 |
| 「需实测」单元格 | 浅灰 #F0EEF7 底纹 + 灰色标签 + 右上角小问号图标 |
| 正文字色 | 墨色 #221E33；说明文字 #4A4560 |
| 边框 | #E8E5F1，行间用 1px 虚线分隔 |
| 底部脚注 | 12px 灰字，固定文案见上 |

### 四、验收标准（制图后逐项打勾）

1. 结构为 8 维度行 × 6 模型列，行列完整无缺格。
2. 全表无分数、无参数量、无价格数字；无比较级断言。
3. 「需实测」标签在接入与合规两行全行使用，底部脚注齐全。
4. 颜色仅使用品牌紫 #7C3AED 与品牌蓝 #2563EB 及规范中的中性色，无其他色相。
5. 中文标注无错别字；导出 SVG 源文件 + 1920px 宽 PNG，投屏时末排可读（正文字不小于 18px 等效）。
6. 讲师实测：按下方讲法脚本走一遍，能在 8 分钟内讲完且不依赖表外补充数据。

## 逐图讲法脚本

### 图 1 · LLM 原理架构图（定位图 · 第 2 节）

- **讲法**：一句话回扣——「上周二我们讲过，大模型是海量数据训练出来的概率续写引擎。训练数据、规模、对齐方式不同，能力就不同——这就是今天讲能力边界的原因。」用手指沿「训练 → 对齐 → 推理」主线走一遍即可，不做技术展开。
- **提问点**：「同样是 pretrain 出来的模型，为什么能力差别这么大？」（预期：数据 / 规模 / 后训练策略不同）
- **过渡话术**：「能力差异存在，那各家分别强在哪？看这张横评表。」

### 图 2 · 模型横评表（本课核心 · 第 2 节）

- **讲法**：先讲前提再讲内容。前提两句：「表上全是公开客观定位，没有跑分；这张表会过期，方法是留给你们的。」然后**按行讲不按列讲**——先讲能力六行（快速扫过），重点停在最后两行「接入与生态」「合规与部署」，强调「国内做产品，能力之外的因素常是决定项」。
- **提问点 1**：「海外模型和国产模型，在国内做产品时真正拉开差距的是什么维度？」（预期：合规备案、可用性、中文适配、私有化）
- **提问点 2**：「为什么有两行全是『需实测』？」（预期：这些信息动态变化，必须以官网实时信息和自测为准——顺势强调方法比结论耐用）
- **过渡话术**：「定位是地图，尺子是三角。怎么衡量『值不值』？」

### 图 3 · 能力-成本-延迟三角图（第 2 节）

- **讲法**：先抛单维选择题制造冲突（「A 最强 B 便宜三倍 C 快三倍，选谁？」，教学示例），等学员发现无法回答后展开三角。逐角讲：能力=先画能力线再挑选；成本=调用（以官网实时价格为准）+运维+切换三层；延迟=用户体感分场景。收束顺序：先定能力线，再比成本与延迟，最后合规兜底。
- **提问点**：「你的产品日调用量涨 100 倍，你还敢用最贵的模型吗？」（教学示例；预期：不敢——成本随调用量线性放大）
- **关键动作**：在黑板同步画三角形，三个角写「能力 / 成本 / 延迟」，让学员抄；补一句「三角是流程图，不是打分表」。

### 图 4 · 选型决策树图（第 3 节）

- **讲法**：五问自上而下逐层走，第 1、2 问标「定能力线」，第 3、4 问标「定档位」，第 5 问标红框「一票否决」。讲到第 2 问分支时停 30 秒专讲「小模型三条件」。结尾带读板书口诀，并补「初选 ≠ 终选，终选靠 W2D3 评测集」。
- **提问点**：「五问里为什么偏偏合规这一问能一票否决？」（预期：数据不能出域时能力再强也不可选）
- **关键动作**：让学员边听边在导学案空白决策树上填，图只做导航，不做阅读材料。

### 图 5 · 对比实验任务卡（第 3 节）

- **讲法**：投屏 3 分钟，念一遍三个任务（摘要 / 逻辑推理 / 带约束写作）和四个观察维度（正确性 / 速度 / 消耗 / 失败方式），然后切到真实模型对话窗口开始实验。本图之后不再回投。
- **提问点**：「四个维度里，我认为哪一个最容易被新手忽略？」（预期：失败方式——错得理直气壮最危险）

### 图 6–8 · 300 分钟版新增图（第 1 / 5 / 全 6 节）

- **术语卡组**：第 1 节按 T01→T12 顺序逐张翻，每张只停约 2 分钟，讲师按「定义 → 类比 → 易混 → 面试说法」四拍讲；不展开技术细节。
- **面试追问链图**：第 5 节题型拆解时投屏，指给学生看「面试官会连追 2–3 层」；两两模拟时保留在侧屏，提醒答者「每层都回到第 1 节术语」。
- **6 节时间轴图**：每节开场指一下当前段与本节产出，不单独讲解，只做导航。
